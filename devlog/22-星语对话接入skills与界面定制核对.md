# 阶段二十二：对话助手接入 skills 流水线，学生端界面定制核对

分支：`feat/star-integration`。

起因：负责人看学生端，觉得"按问卷选的颜色、图形，还有代词处理"都没生效。逐项核对后发现三个原因。

## 一、颜色和图形：代码在，本机演示数据是旧的

- 本机数据库里 4 个演示学生是旧版 `seed_star` 建的（问卷改版之前），问卷里没有颜色、形状、背景的答案，
  `profile.ui` 为空，学生端全部退回默认的米色 + 蓝色。重新运行 `python manage.py seed_star`（不加 `--reset-tasks`，
  任务和作答记录不动）后，四人各自生效：小航 浅蓝底 + 绿色 + 胶囊按钮 + ●；朵朵 白底 + 粉色 + ♥；
  阿杰 浅绿底 + 橙色 + 直角按钮 + ■；小雨 深色底 + ★ + 字号按钮。
- 真正的缺口：最喜欢的形状只在问卷页用作选中标记，任务页的选择题选中标记和流程条"已完成"仍是固定的 ✓。
  现在 `StepsPlayer`（选择题选中）和 `FlowBar`（做完的步骤，闯关和分步学习共用）都用 `starMark`。
- 仍未使用的两项：`icon_style`（图标风格）和 `calm`（少用颜色）只存进了画像，界面还没有按它们变化。

## 二、代词：按 skills 文档接入大模型

此前代词逆转只在 P3 提示词里加一段通用说明，`star/skills` 包（含代词标注）没有接进任何生产代码。
现在 `assistant.reply()` 按 `star/skills/README.md` 的流程走：

```
求助护栏 → 分词 → 仿说检测 → 词表映射 → 代词标注 → 意图识别（P5）→ 生成回复（P3）→ 字面化检查 → 展示
```

- 画像标了代词逆转时，代词标注生成"学生说的'你'可能指他自己（{name}）"之类的提示，意图识别和回复生成两次调用都带上；
  没标的学生不生成提示
- 意图识别走平台的 `llm.chat_json`（发出前姓名换成 `{name}`，写 `LLMCallLog`，新用途 **P5**，迁移 `0002`）
- `need_help` 意图直接转给老师；仿说时不做意图识别，请模型换问法；点选项由规则判定，不调大模型
- 回复除了原来的结构校验，再过 skills 的字面化检查（启蒙层 12 字 / 入门层 20 字、双重否定、反问），不合格回填改一次
- 缓存改为连意图一起缓存（键前缀 `star:chat2:`），重复的问题不再调大模型
- 仿说阈值统一为 0.8
- 教师端"对话"页每条回复显示：意图（及来源：大模型 / 关键词规则 / 点了选项）、词表替换、代词提示、候选新词

## 三、大模型一直 404：开发服务器没有重新读 `.env`

本机 `LLMCallLog` 里此前的调用全部是 `HTTP 404`。直接用 `.env` 的配置请求 DeepSeek 正常（`deepseek-chat` 现在指向
`deepseek-flash`）。原因是 8000 端口的 `runserver` 在 `.env` 修改之前启动，Django 自动重载只重启子进程，
环境变量仍是旧的。**改了 `.env` 之后必须完全停掉 `runserver` 再启动。**

用新进程实测（真实 DeepSeek）：

| 学生 | 输入 | 结果 |
| --- | --- | --- |
| 小雨（代词逆转） | 你要提示，我不会了 | 带两条代词提示；意图 dont_know（大模型）；回复"小雨，先看题目第一行。" |
| 阿杰（未标注） | 同上 | 无代词提示；正常回复 |
| 小雨 | 我肚子疼 | 求助护栏，不调大模型 |
| 小航（启蒙层） | 呜呜车不走了 | 词表替换；回复不超过 12 字 |

每轮约 2.5–3 秒（两次调用）；发出的内容里没有学生姓名。
