# 阶段二十三：个人表达记忆

分支：`feat/star-integration`。

起因：讨论分词 skill 时确认，分词本身已经是 jieba 按词切（加编程术语词典和个人词表），只有仿说检测按标点拆分句；
对孩子说的十来个字的短句，换 pkuseg / HanLP 收益很小。更值得做的是“记忆”——孤独症学生常反复用同一句话
表达同一个意思（刻板语言），把“这个学生的这句话 → 意图”记下来，下次直接用。

## 一、做法

```
分词 → 仿说检测 → 词表映射 → 代词标注 → 表达记忆 ─(命中)→ 直接用记住的意图，不调 P5
                                              └(没命中)→ 意图识别（P5）→ 高置信度时记一票
```

- **比对**（`star/skills/memory.py`，新 skill `expr_memory`，纯 Python）：比的是词表替换之后的文本。
  去掉标点、空白和句末语气词（啦、呀、吧、呢、吗、了……）后完全相同算命中；或者双方都至少 4 个字、相似度 ≥ 0.85、
  否定词（不、没、别）个数相同。“要提示”和“不要提示”永远配不上。
- **学习**（`star/services/expressions.py`）：大模型给出 ask_hint / dont_know / skip / chat / need_help 且置信度 ≥ 0.8 时记一票，
  **同一句话两次一致才生效**，一次误判不会被固定下来。大模型给出不同意图时，自动条目改成新意图、重新计票。
  作答（和题目有关）、仿说、无法判断不记；超过 20 字的句子不记。每人最多 50 条，超出先删自动学到、命中少、最久没用的。
- **教师**：学生详情页“对话记录”上方新增“表达记忆”表，可改意思、确认、删除、手动添加；教师确认或添加的立即生效。
  教师改了某句话的意思后，这句话的旧回复缓存不再使用。对话记录的标签新增“按表达记忆理解 / 记下这句话 / 表达记忆生效”。
- 命中时意图来源记为 `memory`，复述写成“学生用以前说过的话表示……”，不带原话，避免绕过姓名脱敏。
- 数据存在 `LearnerProfile.expressions`（迁移 `0003`）；`seed_star` 给阿杰、小雨各写了几条示例（覆盖三种状态），
  不加 `--reset-tasks` 时保留已经学到的。

和原来的回复缓存的区别：缓存要求同一学生、同一步骤、同一句话，存在临时缓存里；表达记忆跨步骤、跨任务长期有效，
存在画像里，教师看得到、改得了。

## 二、测试

```bash
DB_ENGINE=sqlite SECRET_KEY=test python manage.py test judge star   # 264 个，4 个跳过
python -m unittest discover -s star/skills/tests -t .                # 37 个
```

- skills：去标点和语气词后完全相同、相近匹配要求长度和否定词一致、作答不参与比对、命中时不调大模型、
  点选项优先于记忆、词表替换后再比对
- 平台：两次一致后生效、第三次只调 P3；低置信度和作答不记；教师改意思后旧缓存作废；教师保存整张表时保留计票与命中次数

教师端页面在浏览器里实测：表格显示三种状态，确认后保存写进数据库。
