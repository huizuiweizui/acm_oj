#难度/★

  > 一种支持 $O(\log n)$ 插入和删除最值的二叉树形数据结构，是优先队列的底层实现。

## 定义与特性

- **本质**：一棵满足"堆性质"的完全二叉树

- **小根堆性质**：任意节点的值 $\le$ 其所有子节点的值（根为最小值）

- **大根堆性质**：任意节点的值 $\ge$ 其所有子节点的值（根为最大值）

- **存储**：用数组存储，下标关系十分整洁——若节点编号从 1 开始：

  - 节点 $i$ 的父节点是 $\lfloor i / 2 \rfloor$

  - 节点 $i$ 的左孩子是 $2i$，右孩子是 $2i + 1$

- **不变量**：堆性质在每次操作后必须恢复

## 操作与复杂度

| 操作          | 时间复杂度       | 说明                |
| ----------- | ----------- | ----------------- |
| 插入元素 (push) | $O(\log n)$ | 放在末尾后向上调整（上滤）     |
| 查询最值 (top)  | $O(1)$      | 直接返回堆顶            |
| 删除最值 (pop)  | $O(\log n)$ | 末尾元素替换堆顶后向下调整（下滤） |
| 建堆          | $O(n)$      | 自底向上下滤，比逐个插入更快    |

## 实现方式

实战中直接用 STL 的 `priority_queue` 即可，没必要手写：

```cpp
#include <queue>

// 大根堆（默认）
priority_queue<int> max_pq;

// 小根堆
priority_queue<int, vector<int>, greater<int>> min_pq;

max_pq.push(x);     // 插入

max_pq.top();       // 查询最值

max_pq.pop();       // 删除最值

max_pq.size();      // 元素个数

max_pq.empty();     // 是否为空

```

**手写小根堆**：

```cpp

class min_heap {

private:

    vector<int> heap;   // 下标从 1 开始

    void up(int i) {

        while (i > 1 && heap[i] < heap[i / 2]) {

            swap(heap[i], heap[i / 2]);

            i /= 2;

        }

    }

    void down(int i) {

        int n = heap.size() - 1;

        while (2 * i <= n) {

            int j = 2 * i;

            if (j + 1 <= n && heap[j + 1] < heap[j]) j++;

            if (heap[i] <= heap[j]) break;

            swap(heap[i], heap[j]);

            i = j;

        }

    }

public:

    min_heap() {
    
	     heap.push_back(0);   // 占位，让真实数据从下标 1 开始
	     
	}   

    void push(int x) {

        heap.push_back(x);

        up(heap.size() - 1);

    }

    int top() { 
	    
	    return heap[1];
	    
	}

    void pop() {

        heap[1] = heap.back();

        heap.pop_back();

        if (heap.size() > 1) down(1);

    }

    int size() { 
    
	    return heap.size() - 1; 
    
    }

    bool empty() { 
    
	    return heap.size() == 1; 
    
    }

};
```

## 内部原理

**用数组存完全二叉树**：完全二叉树的形态决定了"按层从左到右编号"得到的下标永远是连续的，因此可以紧密地存进数组。父子关系可以通过下标算术直接计算：

```

       1

      / \

     2   3

    / \ / \

   4  5 6  7

```

数组形式：`[1, 2, 3, 4, 5, 6, 7]`（下标从 1 开始）。

**上滤（push）**：新元素总是先放在数组末尾（即树的最后一层最右侧），然后只要它比父节点小（小根堆），就和父节点交换，直到父节点更小或到达根。这条路径长度为 $O(\log n)$。

**下滤（pop）**：删除堆顶后，把数组最后一个元素移到堆顶，然后让它沉下去——每次和较小的孩子比较，若自身更大则交换。

**建堆为何 $O(n)$**：从最后一个非叶子节点（下标 $n/2$）往前，对每个节点做一次下滤。叶子节点（占一半）下滤代价为 0，倒数第二层下滤代价为 1，... 总和为 $\sum_{h=0}^{\log n} \dfrac{n}{2^{h+1}} \cdot h = O(n)$。

## 适用场景

- 任何"动态维护最值"的需求：[[Dijkstra]]、[[Prim]]、[[堆贪心]] 中典型应用

- Top-K 问题：维护大小为 $K$ 的堆即可

- 与排序对比：堆只能拿出最值，但插入和删除都是 $O(\log n)$；排序后数组查询 $O(1)$ 但无法动态插入

- 不适用：需要查询第 $k$ 大、需要按下标访问 ——> 用 [[平衡树]]
