#难度/★ 

  > 一种先进先出（FIFO）的线性数据结构，元素从队尾入、队首出。
  > 
## 定义与特性

- **本质**：抽象数据类型（ADT），可以用数组或链表实现

- **核心性质**：First In, First Out —— 最先入队的元素最先出队

- **不变量**：队首指针 ≤ 队尾指针（用数组实现时）

- **变种**：循环队列、双端队列（deque）、优先队列（堆）

## 操作与复杂度

| 操作                   | 时间复杂度  | 说明   |
| -------------------- | ------ | ---- |
| `push(x)` 入队         | $O(1)$ | 队尾插入 |
| `pop()` 出队           | $O(1)$ | 队首删除 |
| `front()` 查队首        | $O(1)$ | 不删除  |
| `back()` 查队尾         | $O(1)$ | 不删除  |
| `size()` / `empty()` | $O(1)$ |      |

## 实现方式

实战中直接用 STL 的 `queue` 或 `deque`：

```cpp

#include <queue>

queue<int> q;

q.push(x);          // 入队

q.front();          // 查队首

q.back();           // 查队尾

q.pop();            // 出队（不返回值）

q.size();           // 元素个数

q.empty();          // 是否为空

```

> ⚠️ STL 的 `queue` 不支持遍历、不支持 `clear()`。需要这些操作就用 `deque` 或手写。

**手写循环队列**（用数组模拟）：

```cpp
class circular_queue {

private:

    vector<int> buf;

    int head, tail, cap;

public:

    circular_queue(int n) {
		
		buf.resize(n);
		
		head = 0;
		
		tail = 0;
		
		cap = n;
		
    }

    void push(int x) {

        buf[tail] = x;

        tail = (tail + 1) % cap;

    }

    void pop() {

        head = (head + 1) % cap;

    }

    int front() { 
    
	    return buf[head]; 
	
	}

    bool empty() { 
    
	    return head == tail; 
	    
    }

};

```

## 内部原理

**为什么 FIFO**：把"先到先服务"用最朴素的方式建模——比如银行排队、消息队列、操作系统进程调度。

**用数组实现的关键**：维护两个指针 `head`（指向队首）和 `tail`（指向队尾的下一个空位）。`push` 让 `tail` 后移，`pop` 让 `head` 后移。但纯数组方式会在大量 `push/pop` 后让 `head` 不断右移导致空间浪费——所以引入**循环队列**：用取模让指针在固定大小的数组中"绕圈"。

**STL 的 `queue` 底层默认基于 `deque`**：deque 是分块连续的，能在两端 $O(1)$ 操作，因此队列的所有操作都是真正的 $O(1)$。

## 适用场景

- [[BFS]] 中存放待扩展的节点（最经典应用）

- [[拓扑排序]] 中存放入度为 0 的节点

- 单调性问题用其变种 [[单调队列]]

- 任何需要"按到达顺序处理"的场景

- 不适用：需要随机访问中间元素（用 `vector`）；需要按优先级出队（用 [[堆]]）
