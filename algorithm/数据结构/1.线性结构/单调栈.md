#难度/★★

  > 维护单调性的栈，能在 $O(n)$ 时间内求出每个元素左/右第一个比它大/小的元素。

## 前置知识

- [[栈]]

## 定义与特性

- **本质**：一个普通的栈，但额外约束栈中元素**始终保持单调**（递增或递减）

- **核心性质**：以单调递减栈为例（用于"右边第一个更大值"问题），新元素入栈前，所有比它小的栈顶元素都被弹出——它们的"右边第一个更大值"就是这个新元素

- **关键操作**：插入新元素时，先从栈顶弹出所有破坏单调性的元素（这些元素在被弹出的瞬间确定了答案）

- **不变量**：栈中元素的值（或对应索引的值）严格单调

## 操作与复杂度

| 操作     | 时间复杂度     | 说明             |
| ------ | --------- | -------------- |
| 插入新元素  | 均摊 $O(1)$ | 弹出多次也总共 $O(n)$ |
| 处理整个数组 | $O(n)$    | 每个元素最多入栈和出栈各一次 |

## 实现方式

**经典模板：求每个元素右侧第一个大于自己的位置**（栈中存下标，对应值单调递减）：

```cpp

vector<int> ans(n + 1, 0);    // 0 表示不存在

stack<int> sk;

for (int i = 1; i <= n; i++) {

    // 当前元素 arr[i] 比栈顶大时，弹出栈顶并确定其答案

    while (!sk.empty() && arr[sk.top()] < arr[i]) {

        ans[sk.top()] = i;

        sk.pop();

    }

    sk.push(i);

}

// 此时仍在栈中的元素，右边没有更大值，ans 默认为 0

```

> 💡 **存下标而非值**：因为我们需要给"位置 j 的元素"赋答案，而值无法定位。

## 内部原理

**为什么单调栈能 $O(n)$**：每个元素**最多入栈一次、出栈一次**。整个过程中所有 `pop` 加起来不超过 $n$ 次，所以总时间 $O(n)$。

**核心观察（以求"右侧第一个更大"为例）**：考虑数组中两个位置 $i < j$。如果 $a[i] \le a[j]$，那么 $a[i]$ 永远不会成为后续位置的"右侧第一个更大"——因为 $a[j]$ 比 $a[i]$ 大且更靠右。所以 $a[i]$ 一发现 $a[j]$ 就**作废**了。

把"作废的元素"理解为出栈的瞬间——$a[i]$ 发现一个更大的 $a[j]$ 时，$a[j]$ 就是它的答案，于是 $a[i]$ 被弹出。

## 适用场景

- 求每个元素左/右第一个**更大/更小**的元素及其位置（最经典应用）

- 柱状图中最大矩形面积（[洛谷P4147 玉蟾宫]）

- 经典接雨水问题

- 表达式求值（结合栈的常规用法）

- [[单调队列]] 是它的"双端兄弟"，用于滑动窗口最值

- 不适用：需要快速查询任意区间最值（应用 [[ST表]] 或 [[线段树]]）
