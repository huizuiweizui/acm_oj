#难度/★

  > 由节点组成的线性结构，每个节点通过指针/索引指向下一个节点，支持 $O(1)$ 的中间插入与删除。

## 定义与特性

- **本质**：节点（`struct`）+ 指针的链式结构，每个节点存储数据和指向后继的引用

- **核心性质**：内存上**不连续**，依靠指针链接；牺牲随机访问换取灵活的插入删除

- **常见变种**：

  - **单链表**：每个节点只指向后继

  - **双链表**：每个节点同时指向前驱和后继，支持 $O(1)$ 双向遍历

  - **循环链表**：尾节点的 next 指向头节点

- **不变量**：从头节点出发沿 next 指针能遍历所有有效节点

## 操作与复杂度

| 操作         | 时间复杂度         | 说明                        |
| ---------- | ------------- | ------------------------- |
| 头部插入       | $O(1)$        | 修改两个指针即可                  |
| 已知节点后插入    | $O(1)$        | 仅修改局部指针                   |
| 已知节点删除     | $O(1)$（双链表）   | 单链表需先找前驱，$O(n)$           |
| 按值查找       | $O(n)$        | 必须从头遍历                    |
| 按下标访问      | $O(n)$        | 不支持随机访问                   |

## 实现方式

**单链表（基于 struct + 指针）**：

```cpp

struct list_node {

    int val;

    list_node* next;

};

class linked_list {

private:

    list_node* head;    // 哨兵头节点，简化边界处理

public:

    linked_list() {

        head = new list_node();

        head->val = 0;

        head->next = nullptr;

    }

    // 在头部插入
    void push_front(int x) {

        list_node* node = new list_node();

        node->val = x;

        node->next = head->next;

        head->next = node;

    }

    // 删除值为 x 的第一个节点
    void erase(int x) {

        list_node* p = head;

        while (p->next != nullptr && p->next->val != x) {

            p = p->next;

        }

        if (p->next != nullptr) {

            list_node* tmp = p->next;

            p->next = tmp->next;

            delete tmp;

        }

    }

    // 遍历输出
    void print() {

        list_node* p = head->next;

        while (p != nullptr) {

            cout << p->val << ' ';

            p = p->next;

        }

        cout << '\n';

    }

};

```

> 💡 **哨兵头节点（dummy head）的妙用**：让 `head` 始终是个不存数据的占位节点，这样所有插入/删除操作都不需要单独讨论"链表为空"或"操作头节点"的情形，代码大幅简化。


**双链表（vector 池式写法）**：

竞赛中常用 `vector` 作为节点池，用下标代替指针。这样既避免了 `new/delete` 的开销，也方便定位：

```cpp

struct dlist_node {

    int val;

    int prev, next;     // prev/next 存的是 vector 下标

};

class doubly_linked_list {

private:

    vector<dlist_node> node;

    int tot;            // 节点池计数器，0 号位作哨兵头，1 号位作哨兵尾

public:

    doubly_linked_list(int cap) {

        node.resize(cap + 2);

        tot = 1;

        // 0 是头哨兵，1 是尾哨兵
        node[0].next = 1;

        node[0].prev = -1;

        node[1].prev = 0;

        node[1].next = -1;

    }

    // 在节点 p 之后插入值为 x 的新节点，返回新节点下标
    int insert_after(int p, int x) {

        tot += 1;

        int q = tot;

        node[q].val  = x;

        node[q].prev = p;

        node[q].next = node[p].next;

        node[node[p].next].prev = q;

        node[p].next = q;

        return q;

    }

    // 删除节点 p
    void erase(int p) {

        node[node[p].prev].next = node[p].next;

        node[node[p].next].prev = node[p].prev;

    }

};
```

> ⚠️ **STL 替代方案**：`std::list` 是双链表，`std::forward_list` 是单链表。日常用 STL 即可，仅在卡常或需要特殊操作（如 $O(1)$ 拼接）时手写。

## 内部原理

**为什么链表能 $O(1)$ 插入删除**：因为元素之间没有"位置约束"——不像数组那样必须连续存储，链表节点散落在内存各处，通过指针串起来。修改一个节点的位置只需要改几个指针，不需要移动其他节点。

**链表的代价**：

- 没有随机访问：要找第 $k$ 个节点必须从头遍历

- 缓存不友好：节点散落在内存中，CPU 缓存命中率低，常数比数组大很多

- 额外空间：每个节点要存指针，单链表多 8 字节，双链表多 16 字节（64 位机）

## 适用场景

- 频繁在中间插入/删除的场景（如约瑟夫问题）

- 实现 LRU 缓存（双链表 + 哈希表）

- 一些图论问题中的"链式前向星"——本质就是链表数组

- 实现 [[Trie]] 时孩子节点过多的稀疏情形

- 不适用：需要随机访问（用数组）；元素少且操作集中在两端（用 [[栈]] / [[队列]]）
