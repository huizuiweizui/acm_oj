#难度/★★

  > 维护单调性的双端队列，能在 $O(n)$ 时间内求出所有大小为 $k$ 的滑动窗口最值。

## 前置知识

- [[队列]]

- [[滑动窗口]]

## 定义与特性

- **本质**：一个双端队列（`deque`），队列中**元素的值始终保持单调**

- **核心性质**：以求最大值为例，队首始终是当前窗口的最大值，队列从前到后单调递减

- **关键操作**：插入新元素时，从队尾不断弹出"比新元素小的"过期者；插入后，再从队首弹出"已离开窗口范围"的元素

- **不变量**：队列中的索引在窗口范围内，且对应的值单调

## 操作与复杂度

| 操作     | 时间复杂度     | 说明              |
| ------ | --------- | --------------- |
| 插入新元素  | 均摊 $O(1)$ | 弹出多次也只总共 $O(n)$ |
| 查询当前最值 | $O(1)$    | 即队首             |
| 窗口滑动一格 | 均摊 $O(1)$ | 弹出过期 + 加入新元素    |

## 实现方式

经典的"滑动窗口求最值"模板（求最大值，存的是**下标**便于判断过期）：

```cpp

deque<int> q;     // 存的是下标，对应值单调递减

vector<int> ans;

for (int i = 1; i <= n; i++) {

    // 1. 弹出"比当前小"的队尾，维持单调性

    while (!q.empty() && arr[q.back()] < arr[i]) {

        q.pop_back();

    }

    // 2. 加入新下标

    q.push_back(i);

    // 3. 弹出"已过期"的队首

    while (q.front() <= i - k) {

        q.pop_front();

    }

    // 4. 当窗口形成后记录答案

    if (i >= k) {

        ans.push_back(arr[q.front()]);

    }

}

```

> 💡 **求最小值**只需把 `<` 改成 `>`，其余不变。

## 内部原理

**为什么单调**：考虑窗口内两个元素 $a[i]$ 和 $a[j]$（$i < j$）。如果 $a[i] \le a[j]$，那么 $a[i]$ 永远不会成为最大值——因为 $a[j]$ 比它大且比它"活得久"（更晚过期）。所以可以**直接丢掉 $a[i]$**。

这就是入队时弹尾的依据：新元素一来，所有比它小的旧元素立即"作废"。

**为什么均摊 $O(1)$**：每个元素最多入队一次、出队一次。整个过程中所有 `pop_back` 和 `pop_front` 加起来不超过 $2n$ 次，所以总时间 $O(n)$，均摊到每个元素就是 $O(1)$。

## 适用场景

- 滑动窗口最值（最经典应用）

- [[单调队列优化dp]]：当 dp 转移形如 $f[i] = \min/\max\{f[j] + g(i,j)\}$ 且 $j$ 在某区间内变化时，可用单调队列加速

- [[0-1 BFS]]：双端队列承担类似优先队列的角色

- 不适用：窗口外的元素也要参与计算的情形（应用 [[ST表]] 或 [[线段树]]）
