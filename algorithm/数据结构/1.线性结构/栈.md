#难度/★ 

> 一种后进先出（LIFO）的线性数据结构，元素只能从顶端进出。
> 
## 定义与特性

- **本质**：抽象数据类型（ADT），可以用数组或链表实现

- **核心性质**：Last In, First Out —— 最后入栈的元素最先出栈

- **不变量**：栈顶指针指向最后入栈元素的位置

- **常见变种**：单调栈、双栈模拟队列、调用栈（系统层面）

## 操作与复杂度

| 操作                   | 时间复杂度  | 说明   |
| -------------------- | ------ | ---- |
| `push(x)` 入栈         | $O(1)$ | 顶端插入 |
| `pop()` 出栈           | $O(1)$ | 顶端删除 |
| `top()` 查栈顶          | $O(1)$ | 不删除  |
| `size()` / `empty()` | $O(1)$ |      |

## 实现方式

实战中直接用 STL 的 `stack`：

```cpp

#include <stack>

stack<int> sk;

sk.push(x);         // 入栈

sk.top();           // 查栈顶

sk.pop();           // 出栈（不返回值）

sk.size();          // 元素个数

sk.empty();         // 是否为空

```

> ⚠️ STL 的 `stack` 不支持遍历、不支持随机访问。需要这些操作就用 `vector`（也可以当栈用，`push_back` / `back` / `pop_back`）。

**用数组手写栈**：

```cpp
class array_stack {

private:

    vector<int> buf;

    int top_idx;

public:

    array_stack(int cap) {
    
	    buf.resize(cap);
	    
		top_idx = 0;
	    
    }

    void push(int x) { 
    
	    buf[top_idx] = x;
	    
	    top_idx += 1;
    
    }

    void pop() { 
    
	    top_idx -= 1; 
    
    }

    int top() { 
    
	    return buf[top_idx]; 
    
    }

    bool empty() {
    
	    return top_idx == -1; 
     
    }

    int  size() { 
    
	    return top_idx + 1; 
    
    }

};
```

## 内部原理

**LIFO 模型**：把数据像盘子一样摞起来，只能从最上面拿。这种"最近添加的最先取出"的语义在很多场景中天然出现：函数调用（调用栈）、括号匹配、表达式求值、DFS 的隐式栈等。

**为什么数组实现就够了**：栈的所有操作都集中在一端，只需要一个 `top` 指针记录栈顶位置即可，没有"中间删除"的麻烦。

**STL `stack` 底层默认基于 `deque`**：但实际上用 `vector` 作为底层容器更高效（连续内存、缓存友好）：

```cpp

stack<int, vector<int>> sk;     // 指定 vector 作底层

```

## 适用场景

- 括号匹配、表达式求值（中缀转后缀）

- [[DFS]] 的非递归实现

- 单调性问题用其变种 [[单调栈]]

- 撤销操作（undo）—— 把每次操作压栈，撤销时弹出

- 调用栈模拟（如手动展开递归避免栈溢出）

- 不适用：需要随机访问中间元素（用 `vector`）；需要按到达顺序处理（用 [[队列]]）
