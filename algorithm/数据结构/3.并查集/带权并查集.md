#难度/★★★

> 在并查集的基础上，额外维护每个节点到根的"距离"或"关系"信息，用以处理带约束的连通性问题。

## 前置知识

- [[并查集]]

- [[模运算]]

## 定义与特性

- **本质**：每个节点除了存父指针 `parent[i]` 外，还多存一个权值 `dist[i]`，表示**节点 $i$ 到 `parent[i]` 的"距离"**（或某种关系信息）

- **核心性质**：通过累加沿途权值，可以推导出"任意两个同集合节点之间的关系"

- **关键操作**：路径压缩时，必须**同步更新 `dist[]`**，让 `dist[i]` 始终表示"i 到根"的总距离

- **不变量**：对集合中任意两个节点 $u, v$，关系 $\text{rel}(u, v)$ 可以由 $\text{dist}[u]$ 和 $\text{dist}[v]$ 算出

## 操作与复杂度

| 操作                      | 时间复杂度           | 说明                   |
| ----------------------- | --------------- | -------------------- |
| `find(x)` 查根并更新 dist    | $O(\alpha(n))$  | 路径压缩同时累加权值           |
| `unite(x, y, w)` 合并并设关系 | $O(\alpha(n))$  | 把两棵树拼起来，调整权值         |
| 查询两节点关系                 | $O(\alpha(n))$  | 调用两次 find 后比较 dist   |

## 实现方式

**经典模板：维护"$x$ 比 $y$ 多多少"的差值（数轴关系）**：

```cpp

class weighted_union_find {

private:

    vector<int> parent;

    vector<long long> dist;     // dist[i] = i 到 parent[i] 的距离

public:

    weighted_union_find(int n) {

        parent.resize(n + 1);

        dist.resize(n + 1, 0);

        for (int i = 1; i <= n; i++) {

            parent[i] = i;

        }

    }

    // 查根，同时把 dist[x] 更新为 x 到根的距离
    int find(int x) {

        if (parent[x] == x) {

            return x;

        }

        int root = find(parent[x]);

        dist[x] += dist[parent[x]];     // 累加：x 到旧父亲 + 旧父亲到根

        parent[x] = root;

        return root;

    }

    // 表示关系：x = y + w（即 x 比 y 大 w）
    // 若 x 和 y 已同集合，返回是否与已知关系一致
    bool unite(int x, int y, long long w) {

        int rx = find(x);

        int ry = find(y);

        if (rx == ry) {

            // 已同集合，验证是否一致

            return dist[x] - dist[y] == w;

        }

        // 把 rx 挂到 ry 下，调整 dist[rx] 使关系成立
        dist[rx] = w + dist[y] - dist[x];

        parent[rx] = ry;

        return true;

    }

    // 查询：x 与 y 的关系（x 比 y 大多少）；若不同集合返回 false
    bool relate(int x, int y, long long& diff) {

        if (find(x) != find(y)) {

            return false;

        }

        diff = dist[x] - dist[y];

        return true;

    }

};
```

> ⚠️ **路径压缩必须递归写**：迭代式的"路径减半"无法正确累加 `dist`，因为它会跳过中间节点。这里只能用经典递归式压缩。

> 💡 **核心套路**：弄清楚 `dist` 的定义（"i 到 parent[i]"还是"i 到根"）、合并时如何调整、查询时如何作差。这三步想清楚就能写对。

## 内部原理

**`dist[i]` 在路径压缩中的演化**：

刚建立时 `dist[i]` 表示节点 $i$ 到**直接父亲**的距离。但路径压缩后，所有节点的 `parent` 都直接变成了根，所以压缩**之后** `dist[i]` 应该表示 $i$ 到**根**的距离。

递归式 find 的关键代码：

```cpp

int root = find(parent[x]);          // 先递归，让 dist[parent[x]] 变为"父亲到根"

dist[x] += dist[parent[x]];          // x 到根 = x 到父亲 + 父亲到根

parent[x] = root;

```

注意更新顺序：**先用 `dist[parent[x]]` 累加**，**再把 `parent[x]` 改成根**。颠倒顺序就错了。

**合并时的代数推导**：

设 `find(x) = rx`，`find(y) = ry`，希望最终关系为 $x = y + w$（即 $\text{dist}[x] - \text{dist}[y] = w$，这里 dist 都是"到根"的距离）。

把 $r_x$ 挂到 $r_y$ 下，则 $x$ 到新根的距离变为 $\text{dist}[x] + \text{dist}[r_x]$，要求：

$$\text{dist}[x] + \text{dist}[r_x] - \text{dist}[y] = w \implies \text{dist}[r_x] = w + \text{dist}[y] - \text{dist}[x]$$

这就是 `dist[rx] = w + dist[y] - dist[x]` 的来历。

## 适用场景

- 维护"到根的差值"（食物链类问题：A 吃 B、B 吃 C，问 A 和 C 关系）

- 维护"模 $k$ 等价类"（dist 用模运算）

- 维护"集合的方向/属性"（如逻辑相同/相反）

- 区间维护——把"区间 $[l, r]$ 满足某性质"建模为 $l-1$ 与 $r$ 的关系

- 不适用：关系不满足"传递性"或"可加性"的情形
