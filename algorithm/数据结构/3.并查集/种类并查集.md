#难度/★★★

> 通过开多倍空间，用普通并查集维护"敌对/同类"等多重对立关系。

## 前置知识

- [[并查集]]

## 定义与特性

- **本质**：把每个元素拆成 $k$ 个"分身"（$k$ 是关系种类数），用普通并查集维护这些分身之间的连通性

- **核心思想**：**"敌人的敌人是朋友"** —— 这种二阶传递关系无法用普通并查集表达，但拆分后变成了直接的连通关系

- **常用拆分**：

  - **2 倍空间**（同/异）：节点 $i$ 拆成 $i$（自己）和 $i + n$（敌方阵营）

  - **3 倍空间**（食物链）：节点 $i$ 拆成 $i$、$i + n$、$i + 2n$，分别表示"自己""猎物""天敌"

- **不变量**：所有分身的连通性必须保持一致

## 操作与复杂度

| 操作       | 时间复杂度           | 说明                   |
| -------- | --------------- | -------------------- |
| 同种合并     | $O(\alpha(n))$  | 直接合并对应分身             |
| 对立合并     | $O(\alpha(n))$  | 交叉合并各阵营分身            |
| 查询关系     | $O(\alpha(n))$  | 比较根节点判断属于哪个阵营        |

## 实现方式

**经典 2 倍空间模板：处理"A 与 B 对立"问题**：

```cpp

// 节点 i 占两个位置：
//   i      表示"i 自己"
//   i + n  表示"i 的对立面"

class enemy_union_find {

private:

    vector<int> parent;

    int n;

public:

    enemy_union_find(int total) {

        n = total;

        parent.resize(2 * n + 1);

        for (int i = 1; i <= 2 * n; i++) {

            parent[i] = i;

        }

    }

    int find(int x) {

        while (parent[x] != x) {

            parent[x] = parent[parent[x]];

            x = parent[x];

        }

        return x;

    }

    void unite(int x, int y) {

        int rx = find(x);

        int ry = find(y);

        if (rx != ry) {

            parent[rx] = ry;

        }

    }

    // x 和 y 是朋友
    void set_friend(int x, int y) {

        unite(x, y);            // 自己与自己

        unite(x + n, y + n);        // 对立面与对立面

    }
  
    // x 和 y 是敌人
    void set_enemy(int x, int y) {

        unite(x, y + n);        // x 自己 = y 的对立面

        unite(x + n, y);            // x 的对立面 = y 自己

    }

    // 判断 x 和 y 是否在同一阵营
    bool same_camp(int x, int y) {

        return find(x) == find(y);

    }

    // 判断 x 和 y 是否对立
    bool is_enemy(int x, int y) {

        return find(x) == find(y + n);

    }

};
```

**3 倍空间模板：食物链（A 吃 B，B 吃 C，C 吃 A）**：

```cpp

// 节点 i 占三个位置：
//   i         表示"i 自己"
//   i + n     表示"i 的猎物"
//   i + 2n    表示"i 的天敌"

// "x 与 y 同类"
unite(x, y);

unite(x + n, y + n);

unite(x + 2 * n, y + 2 * n);

  

// "x 吃 y"

unite(x + n, y);            // x 的猎物 = y 自己

unite(x, y + 2 * n);      // x 自己 = y 的天敌

unite(x + 2 * n, y + n);        // x 的天敌 = y 的猎物（C 吃 A）

```

> 💡 **为什么需要双向甚至三向合并**：因为"A 与 B 是敌人"不仅意味着"A 在 B 的对立阵营"，还意味着"B 在 A 的对立阵营"。两个等式都要在并查集里体现出来。

> 💡 **判定矛盾**：如果操作前 `find(x) == find(y + n)`（即 x 与 y 已知敌对），却又要 `set_friend(x, y)`，就检测到一条假命题。许多题目以此来计数虚假命题数量。

## 内部原理

**为什么"敌人的敌人是朋友"会自动成立**：考虑三个人 $A, B, C$。

操作 1：$A$ 和 $B$ 是敌人 → 合并 `(A, B+n)` 和 `(A+n, B)`，于是 `A` 和 `B+n` 在同一集合。

操作 2：$B$ 和 $C$ 是敌人 → 合并 `(B, C+n)` 和 `(B+n, C)`，于是 `B+n` 和 `C` 在同一集合。

由传递性：`A` 和 `C` 在同一集合 → 自动得出 "$A$ 与 $C$ 是朋友"。

**与 [[带权并查集]] 的对比**：

| 维度     | 种类并查集                | 带权并查集                  |
| ------ | -------------------- | ---------------------- |
| 思路     | 拆分元素，纯连通性            | 维护到根的权值/距离             |
| 关系数    | $k$ 倍空间，关系少（2~3 种）适用 | 关系数多时也能做（如 mod $k$）    |
| 实现     | 基于普通并查集即可            | 需要在 find 中累加 dist      |
| 直观性    | 较直观                  | 需要代数推导                 |

## 适用场景

- 二分图判定（敌/友两种关系）

- 食物链类问题（同/猎物/天敌三种关系）

- 真假命题判定

- 通常 $k \le 3$ 时种类并查集更直观；$k$ 较大或维护数值差时换 [[带权并查集]]

- 不适用：关系数 $k$ 很大（空间爆炸），或关系本身是连续值（用带权）
