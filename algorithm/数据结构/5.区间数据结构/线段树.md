#难度/★★★

  > 把数组划分为二叉树形的区间，以 $O(\log n)$ 支持区间修改与区间查询的万能数据结构。

## 前置知识

- [[二分查找]]

## 定义与特性

- **本质**：用一棵二叉树表示区间——根节点表示 $[1, n]$，每个非叶节点把当前区间二分给两个子节点

- **核心性质**：每个节点维护它所代表区间的某种"聚合信息"（区间和、最值、最大子段和……）

- **存储**：通常用数组下标 $1, 2, \ldots, 4n$ 来存（左孩子是 $2i$，右孩子是 $2i + 1$）

- **不变量**：父节点的信息可以由两个子节点的信息合并得到（"合并函数"由具体应用决定）

## 操作与复杂度

| 操作         | 时间复杂度       | 说明                      |
| ---------- | ----------- | ----------------------- |
| 建树 `build` | $O(n)$      | 自顶向下递归构造                |
| 单点修改       | $O(\log n)$ | 找到叶子修改后向上更新             |
| 区间查询       | $O(\log n)$ | 对每个被询问区间完全覆盖的子树直接返回     |
| 区间修改       | $O(\log n)$ | 配合**懒标记**，详见 [[懒标记线段树]] |

> ⚠️ 数组要开 $4n$ 大小，因为最深一层的节点编号最坏可达 $4n$。

## 实现方式

下面是一个**支持单点修改、区间求和**的最简版线段树（区间修改请见 [[懒标记线段树]]）：

```cpp
class segment_tree {

private:

    int n;

    vector<long long> tree;

    void build(const vector<long long>& arr, int p, int l, int r) {

        if (l == r) { 
        
	        tree[p] = arr[l]; 
	        
	        return; 
	        
	    }

        int mid = l + (r - l) / 2;

        build(arr, p * 2, l, mid);

        build(arr, p * 2 + 1, mid + 1, r);

        tree[p] = tree[p * 2] + tree[p * 2 + 1];

    }

    void update(int p, int l, int r, int pos, long long val) {

        if (l == r) { 
	        
	        tree[p] += val; 
	        
	        return; 
	        
		}

        int mid = l + (r - l) / 2;

        if (pos <= mid) {
        
	        update(p * 2, l, mid, pos, val); 
	        
	    } else {
		    
		    update(p * 2 + 1, mid + 1, r, pos, val); 
		    
		}

        tree[p] = tree[p * 2] + tree[p * 2 + 1];

    }

    long long query(int p, int l, int r, int ql, int qr) {

        if (ql <= l && r <= qr)  {
        
	        return tree[p];
		}
		
        int mid = l + (r - l) / 2;

        long long sum = 0;

        if (ql <= mid)  {
        
	        sum += query(p * 2, l, mid, ql, qr);
	    }

        if (mid + 1 <=  qr)  {
        
	        sum += query(p * 2 + 1, mid + 1, r, ql, qr);
	        
	    } 

        return sum;

    }

public:

    segment_tree(const vector<long long>& arr) {

        n = arr.size() - 1;

        tree.resize(4 * n);

        build(arr, 1, 1, n);

    }

    void update(int pos, long long val) { 
    
	    update(1, 1, n, pos, val);
	 }

    long long query(int ql, int qr) {
    
	    return query(1, 1, n, ql, qr); 
	
	}
};
```

> 💡 **写法约定**：

> - `p` 是当前节点编号

> - `[l, r]` 是当前节点表示的区间

> - `[ql, qr]` 是询问/修改区间

## 内部原理

**为什么是 $O(\log n)$**：树高 $\log n$，每次查询路径只覆盖最多 $O(\log n)$ 个完全包含的子区间，且每层最多访问 $O(1)$ 个非完全包含的节点（左右各 1 个），总计 $O(\log n)$。

**关键技巧——区间分解**：当询问区间 $[ql, qr]$ 完全包含当前节点区间 $[l, r]$ 时（即 $ql \le l \le r \le qr$），直接返回当前节点的预存信息，不再下递。这是线段树高效的根本。

**为什么开 $4n$**：

- 当 $n$ 是 2 的幂时，叶子在第 $\log_2 n$ 层，节点总数为 $2n - 1$，开 $2n$ 够用

- 当 $n$ 不是 2 的幂时，最坏情况叶子分布在两层，最大编号可能达到 $4n$

- 保险起见统一开 $4n$

**举例 n = 5 的线段树形态**：

```

              [1,5]

             /     \

         [1,3]     [4,5]

         /  \      /   \

      [1,2] [3,3] [4,4] [5,5]

      /  \

   [1,1] [2,2]

```

## 适用场景

- 区间求和、区间最值、区间染色、区间历史最值、区间最大子段和...... 几乎所有"可由子区间合并得到"的信息

- 配合 [[离散化]] 或 [[动态开点]] 处理大值域问题

- [[树链剖分]] 中的核心数据结构

- [[扫描线]] 算法

- 不适用：需要重平衡的有序集合操作（用 [[平衡树]]）；信息无法 $O(1)$ 合并的情形
