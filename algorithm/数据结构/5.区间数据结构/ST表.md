#难度/★★★

> 基于倍增思想预处理出 $f[i][j]$（从 $i$ 起长度为 $2^j$ 的区间最值），实现 $O(1)$ 静态区间最值查询。

## 前置知识

- [[位运算]]

- [[倍增]]

## 定义与特性

- **本质**：一张二维表 $f[i][j]$，存储**从位置 $i$ 开始、长度为 $2^j$ 的区间**的某种"可重复贡献"信息（如最值、gcd）

- **核心性质**：任意区间 $[l, r]$ 都能被两段长度为 $2^k$ 的区间**重叠覆盖**——只要 $k = \lfloor \log_2(r - l + 1) \rfloor$，则 $[l, l + 2^k - 1]$ 与 $[r - 2^k + 1, r]$ 合起来恰好就是 $[l, r]$（中间可能重叠，但不影响最值）

- **关键约束**：维护的信息必须**可重复贡献**——即 $f(x, x) = x$，重叠不影响结果。最值（max/min）和 gcd 满足；区间和不满足（重叠部分会被加两次）

- **不变量**：$f[i][j]$ 一旦预处理完成不再修改，仅支持查询

## 操作与复杂度

| 操作          | 时间复杂度           | 说明                        |
| ----------- | --------------- | ------------------------- |
| 预处理建表       | $O(n \log n)$   | 倍增递推填表                    |
| 查询区间最值      | $O(1)$          | 直接两段重叠取最值                 |
| 修改          | 不支持             | 完全静态，需修改请用 [[线段树]]        |

## 实现方式

**经典模板：求区间最大值**：

```cpp
class sparse_table {

private:

    int n;

    vector<vector<int>> f;          // f[i][j] = max{ a[i .. i+2^j-1] }

    vector<int> log2_table;         // 预处理 log2 加速查询

public:

    sparse_table(const vector<int>& arr) {

        n = arr.size() - 1;         // 下标从 1 开始

        int K = 0;

        while ((1 << K) <= n) {

            K += 1;

        }

        f.assign(n + 1, vector<int>(K, 0));

        log2_table.resize(n + 1, 0);

  

        // 预处理 log2[i] = floor(log2(i))

        for (int i = 2; i <= n; i++) {

            log2_table[i] = log2_table[i / 2] + 1;

        }

        // 长度为 1 的区间就是元素本身

        for (int i = 1; i <= n; i++) {

            f[i][0] = arr[i];

        }

        // 倍增递推
        for (int j = 1; (1 << j) <= n; j++) {

            for (int i = 1; i + (1 << j) - 1 <= n; i++) {

                f[i][j] = max(f[i][j - 1], f[i + (1 << (j - 1))][j - 1]);

            }

        }

    }

    int query(int l, int r) {

        int k = log2_table[r - l + 1];

        return max(f[l][k], f[r - (1 << k) + 1][k]);

    }

};
```

> 💡 **预处理 log2 表**：直接用 `log2()` 函数会有浮点误差且较慢，预处理整数 log2 既准确又快。

> 💡 **支持的运算**：max、min、gcd、按位 and/or。**不能**直接套用于区间和（要用 [[前缀和]]）、区间异或（用 [[前缀和]] 思想）等"非可重复贡献"的运算。

## 内部原理

**两段重叠覆盖的关键**：

设要查询 $[l, r]$，长度为 $\text{len} = r - l + 1$，取 $k = \lfloor \log_2 \text{len} \rfloor$。则 $2^k \le \text{len} < 2^{k+1}$，即 $2^k$ 是不超过 $\text{len}$ 的最大 2 的幂。

考虑两个长度为 $2^k$ 的区间：

- 从 $l$ 起：$[l, l + 2^k - 1]$

- 到 $r$ 止：$[r - 2^k + 1, r]$

由于 $2 \cdot 2^k > \text{len}$，这两段必然有**重叠**部分，所以它们的并集 $\supseteq [l, r]$。又因为两段都不超过 $[l, r]$，所以并集恰好等于 $[l, r]$。

```
区间 [l ........... r]  长度 len

段 1 [l...2^k 长度 ...]

段 2          [...2^k 长度...r]

              ↑ 重叠区
```

由于 max（min/gcd）有"可重复贡献"性质——重叠部分被算两次也无所谓——所以两段直接取最值即可。

**倍增递推的正确性**：

$$f[i][j] = \max\left(f[i][j-1],\; f[i + 2^{j-1}][j-1]\right)$$

即把长度为 $2^j$ 的区间一分为二，由两个长度为 $2^{j-1}$ 的区间合并而来。这正是 [[倍增]] 的标准套路。

**为什么不能用于区间和**：因为 sum 的"两段重叠相加"会重复计算重叠部分。例如查询 $[1, 3]$，取段 $[1, 2]$ 和 $[2, 3]$，则 $a_2$ 被加两次。max/min 重复元素不影响结果，sum 会出错。

## 适用场景

- **静态区间最值**：数组不修改，多次查询区间 max/min（最经典应用）

- 区间 gcd（gcd 同样满足可重复贡献）

- [[LCA]] 的欧拉序 + RMQ 解法

- 一些字符串问题中的 RMQ 需求

- 不适用：数组会被修改（用 [[线段树]] 或 [[树状数组]]）；维护区间和（用 [[前缀和]]）

## 与 [[线段树]] 的对比

| 维度        | ST 表              | 线段树                   |
| --------- | ----------------- | --------------------- |
| 预处理       | $O(n \log n)$     | $O(n)$                |
| 查询        | $O(1)$            | $O(\log n)$           |
| 是否支持修改    | ❌                 | ✅                     |
| 代码量       | 中等                | 较长                    |
| 适用信息      | 仅"可重复贡献"运算        | 任何可结合运算               |
| 空间        | $O(n \log n)$     | $O(4n)$               |

**经验**：纯静态 + 只查最值/gcd → ST 表；其他场景用线段树。
