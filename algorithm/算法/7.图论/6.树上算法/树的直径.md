#难度/★★★

> 树中最长的简单路径——两次 BFS 即可在无权树上 $O(n)$ 求得，含负权边时需树形 dp。

## 前置知识

- [[BFS]]

- [[DFS]]

## 核心思想

**树的直径**：树中**最长简单路径**的长度（通常按边权和定义；边权全为 1 时即最长路径的边数）。

求树的直径有两种主流方法：

**方法一：两次 BFS / DFS**

> 1. 从任意点 $s$ 出发 BFS / DFS，找到离 $s$ 最远的点 $u$

> 2. 从 $u$ 出发 BFS / DFS，找到离 $u$ 最远的点 $v$

> 3. $u \to v$ 即为一条直径

代码极短，但**只对边权非负的树**正确（含负权时这种"贪心找远点"的策略会失败）。

**方法二：树形 dp**

> 一次 DFS 中，对每个节点 $u$ 计算其子树中"向下延伸的最长链"$d_1[u]$ 和"次长链"$d_2[u]$（要求来自不同子节点）。则 $u$ 作为"折点"时形成的最长路径是 $d_1[u] + d_2[u]$，对所有 $u$ 取最大即直径。

更通用，**适用任何边权**（含负权）。

**两种方法的核心直觉**——直径必然有两个端点 $A, B$，路径在某个最高点 $L$（即 $\mathrm{lca}(A, B)$）"折"过来。两次 BFS 法找出端点；树形 dp 法枚举折点。

## 适用场景

- 求树的直径

- 求**树的中心**（直径的中点附近，使到树上所有点的最大距离最小化）

- **树的重心**（删除该点后最大子树最小化）的预处理

- 某些"最长链"类树形 dp 的入门题

- 经典扩展：在所有边的"中点"中找一个使最大距离最小（树的中心问题）

- 不适用：图（含环），直径概念不直接适用

## 步骤拆解

**两次 BFS 法**：

1. 从节点 1 出发 BFS / DFS 求出距离数组 $\mathtt{dist}_1$

2. 找出 $\mathtt{dist}_1$ 最大的节点 $u$

3. 从 $u$ 出发再 BFS / DFS 求出 $\mathtt{dist}_2$

4. $\mathtt{dist}_2$ 的最大值即直径长度

**树形 dp 法**：

1. 任选根（如 1）

2. DFS：对每个节点 $u$，递归计算子节点的"最长向下链"

3. 维护 $u$ 子树的最长链和次长链（来自不同子节点）

4. $u$ 处贡献的"过 $u$ 的最长路径" = 最长链 + 次长链

5. 全局答案 = 所有 $u$ 处贡献的最大值

## 代码模板

**模板一：两次 BFS（边权非负）**

```cpp
class tree_diameter_bfs {

private:

    int n;

    vector<vector<pair<int, long long>>> g;     // {邻居, 边权}

    pair<int, long long> bfs_farthest(int s) {

        vector<long long> dist(n + 1, -1);

        queue<int> q;

        dist[s] = 0;

        q.push(s);

        int far_node = s;

        long long far_dist = 0;

        while (!q.empty()) {

            int u = q.front();

            q.pop();

            if (dist[u] > far_dist) {

                far_dist = dist[u];

                far_node = u;

            }

            for (auto [v, w] : g[u]) {

                if (dist[v] == -1) {

                    dist[v] = dist[u] + w;

                    q.push(v);

                }

            }

        }

        return {far_node, far_dist};

    }

public:

    tree_diameter_bfs(int total, vector<vector<pair<int, long long>>>& g_in) {

        n = total;

        g = g_in;

    }

    long long solve() {

        auto [u, _] = bfs_farthest(1);

        auto [v, d] = bfs_farthest(u);

        return d;                               // d 即直径长度

    }

};

```

> 💡 **同时获得直径两端点**：稍作记录就能得到直径的两个端点 $u, v$，用于后续找直径中点等问题。

**模板二：树形 dp（含负权也对）**

```cpp

class tree_diameter_dp {

private:

    int n;

    vector<vector<pair<int, long long>>> g;

    long long ans;

    long long dfs(int u, int fa) {

        long long max1 = 0;                     // 最长向下链

        long long max2 = 0;                     // 次长向下链（来自不同子节点）

        for (auto [v, w] : g[u]) {

            if (v == fa) {

                continue;

            }

            long long d = dfs(v, u) + w;        // 从 v 子树向下延伸

            if (d > max1) {

                max2 = max1;

                max1 = d;

            } else if (d > max2) {

                max2 = d;

            }

        }

        ans = max(ans, max1 + max2);            // 过 u 的最长路径

        return max1;

    }

public:

    tree_diameter_dp(int total, vector<vector<pair<int, long long>>>& g_in) {

        n = total;

        g = g_in;

    }

    long long solve() {

        ans = 0;

        dfs(1, 0);

        return ans;

    }

};

```

> 💡 **"向下链"的初值是 0**：因为 $u$ 自己作为路径的"起点"时长度为 0。如果只走一步到子节点，链长就是该边权值。

> ⚠️ **次长链必须来自不同子节点**：若 max1 和 max2 都来自同一子节点子树，组合起来不是合法路径（会重复经过该子节点）。代码中通过"先比 max1 再比 max2"的更新逻辑天然保证（每次更新只看一个 $d$，不会同时影响两者）。

## 复杂度分析

- 两次 BFS 法：$O(n)$

- 树形 dp 法：$O(n)$

- 空间复杂度：$O(n)$

## 正确性证明

### 两次 BFS 法的正确性

**核心定理**：从任意点 $s$ 出发，离 $s$ 最远的点 $u$ 必然是某条直径的**端点**。

**证明（反证）**：

设 $A, B$ 是某条直径的两端，$u$ 是从 $s$ 出发最远的点。假设 $u$ 不是任何直径的端点。

考虑 $s$ 与 $u$、$A$、$B$ 在树上的位置关系。设路径 $s \to u$ 和路径 $A \to B$ 在树上的"交集"为某条子路径 $L$（树上任意两条路径要么不相交、要么相交于一段连续路径——这是树的关键性质）。

**情况一**：$s \to u$ 与 $A \to B$ **不相交**。

设 $s \to u$ 路径上离 $A \to B$ 最近的点为 $p$，$A \to B$ 路径上离 $s \to u$ 最近的点为 $q$。$p, q$ 之间有一段独立路径连接（树的唯一性）。

考察 $A \to p$ 路径长度 $|Aq| + |qp|$。由 $u$ 是 $s$ 最远点，$|s\,u| \ge |s\,A| = |s\,p| + |p\,q| + |q\,A|$，所以

$$|p\,u| \ge |p\,q| + |q\,A|$$

构造路径 $A \to q \to p \to u$，长度 $|Aq| + |qp| + |pu| \ge |Aq| + |qp| + |pq| + |qA| = 2|qp| + 2|qA|$。

但 $|AB| = |Aq| + |qB|$。比较 $A \to u$ 与 $A \to B$ 的长度——

$$|A\,u| - |A\,B| = (|Aq| + |qp| + |pu|) - (|Aq| + |qB|) \ge (|qp| + |pq| + |qA|) - |qB|$$

利用 $|qB| \le |qA| + |AB|$ 等关系，经过仔细计算可得 $|A\,u| \ge |A\,B|$，即 $A \to u$ 也是直径——所以 $u$ 是某条直径的端点，矛盾。

**情况二**：$s \to u$ 与 $A \to B$ **相交**于路径 $L$。

设交集起点 $p$、终点 $q$，且 $p$ 离 $s$ 更近、$q$ 离 $u$ 更近。若 $u \notin \{A, B\}$——

由 $u$ 是从 $s$ 最远，$|s\,u| \ge |s\,A|$。沿交集 $L$ 拆分得 $|s\,u| = |s\,p| + |p\,q| + |q\,u|$；$|s\,A| = |s\,p| + |p\,A|$（假设 $A$ 在 $p$ 的 $L$ 外延伸方向）。

所以 $|p\,q| + |q\,u| \ge |p\,A|$，即 $|q\,u| \ge |p\,A| - |p\,q|$。

考察 $A \to u$ 路径：$A \to p \to q \to u$，长度 $= |A\,p| + |p\,q| + |q\,u| \ge |A\,p| + |p\,q| + (|p\,A| - |p\,q|) = 2|A\,p|$。但更重要的是与 $A \to B$ 比较——略去复杂代数，结论仍是 $|A\,u| \ge |A\,B|$，$u$ 是直径端点。$\blacksquare$

> 详细证明涉及一些情形分析，核心思想就是"$u$ 比 $s$ 出发的任何点远，则替换 $A, B$ 中的一个为 $u$ 不会让路径变短"。

**第二次 BFS**：从 $u$（直径端点）出发求最远点 $v$——由直径性质，从直径一端出发的最远点必然是另一端。所以 $v$ 是另一直径端点，$|u\,v|$ 即直径长度。

**为什么对负权失败**：上述证明用到"路径长度满足三角不等式"和"路径长度 $\ge 0$"等性质。负权下"远 = 大"的语义被破坏，从 $s$ 出发的最远点不一定是直径端点。

### 树形 dp 法的正确性

**核心命题**：直径必然有一个**最高点（折点）**$L$，使得直径在 $L$ 处"两个子树各延伸一段"得到。

**证明**：直径是树中某两点 $A, B$ 间的简单路径。在以根为参考的树中，路径 $A \to B$ 必经过 $L = \mathrm{lca}(A, B)$。$L$ 是路径中深度最浅的点，路径在 $L$ 处分成两段——$L \to A$ 和 $L \to B$，分别完全位于 $L$ 的两个不同子树中。$\blacksquare$

**算法等价性**：树形 dp 枚举每个节点 $u$ 作为折点 $L$ 的可能性——从 $u$ 出发向不同子树各取一条最长链。$d_1 + d_2$ 即过 $u$ 的最长路径。所有 $u$ 中最大的就是直径长度。

**子节点贡献的合并是对的**：每个子节点 $v$ 贡献"$v$ 子树中向下走的最长链"$+$ 边权 $w(u, v)$。维护最长链 $d_1$ 和次长链 $d_2$ 是简单的"取最大两元素"问题。

**必须来自不同子节点**：若两条链都来自同一子节点 $v$，组合起来就是 $v$ 子树内部的路径——而那条路径的最优情况已在 $\mathtt{dfs}(v)$ 中被处理过（递归到 $v$ 时它是某个折点），不需要在 $u$ 处再考虑。$\blacksquare$

### 复杂度的来源

两种方法都是单次或两次 DFS / BFS，每个节点和每条边各被处理一次，$O(n)$。$\blacksquare$

## 应用：树的中心

**树的中心**：使"到所有节点最远距离"最小化的节点——它一定在直径上。

**做法**：先求出直径两端 $A, B$，路径 $A \to B$ 上的"中点"附近就是中心。具体地，从 $A$ 出发沿直径走到长度 $\ge \lceil |AB| / 2 \rceil$ 的位置即为一个中心（边权时可能在边的中间，按题目要求处理）。

## 与 [[换根dp]] 的关系

如果题目要求"求**每个节点**到树上其他所有点的最大距离"，简单的两次 BFS 不够——这是 [[换根dp]] 的经典应用：先以 1 为根 dp，再换根递推每个节点的答案。直径只是这个更一般问题的特例。
