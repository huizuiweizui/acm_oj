#难度/★★★★★

> 把树拆成 $O(\log n)$ 条"重链"，每条重链 dfs 序连续——把树上路径转化为线段树的区间操作。

## 核心思想

树上的路径修改 / 查询是经典难题——朴素做法每次 $O(n)$ 暴力跳，多次操作就退化。**树链剖分（Heavy-Light Decomposition, HLD）**给出了一种漂亮的解法：

> 把树**剖分**为若干条互不相交的"链"，使得每条链上的节点在 dfs 序中**连续**——再用 [[线段树]] 维护这个 dfs 序，把树上路径操作转化为多个区间操作。

**关键的剖分策略——重剖分**：

定义每个非叶节点 $u$ 的**重儿子（heavy child）**：$u$ 的所有儿子中**子树最大**的那个（如有并列任选其一）。其他儿子称**轻儿子**。连接 $u$ 与重儿子的边称**重边**，其他称**轻边**。

> **重链（heavy chain）**：极大的、由重边连接的链——以某个节点（链顶）开始，沿重边向下到某个叶子结束。

整棵树被划分为若干条不相交的重链，每个节点恰属于一条重链。

**关键性质**：从任意点 $u$ 走到根的路径上，**轻边数不超过 $\log_2 n$ 条**。

**证明**：沿轻边 $u \to \mathtt{parent}(u)$ 走时，$\mathtt{parent}(u)$ 的子树大小 $> 2 \cdot$ $u$ 的子树大小（否则 $u$ 才应该是 $\mathtt{parent}(u)$ 的重儿子）。所以每跳一条轻边，子树大小至少翻倍——最多翻倍 $\log_2 n$ 次就到了根。$\blacksquare$

**这意味着**：从 $u$ 到根的路径被分成 $O(\log n)$ 条重链。两点之间的路径同理（拼接两个"到 LCA"的路径）。

**dfs 序的设计**：DFS 时**优先访问重儿子**——这样每条重链的节点 dfs 序连续。配合 [[线段树]] 维护 dfs 序数组，就可以——

**路径 $u \to v$ 的操作**：把路径分成 $O(\log n)$ 段重链，每段对应 dfs 序中的一个连续区间，每段调用线段树操作 $O(\log n)$——总 $O(\log^2 n)$。

**子树 $u$ 的操作**：$u$ 的子树在 dfs 序中**也是连续区间** $[\mathtt{dfn}[u], \mathtt{dfn}[u] + \mathtt{size}[u] - 1]$，所以子树操作就是单次线段树操作 $O(\log n)$。

## 适用场景

- **树上路径修改 / 查询**：求路径权和、路径最值、路径染色等

- **子树修改 / 查询**：子树整体加值、子树求和等

- **LCA 求解**：在剖分过程中用 $O(\log n)$ 时间求 LCA（过程类似路径分段）

- **动态树问题（静态结构）**：树的结构不变但权值变化的各种问题

- 不适用：树的结构动态变化（用 LCT）；问题信息不能 $O(1)$ 合并的场景

## 步骤拆解

**第一次 DFS（信息预处理）**：求每个节点的——

- $\mathtt{depth}[u]$：深度

- $\mathtt{parent}[u]$：父节点

- $\mathtt{size}[u]$：子树大小

- $\mathtt{heavy\_son}[u]$：重儿子（无则为 0）

**第二次 DFS（剖分 + dfs 序）**：DFS 中**优先访问重儿子**，给每个节点分配 dfs 序 $\mathtt{dfn}[u]$，并记录每个节点所在重链的链顶 $\mathtt{top}[u]$——

- 重儿子的 $\mathtt{top}$ 继承父节点的 $\mathtt{top}$

- 轻儿子的 $\mathtt{top}$ 是它自己（开启新重链）

**线段树**：以 dfs 序 $\mathtt{dfn}[u]$ 为下标建线段树，存储节点权值或边权——具体根据题目（点权 / 边权）调整。

**路径操作 $u \to v$**：

```
while top[u] != top[v]:

    若 depth[top[u]] < depth[top[v]]: swap(u, v)

    对线段树区间 [dfn[top[u]], dfn[u]] 操作

    u = parent[top[u]]

若 depth[u] > depth[v]: swap(u, v)

对线段树区间 [dfn[u], dfn[v]] 操作
```

**子树操作 $u$**：直接对线段树区间 $[\mathtt{dfn}[u], \mathtt{dfn}[u] + \mathtt{size}[u] - 1]$ 操作。

## 代码模板

**模板：树上路径加 + 路径求和 + 子树加 + 子树求和**

```cpp
class hld {

private:

    int n, root;

    vector<vector<int>> g;

    vector<long long> w;                        // w[u] = u 的初始权值

    vector<int> depth, parent, sz, heavy_son, top, dfn, rnk;

    int dfn_cnt;

    // 线段树（带懒标记）
    vector<long long> tree, lazy;

    void dfs1(int u, int fa, int d) {

        depth[u] = d;

        parent[u] = fa;

        sz[u] = 1;

        int max_sz = 0;

        for (int v : g[u]) {

            if (v == fa) continue;

            dfs1(v, u, d + 1);

            sz[u] += sz[v];

            if (sz[v] > max_sz) {

                max_sz = sz[v];

                heavy_son[u] = v;

            }

        }

    }

    void dfs2(int u, int t) {

        top[u] = t;

        dfn_cnt += 1;

        dfn[u] = dfn_cnt;

        rnk[dfn_cnt] = u;                       // dfn 序对应的节点（线段树初始化要用）

        if (heavy_son[u] != 0) {

            dfs2(heavy_son[u], t);              // 重儿子继承 top

        }

        for (int v : g[u]) {

            if (v != parent[u] && v != heavy_son[u]) {

                dfs2(v, v);                     // 轻儿子开启新链

            }

        }

    }

    // ============ 线段树部分 ============
    void build(int p, int l, int r) {

        if (l == r) {

            tree[p] = w[rnk[l]];

            return;

        }

        int mid = l + (r - l) / 2;

        build(p * 2, l, mid);

        build(p * 2 + 1, mid + 1, r);

        tree[p] = tree[p * 2] + tree[p * 2 + 1];

    }

    void push_down(int p, int l, int r) {

        if (lazy[p] == 0) return;

        int mid = l + (r - l) / 2;

        tree[p * 2]     += lazy[p] * (mid - l + 1);

        lazy[p * 2]     += lazy[p];

        tree[p * 2 + 1] += lazy[p] * (r - mid);

        lazy[p * 2 + 1] += lazy[p];

        lazy[p] = 0;

    }

    void seg_update(int p, int l, int r, int ql, int qr, long long val) {

        if (ql <= l && r <= qr) {

            tree[p] += val * (r - l + 1);

            lazy[p] += val;

            return;

        }

        push_down(p, l, r);

        int mid = l + (r - l) / 2;

        if (ql <= mid) seg_update(p * 2, l, mid, ql, qr, val);

        if (mid <  qr) seg_update(p * 2 + 1, mid + 1, r, ql, qr, val);

        tree[p] = tree[p * 2] + tree[p * 2 + 1];

    }

    long long seg_query(int p, int l, int r, int ql, int qr) {

        if (ql <= l && r <= qr) return tree[p];

        push_down(p, l, r);

        int mid = l + (r - l) / 2;

        long long sum = 0;

        if (ql <= mid) sum += seg_query(p * 2, l, mid, ql, qr);

        if (mid <  qr) sum += seg_query(p * 2 + 1, mid + 1, r, ql, qr);

        return sum;

    }

public:

    hld(int total, vector<vector<int>>& g_in, vector<long long>& w_in, int root_in) {

        n = total;

        g = g_in;

        w = w_in;

        root = root_in;

        depth.assign(n + 1, 0);

        parent.assign(n + 1, 0);

        sz.assign(n + 1, 0);

        heavy_son.assign(n + 1, 0);

        top.assign(n + 1, 0);

        dfn.assign(n + 1, 0);

        rnk.assign(n + 1, 0);

        dfn_cnt = 0;

        tree.assign(4 * n, 0);

        lazy.assign(4 * n, 0);

        dfs1(root, 0, 1);

        dfs2(root, root);

        build(1, 1, n);

    }

    // 路径 u-v 区间加 val
    void path_update(int u, int v, long long val) {

        while (top[u] != top[v]) {

            if (depth[top[u]] < depth[top[v]]) swap(u, v);

            seg_update(1, 1, n, dfn[top[u]], dfn[u], val);

            u = parent[top[u]];

        }

        if (depth[u] > depth[v]) swap(u, v);

        seg_update(1, 1, n, dfn[u], dfn[v], val);

    }

    // 路径 u-v 求和
    long long path_query(int u, int v) {

        long long sum = 0;

        while (top[u] != top[v]) {

            if (depth[top[u]] < depth[top[v]]) swap(u, v);

            sum += seg_query(1, 1, n, dfn[top[u]], dfn[u]);

            u = parent[top[u]];

        }

        if (depth[u] > depth[v]) swap(u, v);

        sum += seg_query(1, 1, n, dfn[u], dfn[v]);

        return sum;

    }

    // u 的子树加 val
    void subtree_update(int u, long long val) {

        seg_update(1, 1, n, dfn[u], dfn[u] + sz[u] - 1, val);

    }

    // u 的子树求和
    long long subtree_query(int u) {

        return seg_query(1, 1, n, dfn[u], dfn[u] + sz[u] - 1);

    }

    // 顺手得到 LCA
    int lca(int u, int v) {

        while (top[u] != top[v]) {

            if (depth[top[u]] < depth[top[v]]) swap(u, v);

            u = parent[top[u]];

        }

        return depth[u] < depth[v] ? u : v;

    }

};
```

> 💡 **`rnk` 数组的作用**：`rnk[i]` 是 dfs 序为 $i$ 的节点编号，建线段树时要按 dfs 序顺序读取节点权值——`build` 中 `tree[p] = w[rnk[l]]` 即用此映射。

> ⚠️ **边权问题的处理**：上述代码处理点权。若题目是边权——一条经典技巧是把边权"下放"到深节点（即把边 $(u, v)$ 的权值赋给深的那一端）。然后在路径查询时**排除 LCA**——`seg_query(1, 1, n, dfn[u] + 1, dfn[v])`——因为 LCA 节点对应的"边"其实是 LCA 的父边，不在路径上。

## 复杂度分析

- 预处理：$O(n)$（两次 DFS）+ $O(n)$（建线段树）= $O(n)$

- 单次路径操作：$O(\log^2 n)$（$O(\log n)$ 段重链 × $O(\log n)$ 线段树操作）

- 单次子树操作：$O(\log n)$

- 空间复杂度：$O(n)$

## 正确性证明

### 重链分解的关键性质

**性质 1**：每个节点恰属于一条重链。

**证明**：由"每个非叶节点至多有一个重儿子"，重边形成一个**森林**——其实是若干条简单路径（每节点的重边出度 $\le 1$，重边入度 $\le 1$ 因为每节点至多一个父亲）。所以重链彼此不相交。叶子节点单独成一条只有 1 个节点的重链。$\blacksquare$

**性质 2**：从任意节点到根的路径上，轻边数 $\le \log_2 n$。

**证明（核心）**：考察沿轻边 $u \to \mathtt{parent}(u)$ 走的情形。设 $v = \mathtt{parent}(u)$，$h = \mathtt{heavy\_son}(v)$。由 $u \ne h$（轻边），有 $\mathtt{size}[h] \ge \mathtt{size}[u]$。所以

$$\mathtt{size}[v] = 1 + \sum_{c \text{ 是 } v \text{ 的子}} \mathtt{size}[c] \ge 1 + \mathtt{size}[h] + \mathtt{size}[u] \ge 1 + 2 \cdot \mathtt{size}[u] > 2 \cdot \mathtt{size}[u]$$

每跳一条轻边子树至少翻倍。从某节点到根最多翻倍 $\log_2 n$ 次就达到 $\mathtt{size} = n$（根的子树是全树）。$\blacksquare$

### 重链的 dfs 序连续性

**命题**：DFS 中"先访问重儿子"的策略下，每条重链上的节点 dfs 序构成连续区间。

**证明**：考察重链 $c_0 \to c_1 \to \cdots \to c_k$（$c_{i+1}$ 是 $c_i$ 的重儿子）。

DFS 进入 $c_0$ 后，立即进入 $c_1$（重儿子优先），然后立即进入 $c_2$……一直到 $c_k$（叶子）才回溯。在 $c_0 \to c_1$ 的过程中没有"插入"其他节点的访问——它们的访问被推迟到回溯后。

所以 $\mathtt{dfn}[c_0], \mathtt{dfn}[c_1], \ldots, \mathtt{dfn}[c_k]$ 是连续整数。$\blacksquare$

### 子树的 dfs 序连续性

**命题**：节点 $u$ 的子树在 dfs 序中是连续区间 $[\mathtt{dfn}[u], \mathtt{dfn}[u] + \mathtt{size}[u] - 1]$。

**证明**：DFS 进入 $u$ 后，会访问完 $u$ 的整个子树才回溯——子树内 $\mathtt{size}[u]$ 个节点的 dfn 是连续 $\mathtt{size}[u]$ 个值。$\blacksquare$

### 路径分段算法的正确性

**命题**：路径 $u \to v$ 被分为 $O(\log n)$ 段重链。

**证明**：路径 $u \to v$ 经过 LCA。从 $u$ 向上跳到 LCA、$v$ 向上跳到 LCA——两段路径各跨 $O(\log n)$ 条重链（由性质 2，沿轻边跳的次数 $O(\log n)$；沿重边走可任意长但不增加重链数）。

具体算法每次"$u, v$ 中 $\mathtt{top}$ 较深的那个跳到 $\mathtt{top}$ 之上"的过程——每次跳就消耗一条重链——共 $O(\log n)$ 次。最后 $\mathtt{top}[u] = \mathtt{top}[v]$ 时它们在同一重链上，再处理这一段。$\blacksquare$

**LCA 是循环结束时较浅的那个**：当 $\mathtt{top}[u] = \mathtt{top}[v]$ 时，$u$ 和 $v$ 在同一重链上——较浅的那个是 LCA（这是 LCA 在重链上的体现）。

### 复杂度的来源

- 路径操作 $u \to v$：循环 $O(\log n)$ 次跳跃，每次用线段树操作 $O(\log n)$——总 $O(\log^2 n)$

- 子树操作：单次线段树 $O(\log n)$

- 预处理两次 DFS：$O(n)$；线段树建树 $O(n)$

$\blacksquare$

## 经验与常见错误

- **`heavy_son` 未初始化**：默认值要设为 0（或某哨兵），表示"无重儿子"（叶子节点）

- **路径操作中漏掉最后一段**：循环结束后还要处理 $u, v$ 在同一重链的那段，容易忘

- **边权下放**：边权问题要把边权赋给深节点，路径查询时排除 LCA——非常容易出错

- **多次 DFS 时数组不重置**：批量测试样例时 $\mathtt{dfn\_cnt}$ 等要清零
