## 核心思想

**最大流问题（Max Flow）**：给定有向图 $G = (V, E)$，每条边 $(u, v) \in E$ 有**容量** $c(u, v) \ge 0$。指定**源点 $s$** 和**汇点 $t$**。**流** $f$ 是给每条边分配一个流量 $f(u, v)$，满足——

- **容量约束**：$0 \le f(u, v) \le c(u, v)$

- **流量守恒**：除 $s, t$ 外，每个节点流入量 = 流出量

**最大流**就是最大化"从 $s$ 流出的总流量"（等于流入 $t$ 的总流量）。

**核心概念——残量网络**：

> 残量网络 $G_f$ 是在原图基础上修改容量得到的图——
> 
> - 对每条原边 $(u, v)$，残量 $c_f(u, v) = c(u, v) - f(u, v)$（剩余可用容量）
>
> - 对每条原边 $(u, v)$，**反向边** $(v, u)$ 的残量 $c_f(v, u) = f(u, v)$（已用流量可"撤回"）

> **增广路**：残量网络中从 $s$ 到 $t$ 的一条简单路径，路径上每条边残量 $> 0$。增广路上能"再压"的流量 = 路径上最小残量。

**Ford-Fulkerson 框架**：

> 反复找增广路并沿路增广，直到残量网络中无 $s \to t$ 路径——此时流即最大流。

不同算法选择不同的"找增广路"策略：

- **Edmonds-Karp（EK）**：BFS 找**最短**增广路（按边数）。复杂度 $O(VE^2)$

- **Dinic**：BFS 分层 + 在分层图上 DFS 多路增广。复杂度 $O(V^2 E)$，竞赛主流

- **ISAP**：Dinic 的优化版，常数更小

**Dinic 的两层结构**：

- **外层 BFS 分层**：计算 $\mathtt{dist}[u] = $ 残量网络中 $s$ 到 $u$ 的最短距离（按边数）。如果 $t$ 不可达，算法终止

- **内层 DFS 多路增广**：在分层图（只走 $\mathtt{dist}[v] = \mathtt{dist}[u] + 1$ 的边）上找多条增广路，每次找到一条就增广

**当前弧优化**：DFS 中维护 $\mathtt{cur}[u]$ 指向 $u$ "下一条要尝试的边"——失败的边再不重试。这是 Dinic 复杂度保证的关键。

## 适用场景

- **求最大流**（最经典应用）

- **二分图最大匹配**：建源汇、左部连源、右部连汇——最大流即最大匹配（[[二分图最大匹配]] 用匈牙利算法更直接，但 Dinic 在带权或大规模时更快）

- **最小割**：由最大流-最小割定理，最大流 = 最小割

- **最大权闭合子图** / **最大密度子图**：转化为最小割

- **二分图多重匹配** / **任务分配**：建图后跑最大流

- **路径覆盖**：DAG 最小路径覆盖 = $n$ - 二分图最大匹配

- 不适用：纯单源最短路（用 [[Dijkstra]] / [[SPFA]]）；纯连通性问题（用 [[Tarjan]]）

## 步骤拆解

**Dinic 算法**：

1. 初始化所有边流量为 0（残量 = 容量）

2. **BFS 分层**：从 $s$ 出发 BFS，计算 $\mathtt{dist}[]$；若 $t$ 不可达，结束算法

3. **DFS 多路增广**：从 $s$ 开始 DFS，沿分层图找增广路；每找到一条就沿路扣减残量、给反向边加残量、累加流量

4. 重复步骤 2-3 直到 BFS 中 $t$ 不可达

**当前弧优化的实现**：每个节点维护 $\mathtt{cur}[u]$——DFS 中尝试 $u$ 的边时从 $\mathtt{cur}[u]$ 开始；若某条边走不下去（无法到 $t$），把 $\mathtt{cur}[u]$ 推进到下一条。

## 代码模板

**模板：Dinic 算法**

```cpp

class dinic {

private:

    int n, source, sink;

    struct edge {

        int to;

        long long cap;                          // 当前残量

        int rev;                                // 反向边在 g[to] 中的下标

    };

    vector<vector<edge>> g;

    vector<int> dist;                           // BFS 分层

    vector<int> cur;                            // 当前弧

    bool bfs() {

        dist.assign(n + 1, -1);

        queue<int> q;

        dist[source] = 0;

        q.push(source);

        while (!q.empty()) {

            int u = q.front();

            q.pop();

            for (auto& e : g[u]) {

                if (e.cap > 0 && dist[e.to] == -1) {

                    dist[e.to] = dist[u] + 1;

                    q.push(e.to);

                }

            }

        }

        return dist[sink] != -1;

    }

    long long dfs(int u, long long pushed) {

        if (u == sink) {

            return pushed;

        }

        for (int& i = cur[u]; i < (int)g[u].size(); i++) {

            auto& e = g[u][i];

            if (e.cap > 0 && dist[e.to] == dist[u] + 1) {

                long long d = dfs(e.to, min(pushed, e.cap));

                if (d > 0) {

                    e.cap -= d;

                    g[e.to][e.rev].cap += d;

                    return d;

                }

            }

        }

        return 0;

    }

public:

    dinic(int total, int s, int t) {

        n = total;

        source = s;

        sink = t;

        g.assign(n + 1, {});

    }

    void add_edge(int u, int v, long long c) {

        g[u].push_back({v, c, (int)g[v].size()});

        g[v].push_back({u, 0, (int)g[u].size() - 1});

    }

    long long max_flow() {

        long long total = 0;

        while (bfs()) {

            cur.assign(n + 1, 0);

            while (long long d = dfs(source, LLONG_MAX)) {

                total += d;

            }

        }

        return total;

    }

};
```

> 💡 **`rev` 字段的作用**：每条原边和反向边相互引用，加边时记下对方在邻接表中的下标。增广时 `g[e.to][e.rev]` 即为反向边。

> 💡 **当前弧优化的细节**：`for (int& i = cur[u]; ...; i++)` 的 `&` 让 `i` 是 `cur[u]` 的引用——每次循环会**实际推进** `cur[u]`，下次进入 $u$ 从这里继续。

> ⚠️ **加边时反向边容量为 0**：原边容量为 $c$，反向边容量为 0（用于"撤回"原边的流量）。这是构造残量网络的基础。

> ⚠️ **`pushed` 参数**：DFS 的 `pushed` 表示"从 $s$ 到 $u$ 沿路径还能压的最大流量"——是从源点出发一路 `min` 下来的瓶颈。到达 $t$ 时它就是这条增广路的容量。

**典型应用：二分图最大匹配的网络流建模**

```cpp

// 左部点 1..L，右部点 L+1..L+R

// 源点 s = 0，汇点 t = L + R + 1

dinic d(L + R + 2, 0, L + R + 1);

for (int u = 1; u <= L; u++) {

    d.add_edge(0, u, 1);                        // 源点 → 左部

}

for (int v = 1; v <= R; v++) {

    d.add_edge(L + v, L + R + 1, 1);            // 右部 → 汇点

}

for (auto [u, v] : edges) {                     // 左 u 与右 v 有边

    d.add_edge(u, L + v, 1);                    // 左 → 右

}

cout << d.max_flow();                           // 最大匹配数

```

## 复杂度分析

- 时间复杂度：$O(V^2 E)$（Dinic 的标准上界）

- **二分图最大匹配上界**：$O(E \sqrt V)$（Hopcroft-Karp 同等水平）

- **单位容量图**：$O(E \sqrt E)$

- 空间复杂度：$O(V + E)$

## 正确性证明

### 最大流-最小割定理

**割的定义**：把节点划分为 $(S, T)$ 两部分，$s \in S$，$t \in T$。割的容量是从 $S$ 跨到 $T$ 的边的容量和。

**最大流-最小割定理**：

$$\max_{f \text{ 是合法流}} |f| = \min_{(S, T) \text{ 是割}} c(S, T)$$

即**最大流 = 最小割**。这是网络流理论的基石。

**证明**：

**最大流 $\le$ 最小割**：任何合法流 $f$ 跨过任何割 $(S, T)$ 的"流出 $-$ 流入"等于 $|f|$，且流出量 $\le c(S, T)$，所以 $|f| \le c(S, T)$。

**等号可达（增广路定理）**：考虑最大流 $f^*$ 终止时的残量网络 $G_{f^*}$。$G_{f^*}$ 中 $s$ 不能到达 $t$（否则可继续增广，与最大矛盾）。设 $S = $ "$G_{f^*}$ 中 $s$ 可达的节点"，$T = V \setminus S$——则 $(S, T)$ 是个割且 $t \in T$。

割上每条 $S \to T$ 边在残量网络中容量为 0，意味着原边已被流满；每条 $T \to S$ 边在残量网络中容量为 0，意味着原边的反向（即 $S \to T$ 方向）的流量为 0。所以——

$$|f^*| = \sum_{u \in S, v \in T} f^*(u, v) - \sum_{u \in T, v \in S} f^*(u, v) = c(S, T) - 0 = c(S, T)$$

等号成立。$\blacksquare$

### 增广路定理

**定理**：流 $f$ 是最大流 $\Leftrightarrow$ 残量网络 $G_f$ 中不存在 $s \to t$ 路径。

**"$\Rightarrow$"**：若有增广路则可继续增广 $\Rightarrow$ $f$ 不是最大。逆否得"最大 $\Rightarrow$ 无增广路"。

**"$\Leftarrow$"**：由最大流-最小割定理证明的构造，无增广路时存在等于流量的割——所以流是最大的。$\blacksquare$

### Dinic 的正确性

Dinic 是 Ford-Fulkerson 框架的具体实现——只要"反复找增广路并增广"直到无增广路，由增广路定理结果即最大流。

Dinic 的特殊性在于"BFS 分层 + 多路增广"的策略——这只影响**速度**，不影响**正确性**。

### Dinic 的复杂度证明（关键引理）

**引理**：每次 BFS 后，$\mathtt{dist}[t]$ **严格增加**（直到 $t$ 不可达终止）。

**证明**：

DFS 在分层图上找增广路——增广后某些边的残量变为 0，反向边的残量变为正。新增的反向边只能让 $\mathtt{dist}[t]$ 不变或变大（不会变小）。

更准确地，每次 DFS 阶段结束时，分层图上"$s \to t$ 的最短增广路长度" $\ge$ 当前 $\mathtt{dist}[t] + 1$——下次 BFS 必然 $\mathtt{dist}[t]$ 增加。

**复杂度的来源**：

- $\mathtt{dist}[t]$ 最多增加到 $V - 1$ 后必须终止——所以**最多 $O(V)$ 次 BFS**

- 每次 BFS 的 DFS 阶段，由于当前弧优化，所有 DFS 调用累计 $O(E)$（每条边的 `cur` 推进至多 $E$ 次总计）

- 每条增广路的 DFS 时间 $O(V)$（路径长度）

总计 $O(V) \cdot (O(E) + O(V \cdot \text{增广路数})) = O(V^2 E)$。$\blacksquare$

### 二分图最大匹配下的 $O(E\sqrt V)$

**Hopcroft-Karp 定理**：在二分图最大匹配建模下，Dinic 的复杂度 $O(E\sqrt V)$。

**证明（思路）**：基于"短增广路只有 $O(\sqrt V)$ 阶段，长增广路只有 $O(\sqrt V)$ 条"的双重论证。详细证明涉及矩阵分析等技巧。

## 重要应用：最小割建模

**最小割模型的常见套路**：

- **必须二选一**：把"选 A"和"选 B"建为割的两侧

- **选 A 必须先选 B**：从 $A$ 向 $B$ 连一条无穷大边——若 A 在 $S$ 中而 B 在 $T$ 中则割容量无穷大，强制让此情形不出现

- **代价 / 收益**：源点 → 选项 → 汇点，按收益设容量

**经典模型**：

- **最大权闭合子图**：源 → 正权点容量为权，负权点 → 汇容量为绝对值，闭合关系连无穷边。最大权 = 正权和 - 最小割。

- **最小点覆盖**（在二分图）：最大流 = 最小点覆盖（König 定理）

## 几个进阶变种

- **费用流（最小费用最大流）**：每条边有容量和单位费用，求"流量最大且费用最小"。常用 SPFA 找最短增广路。

- **上下界网络流**：每条边有流量下界，转化为标准最大流。

- **多源多汇最大流**：用超级源 / 汇连所有源 / 汇即可。
