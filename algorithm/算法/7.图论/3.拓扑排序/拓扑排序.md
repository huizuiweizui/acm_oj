#难度/★★★ 

> 在 DAG 上给出一个线性序列，使得每条有向边 $(u, v)$ 都满足 $u$ 出现在 $v$ 之前——既是排序，也是 DAG 检测。

- [[DFS]]

## 核心思想

**拓扑排序（Topological Sort）**：给定有向无环图（DAG），输出一个节点的线性序列，使得对每条有向边 $(u, v)$，$u$ 都排在 $v$ 之前。这种序列称为图的**拓扑序**。

拓扑序刻画了"依赖关系"——若 $u \to v$ 表示"做 $v$ 之前必须先做 $u$"，那么按拓扑序执行即可满足所有依赖。

有两种主流实现：

**Kahn 算法（BFS 版）**：基于"入度为 0 即可输出"的直觉——

> DAG 中至少存在一个入度为 0 的节点（无前驱的"源点"）。把它输出后从图中删除，剩余图仍是 DAG，递归处理。

实现上不真删边——只把每个节点的入度 -1，入度变为 0 时入队。

**DFS 算法**：基于一个深刻的观察——

> DFS 的"完成时间"（节点退出递归栈的时刻）逆序就是拓扑序。

因为 DFS 必然先完成所有后继节点才返回，所以一条边 $(u, v)$ 必有 $\mathtt{finish}(u) > \mathtt{finish}(v)$。把完成时间从大到小排列即得拓扑序。

**判环**：拓扑排序天然能检测环——若 Kahn 终止时未能输出全部 $n$ 个节点，或 DFS 中遇到回边，则图含环。

## 适用场景

- **任务调度** / **课程编排**：依赖关系自然是 DAG，按拓扑序执行

- **DAG 上的 dp**：填表顺序必须是拓扑序（典型如最长路、计数）

- **判定 DAG**：拓扑排序成功 $\Leftrightarrow$ 图无环

- **关键路径分析**：求 DAG 上最长路径用于工程进度估计

- **编译依赖** / **构建系统**（make / cmake）：源文件依赖图的拓扑排序

- **CSP 约束传播**：约束图按拓扑序求解

- 不适用：有向有环图（无拓扑序）；无向图（拓扑序对无向图无意义，要用 [[DFS]] 求生成树等）

## 步骤拆解

**Kahn 算法**：

1. 遍历所有边，统计每个节点的入度 $\mathtt{in\_deg}[v]$

2. 把所有入度为 0 的节点入队

3. 循环直到队空：

   a. 出队 $u$，加入拓扑序末尾

   b. 枚举每条出边 $(u, v)$：$\mathtt{in\_deg}[v]$ 减 1；若变为 0，入队

4. 若拓扑序长度 $< n$，图有环；否则即得拓扑序

**DFS 算法**（用三态标记防止重复访问 + 检测环）：

1. 每个节点 `state` 三态：0 (未访问) / 1 (访问中，在递归栈) / 2 (已完成)

2. 对每个 `state == 0` 的节点调用 $\mathtt{dfs}$

3. $\mathtt{dfs}(u)$：先标记 `state[u] = 1`；枚举出边 $(u, v)$：

   - 若 `state[v] == 1`：发现回边 $\Rightarrow$ 有环

   - 若 `state[v] == 0`：递归 $\mathtt{dfs}(v)$

4. 函数末尾把 $u$ 压入栈，置 `state[u] = 2`

5. 栈逆序即为拓扑序

## 代码模板

**模板一：Kahn 算法**

```cpp
class topological_sort_kahn {

private:

    int n;

    vector<vector<int>> g;

public:

    topological_sort_kahn(int total, vector<vector<int>>& g_in) {

        n = total;

        g = g_in;

    }

    // 返回拓扑序；若图有环返回空向量
    vector<int> solve() {

        vector<int> in_deg(n + 1, 0);

        for (int u = 1; u <= n; u++) {

            for (int v : g[u]) {

                in_deg[v] += 1;

            }

        }

        queue<int> q;

        for (int u = 1; u <= n; u++) {

            if (in_deg[u] == 0) {

                q.push(u);

            }

        }

        vector<int> order;

        while (!q.empty()) {

            int u = q.front();

            q.pop();

            order.push_back(u);

            for (int v : g[u]) {

                in_deg[v] -= 1;

                if (in_deg[v] == 0) {

                    q.push(v);

                }

            }

        }

        if ((int)order.size() < n) {

            return {};                          // 有环

        }

        return order;

    }

};
```

**模板二:DFS 算法**

```cpp
class topological_sort_dfs {

private:

    int n;

    vector<vector<int>> g;

    vector<int> state;                          // 0 未访问, 1 访问中, 2 已完成

    vector<int> order;

    bool has_cycle;

    void dfs(int u) {

        state[u] = 1;

        for (int v : g[u]) {

            if (state[v] == 1) {

                has_cycle = true;

                return;

            }

            if (state[v] == 0) {

                dfs(v);

                if (has_cycle) {

                    return;

                }

            }

        }

        state[u] = 2;

        order.push_back(u);                     // 后序入栈

    }

public:

    topological_sort_dfs(int total, vector<vector<int>>& g_in) {

        n = total;

        g = g_in;

    }

    vector<int> solve() {

        state.assign(n + 1, 0);

        order.clear();

        has_cycle = false;

        for (int u = 1; u <= n; u++) {

            if (state[u] == 0) {

                dfs(u);

                if (has_cycle) {

                    return {};

                }

            }

        }

        reverse(order.begin(), order.end());    // 完成时间逆序即拓扑序

        return order;

    }

};
```

> 💡 **字典序最小拓扑序**：把 Kahn 中的普通队列换成**小根堆**（`priority_queue<int, vector<int>, greater<int>>`），每次取编号最小的入度 0 节点即可。复杂度变为 $O((n + m) \log n)$。

> ⚠️ **拓扑序通常不唯一**：DAG 中可能存在多种合法拓扑序（任何"独立"的两个节点都可以互换）。题目若要求特定顺序（字典序、最早开始时间等），需在算法中加额外规则。

## 复杂度分析

- 时间复杂度：$O(n + m)$，每个节点入队/出队各一次，每条边检查一次

- 空间复杂度：$O(n + m)$

## 正确性证明

### Kahn 算法的正确性

**关键不变量**：算法运行中，每次出队的节点 $u$ 在"剩余子图"（未出队节点构成的子图）中入度为 0。

**证明**：每次出队 $u$ 后，对每条出边 $(u, v)$ 把 $\mathtt{in\_deg}[v]$ 减 1——这正等价于"在剩余图上"重新计算入度。新成为入度 0 的节点立即入队，所以队列中始终是"剩余图入度 0"的节点。$\blacksquare$

**拓扑序正确性**：

考察任意一条边 $(u, v)$。$u$ 出队时，$v$ 的入度被 $-1$。$v$ 只有当所有前驱都已出队后入度才能变为 0——所以 $v$ 出队时间晚于它**所有前驱**。即 $u$ 在拓扑序中先于 $v$，符合定义。$\blacksquare$

**判环正确性**：

**命题**：算法终止时输出 $n$ 个节点 $\Leftrightarrow$ 图为 DAG。

**"DAG $\Rightarrow$ 全部输出"**：

DAG 必有入度 0 节点。反证：若所有节点入度 $\ge 1$，从任一节点逆向追溯前驱——节点有限，必形成环，与 DAG 矛盾。

任何时刻"剩余图"是原图的诱导子图，仍是 DAG，必有入度 0 节点——算法不会"卡住"，必能输出所有节点。

**"非 DAG（有环）$\Rightarrow$ 输出 $< n$"**：

环上节点的入度永远不会变为 0。考虑环 $C: c_1 \to c_2 \to \cdots \to c_k \to c_1$。每个 $c_i$ 至少有一个前驱在环上——其入度的"环内贡献"始终 $\ge 1$。即使非环节点全被处理，环上节点的入度仍 $\ge 1$，永不入队。

所以输出节点数 $\le n - k < n$。$\blacksquare$

### DFS 算法的正确性

**关键定理**：在 $\mathtt{dfs}$ 调用过程中，对图中每条边 $(u, v)$ 必有 $\mathtt{finish}(u) > \mathtt{finish}(v)$（除非遇到回边，对应有环）。

**证明**：考察 $\mathtt{dfs}(u)$ 中处理边 $(u, v)$ 的时刻：

- 若 $\mathtt{state}[v] = 0$：递归 $\mathtt{dfs}(v)$，必然先完成才返回——$\mathtt{finish}(v) <$ 处理 $(u, v)$ 之后的某时刻 $< \mathtt{finish}(u)$

- 若 $\mathtt{state}[v] = 2$：$v$ 已完成，$\mathtt{finish}(v) <$ 当前时刻 $< \mathtt{finish}(u)$

- 若 $\mathtt{state}[v] = 1$：$v$ 仍在递归栈中——意味着 $v$ 是 $u$ 的祖先，存在 $v \to \cdots \to u \to v$ 的环

所以无环时所有边都满足 $\mathtt{finish}(u) > \mathtt{finish}(v)$。把节点按 $\mathtt{finish}$ 降序排列——任意边 $(u, v)$ 中 $u$ 的 $\mathtt{finish}$ 大，所以 $u$ 排在 $v$ 之前。$\blacksquare$

**判环**：DFS 中遇到 `state[v] == 1` 的边即为**回边**（back edge），等价于发现环。这是有向图判环的标准方法。

### 两种算法的等价性

Kahn 和 DFS 给出的拓扑序**通常不同**——它们都正确，但具体顺序由算法机制决定：

- Kahn 优先输出"入度先变为 0"的节点（更"早"的源）

- DFS 输出顺序由递归路径决定（更"贪深"）

只要图是 DAG，两者都给出某个合法拓扑序；不同合法序之间互相置换的"自由度"由图中无依赖关系的节点对数决定。

### 复杂度的来源

每个节点恰好入队 / 出队一次，处理一次（$O(n)$）；每条边在出队时被检查一次并作 $-1$ 处理（$O(m)$）。总计 $O(n + m)$。

## 与相关算法的联系

- **DAG 上 dp**：先拓扑排序，按拓扑序填 dp 数组——保证状态转移时所有依赖项已计算完成

- **强连通分量（SCC）**：[[Tarjan]] 在 DFS 上构建 SCC，把每个 SCC 缩成一个点后即得 DAG，再做拓扑排序

- **2-SAT** / **差分约束**：把布尔变量 / 不等式约束转化为图，拓扑排序辅助求解
