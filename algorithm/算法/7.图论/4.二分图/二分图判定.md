#难度/★★

> 用 BFS / DFS 给图做 2-染色——相邻节点必须异色，染不下去就不是二分图。

## 前置知识

- [[BFS]]

- [[DFS]]

## 核心思想

**二分图（Bipartite Graph）**：图 $G = (V, E)$ 的节点集 $V$ 可以划分为两个非空集合 $A$ 和 $B$（$A \cup B = V$，$A \cap B = \emptyset$），使得**每条边的两个端点分别属于 $A$ 和 $B$**。换言之，图中**没有任何一条边的两端在同一部**。

判定算法基于一个直观操作——**2-染色**：

> 用两种颜色给所有节点染色，要求每条边的两端颜色不同。能成功染色 $\Leftrightarrow$ 是二分图。

实现上从任一节点出发 BFS / DFS，先染色为某色（如 1），然后所有邻居染相反色（2），它们的邻居又染回 1……过程中若遇到"邻居已染色且与自己同色"的冲突，说明无法完成 2-染色，即非二分图。

更深刻的等价刻画：

> $G$ 是二分图 $\Leftrightarrow$ $G$ 不含**奇环**（长度为奇数的环）。

这个等价定理是二分图理论的基石——所有 BFS / DFS 染色失败的本质原因都是图中存在奇环。详见正确性证明。

## 适用场景

- 判断图是否为二分图（最经典应用）

- **二分图最大匹配前置判断**：在执行 [[二分图最大匹配]] 算法前先确认图为二分图

- 棋盘类问题：黑白格自然形成二分图（相邻格子颜色不同）

- **图染色问题** 的最简版本（一般图染色 NP-Hard，但 2-染色 $O(n + m)$）

- 一些"两组对立"的建模：如食物链分组、舞会男女配对前置

- 不适用：含自环的图（自环 = 长度 1 的环 = 奇环，必非二分图）；多染色问题（用其他算法）

## 步骤拆解

1. 用数组 `color[]` 初始化为 0（未染色），可选颜色 1 或 2

2. 对每个未染色节点 $s$：

   a. 把 $s$ 染为颜色 1

   b. BFS / DFS 遍历 $s$ 所在连通块，每访问邻居 $v$：

     - 若 $v$ 未染色：染相反色（用 `3 - color[u]` 实现 1↔2 切换）

     - 若 $v$ 已染色但与当前节点 $u$ 同色：返回 `false`

3. 所有节点处理完无冲突 $\Rightarrow$ 二分图

> 💡 **必须遍历所有连通块**：图可能不连通，所以外层要对每个未染色节点都尝试启动 BFS。

## 代码模板

**模板一：BFS 实现**

```cpp
class bipartite_check_bfs {

private:

    int n;

    vector<vector<int>> g;

public:

    bipartite_check_bfs(int total, vector<vector<int>>& g_in) {

        n = total;

        g = g_in;

    }

    bool is_bipartite() {

        vector<int> color(n + 1, 0);            // 0 = 未染色, 1 / 2 = 两种颜色

        for (int s = 1; s <= n; s++) {

            if (color[s] != 0) {

                continue;

            }

            color[s] = 1;

            queue<int> q;

            q.push(s);

            while (!q.empty()) {

                int u = q.front();

                q.pop();

                for (int v : g[u]) {

                    if (color[v] == 0) {

                        color[v] = 3 - color[u];     // 1 ↔ 2 切换

                        q.push(v);

                    } else if (color[v] == color[u]) {

                        return false;                // 染色冲突

                    }

                }

            }

        }

        return true;

    }

};
```

> 💡 **`3 - color[u]` 的小技巧**：由于颜色是 1 或 2，`3 - 1 = 2`，`3 - 2 = 1`，正好实现"切换"。比写 `if-else` 更紧凑。

**模板二：DFS 实现**

```cpp
class bipartite_check_dfs {

private:

    int n;

    vector<vector<int>> g;

    vector<int> color;

    bool dfs(int u, int c) {

        color[u] = c;

        for (int v : g[u]) {

            if (color[v] == 0) {

                if (!dfs(v, 3 - c)) {

                    return false;

                }

            } else if (color[v] == c) {

                return false;

            }

        }

        return true;

    }

public:

    bipartite_check_dfs(int total, vector<vector<int>>& g_in) {

        n = total;

        g = g_in;

    }

    bool is_bipartite() {

        color.assign(n + 1, 0);

        for (int s = 1; s <= n; s++) {

            if (color[s] == 0 && !dfs(s, 1)) {

                return false;

            }

        }

        return true;

    }

};
```

> ⚠️ **递归深度**：DFS 版在链状或长路径图上可能爆栈（$n > 10^5$ 时风险大）。BFS 版更稳妥。

**还原划分**：染完色后，`color[u] == 1` 的节点构成 $A$ 部，`color[u] == 2` 的构成 $B$ 部。

- 时间复杂度：$O(n + m)$

- 空间复杂度：$O(n + m)$

## 正确性证明

### 二分图 $\Leftrightarrow$ 无奇环

**核心定理**：图 $G$ 是二分图当且仅当 $G$ 不含奇环。

**"$\Rightarrow$"（二分图 $\Rightarrow$ 无奇环）**：

设 $G$ 是二分图，节点划分为 $A, B$。考察任一环 $C: v_0 \to v_1 \to \cdots \to v_k = v_0$。

由二分图定义，相邻节点必在不同部。若 $v_0 \in A$，则 $v_1 \in B$，$v_2 \in A$，……$v_i$ 属于哪部由 $i$ 的奇偶性决定：

$$v_i \in \begin{cases} A & i \text{ 偶} \\ B & i \text{ 奇} \end{cases}$$

由 $v_0 = v_k$ 同属 $A$，要求 $k$ 偶——所以环长 $k$ 必为偶数。$\blacksquare$


**"$\Leftarrow$"（无奇环 $\Rightarrow$ 二分图）**：

对每个连通块独立证明。任选起点 $s$，定义

$$\mathtt{color}(v) = \mathtt{dist}(s, v) \bmod 2$$

即按"到起点距离的奇偶性"染色（这正是 BFS 染色实际做的事）。我们要证此染色给出合法的二部划分——即任两个相邻节点 $u, v$ 异色。

反证：假设某相邻节点 $u, v$ 同色，即 $\mathtt{dist}(s, u) \equiv \mathtt{dist}(s, v) \pmod 2$。

考虑从 $s$ 到 $u$ 的最短路 $P_u$，从 $s$ 到 $v$ 的最短路 $P_v$。把它们和边 $(u, v)$ 拼成一条**闭游走**：

$$W:\; s \xrightarrow{P_u} u \xrightarrow{(u,v)} v \xrightarrow{P_v^{-1}} s$$

总长度 $|P_u| + 1 + |P_v|$，由同奇偶性知 $|P_u| + |P_v|$ 为偶数，所以 $|W|$ 为奇数。

**关键引理**：任何闭游走的边集都可以分解为若干简单环的边集的不相交并。当总边数为奇数时，至少有一个分解出的环长度为奇数。

由此 $G$ 含奇环——矛盾于"无奇环"假设。$\blacksquare$

### BFS 染色算法的正确性

**命题**：BFS 染色算法返回 `true` $\Leftrightarrow$ 图是二分图。

**证明**：

"算法返回 `true` $\Rightarrow$ 二分图"：算法成功完成时给出了合法的 2-染色（每条边两端异色）——按此染色把节点分两部，即得二部划分。

"二分图 $\Rightarrow$ 算法返回 `true`"：若图是二分图，由上述等价定理图无奇环。算法本质是"按距离起点奇偶性染色"——若某两个相邻节点被染同色，相当于发现了一个奇环（如上证），与无奇环矛盾。所以算法不会触发冲突，返回 `true`。$\blacksquare$

### DFS 染色等价于 BFS 染色（结果一致）

**命题**：BFS 染色和 DFS 染色对**同一连通块**给出的"颜色分布"完全一致（在固定起点颜色后）。

**证明**：起点 $s$ 染色 1。沿任意路径走奇数步颜色为 2，偶数步颜色为 1——这只取决于"到 $s$ 的某条路径长度的奇偶性"。

无奇环时，从 $s$ 到任意节点 $v$ 的所有路径**奇偶性相同**（否则存在两条不同奇偶性的路径，拼起来形成奇环）。所以每个节点的颜色由"到 $s$ 距离的奇偶性"唯一决定，与遍历顺序无关。BFS 和 DFS 得到的颜色分布相同。$\blacksquare$

### 复杂度的来源

每个节点入队 / 出队一次，每条边在两端各被检查一次。总计 $O(n + m)$。$\blacksquare$

## 几个边界情形

- **空图（无边）**：所有节点可任意染色，是二分图

- **单点图**：是二分图

- **含自环**：自环 $(v, v)$ 等价于长度 1 的环（奇环）——必非二分图。算法中染色 $v$ 为 1 后，遍历 $v$ 的邻居发现 $v$ 自己已染色为 1，返回 `false`

- **重边**：不影响——多次检查同一颜色对，结果一致
