#难度/★★★★

> 匈牙利算法：依次为每个左部点 DFS 寻找增广路，找到就翻转使匹配数 +1，找不到就略过——所有左部点处理完即得最大匹配。

## 核心思想

**匹配（matching）**：边集 $M \subseteq E$，使得 $M$ 中任意两条边没有公共端点。$M$ 中的边称**匹配边**，被某条匹配边覆盖的点称**已匹配点**，否则称**未匹配点**。

**最大匹配**：$|M|$ 最大的匹配。在二分图中求最大匹配是经典问题，匈牙利算法是最常用的解法。

**核心概念——增广路（augmenting path）**：

> 一条以**未匹配点**起、以**未匹配点**止、沿途交替走"非匹配边、匹配边、非匹配边、匹配边、……"的路径。

增广路有一个奇妙的性质——**翻转它就能让匹配数 +1**。具体地，把增广路上每条边的"匹配状态"翻转（匹配 ↔ 非匹配）：原本匹配的非匹配边变多 1 条，匹配边变少 1 条。由增广路定义，"非匹配边比匹配边多 1 条"，所以净增 1。

**Berge 定理（最大匹配的等价刻画）**：

> $M$ 是最大匹配 $\Leftrightarrow$ 不存在关于 $M$ 的增广路。

匈牙利算法基于此——**只要还能找到增广路就反复增广，直到找不到为止**。

实现上利用二分图的特殊结构：增广路必然以左部未匹配点起、以右部未匹配点止。所以**对每个左部点 $u$ 调用 DFS 尝试找增广路**——

> $\mathtt{dfs}(u)$：枚举 $u$ 的每个右部邻居 $v$。

> - 若 $v$ 未被本轮访问过，标记访问。

> - 若 $v$ 当前未匹配，配对成功 $(u, v)$，返回 `true`。

> - 否则递归 $\mathtt{dfs}(\mathtt{match\_r}[v])$ 看 $v$ 当前的配偶能否换个伴儿——能换则 $u$ 抢走 $v$，返回 `true`。

DFS 失败返回 `false`，说明 $u$ 在当前匹配下找不到增广路，跳过。

## 适用场景

- **二分图最大匹配**（最经典应用）

- **二分图最小点覆盖**：König 定理——最大匹配数 = 最小点覆盖数

- **二分图最大独立集**：等于 $n$ - 最大匹配数

- **DAG 最小不相交路径覆盖**：转化为二分图最大匹配（每个节点拆成入点和出点）

- 经典模型：棋盘覆盖、任务分配、稳定婚配的某些变种、某些覆盖问题

- 不适用：**一般图最大匹配**（要用带花树 / Blossom 算法）；**带权二分图匹配**（用 KM 算法）；规模过大（用 Hopcroft-Karp 把复杂度降到 $O(E\sqrt{V})$）

## 步骤拆解

1. 通过 [[二分图判定]] 确认二分图，分出左部 $L$、右部 $R$

2. 初始化 $\mathtt{match\_r}[v] = 0$（$v$ 未匹配）

3. 对每个左部点 $u$ 从 1 到 $|L|$：

   a. 重置 $\mathtt{used}[]$ 为全 `false`（本轮 DFS 中已访问过的右部点）

   b. 调用 $\mathtt{dfs}(u)$ 尝试找增广路；成功则匹配数 + 1

4. 总匹配数即最大匹配

## 代码模板

**模板：匈牙利算法**

```cpp

class hungarian {

private:

    int n_left, n_right;

    vector<vector<int>> g;                      // g[u] = u 在右部的邻居

    vector<int> match_r;                        // match_r[v] = 与 v 配对的左部点（0 = 未匹配）

    vector<bool> used;                          // 本轮 DFS 中已访问的右部点

    bool dfs(int u) {

        for (int v : g[u]) {

            if (used[v]) {

                continue;

            }

            used[v] = true;

            if (match_r[v] == 0 || dfs(match_r[v])) {

                match_r[v] = u;

                return true;

            }

        }

        return false;

    }

public:

    hungarian(int nl, int nr, vector<vector<int>>& g_in) {

        n_left = nl;

        n_right = nr;

        g = g_in;

    }

    int max_matching() {

        match_r.assign(n_right + 1, 0);

        int total = 0;

        for (int u = 1; u <= n_left; u++) {

            used.assign(n_right + 1, false);

            if (dfs(u)) {

                total += 1;

            }

        }

        return total;

    }

};
```

> 💡 **`used[]` 每轮重置的必要性**：每次为新的左部点找增广路时，是从该点出发的全新搜索过程，前一次的访问标记不该影响本次。但**同一轮内不能重复访问**——否则可能死循环（递归回到自己）。

> 💡 **DFS 中"递归换匹配"的妙处**：当遇到 $v$ 已被 $\mathtt{match\_r}[v]$ 占用时，递归 $\mathtt{dfs}(\mathtt{match\_r}[v])$——本质是问"原来的左部点能否让出 $v$ 改去配别人"。这一句递归本身就是在沿增广路探索：如果原配能找到新欢，$u$ 就能抢到 $v$，整条交替路径完成翻转。

## 复杂度分析

- 时间复杂度：$O(V \cdot E)$。每个左部点 DFS 一次，单次 DFS 最坏遍历所有边。

- 空间复杂度：$O(V + E)$

- 进阶：**Hopcroft-Karp 算法**通过同时进行多条增广，可达 $O(E\sqrt{V})$

## 正确性证明

### Berge 定理：最大匹配的等价刻画

**Berge 定理**：匹配 $M$ 是最大匹配 $\Leftrightarrow$ 不存在关于 $M$ 的增广路。

**"$\Rightarrow$"（最大 $\Rightarrow$ 无增广路）（反证）**：

若存在关于 $M$ 的增广路 $P$，长度 $2k + 1$（含 $k$ 条匹配边、$k + 1$ 条非匹配边）。

定义 $M' = M \oplus P$（对称差）——把 $P$ 上每条边的匹配状态翻转。

$M'$ 仍是合法匹配：$P$ 内部的边状态自洽（翻转后仍是交替结构，且端点匹配关系局部正确）；$P$ 外部的边状态不变。

$|M'| = |M| - k + (k + 1) = |M| + 1$，与 $M$ 最大矛盾。$\blacksquare$

**"$\Leftarrow$"（无增广路 $\Rightarrow$ 最大）（反证 + 对称差分析）**：

假设 $M$ 不是最大，存在 $M'$ 使 $|M'| > |M|$。考察对称差 $D = M \oplus M'$（即只属于 $M$ 或 $M'$ 之一的边集）。

**关键观察**：$D$ 中每个节点的度 $\le 2$。理由：每个节点在 $M$ 中至多被一条边覆盖（匹配定义），在 $M'$ 中也至多被一条边覆盖——所以在 $D$ 中至多两条边。

**$D$ 的连通分量是简单路径或简单环**：度 $\le 2$ 的图的连通分量必是路径或环。

**环上 $M$ 边和 $M'$ 边交替**：环上每个节点在 $D$ 中度恰为 2，一条来自 $M$、一条来自 $M'$（不可能两条都来自 $M$，否则该节点在 $M$ 中度 $\ge 2$，违反匹配性）。所以环长偶数，$M$ 和 $M'$ 在环上各贡献一半边。

**路径上 $M$ 边和 $M'$ 边也交替**：同理。

由 $|M'| > |M|$，$D$ 中 $M'$ 边数 $>$ $M$ 边数。环上两者相等——所以一定有某条路径其上 $M'$ 边比 $M$ 边多，即"$M'$ 边数 $-$ $M$ 边数 $= 1$"，意味着路径**长度奇数**且**起讫点在 $M$ 中均未匹配**。

> 详细一点：若路径起点 $u$ 在 $M$ 中匹配，匹配边端点的另一头 $u'$ 也在路径上（否则路径不会终止于 $u$）——但 $u, u'$ 都在路径上意味着路径不止于 $u$，矛盾。

这条路径就是关于 $M$ 的增广路——与"无增广路"假设矛盾。$\blacksquare$

### 匈牙利算法的正确性

**核心命题**：匈牙利算法终止时，得到的匹配 $M$ 是最大匹配。

**证明**：算法对每个左部点 $u = 1, 2, \ldots, |L|$ 依次尝试找增广路——

**关键不变量**：对左部点 $u$ 调用 DFS 失败后，**算法剩余过程中也找不到以 $u$ 为起点的增广路**。

**证明（草图）**：DFS 失败意味着从 $u$ 出发，沿任意"M 交替路径"都到达不了未匹配的右部点——所有可达的右部点都已"完美匹配"，且其匹配方也走不到外面。后续匹配的修改都是为其他左部点 $u' > u$ 增广，这些操作只可能让某些右部点的匹配方变化，但不会"打开"新的可达性。

更严格的证明依赖于一个性质——若 $\mathtt{dfs}(u)$ 失败时探索过的"$M$ 交替子图"在后续算法中保持封闭，详细论证略。这条性质允许算法对每个左部点只尝试一次。

**算法终止时无增广路**：所有左部点都已尝试。任一未匹配左部点已被 DFS 尝试过且失败，所以不存在以它为起点的增广路；二分图中增广路必以左部未匹配点起、右部未匹配点止——所以不存在任何增广路。

由 Berge 定理，$M$ 是最大匹配。$\blacksquare$

### DFS 中"换匹配"的本质

DFS 的关键步骤：

```cpp

if (match_r[v] == 0 || dfs(match_r[v])) {

    match_r[v] = u;

    return true;

}

```

这等价于在沿"M 交替路径"探索：

```

u --(非匹配边)--> v --(匹配边)--> match_r[v] --(非匹配边)--> v' --(匹配边)--> ...

```

DFS 递归到 $\mathtt{match\_r}[v]$ 后，它再去找新的右部邻居——这正是增广路上的下一个"非匹配边"。如果递归最终找到一个未匹配右部点，整条递归调用栈就构成了一条增广路。

返回时层层翻转匹配（每层赋值 $\mathtt{match\_r}[v] = u$）——这就是增广路翻转的具体实现。

### 复杂度的来源

外层循环 $|L|$ 次，每次 DFS 最多遍历所有边（每条边在 $\mathtt{used}$ 标记下最多被检查一次）——总 $O(V \cdot E)$。

实际复杂度通常远好于上界，因为大多数 DFS 只走几步就成功。Hopcroft-Karp 通过 BFS 分层 + 多增广路同时翻转把上界优化到 $O(E\sqrt{V})$。$\blacksquare$

## 重要扩展：König 定理

**König 定理**：在二分图中，**最大匹配数 = 最小点覆盖数**。

> 最小点覆盖：选最少的点，使得每条边至少有一个端点被选中。

这个定理把"边集问题"转化为"点集问题"——很多覆盖类题目可以用最大匹配求解。

进一步推论：**最大独立集 = $n$ - 最大匹配**。

> 最大独立集：选最多的点，使得它们两两之间无边。
