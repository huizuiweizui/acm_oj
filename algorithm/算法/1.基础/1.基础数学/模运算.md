#难度/★

> 处理"取余"的运算，配合各种性质可在大数运算中保持结果不爆数据类型。

## 核心思想

模运算 $a \bmod p$ 的本质是求 $a$ 除以 $p$ 的余数。当题目要求结果对某个 $p$ 取模时，**不需要算出最终大数再取模**——只要在中间过程中合理地取模，就能让所有中间值始终保持在 $[0, p)$ 范围内，避免溢出。

模运算具有以下重要性质：

| 性质  | 公式                                                              |
| --- | --------------------------------------------------------------- |
| 加法  | $(a + b) \bmod p = ((a \bmod p) + (b \bmod p)) \bmod p$         |
| 减法  | $(a - b) \bmod p = ((a \bmod p) - (b \bmod p) + p) \bmod p$     |
| 乘法  | $(a \cdot b) \bmod p = ((a \bmod p) \cdot (b \bmod p)) \bmod p$ |
| 幂   | $a^k \bmod p$ 用 [[快速幂]]                                         |
| 除法  | **不能直接取模！** 需要 [[乘法逆元]]                                         |

## 适用场景

- 题目明确要求结果 $\bmod\ p$（最常见的 $p = 10^9 + 7$ 或 $998244353$，均为质数）

- 防止中间结果溢出 `long long`

- 几乎所有计数类题目（[[计数dp]]、[[组合数]]、[[矩阵快速幂]] 等）

## 步骤拆解

**取模的位置**：原则是"**该取就取**"。每次乘法之后立即取模最稳妥；加法在不溢出的前提下可以不取，最后再统一取一次。

**减法防负数**：$a - b$ 在模意义下可能为负（因为 $a \bmod p$ 可能小于 $b \bmod p$），所以要 $+ p$ 再取模一次：

**除法用逆元**：在质数模 $p$ 下，由费马小定理：

$$a^{-1} \equiv a^{p-2} \pmod p$$

详见 [[乘法逆元]]。

## 代码模板

```cpp

const long long MOD = 1e9 + 7;


// 加：a + b

long long add_mod(long long a, long long b) {

    return (a % MOD + b % MOD) % MOD;

}


// 减：a - b（结果保证非负）

long long sub_mod(long long a, long long b) {

    return ((a - b) % MOD + MOD) % MOD;

}


// 乘：a * b（注意 long long 乘法仍可能溢出，见下方注意）

long long mul_mod(long long a, long long b) {

    return a % MOD * (b % MOD) % MOD;

}

```

> 💡 **负数取模**：C++ 中 `(-7) % 3` 结果为 `-1` 而非 `2`。如果可能出现负数，统一写成 `((x % p) + p) % p`。

## 复杂度分析

- 时间复杂度：单次取模 $O(1)$

- 空间复杂度：$O(1)$

## 正确性证明

模运算性质的证明都基于"整数除法的唯一性"——任意整数 $a$ 可唯一写成 $a = qp + r$，其中 $0 \le r < p$。

**加法性质**：设 $a = q_1 p + r_1$，$b = q_2 p + r_2$，则

$$a + b = (q_1 + q_2) p + (r_1 + r_2)$$

所以 $(a + b) \bmod p = (r_1 + r_2) \bmod p$。

乘法、减法的证明完全类似，只需把 $a, b$ 的分解代入即可。$\blacksquare$

**为什么除法不能直接取模**：因为 $a / b$ 在模 $p$ 下未必有整数解。例如 $p = 7$，$6 / 2 = 3$，但 $(6 \bmod 7) / (2 \bmod 7) = 6 / 2 = 3$ ——这种情形碰巧对，但更一般地，当 $b$ 不能整除 $a$ 时（如 $5 / 2$），就完全没有整数除法的概念了。所以需要逆元。
