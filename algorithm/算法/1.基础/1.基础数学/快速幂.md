#难度/★

> 通过二进制分解指数，将 $O(b)$ 的幂运算优化到 $O(\log b)$。

## 前置知识

- [[位运算]]

- [[模运算]]

## 核心思想

把指数 $b$ 写成二进制形式，比如 $b = 13 = (1101)_2 = 8 + 4 + 1$，那么：

$$a^{13} = a^{8+4+1} = a^8 \cdot a^4 \cdot a^1$$

只需要预处理 $a^1, a^2, a^4, a^8, \dots$ 这些"基幂"（每个由前一个平方得到），然后根据 $b$ 的二进制位选择性地相乘即可。总共只有 $\lfloor \log_2 b \rfloor + 1$ 个二进制位，因此循环次数从 $b$ 次降到 $\log b$ 次。

## 适用场景

- 求 $a^b$ 或 $a^b \bmod p$，其中 $b$ 可能非常大（$b \le 10^9$ 甚至 $10^{18}$）

- 配合矩阵运算可得 [[矩阵快速幂]]，加速线性递推

- 求 [[乘法逆元]]：在质数模 $p$ 下，由费马小定理有 $a^{-1} \equiv a^{p-2} \pmod p$

- 不适用：当"乘法"不满足结合律时，不能用快速幂

## 步骤拆解

1. 初始化结果 `ans = 1`

2. 当 `b > 0`：
    - 如果 `b` 的二进制最低位为 1，则 `ans *= a`
    - `a` 自身平方：`a = a * a`
    - `b` 右移一位：`b >>= 1`

3. 循环结束，`ans` 即为答案

## 代码模板

```cpp
// 求 a^b mod p
long long fast_power(long long a, long long b, long long p) {

    long long ans = 1 % p;       // 兼容 p = 1 的边界
    
    a %= p;                      // 防止初始 a 过大
    
    while (b > 0) {
    
        if (b & 1) {             // 不要写 b & 1 == 1，== 优先级比 & 高
        
            ans = ans * a % p;
            
        }
        
        a = a * a % p;           // 当 mod 接近 1e18 时此处会爆 long long
        
        b >>= 1;
        
    }
    
    return ans;
    
}
```

## 复杂度分析

- 时间复杂度：$O(\log b)$

- 空间复杂度：$O(1)$

## 正确性证明

设 $b$ 的二进制表示为 $b = \sum_{i=0}^{k} c_i \cdot 2^i$，其中 $c_i \in {0, 1}$，则：

$$a^b = a^{\sum c_i \cdot 2^i} = \prod_{i=0}^{k} a^{c_i \cdot 2^i} = \prod_{i ,:, c_i = 1} a^{2^i}$$

循环过程中，第 $i$ 轮迭代时变量 `a` 实际存储的是 $a^{2^i}$（每轮自身平方一次），而 `b >>= 1` 等价于检查 `b` 的从低到高第 $i$ 位 $c_i$。当 $c_i = 1$ 时把 $a^{2^i}$ 乘入答案，正好对应上式。

因此循环结束时，`ans` 等于所有满足 $c_i = 1$ 的 $a^{2^i}$ 之积，即 $a^b$。$\blacksquare$
