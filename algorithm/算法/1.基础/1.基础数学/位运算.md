#难度/★

> 直接对二进制位进行操作的运算，是计算机底层最高效的运算方式。

## 核心思想

计算机以二进制存储所有数据，位运算直接操作这些 0/1 位。理解每种位运算的本质行为，并用它们组合出"取 / 设 / 清 / 翻"某一位的操作，是处理状态压缩、集合表示、数据优化的基本功。

六种基本位运算：

| 运算  | 符号   | 行为                           |
| --- | ---- | ---------------------------- |
| 与   | `&`  | 两位都为 1 才为 1                  |
| 或   | `\|` | 任一位为 1 即为 1                  |
| 异或  | `^`  | 两位不同才为 1                     |
| 非   | `~`  | 按位取反                         |
| 左移  | `<<` | 高位丢弃，低位补 0（相当于乘 $2^k$）       |
| 右移  | `>>` | 低位丢弃，高位补 0 / 符号位（相当于除 $2^k$） |

## 适用场景

- 状态压缩（[[状压dp]]、[[状压BFS]]）：用一个整数的二进制位表示一个集合

- 快速判断奇偶：`x & 1`

- 快速乘除 $2^k$：`x << k` / `x >> k`

- [[快速幂]] 中提取指数的二进制位

- lowbit 操作：[[树状数组]] 的核心

- 异或的"自反性"：`a ^ a = 0`、`a ^ 0 = a`，常用于"找出现奇数次的数"等

## 步骤拆解

针对单个二进制位的常用操作（设第 $b$ 位，从 0 计数）：

| 目的                | 表达式             |
| ----------------- | --------------- |
| 取出 $a$ 的第 $b$ 位   | `(a >> b) & 1`  |
| 把 $a$ 的第 $b$ 位置 1 | `a \| (1 << b)` |
| 把 $a$ 的第 $b$ 位清 0 | `a & ~(1 << b)` |
| 翻转 $a$ 的第 $b$ 位   | `a ^ (1 << b)`  |

## 代码模板

```cpp

// 整体移位
long long shl  = a << b;              // 左移 b 位

long long shr  = a >> b;              // 右移 b 位

  

// 单位操作（操作第 b 位，从 0 计数）
long long bit  = (a >> b) & 1;        // 取出第 b 位

long long set1 = a | (1LL << b);      // 第 b 位置 1

long long clr  = a & ~(1LL << b);     // 第 b 位清 0

long long flip = a ^ (1LL << b);      // 第 b 位翻转

```

> ⚠️ **注意**：`1 << b` 中 `1` 默认是 `int`，当 $b \ge 31$ 时会触发未定义行为。涉及大数时务必写成 `1LL << b` 或 `(long long)1 << b`。

## 复杂度分析

- 时间复杂度：每次位运算 $O(1)$

- 空间复杂度：$O(1)$

## 正确性证明

位运算由 CPU 指令直接支持，行为由处理器架构定义。这里只对几个常用组合做说明：


**取第 $b$ 位**：`a >> b` 把第 $b$ 位移到最低位，再 `& 1` 屏蔽掉其他位，结果即为该位的值。

**置第 $b$ 位为 1**：`1 << b` 是一个仅第 $b$ 位为 1 的"掩码"，与 `a` 做或运算后，第 $b$ 位必为 1，其他位不变。

**清第 $b$ 位**：`~(1 << b)` 是一个仅第 $b$ 位为 0 的掩码，与 `a` 做与运算后，第 $b$ 位必为 0，其他位不变。

**翻转第 $b$ 位**：异或的性质 $x \oplus 1 = \lnot x$、$x \oplus 0 = x$，所以仅第 $b$ 位被翻转。$\blacksquare$
