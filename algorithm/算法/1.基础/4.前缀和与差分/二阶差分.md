#难度/★★

  > 在差分上再做一次差分，把"区间加等差数列"也变成 $O(1)$ 操作。

## 前置知识

- [[差分]]

## 核心思想

普通 [[差分]] 把"区间加常数 $v$"变成两次单点修改。但如果操作是"区间加一个**等差数列**"——即 $a[l], a[l+1], \ldots, a[r]$ 分别加上 $K, K+D, K+2D, \ldots, K+(r-l)D$——普通差分就力不从心了。

这时回到差分的本质：**差分就是相邻项的差**。而等差数列的相邻项之差是常数 $D$，于是对差分数组 $d$ 进行"区间加 $D$"操作，再加上对端点的修正，就能完成对原数组的"区间加等差数列"。

而"对差分数组做区间加常数"……正是再做一次差分！这就是**二阶差分**：定义 $d_2[i] = d[i] - d[i-1]$，对 $d_2$ 做单点修改就能影响 $d$ 的一段后缀，进而影响 $a$ 的更复杂结构。

## 适用场景

- 区间加等差数列（首项 $K$，公差 $D$），最后查询整个数组

- 推广到区间加多项式（$k$ 阶差分对应 $k-1$ 次多项式，但实战中很少用到 $k \ge 3$）

- 不适用：边修改边查询单点或区间和（应使用 [[树状数组]] 或 [[线段树]]）

## 步骤拆解

设要对区间 $[l, r]$ 加首项为 $K$、公差为 $D$ 的等差数列，即对每个 $i \in [l, r]$ 加上 $K + (i - l) D$。

**对一阶差分 $d$ 的影响**：

| 位置                   | $d$ 的变化          |
| -------------------- | ---------------- |
| $d[l]$               | $+K$             |
| $d[l+1] \ldots d[r]$ | 每个 $+D$          |
| $d[r+1]$             | $-(K + (r-l) D)$ |

**对二阶差分 $d_2$ 的影响**（对 $d$ 再差分）：

| 位置         | $d_2$ 的变化          |
| ---------- | ------------------ |
| $d_2[l]$   | $+K$               |
| $d_2[l+1]$ | $+(D - K)$         |
| $d_2[r+1]$ | $-(K + (r-l+1) D)$ |
| $d_2[r+2]$ | $+(K + (r-l) D)$   |

只需修改这 **4 个位置**，每次区间加等差数列就变成 $O(1)$。

最后还原：先对 $d_2$ 做一次前缀和得到 $d$，再对 $d$ 做一次前缀和得到原数组的增量。

## 代码模板

```cpp
const int n = 1e5 + 5;

vector<long long> d2(n + 3);   // 二阶差分数组

// 区间 [l, r] 加首项为 K、公差为 D 的等差数列

auto range_add_ap = [&](int l, int r, long long K, long long D) {

    d2[l]     += K;

    d2[l + 1] += D - K;

    d2[r + 1] -= K + (long long)(r - l + 1) * D;

    d2[r + 2] += K + (long long)(r - l) * D;

};

// 还原原数组（两次前缀和）

for (int i = 1; i <= n; i++) d2[i] += d2[i - 1];   // d2 -> d

for (int i = 1; i <= n; i++) d2[i] += d2[i - 1];   // d  -> 增量数组

// 此时 d2[i] 即为原数组每个位置的增量

```

> ⚠️ **数组开大一点**：因为会修改到 $r+2$。

## 复杂度分析

- 时间复杂度：每次区间加等差数列 $O(1)$，$m$ 次修改后还原 $O(n)$，总 $O(n + m)$

- 空间复杂度：$O(n)$

## 正确性证明

由 [[差分]] 的定义和性质，对原数组 $a$ 执行区间加等差数列操作 $(l, r, K, D)$ 后：

新的一阶差分 $d'[i] - d[i]$ 在各位置的变化为：

$$\Delta d[i] = \begin{cases} K & i = l \\ D & l < i \le r \\ -(K + (r-l) D) & i = r+1 \\ 0 & \text{其他} \end{cases}$$

  
即 $\Delta d$ 是一个"分段常数函数"。再对 $\Delta d$ 做差分得到 $\Delta d_2[i] = \Delta d[i] - \Delta d[i-1]$，只在四个分段交界处非零：

- $i = l$：$\Delta d_2[l] = K - 0 = K$

- $i = l+1$：$\Delta d_2[l+1] = D - K$

- $i = r+1$：$\Delta d_2[r+1] = -(K + (r-l) D) - D = -(K + (r-l+1) D)$

- $i = r+2$：$\Delta d_2[r+2] = 0 - (-(K + (r-l) D)) = K + (r-l) D$

这正好对应代码中的四次修改。$\blacksquare$
