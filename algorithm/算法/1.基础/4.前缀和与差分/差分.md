#难度/★

> 前缀和的"逆运算"：用 $O(1)$ 完成区间加，最后 $O(n)$ 还原数组。

## 前置知识

- [[前缀和]]

## 核心思想

定义差分数组 $d[i] = a[i] - a[i-1]$（约定 $a[0] = 0$）。

容易验证：$a[i]$ 等于 $d[1 \ldots i]$ 的前缀和：

$$a[i] = \sum_{k=1}^{i} d[k]$$


这意味着对差分数组的**单点修改**会影响原数组的**一段后缀**。利用这个性质，对原数组区间 $[l, r]$ 加 $v$ 的操作可以转化为：

$$d[l] \mathrel{+}= v, \quad d[r+1] \mathrel{-}= v$$

这样只用 2 次单点修改就完成了一次区间修改，把 $O(n)$ 降到了 $O(1)$。

## 适用场景

- **离线**多次区间加，最后一次性查询整个数组

- 处理"区间整体增减"，如人数登记、签到统计、温度变化等

- 二维矩阵的区间加（二维差分）

- 不适用：边修改边查询单点（应使用 [[树状数组]]）；区间加 + 区间求和（应使用 [[懒标记线段树]]）

## 步骤拆解

1. 读入原数组 $a[1 \ldots n]$，构造差分数组 $d[i] = a[i] - a[i-1]$

2. 对每个区间修改操作 $(l, r, v)$：$d[l] \mathrel{+}= v$，$d[r+1] \mathrel{-}= v$

3. 最后通过前缀和还原：$a[i] = a[i-1] + d[i]$（也可以直接对 $d$ 做前缀和）

## 代码模板

```cpp
const int n = 1e5 + 5;

vector<long long> a(n + 1), d(n + 1);

// 1. 构造差分数组

for (int i = 1; i <= n; i++) {

    cin >> a[i];

    d[i] = a[i] - a[i - 1];

}

// 2. 区间加：O(1)

auto range_add = [&](int l, int r, long long v) {

    d[l]     += v;

    d[r + 1] -= v;

};

// 3. 还原数组：O(n)

for (int i = 1; i <= n; i++) {

    a[i] = a[i - 1] + d[i];

}

```

## 二维扩展

二维差分用容斥的方式定义：

$$d[i][j] = a[i][j] - a[i-1][j] - a[i][j-1] + a[i-1][j-1]$$

对子矩阵 $(x_1, y_1) \to (x_2, y_2)$ 区间加 $v$ 的操作转化为四个角点的修改：

```cpp

d[x1][y1]     += v;

d[x2+1][y1]   -= v;

d[x1][y2+1]   -= v;

d[x2+1][y2+1] += v;

```

最后做二维前缀和即可还原。

## 复杂度分析

- 时间复杂度：每次区间修改 $O(1)$，$m$ 次修改后还原 $O(n)$，总 $O(n + m)$

- 空间复杂度：$O(n)$

## 正确性证明

设差分数组 $d[i] = a[i] - a[i-1]$，$a[0] = 0$。

**关系式**：$a[i] = \sum_{k=1}^{i} d[k]$（数学归纳法可证：$a[i] = a[i-1] + d[i] = \sum_{k=1}^{i-1} d[k] + d[k]$）。

**区间加的正确性**：对原数组区间 $[l, r]$ 每个位置加 $v$，相当于将 $a[i]$ 改为 $a'[i] = a[i] + v \cdot [l \le i \le r]$。

新差分 $d'[i] = a'[i] - a'[i-1]$，分情况讨论：

- $i = l$ 时：$d'[l] = (a[l] + v) - a[l-1] = d[l] + v$

- $l < i \le r$ 时：$d'[i] = (a[i] + v) - (a[i-1] + v) = d[i]$

- $i = r + 1$ 时：$d'[r+1] = a[r+1] - (a[r] + v) = d[r+1] - v$

- 其他位置不变

所以只需修改 $d[l]$ 和 $d[r+1]$ 两个位置。$\blacksquare$
