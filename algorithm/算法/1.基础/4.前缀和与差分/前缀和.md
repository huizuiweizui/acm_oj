#难度/★

  > 用 $O(n)$ 预处理换取后续每次区间和查询 $O(1)$ 的经典思想。

## 核心思想

定义前缀和数组 $\text{pre}[i] = a[1] + a[2] + \cdots + a[i]$，约定 $\text{pre}[0] = 0$。

则任意区间 $[l, r]$ 的和可在 $O(1)$ 时间求出：

$$\sum_{i=l}^{r} a[i] = \text{pre}[r] - \text{pre}[l-1]$$

本质是把"区间求和"转化为"两点之差"——典型的**空间换时间**与**预处理换查询**思想。

## 适用场景

- 数组**静态**（不会修改），需要多次查询区间和

- 二维矩阵区间和（二维前缀和）

- 区间统计满足某性质的元素个数（前缀计数）

- 与哈希表配合解决"区间和等于 $k$"等问题

- 不适用：数组会被修改的情况（应使用 [[树状数组]] 或 [[线段树]]）

## 步骤拆解

1. 读入原数组 $a[1 \ldots n]$

2. 递推计算 $\text{pre}[i] = \text{pre}[i-1] + a[i]$

3. 查询 $[l, r]$ 的区间和时，输出 $\text{pre}[r] - \text{pre}[l-1]$

## 代码模板

```cpp
const int n = 1e5 + 5;

vector<long long> pre(n + 1);

// 预处理：O(n)

for (int i = 1; i <= n; i++) {

    cin >> a[i];

    pre[i] = pre[i - 1] + a[i];

}

// 查询 [l, r] 区间和：O(1)

long long query(int l, int r) {

    return pre[r] - pre[l - 1];

}

```
  
## 二维扩展

设 $\text{pre}[i][j]$ 表示左上角 $(1,1)$ 到右下角 $(i,j)$ 的子矩阵和：

$$\text{pre}[i][j] = \text{pre}[i-1][j] + \text{pre}[i][j-1] - \text{pre}[i-1][j-1] + a[i][j]$$

查询子矩阵 $(x_1, y_1) \to (x_2, y_2)$ 的和：

$$\text{pre}[x_2][y_2] - \text{pre}[x_1-1][y_2] - \text{pre}[x_2][y_1-1] + \text{pre}[x_1-1][y_1-1]$$

容斥原理的直接体现。

## 复杂度分析

- 时间复杂度：预处理 $O(n)$，查询 $O(1)$

- 空间复杂度：$O(n)$

## 正确性证明

由定义 $\text{pre}[i] = \sum_{k=1}^{i} a[k]$，则：

$$\text{pre}[r] - \text{pre}[l-1] = \sum_{k=1}^{r} a[k] - \sum_{k=1}^{l-1} a[k] = \sum_{k=l}^{r} a[k]$$

即为所求区间和。$\blacksquare$
