#难度/★★★★

> 把序列上的前缀和与差分思想搬到树结构上，处理树上路径、子树的统计与修改。

- [[前缀和]]

- [[差分]]

## 核心思想

序列上的 [[前缀和]] 把"区间求和"变成"两点之差"；[[差分]] 把"区间加"变成两次单点修改。这两种思想可以**完全平移到树上**，只要把"区间"换成"路径"或"子树"即可。

**树上前缀和**：维护 $s[u] = \sum_{v \in \text{path}(\text{root}, u)} a[v]$，即从根到 $u$ 路径上所有点权之和。则 $u$ 到 $v$ 路径权值和为：

$$\text{sum}(u, v) = s[u] + s[v] - 2 \cdot s[\text{lca}(u, v)] + a[\text{lca}(u, v)]$$

——把根到两点的前缀和加起来，再扣掉两次"重复经过的部分"（根到 lca），最后把 lca 自身补回来一次。

**树上差分**：分**点差分**和**边差分**两种，分别用于处理"路径上每个点 $+v$"或"路径上每条边 $+v$"。最后通过一次 [[DFS]] 自下而上累加 子树和，即得每个点 / 边的最终值。

## 适用场景

- **路径权值和**（树上前缀和）：多次询问树上两点路径的点权 / 边权之和

- **路径计数**（树上点差分）：多次"路径覆盖 +1"操作，最后查询每个点被覆盖的次数

- **路径加权**（树上边差分）：多次"路径上每条边 +$v$"，最后查询每条边的权值

- **子树修改 / 查询**（DFS 序差分）：把子树映射成 DFS 序上的连续段，转化为序列差分

- 不适用：路径 / 子树需要**在线**修改（应使用 [[树链剖分]]）

## 步骤拆解

### 1. 树上前缀和

预处理（一次 DFS）：

```
s[root] = a[root]

对其他点 u： s[u] = s[parent[u]] + a[u]
```

查询路径 $(u, v)$ 权值和：先求 $w = \text{lca}(u, v)$，套公式即可。

### 2. 树上点差分

要让路径 $(u, v)$ 上每个点权 $+x$，记 $w = \text{lca}(u, v)$。在差分数组 $d$ 上做四次单点修改：

$$d[u] \mathrel{+}= x,\quad d[v] \mathrel{+}= x,\quad d[w] \mathrel{-}= x,\quad d[\text{parent}(w)] \mathrel{-}= x$$

最后 DFS 自下而上累加子树和：$a[u] += \sum_{v \in \text{children}(u)} a[v]$（递归出栈时累加），即得每个点的最终增量。

### 3. 树上边差

边的修改不便直接维护，技巧是**把边权下放到深度较大的端点上**——节点 $u$ 维护它和父亲之间那条边的权值。这样路径 $(u, v)$ 上的每条边 $+x$ 等价于路径上每个点 $+x$，**但要除掉 lca**（lca 上方的边不在路径上）：

$$d[u] \mathrel{+}= x,\quad d[v] \mathrel{+}= x,\quad d[w] \mathrel{-}= 2x$$

然后 DFS 自下而上累加。

## 代码模板

**模板一：树上前缀和（路径权值和）**

```cpp
class tree_prefix_sum {

private:

    int n;

    vector<vector<int>> g;          // 邻接表

    vector<long long> a;            // 点权

    vector<long long> s;            // s[u] = root 到 u 路径上点权之和

    vector<int> parent, depth;

    // ... LCA 相关数据结构（如倍增 fa）

    void dfs(int u, int fa) {

        parent[u] = fa;

        depth[u] = (fa == 0 ? 0 : depth[fa] + 1);

        s[u] = (fa == 0 ? a[u] : s[fa] + a[u]);

        for (int v : g[u]) {

            if (v != fa) {

                dfs(v, u);

            }

        }

    }

public:

    tree_prefix_sum(int total, vector<long long>& a_in,

                    vector<vector<int>>& g_in, int root) {

        n = total;

        a = a_in;

        g = g_in;

        s.resize(n + 1, 0);

        parent.resize(n + 1, 0);

        depth.resize(n + 1, 0);

        dfs(root, 0);

    }

    // 查询路径 (u, v) 上所有点权之和。lca_uv 由外部 LCA 模块提供
    long long path_sum(int u, int v, int lca_uv) {

        return s[u] + s[v] - 2 * s[lca_uv] + a[lca_uv];

    }

};
```

> 💡 **边权版本**：把 $a[u]$ 改为 "$u$ 到父亲那条边的边权"，公式改为 `s[u] + s[v] - 2 * s[lca]`（不需要补回 lca，因为 lca 没有"向父亲的边"参与）。

**模板二：树上点差分（路径计数）**

```cpp

class tree_diff_node {

private:

    int n;

    vector<vector<int>> g;

    vector<long long> d;            // 差分数组

    vector<int> parent;

    // ... LCA

    void accumulate(int u, int fa) {

        for (int v : g[u]) {

            if (v != fa) {

                accumulate(v, u);

                d[u] += d[v];       // 自下而上累加：u 的最终值 = 自身 + 子树之和

            }

        }

    }

public:

    tree_diff_node(int total, vector<vector<int>>& g_in, int root) {

        n = total;

        g = g_in;

        d.resize(n + 1, 0);

        parent.resize(n + 1, 0);

        // 预处理 parent[]、LCA 等

    }

    // 路径 (u, v) 上每个点 += x。lca_uv、par_lca 由外部提供
    void path_add(int u, int v, int lca_uv, int par_lca, long long x) {

        d[u] += x;

        d[v] += x;

        d[lca_uv] -= x;

        if (par_lca != 0) {

            d[par_lca] -= x;

        }

    }

    // 一次性下推得到每个点的最终增量
    void finalize(int root) {

        accumulate(root, 0);

    }

    long long get(int u) {

        return d[u];

    }

};
```

**模板三：树上边差分**

```cpp

// 边 (u, parent[u]) 的权值由 u 节点维护
// 路径 (u, v) 上每条边 += x：

void path_edge_add(int u, int v, int lca_uv, long long x) {

    d[u] += x;

    d[v] += x;

    d[lca_uv] -= 2 * x;

}

// 最后 finalize 与点差分相同：自下而上累加

```

> ⚠️ **点差分与边差分的区别**：

> - 点差分要扣 `d[lca] -= x`、`d[par(lca)] -= x`（lca 也算路径上的点，但被左右两侧重复算了一次，再向上扣一次）

> - 边差分要扣 `d[lca] -= 2x`（lca 上方的边不在路径上，左右子树都要"切断"）

## 复杂度分析

- 时间复杂度：预处理 $O(n)$（DFS）+ $O(n \log n)$（[[LCA]]）；每次查询 / 修改 $O(\log n)$（LCA 查询主导）；finalize $O(n)$

- 空间复杂度：$O(n)$，加上 LCA 倍增数组的 $O(n \log n)$

## 正确性证明

### 1. 树上前缀和的容斥公式

**命题**：$\text{sum}(u, v) = s[u] + s[v] - 2 \cdot s[w] + a[w]$，其中 $w = \text{lca}(u, v)$。

**证明**：

设根到 $u$ 路径的点集为 $P_u$，根到 $v$ 路径的点集为 $P_v$，根到 $w$ 路径的点集为 $P_w$。

```

        root

         |

        ...

         |

         w

        / \

       ?   ?

      /     \

     u       v

```

由 $w = \text{lca}(u, v)$，路径 $P_u$ 和 $P_v$ 在 $w$ 之前完全重合（即都等于 $P_w$），$w$ 之后分别向 $u$ 和 $v$ 延伸——故 $P_u \cap P_v = P_w$。

由容斥原理：

$$|P_u \cup P_v|_{\text{权和}} = s[u] + s[v] - s[P_u \cap P_v]_{\text{权和}} = s[u] + s[v] - s[w]$$

但 $u \to v$ 的路径恰好是 $P_u \cup P_v$（即 $u \to w \to v$），所以路径权和 = $s[u] + s[v] - s[w]$。

**注意**：上式中 $s[w]$ 包含了 $w$ 自身的权值。但实际上 $w$ 在路径上只出现一次，被减了一次后正好抵消——若用 $-2 s[w] + a[w]$ 的形式，含义是"先减去两条根到 $w$ 的路径，再单独补回 $w$ 自己"，结果完全等价：

$$s[u] - s[w] + a[w] + s[v] - s[w] = s[u] + s[v] - 2s[w] + a[w]$$

读法：$s[u] - s[w]$ 是 $w$ 到 $u$ 的路径权和（不含 $w$），$s[v] - s[w]$ 是 $w$ 到 $v$ 的路径权和（不含 $w$），加上 $w$ 自己的权 $a[w]$ 即整条路径之和。$\blacksquare$

### 2. 树上点差分的下推等价性

**命题**：在差分数组 $d$ 上做修改 $d[u] +\!= x$、$d[v] +\!= x$、$d[w] -\!= x$、$d[\text{par}(w)] -\!= x$，然后做"子树累加"$a[u] = d[u] + \sum_{v \in \text{children}(u)} a[v]$，得到的 $a[u]$ 等价于"路径 $u \to v$ 上每个点 $+x$"的效果。

**证明**：

注意"子树累加"的本质——节点 $u$ 的最终值 $a[u] = \sum_{v \in \text{subtree}(u)} d[v]$（从树叶向上汇总整个子树的差分和）。

考虑任意节点 $z$，分析它的最终值有没有得到这个 $+x$：

$$a[z] = \sum_{y \in \text{subtree}(z)} d[y]$$

我们贡献的差分项有四个：$d[u] +\!= x$、$d[v] +\!= x$、$d[w] -\!= x$、$d[\text{par}(w)] -\!= x$。

对节点 $z$，**位于 $z$ 子树内的差分项**会贡献到 $a[z]$。设：

- $\alpha = [u \in \text{subtree}(z)]$

- $\beta = [v \in \text{subtree}(z)]$

- $\gamma = [w \in \text{subtree}(z)]$

- $\delta = [\text{par}(w) \in \text{subtree}(z)]$

则 $a[z]$ 增量 = $(\alpha + \beta - \gamma - \delta) \cdot x$。

**分类讨论**：

- **$z$ 在路径 $u \to w$ 上（不含 $w$）**：$u \in \text{subtree}(z)$，$v \notin$（因为 $v$ 在 $w$ 的另一侧），$w \notin$（$w$ 是 $z$ 的祖先），$\text{par}(w) \notin$。$(\alpha,\beta,\gamma,\delta) = (1, 0, 0, 0)$，增量 $+x$。✓

- **$z$ 在路径 $w \to v$ 上（不含 $w$）**：对称地 $(0, 1, 0, 0)$，增量 $+x$。✓

- **$z = w$**：$u, v, w \in \text{subtree}(z)$，$\text{par}(w) \notin$。$(1, 1, 1, 0)$，增量 $+x$。✓

- **$z$ 是 $w$ 的祖先（含 $\text{par}(w)$）**：$u, v, w, \text{par}(w)$ 均在 $z$ 子树内。$(1, 1, 1, 1)$，增量 $0$。✓（不在路径上，不应得 $+x$）

- **$z$ 不在路径上且不是 $w$ 的祖先**：四项都不在 $z$ 子树内。$(0, 0, 0, 0)$，增量 $0$。✓

所有情况都正确——路径上的点恰好得 $+x$，其他点不变。$\blacksquare$

### 3. 树上边差分的修正项 $-2x$

**命题**：以 $d[u]$ 表示 "$u$ 到父亲那条边的权值" 时，路径 $u \to v$ 上每条边 $+x$ 的差分操作为：$d[u] +\!= x$、$d[v] +\!= x$、$d[w] -\!= 2x$。

**证明**：

按"边权下放到子端点"的约定，路径 $u \to v$ 上的边对应的节点集 = (路径上除 $w$ 外的点)，因为 $w$ 上方的边不在路径上。

类比点差分的分析，四个差分项中**没有 $\text{par}(w)$ 项**（边权下放后，$w$ 的"对父边"本就不在路径上，无需特殊处理）。

对节点 $z$，$(\alpha, \beta, \gamma) = ([u \in \text{subtree}(z)], [v \in \text{subtree}(z)], [w \in \text{subtree}(z)])$：

- **$z$ 在路径 $u \to w$ 上（不含 $w$）**：$(1, 0, 0)$，增量 $+x$。✓

- **$z$ 在路径 $w \to v$ 上（不含 $w$）**：$(0, 1, 0)$，增量 $+x$。✓

- **$z = w$**：$(1, 1, 1)$，增量 $1 + 1 - 2 = 0$。✓（$w$ 对父边不在路径上）

- **$z$ 是 $w$ 的祖先**：$(1, 1, 1)$，增量 $0$。✓

- **其他**：$(0, 0, 0)$，增量 $0$。✓

修正项是 $-2x$ 而非点差分的 $-x$ 与 $-x$ 各一次——因为没了 $\text{par}(w)$，需要在 $w$ 处一次性扣掉两侧的"多算"。$\blacksquare$

### 4. 与序列差分的一性

序列差分的本质是"前缀和的逆运算"——区间加 $x$ 通过两个端点的修改实现，前缀和后还原为区间增量。

树上差分与之**完全同构**：

- "前缀和"对应"子树累加"——根到某点的链 / 子树对应序列上的前缀

- "区间端点修改"对应"路径端点 + LCA 修正"——只是路径上的"端点"在树上更复杂，需要容斥

掌握序列差分后，树上差分只需多写一步 LCA。本质思想完全一致。
