#难度/★★

> 用两个下标在数组上协同移动，把朴素的 $O(n^2)$ 双重循环优化到 $O(n)$。

## 核心思想

很多看似需要"枚举所有元素对 $(i, j)$"的问题，其实存在**单调性**——当 $i$ 移动时，对应的 $j$ 不必从头开始遍历，而是可以从上次的位置继续推进。这种"$i$ 与 $j$ 的相对运动具有方向性"的特征，就是双指针生效的前提。

把两个指针的运动方式分类，常见有三种形态：

- **相向双指针**：两端起步，向中间逼近（典型应用：有序数组中找两数之和）

- **同向双指针**：都从左端起步，$j$ 永远不超过 $i$ 之后（典型应用：滑动窗口、原地去重）

- **快慢双指针**：在序列上以不同步长走，常用于链表判环

无论哪种，核心都是利用单调性**避免重复比较**——每个指针总共最多遍历 $O(n)$ 次，因此总复杂度 $O(n)$。

## 适用场景

- 有序数组中找满足 $a[i] + a[j] = \text{target}$ 的对（相向）

- 求最长 / 最短"满足某条件"的子区间（同向，即 [[滑动窗口]]）

- 数组原地去重 / 划分 / 归并

- 链表判环（Floyd 判圈，快指针每次走 2 步、慢指针走 1 步）

- 不适用：两个指针的运动**没有单调性**（如 $i$ 增大时 $j$ 可能左可能右）

## 步骤拆解

**判定一个问题能否用双指针**：

1. 找到一个**目标性质**（如"区间和 $\le K$"、"两数之和 $= \text{target}$"）

2. 验证**单调性**：当一个指针朝某方向移动时，另一个指针的"合理范围"也是单调变化的（要么始终向同一方向移动，要么不动）

3. 选择起始位置：相向（两端）或同向（左端）

4. 写循环：每次根据当前状态决定移动哪个指针

## 代码模板

**模板一：相向双指针——有序数组求两数之和等于 target**

```cpp

// a 为升序数组，下标从 1 到 n。返回是否存在 a[i] + a[j] = target
bool two_sum(vector<int>& a, int target) {

    int n = a.size() - 1;

    int l = 1;

    int r = n;

    while (l < r) {

        int sum = a[l] + a[r];

        if (sum == target) {

            return true;

        } else if (sum < target) {

            l += 1;             // 和太小，左指针右移让 sum 增大

        } else {

            r -= 1;             // 和太大，右指针左移让 sum 减小

        }

    }

    return false;

}
```

> 💡 **正确性的关键**：当 `sum < target` 时，因为 `a[r]` 已经是右半段的最大值，所以 `a[l]` 必然不会和**任何 $j \le r$** 凑出 target——可以放心抛弃 `l`，让 `l += 1`。这就是单调性的体现。

**模板二：同向双指针——求"区间和 $\le K$ 的最长区间"**

```cpp
// 给定非负数组 a，求最长的连续子区间，使其和 <= K
int longest_subarray(vector<int>& a, long long K) {

    int n = a.size() - 1;

    int l = 1;

    long long sum = 0;

    int best = 0;

    for (int r = 1; r <= n; r++) {

        sum += a[r];

        // r 右移后窗口和可能超出 K，让 l 右移收缩

        while (sum > K) {

            sum -= a[l];

            l += 1;

        }

        // 此时 [l, r] 是以 r 结尾的最长合法区间

        best = max(best, r - l + 1);

    }

    return best;

}
```

> 💡 **同向双指针 = [[滑动窗口]]**：本质是同一种思想的不同名字。"双指针"更强调指针的运动方式，"滑动窗口"更强调窗口本身的状态变化。

**模板三：快慢双指针——原地去重**

```cpp

// 把升序数组 a 中重复元素去除，返回去重后长度
int unique(vector<int>& a) {

    int n = a.size() - 1;

    if (n == 0) {

        return 0;

    }

    int slow = 1;               // slow 指向"已去重区"的尾部

    for (int fast = 2; fast <= n; fast++) {

        if (a[fast] != a[slow]) {

            slow += 1;

            a[slow] = a[fast];

        }

    }

    return slow;

}

```

## 复杂度分析

- 时间复杂度：$O(n)$，两个指针总共最多移动 $2n$ 次

- 空间复杂度：$O(1)$，原地操作

## 正确性证明

以"有序数组求两数之和"为例。

**循环不变量**：在每一轮迭代开始时，所有满足 $i < l$ 或 $j > r$ 的下标对 $(i, j)$ 都已被排除（即不可能是答案）。

**初始化**：$l = 1$，$r = n$，平凡成立。

**保持**：

- 若 `a[l] + a[r] < target`：因 $a$ 升序，对任意 $j \le r$，有：

$$a[l] + a[j] \le a[l] + a[r] < \text{target}$$

所以 $l$ 不可能与任何 $j \le r$ 配成答案，可以排除 $i = l$ 这一行——`l += 1` 后不变量保持。

- 若 `a[l] + a[r] > target`：对称地，$r$ 不能与任何 $i \ge l$ 配成答案，`r -= 1`。

**终止**：循环结束 $l \ge r$，所有可能的下标对都已被排除或检查。$\blacksquare$

**为什么是 $O(n)$**：每次循环至少有一个指针移动一格，且 $l$ 增、$r$ 减，所以总移动次数不超过 $n$。
