#难度/★★

> 同向双指针的特例——窗口在数组上"滑动"，每次右端扩展、左端收缩，以 $O(n)$ 处理区间问题。

## 前置知识

- [[双指针]]

## 核心思想

滑动窗口维护一个**连续区间** $[l, r]$，整个过程中 $l$ 和 $r$ 都**只向右移动**：

- $r$ 每次循环必然右移一格（扩展窗口）

- $l$ 在每次 $r$ 移动后，根据某个条件决定是否右移（收缩窗口）

由于两个指针都单调右移，每个元素最多被加入一次、移出一次，总操作数 $O(n)$。

滑动窗口的核心是**维护"窗口当前的状态"**——这个状态可以是：

- 一个简单的累加值（如区间和）

- 一个计数器（如各字符出现次数）

- 一个数据结构（如 [[单调队列]] 维护窗口最值）

每当 $r$ 右移加入新元素、$l$ 右移弹出旧元素时，同步更新状态即可。

## 适用场景

- **固定大小窗口**：求所有大小为 $k$ 的子区间的某种属性（求和、最值、众数等）

- **变长窗口**：求"最长 / 最短满足条件"的子区间

- 字符串子串问题：包含某些字符的最短子串、所有字母均匀分布的最长子串等

- 配合 [[单调队列]]：求滑动窗口最大 / 最小值（[[单调队列]] 模板的经典应用）

- 配合哈希表：维护字符 / 数字的出现次数

- 不适用：窗口需要扩展和收缩**双向**进行（即 $l$ 可能左移）；区间和满足某复杂非单调条件

## 步骤拆解

**变长滑动窗口的标准框架**：

1. 初始化 $l = 1$，状态变量（如 `sum = 0`、`cnt = {}`）

2. 让 $r$ 从 $1$ 扫到 $n$：

   a. 把 $a[r]$ 加入窗口，更新状态

   b. 当窗口"违反约束"时，让 $l$ 右移并把 $a[l]$ 移出窗口，直到窗口重新合法

   c. 此时 $[l, r]$ 是以 $r$ 结尾的最优窗口，更新答案

**固定大小滑动窗口**：让 $r$ 扫到 $n$，同时维护 $l = r - k + 1$，每次只需操作"加入 $a[r]$、移出 $a[l - 1]$"两步。

## 代码模板

**模板一：变长滑动窗口——求和不超过 K 的最长区间**

```cpp

// 数组 a 全为非负整数，下标 1..n。求满足 sum <= K 的最长子区间长度
int longest_at_most_K(vector<int>& a, long long K) {

    int n = a.size() - 1;

    int l = 1;

    long long sum = 0;

    int best = 0;

    for (int r = 1; r <= n; r++) {

        sum += a[r];                // 1. 加入新元素

        while (sum > K) {           // 2. 违反约束就收缩

            sum -= a[l];

            l += 1;

        }

        best = max(best, r - l + 1);    // 3. 更新答案

    }

    return best;

}
```

> 💡 **为什么 $a$ 必须非负**：负数会破坏 `sum > K` 的单调性——$r$ 加入负数时 sum 反而变小，$l$ 可能不需要右移。这种情况要用 [[前缀和]] + 其他技巧。

**模板二：变长滑动窗口——含 $k$ 种不同元素的最短区间**

```cpp
// 数组 a 下标 1..n，求至少包含 k 种不同元素的最短子区间长度
int shortest_with_k_kinds(vector<int>& a, int k) {

    int n = a.size() - 1;

    unordered_map<int, int> cnt;        // 窗口内每种元素的出现次数

    int kinds = 0;                      // 当前窗口内不同元素种类数

    int l = 1;

    int best = INT_MAX;

    for (int r = 1; r <= n; r++) {

        cnt[a[r]] += 1;                 // 加入新元素

        if (cnt[a[r]] == 1) {

            kinds += 1;

        }

        while (kinds >= k) {            // 满足条件就尝试收缩

            best = min(best, r - l + 1);

            cnt[a[l]] -= 1;

            if (cnt[a[l]] == 0) {

                kinds -= 1;

            }

            l += 1;

        }

    }

    return best == INT_MAX ? -1 : best;

}
```

**模板三：固定大小滑动窗口——大小为 $k$ 的窗口求和**

```cpp

// 求每个大小为 k 的连续子区间的和

vector<long long> window_sum(vector<int>& a, int k) {

    int n = a.size() - 1;

    vector<long long> ans;

    long long sum = 0;

    for (int r = 1; r <= n; r++) {

        sum += a[r];                    // 加入新元素

        if (r >= k + 1) {

            sum -= a[r - k];            // 移出窗外元素

        }

        if (r >= k) {

            ans.push_back(sum);         // 窗口形成后记录答案

        }

    }

    return ans;

}

```

> 💡 **固定窗口求最值**：上述 `sum` 替换为 [[单调队列]] 即可，详见 [[单调队列]] 笔记的 P1886 解法。

## 复杂度分析

- 时间复杂度：$O(n)$，每个元素加入和移出窗口各一次

- 空间复杂度：取决于状态结构，简单累加 $O(1)$，用哈希表/[[单调队列]] 时 $O(n)$

## 正确性证明

以"求和不超过 K 的最长区间"为例。

**循环不变量**：每轮迭代开始时，

- $[l, r-1]$ 是以 $r-1$ 结尾、和不超过 $K$ 的最长合法区间

- 所有满足 $r' < r$ 且 $l' < l$ 的子区间 $[l', r']$ 都不可能比已记录的 `best` 更长

**保持**：第 $r$ 轮加入 $a[r]$ 后：

- 若 `sum > K`，必须收缩 $l$。**关键单调性**：因 $a$ 非负，"以 $r$ 结尾的合法 $l$"是连续的且不会比上一轮的 $l$ 更小，所以从上一轮的 $l$ 继续右移是正确的，不会漏掉更短的合法 $l$。

- 收缩完成后，$[l, r]$ 是以 $r$ 结尾的最长合法区间。

**终止**：$r = n$ 时所有可能的右端点都已枚举。$\blacksquare$

**为什么 $l$ 不需要左移**：考虑相邻两轮 $r-1$ 与 $r$。设上一轮的最优左端点为 $l^*$，则：$$\sum_{i=l^*}^{r-1} a[i] \le K$$。本轮加入 $a[r]$ 后若仍合法，$l$ 不变；若不合法，必须有 $l \ge l^*$（因为 $a[r] \ge 0$ 让和只增不减）。
