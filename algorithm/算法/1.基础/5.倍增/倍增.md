#难度/★★★

> 预处理"跳 $2^k$ 步"的状态，把"沿某方向跳 $k$ 步"从 $O(k)$ 优化到 $O(\log k)$。

## 前置知识

- [[位运算]]

## 核心思想

很多问题需要在某种结构上"跳 $k$ 步"——比如在树上从节点 $u$ 向上跳 $k$ 层、在序列上从 $i$ 出发跳 $k$ 次某变换。朴素做法是一步一步走，复杂度 $O(k)$。

**倍增的关键观察**：把 $k$ 写成二进制 $k = \sum 2^{b_i}$，则"跳 $k$ 步"等价于先跳 $2^{b_0}$ 步、再跳 $2^{b_1}$ 步……每次跳的步数都是 2 的幂。

如果**预处理出从每个起点跳 $2^j$ 步后的目的地**（记为 $f[i][j]$），则：

- $f[i][0]$：从 $i$ 跳 1 步的目标（直接定义）

- $f[i][j] = f[f[i][j-1]][j-1]$：跳 $2^j$ 步 = 先跳 $2^{j-1}$ 步、再跳 $2^{j-1}$ 步

预处理 $O(n \log n)$，每次查询沿着 $k$ 的二进制位"跳 $\log k$ 次"即可。

倍增和 [[ST表]]、[[矩阵快速幂]]、[[LCA]] 等算法的灵魂完全一致——都是"用 $2^k$ 步代替 1 步"。

## 适用场景

- **树上 $k$ 级祖先**：从某节点向上跳 $k$ 层（[[LCA]] 倍增解法的核心）

- **序列上的函数迭代**：给定 $f: [n] \to [n]$，求 $f^{(k)}(x)$（即 $f$ 应用 $k$ 次的结果）

- **维护 $2^k$ 段的"可结合信息"**：[[ST表]] 用倍增预处理区间最值

- **快速幂思想的拓展**：[[快速幂]]、[[矩阵快速幂]] 都可以视为倍增的特例

- 不适用：跳跃方向**依赖运行时状态**（无法预处理）；信息不可结合

## 步骤拆解

**通用倍增模板**：

1. 定义 $f[i][j]$：从 $i$ 出发跳 $2^j$ 步的目标 / 信息

2. **基础情形**：$f[i][0]$ 由问题直接给出

3. **递推**：$f[i][j] = \text{combine}(f[i][j-1],\ f[f[i][j-1]][j-1])$

4. **查询**：把 $k$ 拆成二进制位，从高位到低位依次跳

```cpp
for (int j = LOG; j >= 0; j -= 1) {

   if (k >> j & 1) {

	   x = f[x][j];

   }

}
```
  
5. 预处理 $K = \lceil \log_2 n \rceil$ 即可（再大的 $j$ 没有意义）

## 代码模板

**模板一：树上 $k$ 级祖先**

```cpp
class tree_jump {

private:

    int n, LOG;

    vector<vector<int>> fa;         // fa[i][j] = i 的 2^j 级祖先（不存在则为 0）

    vector<vector<int>> g;

    vector<int> depth;

    void dfs(int u, int p) {

        fa[u][0] = p;

        for (int j = 1; j <= LOG; j++) {

            fa[u][j] = fa[fa[u][j - 1]][j - 1];

        }

        for (int v : g[u]) {

            if (v != p) {

                depth[v] = depth[u] + 1;

                dfs(v, u);

            }

        }

    }

public:

    tree_jump(int total, vector<vector<int>>& g_in, int root) {

        n = total;

        g = g_in;

        LOG = 0;

        while ((1 << LOG) < n) {

            LOG += 1;

        }

        fa.assign(n + 1, vector<int>(LOG + 1, 0));

        depth.resize(n + 1, 0);

        dfs(root, 0);

    }

    // 求 u 的 k 级祖先（不存在返回 0）
    int kth_ancestor(int u, int k) {

        for (int j = LOG; j >= 0; j -= 1) {

            if ((k >> j) & 1) {

                u = fa[u][j];

                if (u == 0) {

                    return 0;

                }

            }

        }

        return u;

    }

};
```

> 💡 **递推顺序很重要**：`fa[u][j] = fa[fa[u][j-1]][j-1]` 在 DFS 中计算，必须先算 $j-1$ 层再算 $j$ 层。这里因为 DFS 自顶向下，父节点的 fa 已经算好，递推天然成立。

> 💡 **`fa[u][0] = p`** 是基础情形——0 级祖先是直接父亲。注意根节点 `fa[root][0] = 0`，而 0 号节点扮演"虚拟祖先"的角色，方便统一处理边界。

**模板二：序列上的函数迭代**

```cpp

// 给定 next[i]，求每个 i 出发跳 K 次后的位置
class function_iteration {

private:

    int n, LOG;

    vector<vector<int>> f;          // f[i][j] = 从 i 跳 2^j 次的位置

public:

    function_iteration(vector<int>& nxt) {

        n = nxt.size() - 1;

        LOG = 0;

        while ((1 << LOG) <= n) {

            LOG += 1;

        }

        f.assign(n + 1, vector<int>(LOG + 1, 0));

        for (int i = 1; i <= n; i++) {

            f[i][0] = nxt[i];

        }

        for (int j = 1; j <= LOG; j++) {

            for (int i = 1; i <= n; i++) {

                f[i][j] = f[f[i][j - 1]][j - 1];

            }

        }

    }

    int jump(int x, long long k) {

        for (int j = LOG; j >= 0; j -= 1) {

            if ((k >> j) & 1) {

                x = f[x][j];

            }

        }

        return x;

    }

};
```

> 💡 **预处理顺序**：上面是"先 $j$ 后 $i$"——必须保证算 $f[\cdot][j]$ 时 $f[\cdot][j-1]$ 已经填好。这与树上版本（DFS 中"先 $i$ 后 $j$"）不同——后者依赖父节点已经处理过这一约束。

**模板三：倍增维护可结合信息**（如最大值）

```cpp
// 给定序列 a，预处理后 O(log) 查询：从 i 出发跳 k 步路径上的最大值
class max_jump {

private:

    int n, LOG;

    vector<vector<int>> nxt;        // nxt[i][j] = 从 i 跳 2^j 步的位置

    vector<vector<long long>> mx;   // mx[i][j] = 跳 2^j 步路径上的最大值

public:

    // 假设 next_step 已给出，权值 w[i] 表示从 i 走第一步时经过的权值

    max_jump(vector<int>& next_step, vector<long long>& w) {

        n = next_step.size() - 1;

        LOG = 0;

        while ((1 << LOG) <= n) {

            LOG += 1;

        }

        nxt.assign(n + 1, vector<int>(LOG + 1, 0));

        mx.assign(n + 1, vector<long long>(LOG + 1, 0));

        for (int i = 1; i <= n; i++) {

            nxt[i][0] = next_step[i];

            mx[i][0] = w[i];

        }

        for (int j = 1; j <= LOG; j++) {

            for (int i = 1; i <= n; i++) {

                int half = nxt[i][j - 1];

                nxt[i][j] = nxt[half][j - 1];

                mx[i][j] = max(mx[i][j - 1], mx[half][j - 1]);

            }

        }

    }

    long long query(int x, long long k) {

        long long ans = 0;

        for (int j = LOG; j >= 0; j -= 1) {

            if ((k >> j) & 1) {

                ans = max(ans, mx[x][j]);

                x = nxt[x][j];

            }

        }

        return ans;

    }

};
```

## 复杂度分析

- 时间复杂度：预处理 $O(n \log n)$，每次查询 $O(\log k)$

- 空间复杂度：$O(n \log n)$

## 正确性证明

**关键定理**：递推式 $f[i][j] = f[f[i][j-1]][j-1]$ 正确刻画"从 $i$ 跳 $2^j$ 步后的目的地"。

**证明**：从 $i$ 跳 $2^j$ 步可以拆成"先跳 $2^{j-1}$ 步，再跳 $2^{j-1}$ 步"——两段加起来共 $2^j$ 步。

- 第一段：从 $i$ 跳 $2^{j-1}$ 步到达 $f[i][j-1]$（由归纳，$j-1$ 层已正确）

- 第二段：从 $f[i][j-1]$ 再跳 $2^{j-1}$ 步到达 $f[\,f[i][j-1]\,][j-1]$

合起来即 $f[i][j] = f[f[i][j-1]][j-1]$。$\blacksquare$

**查询正确性**：把 $k$ 写成二进制 $k = \sum_{i \in B} 2^i$（$B$ 是 $k$ 二进制中为 1 的位的集合），则：

$$\text{从 } x \text{ 跳 } k \text{ 步} = \text{从 } x \text{ 依次跳 } 2^{i_1}, 2^{i_2}, \ldots \text{ 步（其中 } i_t \in B\text{）}$$

由于"跳跃"操作满足结合律——跳 $a$ 步再跳 $b$ 步等于跳 $a + b$ 步——拆分顺序不影响结果。

代码中从高位到低位检查 $k$ 的每一位，遇到 $1$ 就让 $x$ 跳 $2^j$ 步：

```cpp

for (int j = LOG; j >= 0; j -= 1) {

    if ((k >> j) & 1) {

        x = f[x][j];

    }

}

```

这恰好把 $k$ 的所有"为 1 的二进制位"对应的跳跃都执行了一遍，且总跳数为 $\sum_{j \in B} 2^j = k$。$\blacksquare$

**复杂度的来源**：

- 状态数：$f[i][j]$ 共 $n \times \log n$ 个

- 每个状态 $O(1)$ 转移（一次数组访问）

- 因此预处理 $O(n \log n)$；查询时 $k$ 最多 $\lfloor \log_2 k \rfloor + 1$ 个二进制位，故 $O(\log k)$

**与 [[快速幂]] 的统一性**：

快速幂可以看成一维倍增——预处理"乘 $2^j$ 个 $a$ 后的结果"（即 $a^{2^j}$），然后按二进制位组合。本质完全相同，只是状态从"当前位置"换成了"当前累积的幂值"。

**与 [[ST表]] 的统一性**：

ST 表 $f[i][j]$ 表示从 $i$ 起长度为 $2^j$ 的区间最值。区间长度本身就是"步数"，所以 ST 表是倍增思想的最自然体现。

`fa[fa[u][j-1]][j-1]` 是倍增的灵魂式子——理解了它就理解了倍增的一切：跳 $2^j$ 步 = 跳 $2^{j-1}$ 步两次。这种"半半合并"的思想称为 **Doubling**，在算法竞赛中无处不在。
