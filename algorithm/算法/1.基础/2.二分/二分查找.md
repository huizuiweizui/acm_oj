#难度/★

  > 在有序序列上每次排除一半搜索空间，以 $O(\log n)$ 找到目标元素或确定其位置。

## 核心思想

二分查找的前提是序列**单调**——这意味着对任意中点 $\text{mid}$，我们能通过判断 `a[mid]` 与目标的关系，**确定地排除**左半或右半其中一边。每次循环序列规模减半，总迭代次数为 $O(\log n)$。

本笔记统一采用**开区间二分**：维护开区间 $(l, r)$，循环条件 `while (l + 1 < r)`，每次迭代 $l$ 或 $r$ 直接赋值为 `mid`。这种写法的优点是：

- **一份模板适配所有场景**：不再需要纠结 `mid + 1` 还是 `mid - 1`

- **不变量清晰**：循环过程中 $l$ 永远是"已知不满足条件"的位置，$r$ 永远是"已知满足条件"的位置

- **不会死循环**：每次 $r - l$ 严格减少

## 适用场景

- 有序数组中查找元素 / 第一个 $\ge x$ 的位置 / 最后一个 $\le x$ 的位置

- 单调函数求零点（实数二分）

- 不直接查找元素，而是在"答案空间"上二分（见 [[二分答案]]）

- 不适用：序列没有单调性

## 步骤拆解

**开区间二分的核心约定**：

1. 维护开区间 $(l, r)$，含义是"答案在 $l$ 与 $r$ 之间，但 $l$、$r$ 自身不在搜索范围内"

2. 初始 $l$ 取**比所有合法位置都小一格**的值（如 $0$），$r$ 取**比所有合法位置都大一格**的值（如 $n + 1$）

3. 循环条件：`while (l + 1 < r)`，即 $(l, r)$ 中至少还有一个整数

4. 每次取 $\text{mid} = l + (r - l) / 2$，根据 $\text{check}(\text{mid})$ 决定收缩方向：

   - 若想找"第一个满足条件的位置"，则 `check(mid) == true` 时收缩右边界 `r = mid`，否则 `l = mid`

   - 循环结束后 $r$ 即为答案

## 代码模板

**在升序数组中查找第一个 $\ge x$ 的位置**

```cpp
int lower_bound(vector<int>& a, int x) {

    int n = a.size() - 1;       // a 下标从 1 到 n

    int l = 0;

    int r = n + 1;

    while (l + 1 < r) {

        int mid = l + (r - l) / 2;

        if (a[mid] >= x) {      // 满足要求

            r = mid;

        } else {

            l = mid;

        }

    }

    return r;                   // r 即为第一个 a[r] >= x 的位置；若不存在则 r = n + 1

}
```

> 💡 **`mid` 防溢出**：写成 `l + (r - l) / 2` 而非 `(l + r) / 2`，避免 $l + r$ 在大数时溢出。

> 💡 **浮点数二分**：把循环条件改成 `while (r - l > eps)`，eps 取 `1e-7` 左右；不再有 `mid + 1` 之类的离散问题。

## 复杂度分析

- 时间复杂度：$O(\log n)$，整数二分；浮点数二分为 $O(\log \frac{r - l}{\text{eps}})$

- 空间复杂度：$O(1)$

## 正确性证明

**循环不变量**：在每一轮迭代开始时，$l$ 与 $r$ 满足以下两条性质（以"求第一个满足条件的位置"为例）：

- $l$ 是当前已知"不满足条件"的最大位置（或 $0$）

- $r$ 是当前已知"满足条件"的最小位置（或 $n+1$）

**初始化**：$l = 0$ 视作哨兵不满足条件，$r = n + 1$ 视作哨兵满足条件，不变量成立。

**保持**：每次取 $\text{mid} \in (l, r)$，

- 若 `check(mid)` 为真，说明 mid 是新的满足条件位置，且不大于原来的 $r$，故 `r = mid` 后不变量保持

- 若 `check(mid)` 为假，类似地 `l = mid` 后不变量保持

**终止**：循环条件 `l + 1 < r` 不再成立时，$l$ 与 $r$ 相邻，即 $r = l + 1$。此时所有 $\le l$ 的位置都不满足，所有 $\ge r$ 的位置都满足，故 $r$ 就是第一个满足条件的位置。$\blacksquare$

**`mid` 永远在 $(l, r)$ 内**：由 $l + 1 < r$ 即 $r - l \ge 2$，故 $\text{mid} = l + (r - l)/2 \ge l + 1$ 且 $\text{mid} \le l + (r - l - 1) < r$。这保证了 `l = mid` 或 `r = mid` 之后区间长度严格减小，循环必然终止。
