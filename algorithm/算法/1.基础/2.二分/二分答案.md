#难度/★★

> 把"求最优值"转化为"判定是否可行"，对答案直接二分，是把困难问题降维到 $O(\log V)$ 次判定的强力武器。

- [[二分查找]]

## 核心思想

很多最优化问题不容易直接构造最优解，但若**给定一个候选答案 $x$，判断它是否可行**却很容易。这时关键观察是——**可行性关于 $x$ 单调**：

- "最大化型"问题：若答案 $x$ 可行，则所有 $\le x$ 的值也可行（因为约束更松）

- "最小化型"问题：若答案 $x$ 可行，则所有 $\ge x$ 的值也可行

只要这种单调性成立，就可以**对答案空间二分**：每次取 $\text{mid}$，调用 `check(mid)` 判定可行性，根据结果收缩搜索范围。最终二分出"刚好可行"或"刚好不可行"的临界点，即为最优答案。

把"求解"转化为"判定"——这就是二分答案的灵魂。

## 适用场景

- 答案有明确范围 $[L, R]$，且可行性关于答案单调

- `check(x)` 容易实现（贪心 / 模拟 / DP / 图论判定均可）

- 经典题型：

  - "最大化最小值" / "最小化最大值"

  - 数据范围大但答案范围小的查找问题

- 不适用：答案不连续或不单调；`check` 本身比直接求解还慢

## 步骤拆解

1. **确定答案范围 $[L, R]$**：往外扩一格作哨兵 $l = L - 1$、$r = R + 1$

2. **写出 `check(x)` 函数**：返回 $x$ 是否可行

3. **判断单调方向**：

   - 求**最大可行值** → check 满足时收缩左边界 `l = mid`

   - 求**最小可行值** → check 满足时收缩右边界 `r = mid`

1. **开区间二分**：循环 `while (l + 1 < r)`，每次取 `mid`，按方向收缩

2. **返回答案**：求最大值返回 `l`，求最小值返回 `r`

## 代码模板

**求最大可行值**（满足条件的最大 $x$）

```cpp

// 答案在 [L, R] 范围内，求最大可行 x
long long binary_search_max(long long L, long long R) {

    long long l = L - 1;

    long long r = R + 1;

    while (l + 1 < r) {

        long long mid = l + (r - l) / 2;

        if (check(mid)) {

            l = mid;                // mid 可行，向更大处尝试

        } else {

            r = mid;

        }

    }

    return l;                       // 最大可行值

}

```

> 💡 **方向口诀**：把"想要的方向"作为 check 真时收缩的方向，永远不会错。

## 复杂度分析

- 时间复杂度：$O(\log V \cdot T_{\text{check}})$，其中 $V$ 是答案值域，$T_{\text{check}}$ 是单次判定的复杂度

- 空间复杂度：取决于 `check` 的实现，本身 $O(1)$

## 正确性证明

**前提**：`check` 关于 $x$ 单调（否则二分答案不适用）。

**单调性的形式化定义**：以"求最大可行值"为例，对所有 $x_1 \le x_2$，若 `check(x2)` 为真，则 `check(x1)` 也为真。换言之，"可行集合"是 $[L, x^*]$ 的形式，其中 $x^*$ 是最大可行值。

**循环不变量**：在每一轮迭代开始时，

- $l$ 是当前已知"可行"的最大位置（或哨兵 $L - 1$，视作可行）

- $r$ 是当前已知"不可行"的最小位置（或哨兵 $R + 1$，视作不可行）

**终止**：循环结束时 $r = l + 1$，此时 $l$ 是最大可行值。$\blacksquare$
