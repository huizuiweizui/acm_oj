#难度/★★

  > 在单峰函数上每次排除三分之一的搜索区间，以 $O(\log_{3/2} n)$ 找到极值点。

## 前置知识

- [[二分查找]]

## 核心思想

二分查找需要序列**单调**，但若函数是**单峰**（先增后减或先减后增）的，每次取一个中点不足以判断极值在哪一边——需要取**两个**比较点。

把区间 $[l, r]$ 三等分，得到两个分点 $m_1 = l + (r - l) / 3$ 和 $m_2 = r - (r - l) / 3$。以"求极大值"为例：

- 若 $f(m_1) < f(m_2)$，则极值点必在 $(m_1, r]$ 内（因为单峰函数在 $m_1$ 与 $m_2$ 之间不可能再降再升，所以极值点不在 $[l, m_1]$）

- 若 $f(m_1) > f(m_2)$，则极值点必在 $[l, m_2)$

- 相等时两侧都可去（实战中归到任一侧均可）

每次区间长度变为原来的 $2/3$，迭代 $O(\log_{3/2} n)$ 次后得到极值。

## 适用场景

- 求**单峰函数**的极值点（实数或整数）

- 经典模型：抛物线、二次函数最值、几何最优化（如点到直线的最近点）

- 三分套二分：内层二分判定，外层三分搜索（适合答案是单峰函数的复杂题）

- 不适用：函数有多个峰；函数在区间内不单峰

## 步骤拆解

**浮点数三分**（最常见）：

1. 维护区间 $[l, r]$，初始为答案搜索范围

2. 取分点 $m_1 = l + (r - l) / 3$，$m_2 = r - (r - l) / 3$

3. 比较 $f(m_1)$ 与 $f(m_2)$，按"求极大"还是"求极小"决定收缩方向

4. 当 $r - l < \text{eps}$ 时停止，返回 $l$（或 $(l + r) / 2$）

**整数三分**：把循环条件改为 $l + 2 < r$（保证 $m_1 \neq m_2$），最后在 $[l, r]$ 上暴力扫描。

## 代码模板

**浮点数三分：求单峰函数极大值的位置**

```cpp
const double EPS = 1e-9;

double f(double x) {

    // 单峰函数定义
    return -(x - 3) * (x - 3) + 5;      // 例：在 x = 3 处取极大值

}

double ternary_search_max(double l, double r) {

    while (r - l > EPS) {

        double m1 = l + (r - l) / 3;

        double m2 = r - (r - l) / 3;

        if (f(m1) < f(m2)) {

            l = m1;                     // 极大值在 (m1, r] 内

        } else {

            r = m2;                     // 极大值在 [l, m2) 内

        }

    }

    return l;                           // 此时区间足够小，返回任一端点即可

}
```

> 💡 **eps 的选择**：通常题目要求 6 位精度时取 $10^{-7}$，要求 9 位时取 $10^{-9}$。开太小会增加迭代次数，开太大会精度不够。

## 复杂度分析

- 时间复杂度：$O(\log_{3/2} \frac{r - l}{\text{eps}})$ 实数；$O(\log n)$ 整数

- 空间复杂度：$O(1)$

## 正确性证明

**前提**：函数 $f$ 在 $[l, r]$ 上是**严格单峰**的，即存在唯一的极大值点 $x^*$，使得 $f$ 在 $[l, x^*]$ 上单调递增、在 $[x^*, r]$ 上单调递减。

**关键性质**：对于 $l < m_1 < m_2 < r$，

- 若 $f(m_1) < f(m_2)$，则 $x^* > m_1$（因为若 $x^* \le m_1$，则 $f$ 在 $[m_1, m_2]$ 段单调递减，与 $f(m_1) < f(m_2)$ 矛盾），故 $x^* \in (m_1, r]$

- 若 $f(m_1) > f(m_2)$，对称地有 $x^* \in [l, m_2)$

- 若 $f(m_1) = f(m_2)$，则 $x^* \in [m_1, m_2]$，归到任一侧都不会丢失答案

每次迭代都正确地排除了一段不含极值的区间。$\blacksquare$
