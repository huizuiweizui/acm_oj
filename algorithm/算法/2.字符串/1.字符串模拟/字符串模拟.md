#难度/★★

> 按字面规则一步步处理字符串的题型统称——熟练运用 C++ 字符串 API + 字符判断 + 类型转换是核心。

## 核心思想

**字符串模拟**不是一种"特定算法"，而是一类问题的统称——这类问题通常给定一个字符串或字符串列表，要求按**给定规则**处理它：拼接、分割、查找、替换、解析、格式化输出等。

它的"算法"成分很少，更多考验**对工具的熟练度**和**对边界情况的处理**。能用熟以下工具，绝大多数模拟题都不会成为障碍——

| 类别             | 关键工具                                        |
| -------------- | ------------------------------------------- |
| **字符串操作**      | `s.substr`, `s.find`, `s.replace`, `s += t` |
| **字符判断**       | `isalpha`, `isdigit`, `isalnum`, `isspace`  |
| **大小写转换**      | `tolower`, `toupper`                        |
| **类型转换**       | `stoi`, `stoll`, `stod`, `to_string`        |
| **流式处理**       | `istringstream`, `getline`                  |
| **格式化输出**      | `printf("%05d", x)`, `setw`, `setfill`      |

**典型解题套路**：

1. **看清规则**：题目可能用很多自然语言描述，必须把规则**翻译成精确的步骤**

2. **选择数据结构**：`string` 是首选；只有大量字符级操作或卡常时考虑 `char[]`

3. **一步步实现**：把规则拆成若干"读—判—改—写"的小步，每步独立测试

4. **边界情况**：空字符串、单字符、首尾空白、全角字符、负数、前导 0……

## 适用场景

- **大整数四则运算**：用字符串存储 + 模拟竖式

- **表达式求值**：中缀转后缀，配合 [[栈]] 求值

- **输入解析**：按分隔符（空格、逗号、`:` 等）拆分；多行输入按行读

- **格式化输出**：补零、对齐、保留小数位

- **日期 / IP / 时间字符串**：按格式拆分 + 字段验证

- **配置文件解析**：键值对、注释行、多段结构

- 不适用：需要快速子串匹配（用 [[字符串哈希]] 或 [[KMP]]）；需要在大量字符串中查询模式（用 [[Trie]] 或 [[AC自动机]]）

## 步骤拆解

1. **读输入**：用 `getline(cin, line)` 读整行（含空格），或用 `cin >> s` 读单个 token

2. **预处理**：去首尾空白、统一大小写（如有需要）

3. **拆分**：根据分隔符切成 token——`istringstream` 是最简洁的工具

4. **逐项处理**：对每个 token 或字符做判断和变换

5. **重组输出**：按格式拼接结果

## 代码模板

**模板一：常用字符串 API 快速参考**

```cpp
string s = "Hello World";

// ---- 基本访问与修改 ----
int n = s.size();                               // 长度

char c = s[0];                                  // 'H'，注意：0-indexed

s += " !";                                      // 拼接

// ---- 查找与子串 ----
size_t pos = s.find("World");                   // 6；找不到返回 string::npos

string sub = s.substr(6, 5);                    // "World"，从 6 开始取 5 个

// ---- 替换 ----
s.replace(0, 5, "Bye");                         // 把 [0, 5) 替换为 "Bye"

// ---- 判断与比较 ----
if (s == "Bye World !") { /* ... */ }

if (s.empty()) { /* ... */ }

if (s.find("xxx") != string::npos) { /* 找到了 */ }

// ---- 字符判断（cctype 头文件）----
isalpha('A');                                   // 是字母？

isdigit('5');                                   // 是数字？

isalnum('a');                                   // 是字母或数字？

isspace(' ');                                   // 是空白字符？

// ---- 大小写转换 ----
char up = toupper('a');                         // 'A'

char lo = tolower('B');                         // 'b'

// ---- 数字与字符串互转 ----
int x = stoi("123");                            // 123

long long y = stoll("12345678901234");          // 大整数

double d = stod("3.14");

string t = to_string(456);                      // "456"
```

**模板二:`istringstream` 分割空格分隔的输入**

```cpp
string line;

getline(cin, line);

istringstream iss(line);

int x;

vector<int> nums;

while (iss >> x) {

    nums.push_back(x);

}
```

**模板三：按指定分隔符（如逗号）拆分**

```cpp

vector<string> split(const string& s, char delim) {

    vector<string> parts;

    string cur;

    for (char c : s) {

        if (c == delim) {

            parts.push_back(cur);

            cur.clear();

        } else {

            cur += c;

        }

    }

    parts.push_back(cur);                       // 最后一段

    return parts;

}
```

**模板四：大整数加法（经典模拟）**

```cpp
string big_add(const string& a, const string& b) {

    string res;

    int i = a.size() - 1;

    int j = b.size() - 1;

    int carry = 0;

    while (i >= 0 || j >= 0 || carry > 0) {

        int x = (i >= 0) ? (a[i] - '0') : 0;

        int y = (j >= 0) ? (b[j] - '0') : 0;

        int s = x + y + carry;

        res += (char)('0' + s % 10);

        carry = s / 10;

        i--;

        j--;

    }

    reverse(res.begin(), res.end());

    return res;

}
```

## 复杂度分析

- 大多数 API 是 $O(n)$（如 `find`、`substr`、`replace`）

- `+=` 拼接均摊 $O(1)$（基于动态数组）

- 大整数加法：$O(\max(|a|, |b|))$

- 表达式求值：$O(n)$（一次扫描）

## 关键实现细节

字符串模拟没有"算法正确性"要证明——但有几个**实现细节**特别容易出错——

### 1. 边界情况：空字符串与首尾空白

- 空字符串 `s.size() == 0` 时，`s[0]` 是未定义行为

- 输入可能含末尾换行符或前导空格，要用 `s.erase(remove_if(...))` 或类似手段去除

### 2. `getline` 与 `cin >>` 混用陷阱

读入模式：

```cpp

int n;

cin >> n;

string line;

getline(cin, line);                             // 错！这里读的是 cin >> n 留下的换行

getline(cin, line);                             // 这一行才是真正的下一行

```

因为 `cin >> n` 不消耗换行，`getline` 把残留换行读成空字符串。修正：在 `cin >> n` 后加 `cin.ignore()`，或全部用 `getline` + 手动转换。

### 3. 字符串拼接的优化

- 反复 `s = s + t` 每次都拷贝整个字符串，$O(n^2)$

- 用 `s += t` 或 `s.append(t)` 是均摊 $O(1)$

- 处理大量拼接时考虑预分配 `s.reserve(n)`

### 4. ASCII 数字转换

- `c - '0'` 把字符 `'5'` 转为整数 `5`——这是字符串模拟最常用的小技巧

- 反向：`(char)('0' + 5)` 把整数 `5` 转为字符 `'5'`

- 同理 `c - 'a'` 算字母位置（0 ~ 25）

### 5. 多语言 / 编码

中文、日文等多字节字符在 `string` 中按字节存储——`s.size()` 返回字节数而非字符数。处理多语言文本要谨慎或用 `wstring` / 第三方库。竞赛中通常是纯 ASCII，不必担心。

## 几个经典模拟题型

### 表达式求值（含括号）

用两个 [[栈]]（数字栈 + 运算符栈）模拟中缀求值——遇数字入数字栈；遇运算符按优先级处理；遇 `(` 入栈；遇 `)` 弹出直到 `(`。详细见 [[栈]] 的应用。

### IP 地址判断

合法 IPv4 是 `a.b.c.d`，每段是 0~255 的整数（无前导 0，除非是 0 本身）。

```cpp
bool is_valid_ipv4(const string& s) {

    auto parts = split(s, '.');

    if (parts.size() != 4) return false;

    for (auto& p : parts) {

        if (p.empty() || p.size() > 3) return false;

        if (p.size() > 1 && p[0] == '0') return false;     // 前导 0

        for (char c : p) if (!isdigit(c)) return false;

        int x = stoi(p);

        if (x < 0 || x > 255) return false;

    }

    return true;

}
```

### 读取多行输入

```cpp
int n;

cin >> n;

cin.ignore();                                   // 关键：丢掉 cin >> n 后的换行

for (int i = 0; i < n; i++) {

    string line;

    getline(cin, line);

    // 处理 line

}
```
