#难度/★★★★

> 在每个字符间插入分隔符让奇偶回文统一——再用"已找到回文的对称性"加速后续判定，$O(n)$ 求出所有回文子串。

## 核心思想

**问题**：给定字符串 $s$，求最长回文子串（或所有回文子串总数）。

**朴素做法**：枚举每个中心 + 向两端扩展，$O(n^2)$。

**Manacher 算法**：通过两个巧妙设计把复杂度降到 $O(n)$——

**设计 1：插入分隔符统一奇偶回文**

回文有奇数长（如 `aba`，中心是 `b`）和偶数长（如 `abba`，中心是两字符之间）两种形式——分别处理麻烦。

**插入 `#` 字符**：在每个字符**之间**及首尾插入特殊字符：

```
abba  →  #a#b#b#a#

abc   →  #a#b#c#
```

变换后每个回文（无论原本奇偶）都变成**新串中长度为奇数的回文**——且中心是某个字符（可能是字母或 `#`）。

**关键性质**：变换前的"原回文长度" = 变换后"以同一中心的回文半径"——巧妙的等价！

例如 `abba`（长度 4）→ `#a#b#b#a#` 中以中间 `#` 为中心的回文 `#a#b#b#a#` 半径为 4，正是原长度。

**设计 2：利用对称性加速**

维护数组 $p[i] = $ 新串中以 $i$ 为中心的最长回文半径。同时维护两个变量——

- $c$：当前**最右回文**的中心

- $r = c + p[c]$：当前最右回文的右端点

对每个 $i$ 求 $p[i]$——

- **若 $i < r$**：$i$ 在某个已知回文（中心 $c$、右端 $r$）内部！由这个回文的**对称性**，$i$ 关于 $c$ 的对称点是 $i' = 2c - i$，其 $p[i']$ 已算出。**初值 $p[i] = \min(r - i, p[i'])$**（取较小值——因为可能"对称回文"延伸到了大回文外面，那里就不能照搬）

- **若 $i \ge r$**：没有已知信息，从 0 开始

- **然后扩展**：$\mathtt{while}\ s[i + p[i] + 1] = s[i - p[i] - 1]$ 时 $p[i] \mathrel{+}= 1$

- **更新 $c, r$**：若 $i + p[i] > r$，更新 $c = i$，$r = i + p[i]$

**复杂度 $O(n)$ 的关键**：每次 while 循环要么让 $r$ 向右走、要么不变——$r$ 单调右移，整个过程 while 总执行次数 $\le n$。

## 适用场景

- **求最长回文子串**（最经典应用）

- **求回文子串总数**：每个中心 $i$ 贡献 $\lceil p[i] / 2 \rceil$ 个不同回文

- **判定子串是否回文** + 一些回文计数题

- 经典扩展：以某点为左端点的最长回文串、以某点为右端点的最长回文串

- **[[字符串哈希]]** 也能做回文判定，但 Manacher 是 $O(n)$ 求**所有**回文，效率更高

- 不适用：动态加字符的回文问题（用回文自动机 PAM）；回文子序列问题（用 dp）

## 步骤拆解

1. **预处理**：构造新串 `t`，在原串每个字符**前后**及首尾插入 `#`；首尾再各加一个**互不相同**的哨兵（如 `^`, `$`）防止越界

2. **初始化** $p[\cdot] = 0$，$c = 0, r = 0$

3. **遍历** 新串中除哨兵外的每个位置 $i$：

   a. 若 $i < r$：$p[i] = \min(r - i, p[2c - i])$

   b. 扩展回文：当 $t[i + p[i] + 1] = t[i - p[i] - 1]$ 时 $p[i]$ 加 1

   c. 若 $i + p[i] > r$：更新 $c = i, r = i + p[i]$

4. **回答查询**：$\max p[i]$ 即原串中最长回文长度（这正是变换前后"半径 = 长度"的等价）

## 代码模板

**模板：完整 Manacher**

```cpp
class manacher {

private:

    int n;                                      // 新串长度

    string t;

    vector<int> p;                              // p[i] = 新串中以 i 为中心的最长回文半径

  

    void preprocess(const string& s) {

        t = "^";                                // 左哨兵

        t += '#';

        for (char c : s) {

            t += c;

            t += '#';

        }

        t += '$';                               // 右哨兵

        n = t.size();

    }

public:

    manacher(const string& s) {

        preprocess(s);

        p.assign(n, 0);

  

        int c = 0, r = 0;

        for (int i = 1; i < n - 1; i++) {

            if (i < r) {

                p[i] = min(r - i, p[2 * c - i]);

            }

            while (t[i + p[i] + 1] == t[i - p[i] - 1]) {

                p[i] += 1;

            }

            if (i + p[i] > r) {

                c = i;

                r = i + p[i];

            }

        }

    }

  

    // 原串中最长回文子串的长度

    int longest() {

        int ans = 0;

        for (int x : p) {

            ans = max(ans, x);

        }

        return ans;

    }

  

    // 原串中所有回文子串的数量（不同位置算不同）

    long long count() {

        long long ans = 0;

        for (int x : p) {

            ans += (x + 1) / 2;                 // 每个中心贡献 ⌈p[i]/2⌉ 个回文

        }

        return ans;

    }

};
```

> 💡 **`^` 和 `$` 哨兵**：作用是让 `t[i + p[i] + 1] == t[i - p[i] - 1]` 这个比较自然失败——遇到哨兵两端字符不同，自动停止扩展，避免数组越界判断。

> 💡 **新串半径 = 原串长度**：以 `abba` 为例——新串 `^#a#b#b#a#$`，中间 `#` 处 $p = 4$（往两边各延伸 4 个字符匹配 `abba`）——这正是原回文 `abba` 的长度。

> 💡 **回文计数公式 $\lceil p[i] / 2 \rceil$**：以新串某中心 $i$ 为中心的回文，回文半径 $p[i]$ 时——它自身长度为 $p[i]$ 的回文有 $\lceil p[i] / 2 \rceil$ 个不同的"较短回文"嵌套（每减 2 个字符是一个新回文）。

> ⚠️ **`^` 和 `$` 必须不同且不出现在原串**：通常用 ASCII 中不会出现的字符（如 `^` 和 `$`、`@` 和 `*` 等），保证哨兵能"截断"扩展。

## 复杂度分析

- 时间复杂度：$O(n)$（详见正确性证明）

- 空间复杂度：$O(n)$（新串 + $p$ 数组）

## 正确性证明

### 插入 `#` 后回文的对应关系

**命题**：原串中长度 $L$ 的回文子串，对应新串中以同一中心位置的、回文半径 $L$ 的回文。

**证明（构造对应）**：

设原串中 $s[l..r]$ 是回文，长度 $L = r - l + 1$。中心位置——

- **奇数长**：$L = 2k + 1$，中心是字符 $s[l + k]$。新串中对应位置是该字符位置，$p = L$。

- **偶数长**：$L = 2k$，中心是 $s[l+k-1]$ 与 $s[l+k]$ 之间的"间隙"。新串中对应位置是间隙处的 `#`，$p = L$。

每种情形下两侧扩展严格匹配 $L$ 个字符。$\blacksquare$

### 对称性的合理利用

**关键命题**：处理位置 $i$ 时，若 $i < r$（在大回文 $[l_c, r]$ 内部，$l_c = c - p[c]$），令 $i' = 2c - i$（关于 $c$ 对称的位置），则 $p[i] \ge \min(r - i, p[i'])$。

**证明**：

由"以 $c$ 为中心的回文"的对称性——$t[c - k] = t[c + k]$ 对所有 $|k| \le p[c]$ 成立。

考虑 $t[i - k]$ 和 $t[i + k]$ 的关系——

- $i - k$ 关于 $c$ 对称到 $2c - (i - k) = i' + k$

- $i + k$ 关于 $c$ 对称到 $2c - (i + k) = i' - k$

由大回文对称：$t[i - k] = t[i' + k]$，$t[i + k] = t[i' - k]$。所以 $t[i - k] = t[i + k]$ 等价于 $t[i' + k] = t[i' - k]$——即 $i$ 处的回文性与 $i'$ 处的回文性**在大回文范围内一致**。

只要 $i + k \le r$，对称性都成立。所以 $p[i] \ge \min(r - i, p[i'])$。

**为什么是 $\min$ 而非 $=$**：若 $p[i'] > r - i$，意味着 $i'$ 处的回文延伸到了大回文左外（$i' - p[i'] < l_c$）——那段没有对称保证，所以 $i$ 处的回文不能照搬 $p[i']$，最多只能保证延伸到 $r$。$\blacksquare$

### 复杂度的均摊分析

**关键不变量**：变量 $r$ 在算法运行中**单调不减**。

**证明**：算法只在"$i + p[i] > r$ 时更新 $c, r$"——更新后 $r$ 严格增大。其他时刻 $r$ 不变。所以 $r$ 单调不减。

**$r$ 的最大值是 $n$**：所以 $r$ 最多增加 $n$ 次。

**while 循环总次数**：

- 每次 while 循环让 $p[i]$ 加 1，只要不引发 `t[i + p[i] + 1] != t[i - p[i] - 1]` 失败

- 每次成功的 while 让 $i + p[i]$ 也加 1——而 $i + p[i] > r$ 时会更新 $r = i + p[i]$，"贡献" 1 给 $r$ 的增长

- 所以**所有成功的 while 总次数 $\le$ $r$ 的总增长 $\le n$**

**每次失败的 while 至多 1 次/位置**——$n$ 个位置共 $n$ 次失败。

**初始化 $p[i]$ 用对称性**：$O(1)$ 每次。

总时间 $O(n)$。$\blacksquare$

### 回文计数公式

**命题**：以新串位置 $i$ 为中心、回文半径 $p[i]$ 时，**原串**中以同一"中心"为中心的不同回文有 $\lceil p[i] / 2 \rceil$ 个。

**直觉**：原串中的回文长度只能是 $1, 3, 5, \ldots$（奇）或 $2, 4, 6, \ldots$（偶）——以 $i$ 为中心的回文长度构成一个等差数列（公差 2），最长 $p[i]$。共 $\lceil p[i] / 2 \rceil$ 项（含长度 1 或 2 的最短"回文"）。

**严格论证**：每减少 2 个字符（左右各去 1）仍是回文——所以 $p[i], p[i] - 2, p[i] - 4, \ldots, 1$ 或 $2$ 都是合法回文长度。项数 $\lceil p[i] / 2 \rceil$。$\blacksquare$

> 注：上述统计**会重复计算**——同一回文子串（如 `aba`）只有一个特定中心，所以不会重复。但若题目要求"不同回文子串个数"（即去重，相同串只算一次），需要回文自动机（PAM）。

## 与 [[字符串哈希]] 的对比

| 方法                  | 求最长回文               | 求所有回文计数   | 求"位置 $l..r$ 是否回文" |
| ------------------- | ------------------- | --------- | ----------------- |
| Manacher            | $O(n)$ 一次           | $O(n)$ 一次 | $O(1)$ 查询（预处理后）   |
| [[字符串哈希]]           | $O(n \log n)$（二分扩展） | $O(n^2)$  | $O(1)$ 查询         |
| 朴素枚举 + 扩展           | $O(n^2)$            | $O(n^2)$  | $O(n)$ 查询         |

**经验**：纯回文问题选 Manacher；混合"哈希做其他比较"时可以用哈希一并解决。

## 几个常见错误

- **没插哨兵**：`t[i + p[i] + 1]` 可能越界。哨兵 `^` `$` 让比较自然失败

- **`^` 和 `$` 选了原串可能含的字符**：导致哨兵失效，比赛中会 RE 或 WA。用 ASCII 中不出现的字符

- **新串下标与原串下标转换出错**：原串第 $k$ 个字符（1-indexed）在新串中位置是 $2k$

- **回文长度计数**：$p[i]$ 直接是原串中最长回文长度（变换的奇妙之处），不需要除 2

- **`(p[i] + 1) / 2`** 不要写成 `p[i] / 2`——前者向上取整，后者向下取整。正确公式是向上取整
