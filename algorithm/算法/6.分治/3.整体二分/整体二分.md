#难度/★★★★★

> 把所有查询"打包"放到一个二分框架中——共享一次"对答案值域的二分"，用一次扫描划分查询。

## 核心思想

**整体二分（Parallel Binary Search）**：处理"多次查询且每次查询的答案都可以二分"的问题——把**所有查询整体放入一个二分框架**，共享二分的代价。

**朴素思路**：单独处理每次查询——每次都做一次"二分答案"，每次二分代价 $O(\log V)$，每个二分内部处理 $O(\text{check})$。总复杂度 $O(q \log V \cdot \text{check})$。

**整体二分的洞察**：

> 对所有查询，**共用同一个二分框架**——当前考虑的"候选答案区间"是 $[\mathtt{vl}, \mathtt{vr}]$，候选查询集合是 $Q$。取 $\mathtt{vmid}$，**用一次扫描**就能把所有查询分成两类：

> - 答案 $\le \mathtt{vmid}$ 的查询 → 递归到左半 $[\mathtt{vl}, \mathtt{vmid}]$

> - 答案 $> \mathtt{vmid}$ 的查询 → 递归到右半 $[\mathtt{vmid}+1, \mathtt{vr}]$

每层"扫描 + 划分"花 $O((n + q) \cdot T)$，共 $O(\log V)$ 层——总 $O((n + q) T \log V)$。$T$ 是单次"判断答案是否 $\le \mathtt{vmid}$"的代价。

**经典应用——静态区间第 $k$ 小**：

> 给一个数组 $a[1..n]$，多次查询：$[l, r]$ 内第 $k$ 小的值是什么？

朴素：主席树 $O(\log n)$ 单次查询。

**整体二分**：

1. 把所有"$\le \mathtt{vmid}$"的元素加入 BIT

2. 对每个查询 $(l, r, k)$ 计算 $\mathtt{cnt} = $ "$[l, r]$ 内值 $\le \mathtt{vmid}$ 的元素数"（用 BIT 求区间和）

3. 若 $\mathtt{cnt} \ge k$：答案 $\le \mathtt{vmid}$，划入左半（保留 $k$ 不变）

4. 若 $\mathtt{cnt} < k$：答案 $> \mathtt{vmid}$，划入右半（$k \mathrel{-}= \mathtt{cnt}$，因为已"消耗"了 $\mathtt{cnt}$ 个 $\le \mathtt{vmid}$ 的）

5. 递归处理左右两半

每层 $O(n + q)$ BIT 操作，共 $O(\log V)$ 层——总 $O((n + q) \log n \log V)$。

## 适用场景

- **多次查询同类问题**，每次答案可二分

- **"第 $k$ 小 / 第 $k$ 大"类问题**：静态、带修都行

- **"满足条件的最早 / 最晚时刻"问题**：把时间维放进二分中

- 经典模型：

  - 静态区间第 $k$ 小（替代主席树的离线版）

  - 带修区间第 $k$ 小（动态主席树的优雅替代）

  - **某操作完成后整数最早达到某值的查询**

  - 离线动态最大流 / 最短路类查询

- 不适用：强制在线（整体二分本质离线）；答案不能二分的查询（如众数）

## 步骤拆解

**通用框架**：

1. **设计"操作 / 查询"事件集**：把"修改元素"和"询问答案"统一到一个 `event` 列表中

2. **二分函数 $\mathtt{solve}(\mathtt{vl}, \mathtt{vr}, Q)$**：

   a. 若 $Q$ 为空，返回

   b. 若 $\mathtt{vl} = \mathtt{vr}$：所有查询的答案都是 $\mathtt{vl}$，记录答案返回

   c. $\mathtt{vmid} = (\mathtt{vl} + \mathtt{vr}) / 2$

   d. 遍历 $Q$ 中的每个事件——

     - **修改事件**：若修改值 $\le \mathtt{vmid}$，应用到辅助数据结构（如 BIT）；放入左半队列

     - **查询事件**：用辅助数据结构判断"当前是否满足条件"——满足则放左半，否则更新查询参数后放右半

   e. **撤销**辅助数据结构，避免污染递归

   f. 递归 $\mathtt{solve}(\mathtt{vl}, \mathtt{vmid}, Q_\text{左})$

   g. 递归 $\mathtt{solve}(\mathtt{vmid}+1, \mathtt{vr}, Q_\text{右})$

## 代码模板

**模板：静态区间第 $k$ 小（整体二分版）**

```cpp
class kth_static {

private:

    struct event {

        int type;                               // 0 = 修改（插入元素）, 1 = 查询

        int x, y, k, qid;

        // 修改：x 表示位置, y 表示值

        // 查询：x = l, y = r, k = 当前 k 值, qid = 原始查询编号

    };

    int n, q, max_v;

    vector<event> all_events;

    vector<int> ans;

    vector<int> bit;

    int lowbit(int x) { return x & -x; }

    void update(int i, int val) {

        while (i <= n) { bit[i] += val; i += lowbit(i); }

    }

    int query(int i) {

        int sum = 0;

        while (i > 0) { sum += bit[i]; i -= lowbit(i); }

        return sum;

    }

    int range_query(int l, int r) {

        return query(r) - query(l - 1);

    }

    void solve(int vl, int vr, vector<event>& evs) {

        if (evs.empty()) return;

        if (vl == vr) {

            for (auto& e : evs) {

                if (e.type == 1) {

                    ans[e.qid] = vl;

                }

            }

            return;

        }

        int vmid = vl + (vr - vl) / 2;

        vector<event> left_evs, right_evs;

        for (auto& e : evs) {

            if (e.type == 0) {

                // 修改事件：值 ≤ vmid 才生效
                if (e.y <= vmid) {

                    update(e.x, 1);

                    left_evs.push_back(e);

                } else {

                    right_evs.push_back(e);

                }

            } else {

                int cnt = range_query(e.x, e.y);    // [l, r] 中值 ≤ vmid 的个数

                if (cnt >= e.k) {

                    left_evs.push_back(e);          // 答案 ≤ vmid

                } else {

                    e.k -= cnt;                     // 关键：减去已计数的

                    right_evs.push_back(e);         // 答案 > vmid

                }

            }

        }

        // 撤销 BIT（只清掉本次插入的）
        for (auto& e : evs) {

            if (e.type == 0 && e.y <= vmid) {

                update(e.x, -1);

            }

        }

        solve(vl, vmid, left_evs);

        solve(vmid + 1, vr, right_evs);

    }

public:

    kth_static(int n_in, vector<int>& a, vector<tuple<int, int, int>>& queries) {

        n = n_in;

        q = queries.size();

        max_v = 0;

        bit.assign(n + 1, 0);

        ans.assign(q, 0);

        for (int i = 1; i <= n; i++) {

            max_v = max(max_v, a[i]);

            all_events.push_back({0, i, a[i], 0, 0});

        }

        for (int i = 0; i < q; i++) {

            auto [l, r, k] = queries[i];

            all_events.push_back({1, l, r, k, i});

        }

    }

    vector<int> compute() {

        solve(1, max_v, all_events);

        return ans;

    }

};
```

> 💡 **关键的 $k$ 更新**：当查询被划入右半时，$k \mathrel{-}= \mathtt{cnt}$——意思是"答案在 $> \mathtt{vmid}$ 的部分中是第 ($k - \mathtt{cnt}$) 小"。这种"减去已确定的部分"是整体二分的精髓。

> 💡 **事件次序的保持**：上面代码用 `vector<event>` 顺次存放事件，递归时保持原顺序——这能保证"修改事件在它影响的查询事件之前生效"。如果用了带修问题，还要按时间维严格排序。

> ⚠️ **撤销的两种实现**：

> - **方案 A（笔记中的写法）**：先扫一遍 `evs` 应用所有修改 + 划分，再扫一遍撤销 + 递归。逻辑清晰但要存储两次扫描结果

> - **方案 B（更省常数）**：扫描时同步做"应用 + 划分到队列"；递归前把队列保存，撤销，再递归。一遍扫描完成

## 复杂度分析

- 时间复杂度：$O((n + q) \log n \log V)$

  - $\log V$ 层（值域二分）

  - 每层 $O((n + q) \log n)$（BIT 的 $\log n$）

- 空间复杂度：$O(n + q)$

## 正确性证明

### 整体二分的归纳框架

**核心命题**：算法终止时，每个查询 $\mathtt{q}$ 的 $\mathtt{ans}[\mathtt{q.qid}]$ 等于真实答案。

**关键不变量**：对 $\mathtt{solve}(\mathtt{vl}, \mathtt{vr}, Q)$ 的每次调用——

- **(1) 答案在 $[\mathtt{vl}, \mathtt{vr}]$ 中**：$Q$ 中所有查询的真实答案都属于 $[\mathtt{vl}, \mathtt{vr}]$

- **(2) 修改事件已正确应用**：进入函数前，所有"值 $\le \mathtt{vl} - 1$"的修改已被应用过又撤销了（它们对当前 $Q$ 的判断不再相关）

- **(3) $k$ 已正确折算**：$Q$ 中查询的 $k$ 字段是"在 $[\mathtt{vl}, \mathtt{vr}]$ 值域内第 $k$ 小"中的 $k$

**证明（归纳）**：

**基础** $\mathtt{vl} = \mathtt{vr}$：所有查询的答案都被锁定为 $\mathtt{vl}$（值域只有一个值）。代码直接赋值正确。

**归纳**：假设对所有更小的子区间不变量成立。考察当前 $\mathtt{solve}(\mathtt{vl}, \mathtt{vr}, Q)$——

**划分的正确性**：取 $\mathtt{vmid}$ 后，对每个查询 $(l, r, k)$ 计算 $\mathtt{cnt} = $ "$[l, r]$ 内值 $\le \mathtt{vmid}$ 的元素数"——

- 若 $\mathtt{cnt} \ge k$：$[l, r]$ 内有至少 $k$ 个元素 $\le \mathtt{vmid}$——所以第 $k$ 小 $\le \mathtt{vmid}$。划入左半正确。$k$ 保持不变。

- 若 $\mathtt{cnt} < k$：$[l, r]$ 内只有 $\mathtt{cnt}$ 个元素 $\le \mathtt{vmid}$，第 $k$ 小必 $> \mathtt{vmid}$。划入右半，新 $k = k - \mathtt{cnt}$ 表示"在 $> \mathtt{vmid}$ 的元素中找第 $(k - \mathtt{cnt})$ 小"——正确。

**子调用的不变量满足**：

- 左半调用 $\mathtt{solve}(\mathtt{vl}, \mathtt{vmid}, Q_\text{左})$——$Q_\text{左}$ 中查询答案都 $\le \mathtt{vmid}$（已证），且修改"值 $\le \mathtt{vmid}$"已被应用，划入左半。所以左半调用进入时不变量满足。

- 右半调用 $\mathtt{solve}(\mathtt{vmid}+1, \mathtt{vr}, Q_\text{右})$——撤销了"值 $\le \mathtt{vmid}$"的修改，让 BIT 回到"空"状态；右半递归进入后会重新插入"值 $\le$ 新 $\mathtt{vmid}$"的修改。$k$ 已折算。不变量满足。

由归纳，整个算法正确。$\blacksquare$

### 撤销的必要性

**反例构造**：若不撤销，左半递归插入的元素会"残留"在 BIT 中。当算法回到右半时——

- BIT 中存在的"值 $\le \mathtt{vmid}$ 的元素"被错误地视为"也算上"

- 右半的查询会得到错误的 $\mathtt{cnt}$，划分错误

**正确做法**：每个 $\mathtt{solve}$ 调用结束前必须把本次添加的修改全部撤销——保证 BIT 在"任何 $\mathtt{solve}$ 调用进入时"都是空的（除非父层显式插入了某些元素）。

更准确地，本笔记中的实现在父层 $\mathtt{solve}$ 中：

1. 扫描 → 应用左半修改、划分查询

2. 撤销左半修改

3. 递归左半（左半内部会自己重新插入）

4. 递归右半

这样保证 BIT 在递归边界处是干净的。$\blacksquare$

### 复杂度的来源

- 每层处理一组 $Q$，扫描 + BIT 操作 $O((|Q| + |\text{修改事件}|) \log n)$

- 所有层的 $|Q|$ 之和 $\le q \log V$（每个查询参与每层一次，共 $\log V$ 层）

- 同理修改事件总贡献 $O(n \log V)$

- 总：$O((n + q) \log n \log V)$

### 与朴素二分的对比

朴素地为每个查询独立做二分：

- 每次二分 $\log V$ 步，每步要做一次区间统计（如建主席树或排序后二分）

- 单次查询 $O(\log V \cdot \text{check})$

- 总 $O(q \log V \cdot \text{check})$

整体二分把"每个查询独立的 $\log V$ 二分树"**合并成同一棵树**——每层的检查代价被所有查询**摊销**——总复杂度只多了一个 $\log n$ 因子（来自数据结构操作）。

这是经典的 **离线批处理优化思想**，与 [[CDQ分治]] 的"分治整合"思路类似但不同。

## 应用：带修区间第 $k$ 小

**问题**：动态序列上的查询 $(l, r, k)$，支持单点修改 + 区间第 $k$ 小。

**朴素**：动态主席树（很难写）。

**整体二分的处理**：

- "事件"包括：修改事件（位置 $x$ 的值改为 $v$）和查询事件 $(l, r, k)$

- 修改事件可拆为"删除旧值"和"插入新值"——每个修改产生两个事件

- 在整体二分中按事件顺序处理（保证修改事件先于受其影响的查询）

**关键**：事件**先按时间排序**，确保"修改先于查询"。其他逻辑与静态版完全相同。

| -------------- | ----------------- | -------------------------- | ----- |
| 主席树            | 静态区间第 $k$ 小，在线    | $O((n + q) \log n)$        | 中     |

**经验**：能在线就用主席树（虽然复杂度差不多但代码长）；离线 + "答案可二分"——整体二分往往是写起来最简洁的方案。

## 几个常见错误

- **忘记撤销 BIT**：会污染右半的递归。撤销逻辑要清晰

- **事件顺序错位**：带修问题中修改事件必须先于受其影响的查询事件——按 `qid` 排序或按时间维全局排序

- **$k$ 折算时机错**：必须在划入右半时立即更新 $k$，否则后续递归 $k$ 不对

- **递归终点不写答案**：$\mathtt{vl} = \mathtt{vr}$ 时要把 $\mathtt{ans}[\mathtt{q.qid}] = \mathtt{vl}$ 写好
