#难度/★★★★★

> 离线区间查询的奇妙排序——按"左端点的块、右端点"双关键字排序后，两个指针的总移动次数被压到 $O(n \sqrt n)$。

## 前置知识

- [[分块]]

- [[离散化]]

## 核心思想

**莫队解决什么问题？** 给定一个数组和若干**离线**的区间查询 $(l_i, r_i)$（如"区间内不同数的个数"），朴素 $O(nq)$ 暴力太慢。如果维护信息支持"单步增量"（添加 / 删除一个元素 $O(1)$），莫队能把总耗时压到 $O(n \sqrt n)$。

**核心机制——两指针扫描**：维护两个指针 $L, R$ 表示"当前区间 $[L, R]$"，每次查询通过若干次"端点 $\pm 1$"的小步移动到达目标区间，移动过程中用 `add(pos)` / `remove(pos)` 增量维护答案。

**关键的排序策略**：把所有查询按 $(\mathtt{bl}(L_i), R_i)$ **双关键字**排序——

- 同一个 $L$ 块内的查询按 $R$ 单调排序

- $L$ 在每个查询内部至多移动 $O(\sqrt n)$ 步（块大小）

- 跨块时 $L$ 至多跳 $O(\sqrt n)$ 步

**核心思想总结**——"牺牲单次查询的移动顺序，换取整体的有序性"。朴素按读入顺序每个查询最坏 $O(n)$ 移动；莫队排序后整体 $O((n + q) \sqrt n)$，平均每查询 $O(\sqrt n)$。这是典型的"离线 $+$ 整体优化"思路。

**必备前提**：单步移动（添加 / 删除一个元素）必须是 $O(1)$ 或小常数——莫队的复杂度全靠这个支撑。

**不变量**：进入处理某个查询前，全局变量 / 桶反映的是当前 $[L, R]$ 区间的真实信息。

## 适用场景

- **离线区间查询**问题：区间不同数个数、区间众数、区间第 $k$ 小（变种）

- **可逆的增量信息**：

  - ✅ **可维护**：区间元素和、出现次数、不同值个数、异或和、$\sum a_i^2$ 等"加法可逆"信息

  - ❌ **不可维护**：区间最大值（删除时不知最大值变成什么）、区间排序后第 $k$ 大（频繁查询要 $O(\log)$）

- 不适用：强制在线（莫队是离线的）；信息无法 $O(1)$ 增量维护（需考虑回滚莫队）

## 步骤拆解

**通用框架**：

1. **读入所有查询**，给每个查询编号

2. **按莫队规则排序**（$L$ 块号升序，同块内 $R$ 升序——可加奇偶优化）

3. **初始化**两个指针 $L = 1, R = 0$（表示空区间）和**全局信息**（如当前区间内每个值的出现次数桶）

4. **依次处理每个查询**：用 add / remove 把 $L, R$ 调整到目标位置；调整顺序遵循"**先扩张后收缩**"避免 $L > R$ 的非法状态

5. **记录答案**到原查询编号对应位置

6. **输出**时按原编号还原顺序

## 代码模板

**模板：经典区间不同数个数（区间内有多少种不同的值）**

```cpp

class mo_distinct {

private:

    int n, q;

    int B;                                      // 块大小 = sqrt(n)

    vector<int> a;                              // 原数组（已离散化）

    int max_val;                                // 离散化后的值域大小

    struct query {

        int l, r, id;

    };

    vector<query> queries;

    vector<int> cnt;                            // cnt[v] = 当前区间中值 v 的出现次数

    int cur_distinct;                           // 当前不同值的个数

    int bl(int i) { return (i - 1) / B + 1; }

    void add(int pos) {

        int v = a[pos];

        if (cnt[v] == 0) {

            cur_distinct += 1;

        }

        cnt[v] += 1;

    }

    void remove(int pos) {

        int v = a[pos];

        cnt[v] -= 1;

        if (cnt[v] == 0) {

            cur_distinct -= 1;

        }

    }

public:

    mo_distinct(vector<int>& a_in, vector<pair<int, int>>& qs, int max_val_in) {

        n = a_in.size() - 1;

        q = qs.size();

        a = a_in;

        max_val = max_val_in;

        B = max(1, (int)sqrt(n));

        queries.resize(q);

        for (int i = 0; i < q; i++) {

            queries[i] = {qs[i].first, qs[i].second, i};

        }

    }

    vector<int> solve() {

        // 1. 莫队排序（带奇偶优化）
        sort(queries.begin(), queries.end(), [&](const query& x, const query& y) {

            int bx = bl(x.l), by = bl(y.l);

            if (bx != by) {

                return bx < by;

            }

            return (bx & 1) ? x.r > y.r : x.r < y.r;

        });

        // 2. 双指针处理
        cnt.assign(max_val + 1, 0);

        cur_distinct = 0;

        int L = 1, R = 0;

        vector<int> ans(q);

        for (auto& qu : queries) {

            // 注意四个 while 的顺序——先扩张后收缩，避免 L > R 时的非法状态
            while (R < qu.r) add(++R);

            while (L > qu.l) add(--L);

            while (R > qu.r) remove(R--);

            while (L < qu.l) remove(L++);

            ans[qu.id] = cur_distinct;

        }

        return ans;

    }

};
```

> 💡 **奇偶优化（"卡常神器"）**：排序时若 $L$ 块号为奇数则 $R$ 降序，偶数则 $R$ 升序。这样跨块时 $R$ 不需要"从最大跳到最小"重新走一遍——它顺势从一个方向跑到另一个方向。理论上仍是 $O(n \sqrt n)$，但常数减半。

> ⚠️ **四个 while 的顺序至关重要**：必须先 add 后 remove——

```cpp

while (R < qu.r) add(++R);          // R 右扩

while (L > qu.l) add(--L);          // L 左扩

while (R > qu.r) remove(R--);       // R 左收

while (L < qu.l) remove(L++);       // L 右收
```

> 若顺序错（如先 `R--` 再 `L++`），中间可能出现 `L > R` 的非法状态，导致 add / remove 操作的元素重叠或缺失，统计错误。

> ⚠️ **离散化与值域桶**：若原值很大（如 $10^9$），先 [[离散化]] 把值压到 $[1, n]$，否则 `cnt[]` 数组开不下。

## 复杂度分析

- 时间复杂度：

  - 排序：$O(q \log q)$（双关键字排序）

  - 单次端点移动：$O(1)$（由具体问题的 add / remove 决定）

  - 处理 $q$ 次查询：$O((n + q) \sqrt n)$

  - 总体：通常 $q$ 与 $n$ 同级，简记为 $O(n \sqrt n)$

- 空间复杂度：$O(n + q)$（原数组 $+$ 值域桶 $+$ 查询数组）

## 正确性证明

### 为什么 $O(n \sqrt n)$ 总移动

**关键命题**：经莫队排序后，$L$ 指针总移动次数 $O(n + q \sqrt n)$，$R$ 指针总移动次数 $O(n \sqrt n)$。

**$L$ 的移动分析**：

- **同一 $L$ 块内**：所有查询的 $L$ 都在同一个 $\sqrt n$ 大小的块里——$L$ 在块内随便走也至多 $\sqrt n$ 步/查询。$q$ 个查询合计 $O(q \sqrt n)$

- **跨 $L$ 块**：从一块切换到下一块时 $L$ 跳一次，每次跳跃 $\le 2 \sqrt n$ 步。共 $\sqrt n$ 个块——总跳跃 $O(n)$

合计 $O(n + q \sqrt n)$。

**$R$ 的移动分析**：

- **同一 $L$ 块内**：所有查询按 $R$ 升序排列——$R$ 单调右移，整个块内总移动 $\le n$

- **跨 $L$ 块**：从前一块的最后一个查询切到当前块的第一个查询——$R$ 可能从 $n$ 跳回到很小。最坏每次跨块 $R$ 跳 $O(n)$ 步。共 $\sqrt n$ 个块切换——合计 $O(n \sqrt n)$

总计 $O(n \sqrt n + q \sqrt n) = O((n + q) \sqrt n)$，常 $q \le n$ 时简记为 $O(n \sqrt n)$。$\blacksquare$

### 为什么 $L$ 块大小 $= \sqrt n$ 最优

设块大小为 $B$。

- $L$ 块内移动：$O(q \cdot B)$

- $L$ 跨块跳跃：$O(B \cdot n / B) = O(n)$

- $R$ 同块单调：$O(n)$ 每块，共 $n / B$ 块，合计 $O(n^2 / B)$

总 $T(B) = O(q B + n^2 / B)$。求导得 $B = n / \sqrt q$。当 $q \approx n$ 时 $B = \sqrt n$，得 $O(n \sqrt n)$。

实战中通常取 $B = \sqrt n$ 即可。

### 排序策略的本质

莫队的"奇思妙想"在于**牺牲单次查询的移动**换取**整体的有序性**——

- 朴素按读入顺序处理：每个查询最坏 $O(n)$ 移动，总 $O(nq)$

- 莫队排序：每个查询平均 $O(\sqrt n)$ 移动，总 $O((n + q) \sqrt n)$

这是经典的"离线 $+$ 整体优化"思路——单看每次操作很慢，但整体加起来反而快。

### 维护信息的"增量性"要求

莫队的精髓是 add / remove 操作 $O(1)$。这意味着可维护信息必须是"加法可逆"的——区间元素和、出现次数、不同值个数、异或和、$\sum a_i^2$ 等都行。但区间最大值这类"删除困难"的信息不行（删除时不知最大值变成什么）。

对于"删除困难"的问题，有**回滚莫队**——只 add 不 remove，每次查询前回滚到一个保存好的状态。代价是代码复杂得多。

### 与 [[分块]] 的关系

莫队**借用了分块的思想来排序**——把 $L$ 按块分组，块内按 $R$ 排序。所以"莫队 $=$ 排序意义上的分块 $+$ 双指针扫描"，常被归入分块的扩展。

## 应用扩展

**变种一：区间众数**

维护 `cnt[v]`（值频次）$+$ `cnt_freq[k]`（频次为 $k$ 的值个数）。但移除时"频次最高的值变化"难以 $O(1)$ 维护——需要更精巧的"分块 $+$ 莫队"。

**变种二：带修莫队**

增加"时间维度"，按 $($ $L$ 块, $R$ 块, 时间 $)$ 三维排序，复杂度 $O(n^{5/3})$。

**变种三：树上莫队**

把树上路径转 DFS 序后跑莫队，常配合括号序处理路径上的点权。

**变种四：回滚莫队**

只 add 不 remove，每次查询前回滚到一个保存好的状态。处理 max / min / mex 这类"删除困难"的信息。

| 算法            | 复杂度                   | 适用                | 实现难度  |
| ------------- | --------------------- | ----------------- | ----- |
| 莫队            | $O(n \sqrt n)$        | 增量可维护的区间信息        | 中     |
| [[整体二分]]      | $O((n + q) \log^2 n)$ | 可二分的查询            | 高     |
| [[CDQ分治]]     | $O(n \log^2 n)$       | 二维 / 三维偏序         | 高     |
| 离线 [[扫描线]]    | $O((n + q) \log n)$   | 线段树能维护的离线区间问题     | 中     |
