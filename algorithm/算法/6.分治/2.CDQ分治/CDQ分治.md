## 核心思想

**CDQ 分治**（陈丹琦命名）是处理"**多维偏序**"问题的标准技巧——

> **三维偏序问题**：给定 $n$ 个三元组 $(a_i, b_i, c_i)$，对每个 $i$ 求满足 $a_j \le a_i \land b_j \le b_i \land c_j \le c_i$（$j \ne i$）的 $j$ 的个数。

**朴素 $O(n^2)$ 太慢，主席树或线段树嵌套又写得复杂**——CDQ 分治给出 $O(n \log^2 n)$ 的优雅离线解法。

**核心思想**——**用归并分治"消去"一维**：

1. 先按第一维 $a$ 排序（消去第一维：现在 $i < j \Rightarrow a_i \le a_j$）

2. CDQ 分治：把序列分成左右两半 $[l, \mathtt{mid}]$ 和 $[\mathtt{mid}+1, r]$——

   - 递归处理 $[l, \mathtt{mid}]$ 内部的贡献

   - 递归处理 $[\mathtt{mid}+1, r]$ 内部的贡献

   - **关键**：处理"左半元素对右半元素"的**跨区间贡献**

3. 跨界贡献：左半的所有元素 $a$ 都 $\le$ 右半（已排序），第一维**自动满足**。剩下两维用——

   - **第二维**：按 $b$ 归并排序两半，左半 $i$ 在 $b$ 升序中加入 BIT

   - **第三维**：右半 $j$ 在 BIT 中查询 $c \le c_j$ 的元素个数

**为什么"消去一维"？**

普通做法处理三维偏序需要"三维数据结构"（如三维 BIT）——空间和复杂度都很高。CDQ 分治通过递归"假装"一维已经处理好（左半的 $a$ 都 $\le$ 右半），把问题降到二维。

**类比 [[扫描线]]**：扫描线是按一维排序后用一维数据结构维护另一维——CDQ 分治类似，只不过"扫描"由"分治"代替，能处理更复杂的偏序结构。

## 适用场景

- **三维偏序计数**（最经典应用）

- **二维带修偏序**：把"修改时间"作为第三维，离线后跑三维 CDQ

- **决策单调性 dp 优化**：CDQ 分治 + 凸壳维护

- **动态加点的最近点对**之类需要"按时间维度切分"的离线问题

- **天平类问题** / **某些区间统计**：当问题能分解为多维偏序时

- 不适用：强制在线（CDQ 是离线算法）；偏序维度过多（4 维以上效率低）

## 步骤拆解

**三维偏序的 CDQ 框架**：

1. **预处理**：按第一维 $a$ 排序；对相同 $(a, b, c)$ 的元组**去重**并记录数量（避免重复计数）

2. **递归 cdq($l, r$)**：

   a. 若 $l \ge r$ 返回

   b. $\mathtt{mid} = (l + r) / 2$

   c. 递归 cdq($l, \mathtt{mid}$)

   d. 递归 cdq($\mathtt{mid}+1, r$)

   e. **合并**：按 $b$ 归并排序左右两半，处理跨界贡献——

     - 左半元素加入 BIT（按 $c$ 维度）

     - 右半元素在 BIT 中查询 $c \le c_j$ 的个数

   f. **撤销**：把左半元素从 BIT 中去掉，避免影响其他递归

3. 最终每个元组 $i$ 的 $\mathtt{ans}[i]$ 即"满足 $a_j \le a_i \land b_j \le b_i \land c_j \le c_i$ 的 $j$ 个数"

## 代码模板

**模板：三维偏序计数**

```cpp
class cdq_3d {

private:

    struct point {

        int a, b, c;

        int cnt;                                // 相同 (a, b, c) 的元组数

        int ans;                                // 答案：有多少元组满足偏序条件

    };

    int n, max_c;

    vector<point> ps;

    vector<int> bit;

    int lowbit(int x) { return x & -x; }

    void update(int i, int val) {

        while (i <= max_c) { bit[i] += val; i += lowbit(i); }

    }

    int query(int i) {

        int sum = 0;

        while (i > 0) { sum += bit[i]; i -= lowbit(i); }

        return sum;

    }

    void cdq(int l, int r) {

        if (l >= r) return;

        int mid = l + (r - l) / 2;

        cdq(l, mid);

        cdq(mid + 1, r);

        // 合并：按 b 归并 + BIT 维护 c
        vector<point> tmp;

        tmp.reserve(r - l + 1);

        int i = l, j = mid + 1;

        while (i <= mid && j <= r) {

            if (ps[i].b <= ps[j].b) {

                update(ps[i].c, ps[i].cnt);     // 左半元素插入 BIT

                tmp.push_back(ps[i]);

                i++;

            } else {

                ps[j].ans += query(ps[j].c);    // 右半元素查询

                tmp.push_back(ps[j]);

                j++;

            }

        }

        while (i <= mid) {

            update(ps[i].c, ps[i].cnt);

            tmp.push_back(ps[i++]);

        }

        while (j <= r) {

            ps[j].ans += query(ps[j].c);

            tmp.push_back(ps[j++]);

        }

        // 撤销 BIT（仅清掉本次合并加进去的左半元素）
        for (int k = l; k <= mid; k++) {

            update(ps[k].c, -ps[k].cnt);

        }

        // 写回归并结果（保持 b 的有序性，方便上层归并）
        for (int k = 0; k < (int)tmp.size(); k++) {

            ps[l + k] = tmp[k];

        }

    }

public:

    cdq_3d(vector<point>& pts, int max_c_in) {

        ps = pts;

        n = ps.size() - 1;

        max_c = max_c_in;

        // 1. 按 a 排序，相同 a 按 b、再按 c
        sort(ps.begin() + 1, ps.end(), [](const point& x, const point& y) {

            if (x.a != y.a) return x.a < y.a;

            if (x.b != y.b) return x.b < y.b;

            return x.c < y.c;

        });

        // 2. 去重（合并相同三元组的 cnt）

        // ... (省略具体去重代码)

        bit.assign(max_c + 1, 0);

    }

    void solve() {

        cdq(1, n);

        // 注意：相同三元组之间也要互相计数（cnt - 1 个互相统计）
        for (int i = 1; i <= n; i++) {

            ps[i].ans += ps[i].cnt - 1;

        }

    }

};
```

> 💡 **关键三步**：**插入左半 → 查询右半 → 撤销左半**。撤销很重要——不然会污染 BIT 影响其他递归调用。

> 💡 **三相同元组的特殊处理**：若三元组 $(a, b, c)$ 与某 $j$ 完全相同——按字典序排序后这些元组连续，但分治可能把它们切到不同段中。一种简洁做法：**先去重**，把完全相同的元组合并并记录数量 `cnt`；插入 BIT 时加 `cnt`，查询时累加 `cnt`。最后还要补上"自己人内部互相计数"。

> ⚠️ **写回归并结果的必要性**：合并完成后 `ps[l..r]` 应按 $b$ 升序——这样上层递归调用本段时不需要重新排序。**不写回是常见错误**！

> ⚠️ **`b` 相等时的处理**：归并条件用 `<=` 而非 `<`——表示"左半中 $b$ 等于当前右半 $j$ 的元素也算 $\le b_j$"，被纳入贡献统计。这与"$j_2 \le j_1$"的偏序定义一致。

## 复杂度分析

- 时间复杂度：$O(n \log^2 n)$

  - 每层归并 $O(n)$ + BIT 操作 $O(n \log n)$

  - 共 $O(\log n)$ 层

- 空间复杂度：$O(n)$（BIT + 临时归并数组）

## 正确性证明

### 三维偏序的贡献分类

**核心命题**：每对元组 $(i, j)$（$i \ne j$）的偏序贡献被算法**恰好统计一次**。

把所有"满足偏序的对"分类：

1. **同段内的对**（$i, j$ 都在 $[l, \mathtt{mid}]$ 或都在 $[\mathtt{mid}+1, r]$）→ 由递归调用统计

2. **跨段对**（$i \in [l, \mathtt{mid}], j \in [\mathtt{mid}+1, r]$）→ 由当前层合并统计

由于第一维已排序，跨段对自动满足 $a_i \le a_j$。

### 跨段贡献的统计正确性

**合并步骤的不变量**：每次"右半 $j$ 查询 BIT"前，BIT 中恰好包含**当前左半中所有 $b \le b_j$ 的元素**（按 $c$ 维度）。

**证明（归并的双指针逻辑）**：

考虑归并指针 $i$（左半）和 $j$（右半）。每次比较 $b_i$ 和 $b_j$——

- 若 $b_i \le b_j$：把左半 $i$ 加入 BIT（$b_i$ 被"激活"），$i$ 推进

- 若 $b_i > b_j$：右半 $j$ 在 BIT 中查询 $c \le c_j$ 的个数；$j$ 推进

**关键**：$j$ 查询时 BIT 中包含的左半元素 $i'$ 满足 $b_{i'} \le b_j$。这是因为指针推进规则：$i'$ 加入 BIT 时必有 $b_{i'} \le$ 某个右半元素 $j'$ 的 $b_{j'}$；右半已按 $b$ 升序，$j' \le j$ 蕴含 $b_{j'} \le b_j$，所以 $b_{i'} \le b_j$。

进一步，BIT 查询 `query(c_j)` 给出 $c_{i'} \le c_j$ 的元素个数——满足 $b_{i'} \le b_j \land c_{i'} \le c_j$ 的左半元素数。结合"左半 $a_{i'} \le a_j$"（按 $a$ 排序的全局性质），这些就是对 $j$ 有贡献的 $i'$。$\blacksquare$

### 撤销 BIT 的必要性

合并结束后，BIT 中残留了左半元素的"频次"。如果不撤销，递归回到父层处理另一段时——

- 父层的"另一边"在被调用时，BIT 中混入了无关数据，查询结果错误

**正确做法**：每次合并完成后立即撤销——把本次插入的左半元素逐个 `update(-cnt)` 抹掉。这样 BIT 保持"全局空"的不变量。$\blacksquare$

### 写回归并结果的必要性

**原因**：合并完成后 $\mathtt{ps}[l..r]$ 应按 $b$ 升序。当父层调用 cdq 处理更大的区间时，左右两半各自已按 $b$ 排序——可以直接归并，无需重新排序。

如果不写回——子层的递归乱序了 $b$，父层归并时双指针逻辑不再成立（左半不是升序）。$\blacksquare$

### 复杂度的来源

设 $T(n)$ 为分治函数处理长度 $n$ 的耗时。

$$T(n) = 2 T(n / 2) + O(n \log n)$$

合并的 $O(n)$ 归并 + $O(n)$ 次 BIT 操作 = $O(n \log n)$。由主定理（$f(n) = n \log n > n^{c^*} = n$）：

$$T(n) = O(n \log^2 n)$$

$\blacksquare$

## 应用：二维带修偏序

经典问题——**带修区间逆序对**：维护一个序列，支持单点修改 + 查询区间逆序对。

**转化为三维偏序**：每次操作 $(t, x, v)$ 看作三元组——

- 第一维 $t$：操作时间

- 第二维 $x$：位置

- 第三维 $v$：值

**修改的本质**：在时间 $t$ 加入 $(x, v)$（增加一个"存在"），同时减去之前的 $(x, v_\text{old})$。

**查询逆序对**：需统计"时间在前、位置在前、值在后"的对数——三维偏序计数的变种。

CDQ 分治套上"按时间分治 + 按位置归并 + 按值用 BIT"即可。这是 CDQ 应用的典型范式。

## 几个常见错误

- **忘记排序第一维**：CDQ 分治依赖"分治后左半的 $a$ 都 $\le$ 右半"，必须先按 $a$ 排序

- **忘记去重**：相同三元组的处理要谨慎，否则可能重复计数或漏计数

- **撤销 BIT 时机错**：必须在合并的 ***最后***、写回归并结果 ***之前*** 撤销

- **忘记写回**：递归回父层时左右两半应按 $b$ 升序——不写回会破坏父层归并
