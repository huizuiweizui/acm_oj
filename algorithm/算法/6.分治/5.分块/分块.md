#难度/★★★★

> 把序列分成 $\sqrt n$ 个块，每块维护聚合信息——用"$O(\sqrt n)$ 个完整块 + 边角暴力"给出朴素易写的 $O(n \sqrt n)$ 区间操作。

## 核心思想

**为什么需要分块？** 区间问题朴素做法是 $O(n)$ 每次操作；线段树能 $O(\log n)$ 但有时维护的信息（如**区间众数**、**区间第 $k$ 大**）难以高效合并。分块给出第三种思路：用 $O(\sqrt n)$ 换"维护信息的灵活度"。

**核心思想——平衡两种"暴力"**：把长度为 $n$ 的序列等分为约 $\sqrt n$ 个**块**，每块大小约 $\sqrt n$；每块维护一些**聚合信息**（如块和、块最值、块的懒标记）——

- **块内暴力**：处理"块的边角"时直接遍历块内元素，单块 $O(\sqrt n)$

- **块间快速**：处理"完整覆盖的块"时直接用块的聚合信息，单块 $O(1)$

**为什么是 $\sqrt n$？** 设块大小为 $B$，区间操作要遍历 $O(n / B)$ 个完整块和 $2$ 个边角块（总共 $O(B)$ 项）。总耗时 $O(n / B + B)$，由 AM-GM 不等式在 $B = \sqrt n$ 时取最小值 $O(\sqrt n)$。

**不变量**：每个块的聚合量始终反映"该块的当前状态"——包括其上的懒标记效果。

## 适用场景

- **区间修改 + 区间查询**：当 [[线段树]] 写起来太复杂时的备选

- **维护复杂信息**：区间众数、区间第 $k$ 大、区间内某值出现次数等线段树难以高效合并的信息

- **配合 [[莫队]] 等离线技巧**：莫队中用分块来实现 $O(\sqrt n)$ 修改 $+$ $O(1)$ 查询的需求

- **题目卡了线段树常数**：分块虽然渐进慢但常数小，有时反而能过

- 不适用：信息能高效合并且要求 $O(\log n)$（用 [[线段树]] / [[树状数组]] / [[懒标记线段树]]）

## 步骤拆解

**核心约定**：

- $\mathtt{B}$：块大小，通常 $\lceil \sqrt n \rceil$

- $\mathtt{bl}[i] = (i - 1) / B + 1$：位置 $i$ 所属块（从 1 编号）

- 块 $b$ 覆盖的位置范围：$[(b-1) \cdot B + 1,\ \min(b \cdot B, n)]$

**通用框架**——对一段区间 $[l, r]$ 的修改 / 查询都遵循"三段式"处理：

1. **预处理（一次性）**：$B = \lceil \sqrt n \rceil$；遍历原数组，把每块的初始聚合量算好

2. **单点修改 / 查询**：定位 $\mathtt{bl}(i)$，直接改 / 读 $a[i]$，同步更新块聚合量

3. **区间修改 / 查询**——根据 $[l, r]$ 与块的关系分三段：

   a. **左边角不完整块**：从 $l$ 到本块末尾，**暴力遍历**修改 / 累加

   b. **中间完整块**：每块 $O(1)$，**直接打懒标记** / 用聚合量

   c. **右边角不完整块**：从下一块开头到 $r$，**暴力遍历**修改 / 累加

4. **特殊情况**：若 $l, r$ 在同一块内——退化为该块内暴力遍历

## 代码模板

**模板：区间加 + 区间求和**

```cpp

class block_decomposition {

private:

    int n, B, num_blocks;

    vector<long long> a;                        // 原数组

    vector<long long> sum;                      // sum[b] = 块 b 内当前元素之和

    vector<long long> tag;                      // tag[b] = 块 b 的懒标记（区间加值）

    int bl(int i) { return (i - 1) / B + 1; }

    int block_l(int b) { return (b - 1) * B + 1; }

    int block_r(int b) { return min(b * B, n); }

public:

    block_decomposition(vector<long long>& a_in) {

        n = a_in.size() - 1;

        a = a_in;

        B = max(1, (int)sqrt(n));

        num_blocks = (n + B - 1) / B;

        sum.assign(num_blocks + 1, 0);

        tag.assign(num_blocks + 1, 0);

        for (int i = 1; i <= n; i++) {

            sum[bl(i)] += a[i];

        }

    }

    void update(int l, int r, long long val) {

        int bl_l = bl(l), bl_r = bl(r);

        if (bl_l == bl_r) {

            // 同一块内：暴力修改
            for (int i = l; i <= r; i++) {

                a[i] += val;

                sum[bl_l] += val;

            }

            return;

        }

        // 左边角：暴力修改
        for (int i = l; i <= block_r(bl_l); i++) {

            a[i] += val;

            sum[bl_l] += val;

        }

        // 中间完整块：打懒标记
        for (int b = bl_l + 1; b <= bl_r - 1; b++) {

            tag[b] += val;

            sum[b] += val * (block_r(b) - block_l(b) + 1);

        }

        // 右边角：暴力修改
        for (int i = block_l(bl_r); i <= r; i++) {

            a[i] += val;

            sum[bl_r] += val;

        }

    }

    long long query(int l, int r) {

        int bl_l = bl(l), bl_r = bl(r);

        long long res = 0;

        if (bl_l == bl_r) {

            for (int i = l; i <= r; i++) {

                res += a[i] + tag[bl_l];        // 注意叠加懒标记

            }

            return res;

        }

        for (int i = l; i <= block_r(bl_l); i++) {

            res += a[i] + tag[bl_l];

        }

        for (int b = bl_l + 1; b <= bl_r - 1; b++) {

            res += sum[b];                      // 块 sum 已含懒标记

        }

        for (int i = block_l(bl_r); i <= r; i++) {

            res += a[i] + tag[bl_r];

        }

        return res;

    }

};
```

> 💡 **`sum[b]` 已含懒标记**：每次给块打懒标记时同步更新 `sum[b] += val * 块长`——这样查询完整块时不需要再加懒标记。代价是单点查询时要单独 `a[i] + tag[bl(i)]` 拼出真实值。

> ⚠️ **边角"打散"懒标记**：当区间操作的边角不完整时，必须先把块的懒标记**下放**到原数组中，再做局部修改——否则懒标记和暴力修改混合会出错。简化的做法是"不下放，但每次访问时都加上 tag"——上面代码用的就是这种风格（`a[i] + tag[bl(i)]` 总能给出真实值）。

## 复杂度分析

- 时间复杂度：

  - 建块（预处理）：$O(n)$

  - 单点修改 / 单点查询：$O(1)$

  - 区间修改 / 区间查询：$O(\sqrt n)$（$O(n/B)$ 个完整块 $+$ $2$ 个边角块的 $O(B)$）

- 空间复杂度：$O(n + \sqrt n) = O(n)$（原数组 $+$ 块聚合量 $+$ 块懒标记）

## 正确性证明

### 为什么 $B = \sqrt n$ 最优

设块大小为 $B$，则块数为 $\lceil n / B \rceil$。一次区间操作涉及——

- 至多 $O(n / B)$ 个**完整块**：每个 $O(1)$

- 至多 $2$ 个**边角块**：每个内部 $O(B)$

总耗时 $T(B) = O(n / B + B)$。求导 $\frac{dT}{dB} = -n / B^2 + 1 = 0$ 得 $B = \sqrt n$，此时 $T = O(\sqrt n)$。

**这是 AM-GM 不等式的应用**：$\frac{n}{B} + B \ge 2 \sqrt{n}$，等号当且仅当 $\frac{n}{B} = B$ 即 $B = \sqrt n$ 时取到。

### 边角暴力的正确性

边角操作直接遍历原数组——必须保证读到的 $a[i]$ 是"考虑懒标记后的真实值"。两种实现策略——

**策略 A（懒标记下放式）**：每次操作边角块前，把块的 `tag` 全部应用到 $a[\cdot]$ 上、清空 `tag`。优点是 $a[i]$ 永远反映真实值，逻辑简单；缺点是边角操作可能多 $O(\sqrt n)$ 工作（虽不影响渐进复杂度）。

**策略 B（懒标记不下放式）**：永不下放，访问 $a[i]$ 时拼接 $a[i] + \mathtt{tag}[\mathtt{bl}(i)]$。优点是逻辑紧凑；缺点是修改边角时容易错（修改要"算上历史懒标记"或"修改前先下放本块"）。

上面代码用了**策略 B 的简化版**——边角修改不下放（直接累加，懒标记仍生效到所有元素），查询时拼接。这要求懒标记是"加法"形式（可叠加）才行。若是"赋值"型懒标记则必须用策略 A。

### 完整块的正确性

完整块的 $\mathtt{sum}[b]$ 维护"该块当前元素和"——包含懒标记的效果（每次打 tag 时同步更新 sum）。所以查询时直接用 $\mathtt{sum}[b]$ 即可。

$\blacksquare$

## 与其他区间数据结构的对比

| 结构        | 区间修改            | 区间查询           | 代码量 | 灵活度（维护复杂信息）  |
| --------- | --------------- | -------------- | --- | ------------ |
| [[树状数组]]  | $O(\log n)$（差分） | $O(\log n)$    | 短   | 仅可差分信息       |
| [[线段树]]   | $O(\log n)$     | $O(\log n)$    | 中   | 较强           |
| 懒标记 [[线段树]] | $O(\log n)$     | $O(\log n)$    | 长   | 强            |
| 分块        | $O(\sqrt n)$    | $O(\sqrt n)$   | 短   | 极强（任何块内信息）   |

**与 [[线段树]] 的本质区别**：

- **线段树**：用递归把序列切成 $O(\log n)$ 层、每层 $O(1)$ 个相关区间——总 $O(\log n)$

- **分块**：直接切成 $\sqrt n$ 个等大块——总 $O(\sqrt n)$

**分块的优势**：

- **代码极简**：30 行能写完，不需要懒标记下传等复杂逻辑

- **支持线段树难以维护的信息**：如区间众数、区间第 $k$ 大、区间内某值出现次数——这类问题的"块聚合"可以是值域桶、排序数组等灵活结构

- **可与 [[莫队]] 等离线技巧自然结合**

**分块的劣势**：

- 复杂度 $O(\sqrt n)$ 比 $O(\log n)$ 慢——$n = 10^6$ 时分块约 1000 倍操作，线段树仅 20 倍

**经验**：写线段树前先想想分块——若题目维护的信息不规则（如众数、第 $k$ 大），分块往往是唯一解。
