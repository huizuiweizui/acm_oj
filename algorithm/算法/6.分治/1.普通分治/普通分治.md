#难度/★★★

> 把大问题分成规模更小的同类子问题，分别递归解决后再合并——经典的"分而治之"范式。

- [[二分查找]]

## 核心思想

**分治（Divide and Conquer）**：处理一个规模为 $n$ 的问题时，遵循三步——

1. **Divide（分）**：把当前问题拆成若干**规模更小、性质相同**的子问题

2. **Conquer（治）**：递归求解每个子问题（直到基准情况）

3. **Combine（合）**：把子问题的答案**合并**为原问题的答案

分治的精髓是"**子问题与原问题同构**"——递归处理子问题用的是完全相同的算法。这种自相似性让代码极简，复杂度也容易用主定理分析。

**经典分治算法举例**：

- **归并排序**：把数组切成两半，分别排序后合并——是分治最纯粹的例子

- **快速排序**：选基准 + 划分 + 递归（虽不是严格平衡的分治，但思想一致）

- **平面最近点对**：按 $x$ 切两半，递归找各半最近对，合并时检查"跨界对"

- **求逆序对**：归并排序中顺手统计——合并时左半剩余元素都"逆序于"已加入右半的某些元素

- **快速幂**：$a^n = a^{n/2} \cdot a^{n/2}$（也是分治的简单形式）

**主定理（Master Theorem）**——分治算法复杂度的标准分析工具：

> 若 $T(n) = a \cdot T(n / b) + f(n)$，其中 $a \ge 1, b > 1$，记 $c^* = \log_b a$，则——
>
> - $f(n) = O(n^c)$ 且 $c < c^*$ → $T(n) = \Theta(n^{c^*})$
>
> - $f(n) = \Theta(n^{c^*})$ → $T(n) = \Theta(n^{c^*} \log n)$
>
> - $f(n) = \Omega(n^c)$ 且 $c > c^*$（满足正则条件）→ $T(n) = \Theta(f(n))$

例如归并排序 $T(n) = 2T(n/2) + O(n)$——$a = 2, b = 2, c^* = 1$，$f(n) = O(n)$ 落在第二种，$T(n) = O(n \log n)$。

## 适用场景

- **可分解为同类子问题**的问题

- **合并代价 $\le$ 子问题求解代价**的问题（否则不划算）

- 经典模型：

  - 排序（归并排序、快速排序）

  - 求逆序对、求二维偏序

  - 平面最近点对

  - 矩阵快速幂、整数快速幂

  - 快速幂、矩阵乘法（Strassen 算法）

  - **大整数乘法**（Karatsuba 算法 $O(n^{1.585})$、FFT $O(n \log n)$）

  - 一些**枚举型 dp** 的优化（如决策单调性 + 分治）

- 不适用：子问题之间高度依赖（不独立）；子问题规模缩减太慢（如减 1 不减半）

## 步骤拆解

1. **确定基准情形**：递归到何时停止？通常是 $n = 1$ 或 $n = 0$

2. **分**：怎么把问题拆成子问题？拆几份？规模多大？

3. **治**：递归调用自己处理子问题

4. **合并**：用子问题答案构造原问题答案——这是创造性的一步，决定算法效率

## 代码模板

**模板一：归并排序（最纯粹的分治）**

```cpp
class merge_sort {

private:

    void merge(vector<int>& a, int l, int mid, int r) {

        vector<int> tmp;

        tmp.reserve(r - l + 1);

        int i = l, j = mid + 1;

        while (i <= mid && j <= r) {

            if (a[i] <= a[j]) {

                tmp.push_back(a[i++]);

            } else {

                tmp.push_back(a[j++]);

            }

        }

        while (i <= mid) tmp.push_back(a[i++]);

        while (j <= r)   tmp.push_back(a[j++]);

        for (int k = 0; k < (int)tmp.size(); k++) {

            a[l + k] = tmp[k];

        }

    }

    void sort_impl(vector<int>& a, int l, int r) {

        if (l >= r) {

            return;                             // 基准：单元素已有序

        }

        int mid = l + (r - l) / 2;

        sort_impl(a, l, mid);                   // 治左

        sort_impl(a, mid + 1, r);               // 治右

        merge(a, l, mid, r);                    // 合并

    }

public:

    void sort(vector<int>& a) {

        sort_impl(a, 0, (int)a.size() - 1);

    }

};
```

**模板二：求逆序对（归并 + 统计）**

```cpp
class inversion_count {

private:

    long long count;

    void merge(vector<int>& a, int l, int mid, int r) {

        vector<int> tmp;

        int i = l, j = mid + 1;

        while (i <= mid && j <= r) {

            if (a[i] <= a[j]) {

                tmp.push_back(a[i++]);

            } else {

                count += mid - i + 1;           // a[i..mid] 都 > a[j]，构成逆序对

                tmp.push_back(a[j++]);

            }

        }

        while (i <= mid) tmp.push_back(a[i++]);

        while (j <= r)   tmp.push_back(a[j++]);

        for (int k = 0; k < (int)tmp.size(); k++) {

            a[l + k] = tmp[k];

        }

    }

    void solve(vector<int>& a, int l, int r) {

        if (l >= r) return;

        int mid = l + (r - l) / 2;

        solve(a, l, mid);

        solve(a, mid + 1, r);

        merge(a, l, mid, r);

    }

public:

    long long compute(vector<int>& a) {

        count = 0;

        solve(a, 0, (int)a.size() - 1);

        return count;

    }

};
```

> 💡 **逆序对统计的关键观察**：归并时若 `a[i] > a[j]`，由于左半已升序——$a[i], a[i+1], \ldots, a[\mathtt{mid}]$ 都 $> a[j]$。所以跳过 $a[j]$（先加入答案）会贡献 `mid - i + 1` 个逆序对。

**模板三：平面最近点对（经典分治几何）**

```cpp
class closest_pair {

private:

    struct point {

        double x, y;

    };

    double dist(const point& a, const point& b) {

        double dx = a.x - b.x;

        double dy = a.y - b.y;

        return sqrt(dx * dx + dy * dy);

    }

    double solve(vector<point>& ps, int l, int r) {

        if (r - l <= 3) {                       // 暴力小情况

            double d = 1e18;

            for (int i = l; i <= r; i++) {

                for (int j = i + 1; j <= r; j++) {

                    d = min(d, dist(ps[i], ps[j]));

                }

            }

            return d;

        }

        int mid = l + (r - l) / 2;

        double mid_x = ps[mid].x;

        double dl = solve(ps, l, mid);

        double dr = solve(ps, mid + 1, r);

        double d = min(dl, dr);

        // 合并：检查跨界点对——只考虑 |x - mid_x| < d 的点
        vector<point> strip;

        for (int i = l; i <= r; i++) {

            if (abs(ps[i].x - mid_x) < d) {

                strip.push_back(ps[i]);

            }

        }

        sort(strip.begin(), strip.end(),

             [](const point& a, const point& b) { return a.y < b.y; });

        // 关键引理：每个点在 strip 中只需检查后面 7 个邻居
        for (int i = 0; i < (int)strip.size(); i++) {

            for (int j = i + 1; j < (int)strip.size() && strip[j].y - strip[i].y < d; j++) {

                d = min(d, dist(strip[i], strip[j]));

            }

        }

        return d;

    }

public:

    double compute(vector<point>& ps) {

        sort(ps.begin(), ps.end(),

             [](const point& a, const point& b) { return a.x < b.x; });

        return solve(ps, 0, (int)ps.size() - 1);

    }

};
```

> 💡 **"7 个邻居"引理**：在 $d \times 2d$ 的矩形条带内，最多只能放 $7$ 个两两距离 $\ge d$ 的点（鸽笼原理）。所以每个点只需检查 $y$ 方向后续 7 个邻居即可——这是合并步骤 $O(n)$ 而不是 $O(n^2)$ 的关键。

## 复杂度分析

- 由具体问题的"分 + 合"代价决定，用主定理分析

- 归并排序：$T(n) = 2T(n/2) + O(n) = O(n \log n)$

- 平面最近点对：$T(n) = 2T(n/2) + O(n) = O(n \log n)$（合并 $O(n)$ 已含 strip 的 $O(n)$ 排序——实际上若先按 $y$ 全局排序，可省到真正 $O(n)$；否则每层 $O(n \log n)$ 排序，总 $O(n \log^2 n)$）

- 快速排序：$T(n) = T(k) + T(n - k - 1) + O(n)$，期望 $O(n \log n)$，最坏 $O(n^2)$

- 空间复杂度：$O(\log n)$ 递归栈 + 算法所需辅助空间

## 正确性证明

### 分治的归纳框架

**模板**：用强归纳法证明分治算法正确。

**命题**：对任意规模 $n \ge 1$，算法返回的结果正确。

**基础**：$n = 1$（或某个小常数）—— 直接验证基准情形的正确性（通常显然）。

**归纳**：假设对所有 $k < n$ 算法都返回正确结果。证明对 $n$ 也正确。

- **分**：把规模 $n$ 拆为若干 $k_i < n$ 的子问题。

- **治**：由归纳假设，子问题的递归调用都正确返回。

- **合并**：证明"由子问题正确答案，合并步骤产出原问题正确答案"——这一步是**核心**。

### 归并排序的正确性

**基础** ($n = 1$)：单元素数组本来就有序，正确。

**归纳**：假设对长度 $< n$ 的数组都能正确排序。考察长度 $n$——

- 分成两半 $[l, \mathtt{mid}]$ 和 $[\mathtt{mid}+1, r]$，每半长度 $< n$

- 递归调用按归纳假设正确排序两半

- merge 步骤：在两个有序数组上做归并——每次取两数组当前最小者中更小的，结果是两数组合并后的有序数组（这是经典归并算法的正确性）

所以原数组被正确排序。$\blacksquare$

### 求逆序对的正确性

**关键观察**：对任意逆序对 $(i, j)$（$i < j$ 且 $a_i > a_j$），它属于以下三类之一——

1. $i, j$ 都在左半（$i < j \le \mathtt{mid}$）

2. $i, j$ 都在右半（$\mathtt{mid} < i < j$）

3. $i$ 在左半，$j$ 在右半

第 1, 2 类由递归调用统计；第 3 类由 merge 步骤统计——

**第 3 类的统计**：merge 中遇到 `a[i] > a[j]`（其中 $i$ 在左半、$j$ 在右半的当前指针）时——左半剩余的 $a[i], a[i+1], \ldots, a[\mathtt{mid}]$ 都 $\ge a[i] > a[j]$（左半已升序）。所以这些位置都与 $j$ 构成逆序对，共 `mid - i + 1` 个。

**遍历完整性**：merge 把每个 $j$ 与其前面"剩余的左半位置"配对一遍。当某个 $j$ 被加入答案时，所有"左半中比 $a[j]$ 大且未被加入"的位置都被计入。$\blacksquare$

### 平面最近点对的正确性

**两步分治**：

1. 递归得 $d = \min(d_\text{左}, d_\text{右})$

2. 合并：检查"一点在左半、另一点在右半"的跨界对，看是否能进一步降低 $d$

**跨界对的限制**：若跨界对距离 $<d$，则两个点都在 $|x - \mathtt{mid\_x}| < d$ 的"垂直带" $S$ 中。

**带内 $y$ 方向窗口**：对 $S$ 中任一点 $p$，与它距离 $< d$ 的点必满足 $|y - p.y| < d$——所以只需检查 $y$ 方向 $[p.y, p.y + d)$ 区间内的点。

**鸽笼引理**：在 $d \times d$ 的方格中，至多有 $4$ 个两两距离 $\ge d$ 的点（每个 $\frac{d}{2} \times \frac{d}{2}$ 子方格至多 $1$ 点）。所以"$y$ 方向 $[p.y, p.y + d)$ 内、且在 $S$ 中"的点至多 $7$ 个（左 4 + 右 4 - 自己 1）。

合并步骤每点检查 $7$ 个邻居 $\Rightarrow$ $O(n)$。$\blacksquare$

### 主定理为什么对

**展开递归**：$T(n) = aT(n/b) + f(n)$。展开 $\log_b n$ 层后到达基准：

$$T(n) = a^{\log_b n} \cdot T(1) + \sum_{i = 0}^{\log_b n - 1} a^i \cdot f(n / b^i)$$

第一项 $a^{\log_b n} = n^{\log_b a} = n^{c^*}$——是基准层的总工作量。

第二项是递归各层的工作量之和。三种情况分别对应：

- 基准层主导（$f$ 增长慢）→ $T = \Theta(n^{c^*})$

- 各层均衡（$f$ 与 $n^{c^*}$ 同阶）→ $T = \Theta(n^{c^*} \log n)$

- 顶层主导（$f$ 增长快）→ $T = \Theta(f(n))$

详细证明涉及级数分析。$\blacksquare$

## 几个分治的"细节陷阱"

- **避免重复计算**：递归调用切忌反复访问同一区间。$\mathtt{mid} = l + (r - l) / 2$，左半是 $[l, \mathtt{mid}]$，右半是 $[\mathtt{mid}+1, r]$——边界绝不重叠

- **基准情形要小心**：$l \ge r$ 时是单元素或空区间。若忘记 `return` 会无限递归

- **整数溢出**：$\mathtt{mid} = (l + r) / 2$ 当 $l, r$ 都是大正数时可能溢出。用 $\mathtt{mid} = l + (r - l) / 2$

- **递归栈深度**：$O(\log n)$ 是常态。但若分治不平衡（如最坏快速排序），栈可能达 $O(n)$ 而爆栈

## 与其他范式的对比

| 范式       | 核心思想              | 典型问题             | 复杂度典型         |
| -------- | ----------------- | ---------------- | ------------- |
| 分治       | 分 → 治 → 合         | 排序、最近点对、求逆序对     | $O(n \log n)$ |
| 动态规划     | 子问题 + 重叠 + 最优子结构  | 各种 dp            | 多样            |
| 贪心       | 局部最优 = 全局最优       | 排序贪心、最小生成树等      | $O(n \log n)$ |
| 回溯       | 枚举 + 剪枝           | 八皇后、子集枚举         | 指数级           |

**分治与 dp 的细微区别**：分治的子问题**互相独立**（求解一个不依赖另一个）；dp 的子问题可能**重叠**（同一个子问题被多次用到，所以需要记忆化）。
