#难度/★★

> 把若干区间按端点排序后贪心选择，处理"不相交区间最多""覆盖最少"等问题。

## 前置知识

- [[排序贪心]]

## 核心思想

区间贪心是排序贪心在"区间型问题"上的特化形态。给定 $n$ 个区间 $[l_i, r_i]$，要求满足某种约束下的最优选取——这类问题的经典解法是：

1. 把区间按某个端点（左端点 / 右端点）排序

2. 按顺序扫描，用一个变量维护"当前已选最末端"

3. 根据当前区间与该末端的关系决定取舍

不同问题对应不同的排序方式：

| 问题                       | 排序方式      |
| ------------------------ | --------- |
| 选最多不相交区间                 | **右端点升序** |
| 用最少点扎穿所有区间               | **右端点升序** |
| 区间覆盖（选最少区间覆盖目标 $[L, R]$） | 左端点升序     |
| 区间分组（最少多少组使每组互不相交）       | 左端点升序 + 堆 |

## 适用场景

- 经典模型：

  - **最大不相交区间集**：右端点排序后贪心选最早结束的

  - **最少点覆盖所有区间**：每组不相交区间一个点足矣

  - **区间覆盖**：选最少区间覆盖目标线段

  - **区间分组**：把区间分成最少组，使每组内两两不相交

- 涉及"会议安排""课程冲突""线段染色"等场景

- 不适用：区间数关系复杂（可能要 [[线段树]] 或 [[扫描线]]）；区间带权（变成 [[区间dp]]）

## 步骤拆解

**最大不相交区间集（标准模板）**：

1. 把所有区间按 $r_i$ 升序排序

2. 维护当前已选区间的最大右端点 `last_r = -∞`

3. 扫描每个区间：若 $l_i \ge \text{last\_r}$（这里假设端点严格不重叠，否则改 `>`），选中该区间，更新 `last_r = r_i`

4. 计数选中数量

## 代码模板

**模板一：最大不相交区间集**

```cpp

struct interval {

    int l, r;

};

// 求最多能选多少个两两不相交的区间
int max_disjoint(vector<interval>& a) {

    int n = a.size() - 1;                   // 下标 1..n

    sort(a.begin() + 1, a.end(), [](const interval& x, const interval& y) {

        return x.r < y.r;                    // 按右端点升序

    });

    int cnt = 0;

    long long last_r = LLONG_MIN;

    for (int i = 1; i <= n; i++) {

        if (a[i].l >= last_r) {              // 不冲突

            cnt += 1;

            last_r = a[i].r;

        }

    }

    return cnt;

}
```


**模板二：最少点扎穿所有区间**

> 给定 $n$ 个区间，问最少放多少个点，使每个区间至少包含一个点。

```cpp
int min_piercing_points(vector<interval>& a) {

    int n = a.size() - 1;

    sort(a.begin() + 1, a.end(), [](const interval& x, const interval& y) {

        return x.r < y.r;

    });

    int cnt = 0;

    long long last_point = LLONG_MIN;

    for (int i = 1; i <= n; i++) {

        if (a[i].l > last_point) {           // 当前区间未被已放的点覆盖

            cnt += 1;

            last_point = a[i].r;             // 在右端点放新点

        }

    }

    return cnt;

}
```

**模板三：区间分组（最少分组数）**

> 给定 $n$ 个区间，要把它们分成若干组，使每组内任意两区间不相交。求最少分组数。

```cpp

int min_groups(vector<interval>& a) {

    int n = a.size() - 1;

    sort(a.begin() + 1, a.end(), [](const interval& x, const interval& y) {

        return x.l < y.l;

    });

    // 用最小堆维护每组的"最末右端点"

    priority_queue<long long, vector<long long>, greater<long long>> pq;

    for (int i = 1; i <= n; i++) {

        if (!pq.empty() && pq.top() < a[i].l) {

            // 可以加入"最末右端点最早"的那组

            pq.pop();

        }

        pq.push(a[i].r);

    }

    return pq.size();

}

```

> 💡 **结论**：最少组数 = 任一时刻同时有效的最大区间数。这个结论可以用扫描线直接得到，但堆贪心写法更简洁。

## 复杂度分析

- 时间复杂度：$O(n \log n)$（排序为主），堆版本同阶

- 空间复杂度：$O(n)$（堆）或 $O(1)$（朴素扫描）

## 正确性证明

证明"按右端点升序选最早结束的"对**最大不相交区间集**是最优策略。

**核心引理**：贪心选的第 $i$ 个区间 $g_i$ 的右端点不晚于任意最优解的第 $i$ 个区间 $o_i$ 的右端点。

设贪心解为 $G = \{g_1, g_2, \ldots, g_k\}$（按选中的顺序），任一最优解为 $O = \{o_1, o_2, \ldots, o_m\}$（按右端点升序）。要证 $k \ge m$，即 $|G| \ge |O|$。

**归纳证明引理**：

- $i = 1$：贪心选了所有区间中右端点最小的一个，所以 $r_{g_1} \le r_{o_1}$。

- 假设 $r_{g_i} \le r_{o_i}$。考虑 $o_{i+1}$——它的左端点 $l_{o_{i+1}} > r_{o_i} \ge r_{g_i}$，所以 $o_{i+1}$ 与 $g_i$ 不冲突，是贪心扫描时的可选区间。贪心会从所有可选区间中挑右端点最早的，所以 $r_{g_{i+1}} \le r_{o_{i+1}}$。

由引理，若最优解有 $m$ 个，贪心至少能选满 $m$ 个，故 $k \ge m$。又 $k \le m$ 显然（因为 $O$ 是最优解），所以 $k = m$。$\blacksquare$

**为什么是"右端点"而不是"左端点"或"长度"**：

直觉解释——右端点早结束的区间"最不挡道"，能给后续区间留出最多空间。

反例（按左端点排序贪心错）：考虑区间 $[1, 100]$、$[2, 3]$、$[4, 5]$。按左端点升序贪心会选 $[1, 100]$，只得 1 个；但最优是后两个，得 2 个。

反例（按长度排序贪心错）：区间 $[1, 3]$、$[2, 4]$、$[3, 5]$。按长度升序三者长度相同，但若先选了 $[2, 4]$ 就只能再选 0 个；正确选法是 $[1, 3]$ 和 $[3, 5]$（若端点重合不冲突）。

**最少点扎穿问题的等价性**：

每组互不相交的区间至少需要一个点扎穿——所以"最少点数 ≥ 最大不相交区间数"。反过来，把每个不相交组里"最早结束区间的右端点"设为放点位置，每个区间都被这个点扎穿（因为后续区间的左端点 ≤ 该点）——所以"最少点数 ≤ 最大不相交区间数"。两者相等。$\blacksquare$
