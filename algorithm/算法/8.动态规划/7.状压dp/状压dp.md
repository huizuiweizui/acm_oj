#难度/★★★★

> 把 dp 状态中的"子集"用一个整数的二进制位编码——每位代表一个元素是否被选 / 被访问。$n$ 越小，状压越香；$n \le 20$ 是它的舒适区。

## 核心思想

某些 dp 题中，"已经处理过的元素集合" 是状态的核心组成——比如旅行商问题中"已访问点集"、棋盘问题中"哪些列被占用"。这种集合状态如果用 `set` 或数组存，**状态数会爆炸**——但若 $n \le 20$，集合的所有可能恰好对应 $\{0, 1, \ldots, 2^n - 1\}$ 这 $2^n$ 个整数，**每个整数的二进制位编码集合的特征向量**：

$$S \in [0, 2^n) \;\longleftrightarrow\; \{i : S \text{ 的第 } i \text{ 位为 1}\} \subseteq \{0, 1, \ldots, n-1\}$$

集合运算被位运算优雅替代——

| 集合运算                             | 位运算                     |
| -------------------------------- | ----------------------- |
| $i \in S$                        | `(S >> i) & 1`          |
| $S \cup \{i\}$                   | `S \| (1 << i)`         |
| $S \setminus \{i\}$（当 $i \in S$） | `S ^ (1 << i)`          |
| $S \cap T$                       | `S & T`                 |
| $S \cup T$                       | `S \| T`                |
| 全集（$n$ 个元素）                      | `(1 << n) - 1`          |
| $\lvert S \rvert$（元素个数）          | `__builtin_popcount(S)` |

> 💡 **为什么 $n$ 必须小**：状态数 $2^n$ 决定了空间下限。$n = 20$ 时 $2^{20} \approx 10^6$ 还好；$n = 25$ 时 $3 \times 10^7$ 极限；$n \ge 30$ 几乎不可能（除非有非常苛刻的剪枝）。

## 经典例题：最短哈密顿路径

> 给定 $n$ 个点的**完全图**，边权 $w(u, v)$ 已知（$0 \le u, v < n$）。求一条**从 $0$ 号点出发、到 $n-1$ 号点结束、经过每个点恰好一次**的路径，使总边权最小。

**状态怎么想**：路径具有"已访问集合"和"当前位置"两个核心属性。把"已访问集合"压缩为位掩码 $S$、把"当前位置"作为 $u$——

$$f[S][u] = \text{已访问集合恰为 } S\text{（必须 } u \in S\text{），当前在点 } u \text{ 时的最短路径长度}$$

**为什么这状态够用**：路径的未来决策（下一步走哪个未访问点）**只依赖 $(S, u)$**——下一步合法点是 $\{v : v \notin S\}$，候选与"具体是怎么走来的"无关。这是无后效性。

**转移怎么推**：考察 $f[S][u]$ 的最优路径的**最后一步**——它必从 $S$ 中某点 $v \ne u$ 走到 $u$。所以——

$$f[S][u] = \min_{v \in S,\, v \ne u} \left( f[S \setminus \{u\}][v] + w(v, u) \right)$$

注意右侧的 $f[S \setminus \{u\}][v]$ 中——

- 集合是 $S$ 去掉 $u$：因为前一步还没走到 $u$

- 终点是 $v$：因为前一步停在 $v$

**边界**：$f[\{0\}][0] = 0$（即位掩码 `1`、点 `0`，路径起点是 0 单独一点，长度 0）；其余初始化为 $+\infty$（不可达）。

**答案**：$f[\text{full}][n - 1]$，其中 $\text{full} = 2^n - 1$。

**遍历顺序**：$f[S][\cdot]$ 依赖 $f[S \setminus \{u\}][\cdot]$——$S \setminus \{u\}$ 的元素数比 $S$ 少 1。所以**按 $S$ 的数值从小到大**遍历即可（因为 $S$ 在二进制下"少一位"的数 $S \setminus \{u\} = S - (1 \ll u) < S$）。

> 💡 **为什么按 $S$ 数值递增即可**：把 $u$ 从 $S$ 中拿掉得到 $S \setminus \{u\}$，二进制下少了一个 1——数值严格更小。这意味着所有"子集"在数值上比"超集"小，遍历 $S$ 从 0 到 $2^n - 1$ 时，超集出现时其所有子集已算过。

## 适用场景

- 状态中含"集合"且元素数 $n$ 很小（$n \le 20$ 是甜区，$n \le 24$ 极限）

- 经典模型：旅行商 / 哈密顿路径、互不侵犯（棋盘放棋）、最小集合覆盖、子集分割

- 与 [[树形dp]] 结合：树上某些有"子集语义"的子问题

- 与 [[数位dp]] 结合：少数题中数位状态本身就是位集

- 不适用：$n$ 过大（找非状压方法，如贪心、流、其他 dp）；状态不能"集合化"

## 步骤拆解

1. **判断 $n$ 是否够小**：$n \le 20$ 时考虑状压；$n \ge 25$ 一般不行

2. **确定"集合"的含义**：哪些元素需要状压（已访问、已选、当前行已放置的列……）

3. **加上其他维度**：通常状态还要带"当前位置"、"行号"等额外信息——形如 $f[S][\text{aux}]$

4. **写转移**：用位运算表达集合运算，按"少一位"的关系写转移方程

5. **遍历顺序**：状压通常按 $S$ 从小到大；若依赖关系不是"严格子集"则需 [[记忆化搜索]]

6. **答案**：通常在 $S = \text{full}$ 的某个 $\text{aux}$ 上

## 代码模板

**模板：最短哈密顿路径**

```cpp

class shortest_hamilton_path {

private:

    int n;

    vector<vector<long long>> w_;                       // 邻接矩阵，0-indexed

    vector<vector<long long>> f;                        // f[S][u]

    static constexpr long long INF = LLONG_MAX / 2;     // 防加法溢出

public:

    shortest_hamilton_path(int n_in,

                           const vector<vector<long long>>& w_in) {

        n = n_in;

        w_ = w_in;

        f.assign(1 << n, vector<long long>(n, INF));

    }

    long long solve() {

        f[1][0] = 0;                                    // 起点：集合 = {0}，当前在 0

        for (int S = 1; S < (1 << n); S++) {

            for (int u = 0; u < n; u++) {

                if (!((S >> u) & 1)) continue;          // u 必须在 S 中

                if (f[S][u] >= INF) continue;           // 不可达跳过

                // 从 (S, u) 转出：走到下一个点 v（v 不在 S 中）

                for (int v = 0; v < n; v++) {

                    if ((S >> v) & 1) continue;

                    int new_S = S | (1 << v);

                    if (f[S][u] + w_[u][v] < f[new_S][v]) {

                        f[new_S][v] = f[S][u] + w_[u][v];

                    }

                }

            }

        }

        return f[(1 << n) - 1][n - 1];

    }

};
```

> 💡 **状压代码用 0-indexed 更自然**：位 $i$ 直接对应元素 $i$，避免"位 1 对应元素 1"vs"位 0 对应元素 1"的转换混乱。状压 dp 的代码可以打破本仓库其他笔记的 1-indexed 习惯。

> ⚠️ **`INF = LLONG_MAX / 2`**：状压 dp 中常做 `f[S][u] + w[u][v]` 的加法——直接用 `LLONG_MAX` 会溢出。用 `LLONG_MAX / 2` 给加法留出空间是经典习惯。

## 复杂度分析

- 时间复杂度：$O(2^n \cdot n^2)$

  - 状态数 $2^n \cdot n$（$2^n$ 个集合 × $n$ 个当前位置）

  - 每个状态枚举 $O(n)$ 个转移目标

- 空间复杂度：$O(2^n \cdot n)$（$f$ 数组）

> 💡 **典型量级**：$n = 20$ 时 $2^n \cdot n^2 \approx 4 \times 10^8$——卡常的话能过；$n = 18$ 时 $\approx 8 \times 10^7$ 很稳；$n = 15$ 时几乎瞬间。

## 正确性证明

### 位掩码与集合的双向唯一对应

**命题**：$[0, 2^n)$ 中的整数与 $\{0, \ldots, n-1\}$ 的子集之间存在双射。

**证明**：每个整数 $S$ 有唯一的 $n$ 位二进制表示 $b_{n-1} b_{n-2} \cdots b_0$；与之对应的集合是 $\{i : b_i = 1\}$。反过来，每个子集 $T \subseteq \{0, \ldots, n-1\}$ 唯一地给出二进制位 $b_i = [i \in T]$、组合为整数 $\sum_{i \in T} 2^i \in [0, 2^n)$。双射成立。$\blacksquare$

### 转移方程的正确性

**命题**：$f[S][u] = \min_{v \in S,\, v \ne u} (f[S \setminus \{u\}][v] + w(v, u))$ 正确。

**证明**：

**$\le$ 方向**：对任意 $v \in S \setminus \{u\}$，取 $f[S \setminus \{u\}][v]$ 对应的"访问 $S \setminus \{u\}$、终点 $v$"的最短路径——在它末尾加上边 $(v, u)$ 得到"访问 $S$、终点 $u$"的合法路径，长度 $f[S \setminus \{u\}][v] + w(v, u)$。所以 $f[S][u] \le \min_v (\cdots)$。

**$\ge$ 方向**：设 $f[S][u]$ 对应的最优路径为 $\pi$。$\pi$ 的最后一条边设为 $(v^*, u)$（$v^* \in S \setminus \{u\}$）。把 $\pi$ 末尾的边去掉，得到"访问 $S \setminus \{u\}$、终点 $v^*$"的合法路径，长度 $f[S][u] - w(v^*, u)$。由 $f[S \setminus \{u\}][v^*]$ 的定义，

$$f[S][u] - w(v^*, u) \ge f[S \setminus \{u\}][v^*]$$

所以 $f[S][u] \ge f[S \setminus \{u\}][v^*] + w(v^*, u) \ge \min_v (\cdots)$。

两方向结合，转移正确。$\blacksquare$

### 遍历顺序的正确性

**命题**：按 $S$ 数值从小到大遍历时，计算 $f[S][\cdot]$ 时所需的 $f[S \setminus \{u\}][\cdot]$ 必已算过。

**证明**：$S \setminus \{u\} = S - 2^u < S$（当 $u \in S$ 时）——子集的数值严格小于超集。按 $S$ 递增遍历时，所有 $S' < S$ 已处理。$\blacksquare$

## 应用扩展

### 应用一：互不侵犯（玉米田 / 国王问题）

> 在 $n \times m$ 的棋盘上放若干个国王（$n, m \le 9$），任意两个不能相邻（八方向都不行）。求方案数。

**状态怎么想**：行按顺序处理——按行 dp。每行的"状态"是"该行哪些列被放了国王"——这是个 $m$ 位的位掩码 $S$。

定义 $f[i][S]$ = 处理完前 $i$ 行、第 $i$ 行状态为 $S$ 时的方案数。

**转移**：枚举上一行状态 $T$——

- 自约束：$S$ 自身合法（无相邻两位都是 1）：`(S & (S << 1)) == 0`

- 行间约束：$S$ 与 $T$ 不冲突（任一列上下不能同时为 1，对角也不行）：`(S & T) == 0 && (S & (T << 1)) == 0 && (S & (T >> 1)) == 0`

$$f[i][S] = \sum_{T \text{ 合法且 } (S, T) \text{ 兼容}} f[i-1][T]$$

复杂度：$O(n \cdot 4^m)$（其中 $4^m$ 是 $(S, T)$ 对的枚举）。$m \le 9$ 时是 $9 \times 4^9 \approx 2 \times 10^6$，能过。

> 💡 **预处理合法状态**：实际实现中先把所有"自合法"的 $S$ 求出（一行内合法的位掩码），避免对所有 $2^m$ 个 $S$ 都做转移。

### 应用二：旅行商（哈密顿回路）

> 与最短哈密顿路径类似，但要求**回到起点**。

只需在答案处再加一条回边：$\min_{u \ne 0} (f[\text{full}][u] + w(u, 0))$。

### 应用三：子集枚举的标准写法

某些题目（如集合最优划分）需要枚举 $S$ 的所有**非空真子集** $T$——

```cpp

for (int T = (S - 1) & S; T > 0; T = (T - 1) & S) {

    // T 是 S 的非空真子集

}

```

这个循环复杂度的总和是 $\sum_{S} 2^{|S|} = 3^n$（每个元素三种状态：不在 $S$、在 $S$ 但不在 $T$、在 $T$）——对状压 dp 中"枚举子集分裂"的题非常重要。

### 应用四：SOS DP（Sum over Subsets）

> 给定 $f[S]$（$S$ 为 $n$ 位掩码），计算 $g[S] = \sum_{T \subseteq S} f[T]$ 的高效方法。

朴素 $O(3^n)$；SOS DP 用类似"对每位枚举是否加入"的转移降到 $O(n \cdot 2^n)$。状压 dp 的进阶技巧，常用于高维前缀和、莫比乌斯反演的位掩码版本。

## 几个常见错误

- **$n$ 估算错误**：把 $n = 25$ 的题硬上状压会 MLE / TLE。先估算 $2^n$ 的量级

- **位运算优先级**：`S >> u & 1` 中 `&` 优先级低于 `>>`，写法 OK；但 `S & 1 << u` 是 `S & (1 << u)`，与 `(S & 1) << u` 不同——加括号最稳妥

- **初始状态错位**：忘了 $f[\{0\}][0] = 0$ 而把 $f[\emptyset][0] = 0$（位掩码 0 表示空集，但路径从 0 出发后**已经访问了 0**，集合应是 $\{0\}$ = 位掩码 1）

- **`(1 << n)` 溢出**：$n$ 较大（$\ge 31$）时 `1 << n` 在 `int` 下溢出——大 $n$ 用 `1LL << n`

- **遍历顺序错**：用记忆化搜索时若状态依赖关系不是"严格子集"（如同集合大小的状态间互依赖），按 $S$ 递增遍历会出错——这种情况用 [[记忆化搜索]] 更稳

- **`INF + w` 溢出**：用 `INF = LLONG_MAX` 直接做加法溢出。永远用 `LLONG_MAX / 2`
