#难度/★★★

> 当 dp 状态中天然带有一个"机器状态"——是否持股、刚选了什么、当前涂的颜色——决策就成了"在一张有向状态机图上行走"，转移方程恰是图上的边。

## 前置知识

- [[线性dp]]

## 核心思想

状态机 dp 是一类**有结构的线性 dp**——它的状态除了"进度"（位置 $i$、阶段……）外，还显式地存一个"当前所处的机器状态" $s$。每一步决策只依赖当前 $s$，按某种规则切换到下一个状态。

判断一道题是不是状态机 dp，看它有没有这三个特征——

- 题目存在某种**有限的状态集合**（如"持有股票/不持有"、"刚选了/刚没选"、"红/绿/蓝"……）

- 状态之间有明确的**允许转移规则**（哪些状态间能一步切换、对应代价/收益是什么）

- 整个 dp 过程可以画成一张**状态机图**——节点是机器状态、边是允许转移

**通用状态定义**：

$$f[i][s] = \text{处理完前 } i \text{ 个元素、当前状态机处于 } s \text{ 时的最优值}$$

**通用转移**：

$$f[i][s] = \mathop{\text{opt}}_{s' \xrightarrow{\text{合法}} s} \left( f[i-1][s'] + \text{cost}(s' \to s,\, a_i) \right)$$

其中 $\text{opt}$ 视题意是 $\max$ 还是 $\min$，$\text{cost}$ 是该转移在第 $i$ 个元素上的代价或收益。

> 💡 **状态机图的可视化作用**：复杂题目（尤其股票买卖系列）状态多、转移密——画图能避免漏掉某条边。每条边写清"$s' \to s$ 在第 $i$ 个元素上消耗 / 获得多少"，转移方程就是把每条入边都对应到一个候选项里取 $\max$ / $\min$。

## 三个经典模型

### 模型一：打家劫舍

> 给定一排 $n$ 间房屋的金额 $a[1..n]$，相邻两间不能同时偷（一旦相邻同时偷会触发警报）。求能偷到的最大金额。

**状态怎么想**：每间房只有"偷"或"不偷"两种选择——这是最朴素的二元状态机。但若只用 $f[i] = $ "前 $i$ 间最大金额"，转移时无法判断"第 $i$ 间偷不偷"对下一间的约束。所以**必须把"第 $i$ 间是否偷"显式纳入状态**。

定义两个状态——

- $f[i][0] =$ **不偷**第 $i$ 间时，前 $i$ 间的最大金额

- $f[i][1] =$ **偷**第 $i$ 间时，前 $i$ 间的最大金额

**状态机图**：两个节点 `[0 不偷]` 和 `[1 偷]`，从第 $i-1$ 间到第 $i$ 间的允许转移共 3 条——

- `[0]` → `[0]`：上一间不偷、当前也不偷 ✓

- `[1]` → `[0]`：上一间偷、当前不偷 ✓

- `[0]` → `[1]`：上一间不偷、当前偷 ✓

- `[1]` → `[1]`：上一间偷、当前也偷 ✗（相邻同偷违反规则）

**转移怎么推**：

- 第 $i$ 间不偷（$f[i][0]$）：第 $i-1$ 间偷不偷都合法——取较大者。所以 $f[i][0] = \max(f[i-1][0],\, f[i-1][1])$

- 第 $i$ 间偷（$f[i][1]$）：第 $i-1$ 间**必须不偷**——只能从 $f[i-1][0]$ 转过来，再加上 $a[i]$。所以 $f[i][1] = f[i-1][0] + a[i]$

**边界**：$f[1][0] = 0$、$f[1][1] = a[1]$。

**答案**：$\max(f[n][0],\, f[n][1])$。

```cpp

class house_robber {

private:

    int n;

    vector<long long> a;

public:

    house_robber(int n_in, const vector<long long>& a_in) {

        n = n_in;

        a = a_in;

    }

    long long solve() {

        vector<vector<long long>> f(n + 1, vector<long long>(2, 0));

        f[1][0] = 0;

        f[1][1] = a[1];

        for (int i = 2; i <= n; i++) {

            f[i][0] = max(f[i - 1][0], f[i - 1][1]);

            f[i][1] = f[i - 1][0] + a[i];

        }

        return max(f[n][0], f[n][1]);

    }

};
```

### 模型二：股票买卖（最多 k 次交易）

> 给定 $n$ 天的股价 $p[1..n]$，每天可以买入、卖出或什么都不做，**最多同时持有一只股票**，最多完成 $k$ 次交易（一买一卖算一次完整交易）。求最大利润。

**状态怎么想**：每天结束后的"机器状态"由两个分量决定——

- **是否持股**：0 表示空仓、1 表示持股

- **已完成的交易数**：从 0 到 $k$

为什么要把"交易数"也作为状态？因为题目限制了 $k$，而交易数会随每次"完整买卖"递增——若不显式跟踪，就无法判断"还能不能再买"。

定义：

- $f[i][j][0] =$ 第 $i$ 天结束、已完成 $j$ 次完整交易、当前空仓时的最大利润

- $f[i][j][1] =$ 第 $i$ 天结束、已完成 $j$ 次完整交易（**正在进行的不计入**）、当前持股时的最大利润

> 💡 **关于"什么时候 $j$ 加 1"的约定**：这里采用"**卖出时**计入第 $j$ 次"——即买入不增 $j$、卖出时 $j$ 加 1。也有反过来约定的，两者等价但转移略有差别，注意一致。

**状态机图**（节点 = $(j, 0/1)$，边 = 一天的操作）：每个节点有"不操作"自环；其余边——

- `(j, 空仓)` → `(j, 持股)`：买入，开始第 $j+1$ 次交易（$j$ 暂不变）

- `(j, 持股)` → `(j+1, 空仓)`：卖出，第 $j+1$ 次完成（$j$ 加 1）

**转移怎么推**：

- $f[i][j][0]$（今日结束空仓、已完成 $j$ 次）的来源：

  - 昨日就空仓且已完成 $j$ 次，今日不操作：$f[i-1][j][0]$

  - 昨日持股（已完成 $j-1$ 次完整交易、正在进行第 $j$ 次），今日卖出：$f[i-1][j-1][1] + p[i]$，且**第 $j$ 次完成**

  等等——这里有个语义陷阱。我们说"$f[i-1][j-1][1]$ 持股时已完成 $j-1$ 次完整交易"，今日卖出后 $j-1+1 = j$ 次完成，状态切到 $f[i][j][0]$。所以：
  $$f[i][j][0] = \max(f[i-1][j][0],\, f[i-1][j-1][1] + p[i])$$

- $f[i][j][1]$（今日结束持股、已完成 $j$ 次完整交易）的来源：

  - 昨日就持股，今日不操作：$f[i-1][j][1]$

  - 昨日空仓（已完成 $j$ 次），今日买入开始第 $j+1$ 次交易（**未完成不计入**）：$f[i-1][j][0] - p[i]$
  $$f[i][j][1] = \max(f[i-1][j][1],\, f[i-1][j][0] - p[i])$$

**边界**：$f[0][0][0] = 0$；其余 $f[0][j][0] = f[0][j][1] = -\infty$（第 0 天结束时除"空仓 + 0 次交易"外都不可达）。

**答案**：$\max_{0 \le j \le k} f[n][j][0]$（最后一天空仓才把所有利润落袋）。

```cpp

class stock_k_trades {

private:

    int n, k;

    vector<long long> p;

    static constexpr long long NEG_INF = LLONG_MIN / 2;     // 防加法溢出

public:

    stock_k_trades(int n_in, int k_in, const vector<long long>& p_in) {

        n = n_in;

        k = k_in;

        p = p_in;

    }

    long long solve() {

        // f[i][j][0/1]
        vector<vector<vector<long long>>> f(

            n + 1,

            vector<vector<long long>>(k + 1, vector<long long>(2, NEG_INF))

        );

        f[0][0][0] = 0;

        for (int i = 1; i <= n; i++) {

            for (int j = 0; j <= k; j++) {

                f[i][j][0] = f[i - 1][j][0];                         // 空仓不操作

                if (j >= 1 && f[i - 1][j - 1][1] != NEG_INF) {

                    f[i][j][0] = max(f[i][j][0], f[i - 1][j - 1][1] + p[i]);// 卖出

                }

                f[i][j][1] = f[i - 1][j][1];                         // 持股不操作

                if (f[i - 1][j][0] != NEG_INF) {

                    f[i][j][1] = max(f[i][j][1], f[i - 1][j][0] - p[i]); // 买入

                }

            }

        }

        long long ans = 0;

        for (int j = 0; j <= k; j++) {

            ans = max(ans, f[n][j][0]);

        }

        return ans;

    }

};
```

> ⚠️ **不可达状态置 $-\infty$**：第 0 天就持股、或第 0 天已完成 $j \ge 1$ 次交易都不可能，必须置 $-\infty$ 让 $\max$ 自动忽略。代码中用 `LLONG_MIN / 2` 而不是 `LLONG_MIN`——避免转移时 `+p[i]` 或 `-p[i]` 溢出。

> 💡 **$k$ 极大时的退化**：若 $k \ge n / 2$，相当于"无限次交易"——可证明此时直接贪心（每个上涨段都吃掉）就行：$\sum_i \max(0,\, p[i] - p[i-1])$，无需 dp。这是经典优化点。

### 模型三：粉刷房子

> 有 $n$ 间房屋排成一列，每间房可刷成红、绿、蓝三种颜色之一，第 $i$ 间刷成颜色 $k$ 的代价是 $c[i][k]$（$k \in \{0, 1, 2\}$）。相邻两间不能同色。求总代价的最小值。

**状态怎么想**：和打家劫舍相同——"相邻有限制"意味着必须把"第 $i$ 间的颜色"纳入状态。

定义 $f[i][k] =$ 第 $i$ 间刷成颜色 $k$ 时、前 $i$ 间的最小代价。

**状态机图**：3 个节点（红/绿/蓝），任意两不同色之间双向可达——共 6 条有向边（3 个节点两两连通），自环（同色相邻）禁止。

**转移**：第 $i$ 间刷成颜色 $k$，第 $i-1$ 间只能是其他两种颜色之一——

$$f[i][k] = \min_{k' \ne k} f[i-1][k'] + c[i][k]$$

**边界**：$f[1][k] = c[1][k]$。

**答案**：$\min_{k} f[n][k]$。

```cpp

class paint_house {

private:

    int n;

    vector<vector<long long>> c;                     // c[i][k]，1-indexed for i

  

public:

    paint_house(int n_in, const vector<vector<long long>>& c_in) {

        n = n_in;

        c = c_in;

    }

    long long solve() {

        vector<vector<long long>> f(n + 1, vector<long long>(3, 0));

        for (int k = 0; k < 3; k++) {

            f[1][k] = c[1][k];

        }

        for (int i = 2; i <= n; i++) {

            for (int k = 0; k < 3; k++) {

                long long best = LLONG_MAX;

                for (int k2 = 0; k2 < 3; k2++) {

                    if (k2 != k) {

                        best = min(best, f[i - 1][k2]);

                    }

                }

                f[i][k] = best + c[i][k];

            }

        }

        return min({f[n][0], f[n][1], f[n][2]});

    }

};

```

## 适用场景

- 决策序列中存在"有限的隐藏状态"，影响下一步选择（如持仓、刚选过、当前颜色）

- 经典模型：股票买卖（含冷冻期、含手续费的变形）、相邻限制问题、染色问题、打劫问题

- 状态空间小（$S$ 个机器状态，$S$ 通常 $\le 10$），转移规则清晰

- 不适用：状态数指数级（用 [[状压dp]] 把状态压成位掩码）；状态间没有明确的"图结构"（普通线性 dp 即可）

## 步骤拆解

1. **找出机器状态集合**：列出所有有限的"内部状态"，通常 2-5 个

2. **画状态机图**：节点 = 状态、边 = 允许转移、边权 = 该转移在第 $i$ 步的代价/收益

3. **设计 dp 状态**：$f[i][s]$ 表示"处理完前 $i$ 个元素 + 当前状态 $s$ 时的最优值"

4. **写转移方程**：枚举每条入边 $s' \to s$，取 $\max$ / $\min$

5. **确定边界**：$f[0][s_0] = 0$，其余不可达态置 $\pm \infty$

6. **答案位置**：$f[n][s_{\text{end}}]$ 或 $\mathop{\text{opt}}_{s} f[n][s]$（视题意）

## 复杂度分析

- 时间复杂度：$O(n \cdot S \cdot T)$，其中 $S$ 是机器状态数、$T$ 是平均入边数

- 空间复杂度：$O(n \cdot S)$，可滚动到 $O(S)$（只保留上一行）

> 💡 **常见量级**：打家劫舍 $S = 2$、$T = O(1)$，总 $O(n)$；粉刷房子 $S = 3$、$T = 2$，总 $O(n)$；股票 $k$ 次交易 $S = O(k)$，总 $O(nk)$。

## 正确性证明

### 状态定义的无后效性

**命题**：$f[i][s]$ 只依赖 $f[i-1][\cdot]$，不依赖更早的决策细节。

**证明**：固定 $i$ 与 $s$。任何合法决策序列在第 $i$ 步达到状态 $s$ 时，从第 $i+1$ 步起的可行后续**只取决于 $s$**——这正是"状态机"的本质：未来转移只看当前节点，不看怎么走到的。

所以 $f[i][s]$ 取的是"所有第 $i$ 步达到状态 $s$ 的合法序列"中的最优值——而每个这样的序列长度为 $i$，第 $i-1$ 步的状态 $s'$ 满足 $s' \to s$ 合法，前 $i-1$ 步的最优解恰是 $f[i-1][s']$（这正是 $f$ 的定义本身）。归纳成立。$\blacksquare$

### 转移方程的完备性

**命题**：转移枚举的"$s' \to s$ 合法"覆盖了所有真实可能的转移路径——即不会漏掉某种合法决策。

**证明**：状态机图本身就是题目"允许的转移规则"的画图——只要画图时枚举完整（每个状态对外的入边都列出），转移方程就是完备的。

**反过来的常见错误**：漏掉某条边等价于禁止了某种合法转移，会让 dp 误判某些真实可达的状态为"不可达"，从而漏掉最优解。所以**画状态机图时必须穷尽**——这是状态机 dp 最大的纪律。$\blacksquare$

## 几个常见错误

- **遗漏机器状态**：把"是否持股"漏了，转移时无法表达买/卖操作

- **遗漏转移边**：股票题中漏了"昨日空仓今日不操作"这种"什么都不做"的边，会导致 $f[i][j][0]$ 始终低估

- **边界初始化错误**：不可达状态写成 0 而不是 $-\infty$，让 $\max$ 误取这个 0

- **滚动数组的状态值未及时备份**：转移时若同时读写同一个机器状态，要小心顺序——通常分两个数组或用临时变量

- **$j$ 加 1 的约定不一致**：股票题中"买入加 1"还是"卖出加 1"的两种约定下，转移方程不同——选定一种后通篇坚持

## 应用扩展

### 股票变形：含冷冻期 / 含手续费

**含冷冻期**（卖出后下一天不能买入）：

新增一个机器状态"冷冻"——

- $f[i][0]$：今日空仓且**非冷冻**（昨日没卖出）

- $f[i][1]$：今日持股

- $f[i][2]$：今日空仓但**冷冻中**（今日刚卖出）

转移图多了一条 $[1] \xrightarrow{\text{卖出}} [2]$、$[2] \xrightarrow{\text{自然解冻}} [0]$。

**含手续费**：每次卖出额外扣 $\text{fee}$——只需在转移 $f[i][\cdot][0] \leftarrow f[i-1][\cdot][1] + p[i]$ 时改成 $+ p[i] - \text{fee}$。

### 状态机 + 树形结构

[洛谷P1352 没有上司的舞会](https://www.luogu.com.cn/problem/P1352)——树上每个节点要么"来"要么"不来"（2 状态机），父子约束类似打家劫舍。这是 [[树形dp]] 与状态机 dp 的合体。

### 状态机 + 段限制

[洛谷P2627 修剪草坪](https://www.luogu.com.cn/problem/P2627)——连续 $k$ 个位置中至少跳过一个。可设状态 $f[i][j] = $ "末尾连续 $j$ 个被选时的最优值"，$j \in [0, k-1]$，是更复杂的状态机。
