#难度/★★

> 双序列匹配的经典 dp——以 $f[i][j]$ 跟踪两序列前缀的对齐进度，是编辑距离、序列比对等问题的祖师爷。

## 前置知识

- [[线性dp]]

## 核心思想

> 给定两个序列 $a[1..n]$ 和 $b[1..m]$，求**最长公共子序列**（Longest Common Subsequence，LCS）的长度。子序列是从原序列中**按原顺序**抽取若干元素得到的（允许跳过，但不能调换次序）。

**状态怎么想**：朴素思路是枚举 $a$ 的所有子序列，再判断是否在 $b$ 中——$2^n$ 级别，爆炸。

要找好的状态，得问自己——"什么样的'部分进度'能完整描述 LCS 的一个**子问题**？"答案是**两个序列各自的前缀长度**：考察 $a[1..i]$ 和 $b[1..j]$ 之间的 LCS，原问题就是 $i = n,\, j = m$ 的特例。

定义 $f[i][j] =$ $a[1..i]$ 与 $b[1..j]$ 的最长公共子序列长度。

这个定义有两个好性质——

- **无后效性**：$f[i][j]$ 只依赖前缀对齐的"长度"，与"具体哪些位置配对"无关

- **最优子结构**：$f[i][j]$ 的最优解可由若干 $f[i'][j']\ (i' \le i,\, j' \le j)$ 的最优解组合得到（下文转移会证）

**转移怎么推**：决策的"切入点"是**最后一对元素 $(a_i, b_j)$ 的处理方式**。讨论两种情形——

**情形一：$a_i = b_j$**

这两个相等的末元素**可以**作为 LCS 的最后一对配对。此时 LCS 中除去这对配对，剩下的就是 $a[1..i-1]$ 和 $b[1..j-1]$ 的 LCS——为 $f[i-1][j-1] + 1$。

形式上，$a_i = b_j$ 时还有"不配对它们"的可能（依赖 $f[i-1][j]$ 或 $f[i][j-1]$）——但下文会证明配对最优，所以——

$$f[i][j] = f[i-1][j-1] + 1$$

**情形二：$a_i \ne b_j$**

这两个不相等的元素**不能**同时进入 LCS 的最后一对（否则它们要相等才能配对，矛盾）。所以 LCS 中要么不含 $a_i$、要么不含 $b_j$——

- 不含 $a_i$：LCS 全部来自 $a[1..i-1]$ 与 $b[1..j]$，长度为 $f[i-1][j]$

- 不含 $b_j$：LCS 全部来自 $a[1..i]$ 与 $b[1..j-1]$，长度为 $f[i][j-1]$

- 两情形都不含 $a_i, b_j$：被前两情形包含（不必单列）

取大者：

$$f[i][j] = \max(f[i-1][j],\, f[i][j-1])$$

**合写**：

$$f[i][j] = \begin{cases} f[i-1][j-1] + 1 & a_i = b_j \\ \max(f[i-1][j],\, f[i][j-1]) & a_i \ne b_j \end{cases}$$

**边界**：$f[0][j] = f[i][0] = 0$（任一序列为空时 LCS 为 0）。

**答案**：$f[n][m]$。

> 💡 **三个方向的依赖**：$f[i][j]$ 依赖 $f[i-1][j-1]$（左上）、$f[i-1][j]$（上方）、$f[i][j-1]$（左方）——这是双序列 dp 的典型形态，决定了一维滚动数组要小心保留"左上"的旧值。

## 适用场景

- 求两序列的最长公共子序列、最长公共子数组（连续要求严格）

- 编辑距离（Levenshtein Distance）：$f[i][j]$ 表示 $a[1..i] \to b[1..j]$ 的最少编辑次数

- DNA 序列比对、文本 diff、模糊匹配

- 一些"双指针对齐"型的 dp 问题

- 不适用：单序列上的子序列问题（用 [[最长上升子序列]]）；两序列长度差异极大且都很大（$O(nm)$ 太慢，需用 Hunt-Szymanski 等高级算法）

## 步骤拆解

1. 初始化二维数组 $f$，置 $f[0][\cdot] = f[\cdot][0] = 0$

2. 双层循环 $i = 1 \to n$，$j = 1 \to m$

3. 按照情形分类执行转移

4. 输出 $f[n][m]$

## 代码模板

**模板一：二维 dp**

```cpp

class lcs_2d {

private:

    int n, m;

    vector<int> a, b;

    vector<vector<int>> f;

public:

    lcs_2d(const vector<int>& a_in, const vector<int>& b_in) {

        n = a_in.size() - 1;                            // 1-indexed

        m = b_in.size() - 1;

        a = a_in;

        b = b_in;

        f.assign(n + 1, vector<int>(m + 1, 0));

    }

    int solve() {

        for (int i = 1; i <= n; i++) {

            for (int j = 1; j <= m; j++) {

                if (a[i] == b[j]) {

                    f[i][j] = f[i - 1][j - 1] + 1;

                } else {

                    f[i][j] = max(f[i - 1][j], f[i][j - 1]);

                }

            }

        }

        return f[n][m];

    }

};
```

**模板二：滚动数组（一维）**

LCS 的一维滚动需要保存"左上方"的旧值——用一个临时变量 `prev` 暂存即可。

```cpp

class lcs_1d {

private:

    int n, m;

    vector<int> a, b;

public:

    lcs_1d(const vector<int>& a_in, const vector<int>& b_in) {

        n = a_in.size() - 1;

        m = b_in.size() - 1;

        a = a_in;

        b = b_in;

    }

    int solve() {

        vector<int> f(m + 1, 0);

        for (int i = 1; i <= n; i++) {

            int prev = 0;                               // f[i-1][0] = 0

            for (int j = 1; j <= m; j++) {

                int tmp = f[j];                         // 暂存 f[i-1][j]

                if (a[i] == b[j]) {

                    f[j] = prev + 1;                    // 用 f[i-1][j-1]

                } else {

                    f[j] = max(f[j], f[j - 1]);         // f[i-1][j] / f[i][j-1]

                }

                prev = tmp;                             // 更新"左上"为下一轮的左上

            }

        }

        return f[m];

    }

};
```

> 💡 **`prev` 的角色**：进入第 $j$ 轮时，`prev` 保存的是 $f[i-1][j-1]$（即"左上"的旧值）。处理完后把 `tmp`（旧的 $f[j]$，也就是 $f[i-1][j]$）赋给 `prev`，正好成为下一轮（$j+1$）的左上。

> ⚠️ **滚动数组写错的高发区**：很多人把 `prev` 在分支里更新的位置弄错——必须**先暂存** `tmp = f[j]`，**再更新** `f[j]`，**最后把 tmp 赋给 prev**，三步顺序不能乱。

## 复杂度分析

- 时间复杂度：$O(nm)$

- 空间复杂度：

	- 二维 $O(nm)$
	
	- 一维 $O(\min(n, m))$（短的那一边作内层）

## 正确性证明

### 状态定义的最优子结构

**命题**：$f[i][j]$ 等于 $a[1..i]$ 与 $b[1..j]$ 所有公共子序列长度的最大值。

**证明**：归纳证明转移方程的正确性同时蕴含此命题。

### 转移方程的正确性

**情形一（$a_i = b_j$）**：要证 $f[i][j] = f[i-1][j-1] + 1$。

**$\ge$ 方向**：取 $a[1..i-1]$ 与 $b[1..j-1]$ 的最长公共子序列（长度 $f[i-1][j-1]$），末尾追加配对 $(a_i, b_j)$——这是 $a[1..i]$ 与 $b[1..j]$ 的合法公共子序列，长度 $f[i-1][j-1] + 1$。所以 $f[i][j] \ge f[i-1][j-1] + 1$。

**$\le$ 方向**：设最优 LCS $S$ 长度为 $L = f[i][j]$。讨论 $S$ 的最后一对配对：

- 若 $S$ 的最后一对配对是 $(a_i, b_j)$（即在 $a$ 中位置 $i$、$b$ 中位置 $j$ 配对）：剔除这对，得到 $a[1..i-1]$ 与 $b[1..j-1]$ 的公共子序列，长度 $L - 1$。由定义 $L - 1 \le f[i-1][j-1]$，即 $L \le f[i-1][j-1] + 1$。

- 若 $S$ 的最后一对配对不是 $(a_i, b_j)$：那这对配对 $(a_p, b_q)$ 满足 $p < i$ 或 $q < j$。但既然 $a_i = b_j$，可以把这对替换为 $(a_i, b_j)$（在原配对位置之后追加，不破坏顺序）——构造出长度仍为 $L$ 的另一个 LCS，其最后一对是 $(a_i, b_j)$，归入第一种情形。

所以 $L \le f[i-1][j-1] + 1$。

结合两方向，$f[i][j] = f[i-1][j-1] + 1$。$\blacksquare$

**情形二（$a_i \ne b_j$）**：要证 $f[i][j] = \max(f[i-1][j],\, f[i][j-1])$。

**$\ge$ 方向**：$a[1..i-1]$ 与 $b[1..j]$ 的 LCS（长度 $f[i-1][j]$）也是 $a[1..i]$ 与 $b[1..j]$ 的合法公共子序列，所以 $f[i][j] \ge f[i-1][j]$。同理 $f[i][j] \ge f[i][j-1]$。

**$\le$ 方向**：设最优 LCS $S$ 长度为 $L = f[i][j]$。考察 $S$ 中是否含 $a_i$ 与 $b_j$——

- 若 $S$ 不含 $a_i$：$S$ 是 $a[1..i-1]$ 与 $b[1..j]$ 的公共子序列，$L \le f[i-1][j]$

- 若 $S$ 不含 $b_j$：$L \le f[i][j-1]$

- 若 $S$ 同时含 $a_i$ 和 $b_j$：因 $S$ 是 $a$ 的子序列也是 $b$ 的子序列，$a$ 中 $a_i$ 位置 $i$ 是末位，$b$ 中 $b_j$ 位置 $j$ 也是末位——所以 $a_i$ 与 $b_j$ 必须**配对**（双方的最后一个被选元素必须互配）。但 $a_i \ne b_j$ 使配对不合法，矛盾。

所以 $L \le \max(f[i-1][j],\, f[i][j-1])$。$\blacksquare$

## 应用扩展

### 求方案：还原 LCS 本身

$f$ 只能告诉我们长度。要还原一个 LCS，需要保留二维 $f$，从 $(n, m)$ **反向追溯**：

```cpp

string reconstruct() {

    string s;

    int i = n, j = m;

    while (i > 0 && j > 0) {

        if (a[i] == b[j]) {

            s += a[i];                                  // 假设 a 是 string

            i -= 1; j -= 1;

        } else if (f[i - 1][j] >= f[i][j - 1]) {

            i -= 1;

        } else {

            j -= 1;

        }

    }

    reverse(s.begin(), s.end());

    return s;

}
```

> ⚠️ 滚动数组无法直接还原方案——求方案必须保留二维 $f$。

### 编辑距离（Levenshtein）

> 给两个串 $a, b$，求把 $a$ 变成 $b$ 需要的最少操作数（操作有三种：插入一字符、删除一字符、修改一字符）。

定义 $f[i][j] =$ $a[1..i] \to b[1..j]$ 的最少操作数。转移：

$$f[i][j] = \begin{cases} f[i-1][j-1] & a_i = b_j \\ \min(f[i-1][j],\, f[i][j-1],\, f[i-1][j-1]) + 1 & a_i \ne b_j \end{cases}$$

三个分支分别对应"删 $a_i$"、"插入 $b_j$"、"把 $a_i$ 改成 $b_j$"。边界 $f[0][j] = j$、$f[i][0] = i$，答案 $f[n][m]$。

### 当两序列都是排列：化为 LIS

若 $a, b$ 都是 $1..n$ 的排列，可在 $O(n \log n)$ 解 LCS——

把 $a$ 中每个数在 $b$ 中的位置取出，得到一个新数组 $p[1..n]$（$p[i] = $ "$a[i]$ 在 $b$ 中的下标"）。则 **$a$ 与 $b$ 的 LCS 等于 $p$ 的最长上升子序列**——详见 [[最长上升子序列]] 中的应用部分。

这把 $O(nm)$ 的 LCS 优化到 $O(n \log n)$，是经典技巧（如 [洛谷P1439](https://www.luogu.com.cn/problem/P1439)）。

## 几个常见错误

- **滚动数组的 `prev` 写错**：忘了暂存 `tmp = f[j]`、或者 `prev` 更新位置不对——LCS 滚动是高频出 bug 的地方

- **混淆"子序列"与"子数组"**：子序列允许跳过，子数组（子串）必须连续。LCS 是子序列；最长公共子数组是另一个不同问题（用经典的"以位置 $(i,j)$ 结尾"的子数组 dp）

- **下标 0 vs 1**：本笔记用 1-indexed，$f[0][\cdot]$ 与 $f[\cdot][0]$ 是哨兵行/列。若用 0-indexed 要相应调整

- **判等用错操作符**：字符比较 `a[i] == b[j]`，整数同；自定义类型注意重载
