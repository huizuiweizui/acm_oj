#难度/★★★

> 单序列上的子序列 dp 经典——朴素 $O(n^2)$ 看似平凡，但配上一个巧妙的"长度→最小末尾"数组就能优化到 $O(n \log n)$，是 dp + 二分的经典缝合。

## 核心思想

> 给定一个长 $n$ 的数组 $a[1..n]$，求最长**严格上升子序列**（Longest Increasing Subsequence，LIS）的长度——子序列允许跳过元素但保持原顺序，且后一项**严格大于**前一项。

LIS 有两种主流解法——朴素的 $O(n^2)$ dp 容易想到，但卡到 $n = 10^5$ 时就过不去；$O(n \log n)$ 的二分优化才是真正实用的版本。

### 朴素 $O(n^2)$ dp

**状态怎么想**：考虑 LIS 的"结尾位置"——若一个上升子序列以 $a[i]$ 结尾，那它前面的所有元素必然来自某个以 $a[j]\ (j < i,\ a[j] < a[i])$ 结尾的更短上升子序列。这意味着——**只要知道"以每个 $j$ 结尾的最长上升子序列长度"，就能 $O(n)$ 算出"以 $i$ 结尾的"**。

定义 $f[i] =$ 以 $a[i]$ 结尾的最长上升子序列长度。

无后效性：$f[i]$ 只依赖 $f[j]\ (j < i)$；最优子结构：以 $i$ 结尾的最优解去掉末尾就是某个 $f[j]$ 的最优解（去掉一个元素的最优依然是最优——因为加 $a_i$ 时只看 $a_j$ 与 $a_i$ 的大小关系，不看路径细节）。

**转移怎么推**：以 $a[i]$ 结尾的上升子序列分两类——

- 长度为 1：仅 $\{a[i]\}$ 自身——长度 1

- 长度 $\ge 2$：上一个元素是某个 $a[j]$（要求 $j < i$ 且 $a[j] < a[i]$），对应长度 $f[j] + 1$

取较大者：

$$f[i] = \max\left(1,\, \max_{j < i,\, a[j] < a[i]} f[j] + 1\right)$$

**边界**：$f[i] \ge 1$（任一元素自成长度 1 的上升子序列）。

**答案**：$\max_{i=1}^{n} f[i]$（不是 $f[n]$！LIS 不一定以末尾结尾）。

### 二分优化 $O(n \log n)$

**关键观察**：朴素 dp 内层枚举 $j$ 的 $O(n)$ 是浪费的——我们其实只关心"在所有满足 $a[j] < a[i]$ 的 $j$ 中，$f[j]$ 的最大值"。如果有个数据结构能 $O(\log n)$ 回答这个问题，整体就降到 $O(n \log n)$。

但其实有更巧妙的角度——不直接维护 $f$，而是维护一个辅助数组 $g$：

> $g[k] =$ 当前已扫描元素中，**所有长度为 $k$ 的上升子序列的结尾元素的最小值**

$g$ 数组有一个非平凡的性质——**严格递增**（下文证明）。这意味着我们可以在 $g$ 上**二分**！

**算法**：依次扫描 $a[1], a[2], \ldots, a[n]$。对每个 $a[i]$——

- 若 $a[i]$ 大于 $g$ 当前末尾（即比所有已记录的"长度 $k$ 的最小末尾"都大），则可以**延长** LIS：把 $a[i]$ append 到 $g$ 的末尾，最大长度 +1

- 否则，二分找到 $g$ 中第一个 $\ge a[i]$ 的位置 $k$，把 $g[k]$ 替换为 $a[i]$（更小的末尾让长度 $k$ 更"可延长"）

最终 $g$ 的长度就是 LIS 的长度。

> 💡 **$g$ 数组不是任何真实子序列**：它只是"每种长度的最小可能末尾"的记录——是一个**虚构的辅助数组**。LIS 的实际值是"过程中达到过的最大长度"，恰好等于 $g$ 的最终长度。

> ⚠️ **严格 vs 非严格**：
> 
> - 严格上升（$a[j] < a[i]$）：二分用 `lower_bound`（找第一个 $\ge a[i]$ 的位置替换）
>
> - 非严格上升即不下降（$a[j] \le a[i]$）：用 `upper_bound`（找第一个 $> a[i]$ 的位置替换）
>
> 一字之差，结果可能差很多。

## 适用场景

- 求一个序列的最长上升 / 下降 / 不降 / 不升子序列长度

- 导弹拦截系列（Dilworth 定理：最少子序列数 = 最长反向链）

- 排列上的 LCS 问题（化为 LIS）

- 限制条件下的子序列问题（如带权 LIS、二维 LIS——常需配合 [[树状数组]] / [[线段树]]）

- 不适用：要求子序列连续（最长上升子段，是另一类简单问题）；多序列匹配（用 [[最长公共子序列]]）

## 步骤拆解

**朴素法**：双层循环；外层 $i$ 推进；内层 $j$ 找前驱。

**二分法**：

1. 维护单调递增数组 $g$，初始为空

2. 扫描 $a[i]$——若 $a[i] > g.\text{back}()$，append；否则二分找位置替换

3. 答案 = $g.\text{size}()$

## 代码模板

**模板一：朴素 $O(n^2)$**

```cpp

class lis_n2 {

private:

    int n;

    vector<int> a;

public:

    lis_n2(const vector<int>& a_in) {

        n = a_in.size() - 1;

        a = a_in;

    }

    int solve() {

        vector<int> f(n + 1, 1);                        // 每个元素至少长 1

        int ans = 1;

        for (int i = 1; i <= n; i++) {

            for (int j = 1; j < i; j++) {

                if (a[j] < a[i]) {

                    f[i] = max(f[i], f[j] + 1);

                }

            }

            ans = max(ans, f[i]);

        }

        return ans;

    }

};
```

**模板二：二分优化 $O(n \log n)$**

```cpp

class lis_nlogn {

private:

    int n;

    vector<int> a;

public:

    lis_nlogn(const vector<int>& a_in) {

        n = a_in.size() - 1;

        a = a_in;

    }

    int solve() {

        vector<int> g;                                  // g[k-1] 即长度 k 的最小末尾

        for (int i = 1; i <= n; i++) {

            auto it = lower_bound(g.begin(), g.end(), a[i]);    // 严格上升

            if (it == g.end()) {

                g.push_back(a[i]);                      // 延长

            } else {

                *it = a[i];                             // 替换

            }

        }

        return (int)g.size();

    }

};
```

> 💡 **两版代码的取舍**：朴素版好理解、好改（带权、带方案、带额外约束都可拓展）；二分版快、空间小，但适应性差——一旦题目加复杂条件，常常要回退到 $O(n^2)$ 或换 [[树状数组]] 维护前缀最值的 dp。

## 复杂度分析

- 时间复杂度：

  - 朴素 dp：$O(n^2)$

  - 二分优化：$O(n \log n)$

  - 树状数组优化：$O(n \log n)$

- 空间复杂度：$O(n)$（三种方法都是）

> 💡 **何时用哪种**：纯 LIS 且 $n$ 大用二分；带权或带额外约束（如二维偏序）用 [[树状数组]] 维护前缀最值的朴素 dp 优化；$n \le 5000$ 或要求输出方案时朴素版最稳妥。

## 正确性证明

### 朴素 dp 的正确性

**命题**：$f[i] = $ 以 $a[i]$ 结尾的最长上升子序列长度。

**证明**：归纳。$f[1] = 1$ 显然。假设 $f[1..i-1]$ 正确——

设以 $a[i]$ 结尾的最长上升子序列为 $S$，长度 $L$。若 $L = 1$ 则 $S = \{a[i]\}$，$f[i]$ 转移取到 1 这条分支；若 $L \ge 2$，设 $S$ 的倒数第二个元素是 $a[j^*]$——则 $S \setminus \{a[i]\} = $ 以 $a[j^*]$ 结尾的某个上升子序列，长度 $L - 1$。由 $f[j^*]$ 的定义 $L - 1 \le f[j^*]$，且 $a[j^*] < a[i]$，所以转移枚举 $j = j^*$ 的分支取到 $f[j^*] + 1 \ge L$。

反方向，$f[i]$ 取到的任何值都对应一个真实的合法上升子序列。所以 $f[i] = L$。$\blacksquare$

### $g$ 数组的严格递增性

**命题**：在二分优化算法的任意时刻，$g[1] < g[2] < \cdots < g[\ell]$ 严格递增（$\ell$ 是当前 $g$ 的长度）。

**证明**：归纳证明每次操作后 $g$ 仍递增。

**操作 1：append**（即 $a[i] > g[\ell]$）：新追加的 $g[\ell + 1] = a[i] > g[\ell]$，递增性保持。

**操作 2：替换**（在位置 $k$ 把 $g[k]$ 改为 $a[i]$）：要证 $g[k-1] < a[i] < g[k+1]$（替换后的相邻关系）。

- $a[i] < g[k]$（因为 $g[k]$ 是替换前 $\ge a[i]$ 的第一个，再加上严格递增 $\Rightarrow$ 之前的 $g[k]$ 严格大于 $a[i]$）——而 $g[k+1]$ 在替换前 $> g[k]$，所以 $a[i] < g[k] < g[k+1]$，新 $g[k] < g[k+1]$ ✓

- 关于左边：$g[k-1] < g[k]$ 且 $g[k-1] < a[i]$（$g[k]$ 是 $\ge a[i]$ 的第一个，所以 $g[k-1] < a[i]$）——所以 $g[k-1] < a[i]$ ✓

替换后 $g$ 仍严格递增。$\blacksquare$

### 二分算法的正确性

**命题**：算法终止时 $|g|$ 等于 LIS 的长度。

**证明分两方向**：

**$|g| \le \text{LIS}$**：归纳证明任意时刻"$g[k] = $ 长度 $k$ 的上升子序列结尾的最小值"。

- 初始 $g$ 为空——对应"长度 0 的子序列"。

- 操作"append $a[i]$"：发生时 $a[i]$ 比 $g$ 末尾大，把它接在长度为 $\ell$（$g$ 的旧长度）的最优后缀之后，构造出长度 $\ell + 1$、结尾 $a[i]$ 的上升子序列。

- 操作"替换 $g[k] \leftarrow a[i]$"：原 $g[k]$ 是长度 $k$ 的最小末尾。$a[i] < g[k]$ 且 $a[i] > g[k-1]$ ——把"长度 $k-1$、结尾 $g[k-1]$ 的某个上升子序列"接上 $a[i]$，得到长度 $k$、结尾 $a[i]$ 的上升子序列。所以"长度 $k$ 的最小末尾"被 $a[i]$ 替换，更新合法。

**$|g| \ge \text{LIS}$**：设 LIS 为 $a_{i_1} < a_{i_2} < \cdots < a_{i_L}$。归纳证明扫描完 $a_{i_k}$ 之后，$g$ 至少有长度 $k$（即至少能"追上"LIS 的进度）：

- 扫描 $a_{i_1}$ 后 $|g| \ge 1$（不是 append 就是替换 $g[1]$，$g$ 都非空）

- 扫描 $a_{i_k}$ 时，扫描完 $a_{i_{k-1}}$ 后 $|g| \ge k - 1$。$a_{i_k} > a_{i_{k-1}} \ge g[k-1]$（由"$g[k-1]$ 是长度 $k-1$ 的最小末尾"）——所以处理 $a_{i_k}$ 时要么 append（$|g|$ 变成 $\ge k$）要么替换 $g[k]$ 或更后位置（$|g|$ 不减）。所以 $|g| \ge k$。

扫描完 $a_{i_L}$ 后 $|g| \ge L$。$\blacksquare$

## 应用扩展

### 输出 LIS 方案

二分版要在替换时记录"$a[i]$ 加入时所在的长度位置"——这给出每个 $a[i]$ 的"层号"。然后从最大层号开始**反向追溯**：找最后一个层号为 $L$ 的 $a[i]$，再找它之前最后一个层号为 $L-1$ 且值 $< a[i]$ 的，依此类推。

朴素版输出方案更直接——存 $\mathtt{prev}[i]$ 记录转移来源即可。

### Dilworth 定理：导弹拦截

> 一组导弹的高度，每套拦截系统**不上升**地拦截。问最少需要几套系统才能拦截所有导弹？

**结论**：最少系统数 = 最长**严格上升**子序列长度。这是 **Dilworth 定理** 的经典应用——

**证明思路**：把"系统数"理解为"最少多少条不上升链覆盖所有点"。Dilworth 定理在数论偏序集中说"最少链覆盖数 = 最长反链"。这里"反链"对应"任意两元素都不能同链"——即严格递增的子序列。所以——

$$\min\{\text{不上升子序列覆盖数}\} = \max\{\text{严格上升子序列长度}\}$$

实现上：对原数组求严格上升 LIS（用 `lower_bound`），即为答案。

### 排列的 LCS 化为 LIS

若 $a, b$ 都是 $1..n$ 的排列，[[最长公共子序列]] 可以这样化为 LIS——

- 设 $\mathtt{pos}[x] =$ "$x$ 在 $b$ 中的位置"

- 构造数组 $p[i] = \mathtt{pos}[a[i]]$（$i = 1..n$）

- $a$ 与 $b$ 的 LCS 等于 $p$ 的 LIS 长度

**直觉**：LCS 即"在 $a, b$ 中各选位置序列，使取出的元素序列在两边都递增"。把每个 $a[i]$ 翻译成它在 $b$ 中的位置后，"在 $a$ 中递增 + 在 $b$ 中递增" 就化为 "$p$ 上递增"——即 $p$ 的 LIS。

```cpp

// 排列 LCS → LIS

vector<int> pos(n + 1);

for (int j = 1; j <= n; j++) pos[b[j]] = j;

vector<int> p(n + 1);

for (int i = 1; i <= n; i++) p[i] = pos[a[i]];

int ans = lis_nlogn(p).solve();

```

复杂度从 $O(n^2)$（朴素 LCS）降到 $O(n \log n)$。

## 几个常见错误

- **混淆严格 vs 非严格**：`lower_bound` 与 `upper_bound` 一字之差，结果可能差一倍长度

- **答案写成 $f[n]$**：朴素 dp 的答案是 $\max_i f[i]$，不是 $f[n]$

- **下降 LIS**：求最长**下降**子序列时，把比较反过来即可——对原数组 $a$ 求"严格下降"等价于对 $-a$ 求"严格上升"

- **以为 $g$ 数组就是 LIS**：$g$ 只是辅助数组，**不是**真实的 LIS——它的元素来自不同的子序列。要还原方案得另存层号

## 与朴素 dp 的对比

| 维度           | 朴素 $O(n^2)$             | 二分 $O(n \log n)$     |
| ------------ | ----------------------- | -------------------- |
| 时间           | $O(n^2)$                | $O(n \log n)$        |
| 空间           | $O(n)$                  | $O(n)$               |
| 推广能力         | 强（可改成带权、带约束）            | 弱（依赖单一可比较的"末尾值"）     |
| 输出方案         | 直观（存 $\mathtt{prev}$）   | 间接（存层号 + 反向追溯）       |
| 适合 $n$ 的规模   | $\le 5000$              | $\le 10^6$           |

**经验**：纯 LIS 上二分；带权或带额外约束的 LIS 用 [[树状数组]] 维护前缀最值的朴素 dp 优化。
