#难度/★★

> 状态在一维序列上单向推进的 dp——是接触动态规划的第一站，也是理解"状态如何定义、转移如何浮现"的最好课堂。

## 核心思想

线性 dp 不是一个具体算法，而是**一类思想**——状态按某个**单调推进的维度**（数组下标 $i$、字符位置、阶段编号……）展开，每个 $f[i]$ 只依赖前面若干个 $f[j]\ (j < i)$。

每道线性 dp 题都共享下面这套思考框架——

1. **找推进维度**：是数组下标？字符位置？阶段？通常是题目中"按顺序处理"的那个量

2. **设计状态**：$f[i]$ 表示什么——往往是"考虑到前 $i$ 个元素时的某种最优值/计数"

3. **建立转移**：$f[i]$ 由 $f[i-1], f[i-2], \ldots$ 中的若干个推出，转移规则源自题目对"第 $i$ 个元素如何决策"的约束

4. **确定边界**：$f[0]$ 或 $f[1]$ 的初值；不可达状态置 $\pm \infty$

5. **答案位置**：通常是 $f[n]$，但也可能是 $\max_i f[i]$（如最大子段和）

> 💡 **dp 设计的灵魂——无后效性 + 最优子结构**：
>
> - **无后效性**：$f[i]$ 只依赖前面的状态值，不依赖"前面是怎么来的"——这是 dp 能压缩状态空间的根本
>
> - **最优子结构**：原问题的最优解可由更小子问题的最优解组合得到——这保证转移方程"取 $\max$ / $\min$"是合法的
>
> 设计 dp 时若发现这两条性质都成立，转移方程往往就在那里了。

## 三个经典模板

下面三道题是线性 dp 的"基石"——每道题都按上述框架走一遍，看清"状态/转移"是怎么从题面自然涌出来的。

### 模板一：爬楼梯

> 共有 $n$ 级台阶，每次只能跨 1 级或 2 级，问从第 0 级到第 $n$ 级有多少种走法。

**状态怎么想**：每次只能跨 1 或 2——意味着站在第 $i$ 级时，**上一步只能从 $i-1$ 或 $i-2$ 跨过来**。这告诉我们"到达第 $i$ 级"的方案数只依赖"到达 $i-1$"和"到达 $i-2$"——一维线性推进的特征已经显现。

定义 $f[i] =$ 从第 0 级到第 $i$ 级的方案数。这个状态有**无后效性**：到达 $i$ 后，"接下来怎么走"与"$i$ 之前是怎么走过来"无关。

**转移怎么推**：到达第 $i$ 级的最后一步必属于以下两类之一：

- 从 $i-1$ 跨 1 级上来——前面是任意一种"到 $i-1$"的走法，共 $f[i-1]$ 种

- 从 $i-2$ 跨 2 级上来——共 $f[i-2]$ 种

两类**互斥**（最后一步要么 1 级要么 2 级，不可能两者）且**穷尽**（题目只给这两种跨步方式）——所以——

$$f[i] = f[i-1] + f[i-2]$$

（这恰好是斐波那契数列）

**边界**：$f[0] = 1$（"在起点"算一种方案）、$f[1] = 1$。

**答案**：$f[n]$。

```cpp

class climb_stairs {

private:

    int n;

public:

    climb_stairs(int n_in) {

        n = n_in;

    }

    long long solve() {

        vector<long long> f(n + 2, 0);                 // 多开一位防 n=0 越界

        f[0] = 1;

        if (n >= 1) {

            f[1] = 1;

        }

        for (int i = 2; i <= n; i++) {

            f[i] = f[i - 1] + f[i - 2];

        }

        return f[n];

    }

};
```

### 模板二：数字三角形

> 给定 $n$ 行的三角形 $a[i][j]$（$1 \le j \le i$），从顶端 $(1, 1)$ 走到底端，每一步只能往**正下方** $(i+1, j)$ 或**右下方** $(i+1, j+1)$。求路径上数字之和的最大值。

**状态怎么想**：路径自上而下推进——"当前所在位置"是 $(i, j)$。注意一个关键问题：定义"$f[i][j] = $ 走到 $(i, j)$ 的最大和"是否满足无后效性？

是的——一旦走到 $(i, j)$，未来的决策只取决于 $(i, j)$ 的位置，与"具体怎么走来的"无关。所以历史路径细节可以**完全丢弃**，只保留它的"和"作为状态值。

定义 $f[i][j] =$ 从 $(1, 1)$ 走到 $(i, j)$ 的最大路径和。

**转移怎么推**：能走到 $(i, j)$ 的上一步**只可能**来自 $(i-1, j-1)$（向右下走来）或 $(i-1, j)$（向正下走来）——这是题目"两种走法"的逆。两源互斥取 $\max$，再加上当前格子的值：

$$f[i][j] = \max(f[i-1][j-1],\, f[i-1][j]) + a[i][j]$$

**边界**：$f[1][1] = a[1][1]$。形式上，$f[i][0]$ 与 $f[i][i+1]$ 视为 $-\infty$（不可达），让 $\max$ 自然忽略。

**答案**：$\max_{j=1}^{n} f[n][j]$（最后一行所有列的最大值）。

```cpp

class number_triangle {

private:

    int n;

    vector<vector<long long>> a;

    vector<vector<long long>> f;

public:
  
    number_triangle(int n_in, const vector<vector<long long>>& a_in) {

        n = n_in;

        a = a_in;

        f.assign(n + 1, vector<long long>(n + 2, LLONG_MIN));

    }

    long long solve() {

        f[1][1] = a[1][1];

        for (int i = 2; i <= n; i++) {

            for (int j = 1; j <= i; j++) {

                long long up_left  = (j >= 2)  ? f[i - 1][j - 1] : LLONG_MIN;

                long long up_right = (j <= i-1) ? f[i - 1][j]    : LLONG_MIN;

                f[i][j] = max(up_left, up_right) + a[i][j];

            }

        }

        long long ans = LLONG_MIN;

        for (int j = 1; j <= n; j++) {

            ans = max(ans, f[n][j]);

        }

        return ans;

    }

};

```

> 💡 **正向 dp vs 反向 dp**：上述是从顶向下推。也可以反过来——定义 $g[i][j] = $ 从 $(i, j)$ 走到底端的最大和，转移 $g[i][j] = \max(g[i+1][j],\, g[i+1][j+1]) + a[i][j]$，答案直接是 $g[1][1]$，省去最后一步的 $\max$。两种写法等价。

### 模板三：最大子段和（Kadane）

> 给一个长为 $n$ 的数组 $a[1..n]$（可含负数），求所有非空连续子段的和的最大值——即 $\max_{1 \le l \le r \le n} \sum_{i=l}^{r} a_i$。

**状态怎么想**：暴力是 $O(n^2)$ 枚举 $(l, r)$。要降到 $O(n)$，得想办法"沿单一维度推进"。一个直觉的想法是**枚举右端点 $r$**——固定 $r$ 后，问题变成"在 $[1, r]$ 中选最优左端点 $l$"。

但这样仍是 $O(n)$ 内层枚举 $l$。关键的洞察是——不要存"$[1, r]$ 中所有起点的和"，只存"以 $r$ 结尾的最优子段和"这一个数。

定义 $f[i] =$ **以 $i$ 为右端点**的最大子段和（即所有形如 $[l, i]$ 的子段中和的最大值）。

注意——$f[i]$ 不一定就是答案！它只是"右端点为 $i$"的局部最优。最终答案要在所有 $i$ 中再取一次 $\max$。

**转移怎么推**：考察以 $i$ 为右端点的子段 $[l, i]$ 中 $l$ 的取值——

- **若 $l < i$**（子段长度 $\ge 2$）：$[l, i] = [l, i-1] \cup \{i\}$。若 $[l, i]$ 是以 $i$ 为右端点的最优子段，那 $[l, i-1]$ 一定也是以 $i-1$ 为右端点的最优子段（否则把它换成更优的会让 $[l', i]$ 更大，矛盾）——这就是**最优子结构**。所以这种情形的最大值是 $f[i-1] + a_i$。

- **若 $l = i$**（子段长度 $= 1$）：和就是 $a_i$。

两情形取大者：

$$f[i] = \max(f[i-1] + a_i,\, a_i) = \max(f[i-1],\, 0) + a_i$$

**边界**：$f[1] = a[1]$。

**答案**：$\max_{i=1}^{n} f[i]$。

```cpp
class max_subarray {

private:

    int n;

    vector<long long> a;

public:

    max_subarray(int n_in, const vector<long long>& a_in) {

        n = n_in;

        a = a_in;

    }

    long long solve() {

        long long cur = a[1];                       // 滚动：cur = f[i]

        long long ans = a[1];

        for (int i = 2; i <= n; i++) {

            cur = max(cur, 0LL) + a[i];

            ans = max(ans, cur);

        }

        return ans;

    }

};

```

> 💡 **"以 $i$ 结尾"是 Kadane 的灵魂**——把二维 $(l, r)$ 的搜索压扁成一维 $f[i]$。这种"枚举一端 + 维护另一端最优"的思路在线性 dp 中反复出现（[[最长上升子序列]] 用同样的技巧）。

> ⚠️ **不要把答案写成 $f[n]$**：$f[n]$ 只是"以 $n$ 结尾的最大子段和"，未必全局最优。必须 $\max_i f[i]$。

## 适用场景

- 状态可"按顺序"沿一个维度推进（数组下标、字符位置、阶段、时间……）

- 转移依赖**有限的、最近的**前驱状态（$f[i-1]$、$f[i-2]$ 等，不会跳得太远）

- 经典模型：计数路径数、路径最值、子段最值、序列匹配

- 不适用：状态间没有"线性"关系（[[树形dp]] / [[区间dp]] / [[状压dp]]）；状态依赖是"图"而非"链"

## 一般框架

```cpp

// 1. 状态：f[i] 表示 ...

// 2. 边界：f[0] / f[1] = ...

// 3. 推进：for (i = ...; i <= n; i++) f[i] = (由 f[i-1] 等推出);

// 4. 答案：f[n] 或 max_i f[i]
```

## 复杂度分析

线性 dp 的复杂度由"状态数 × 单次转移代价"决定。三个模板各自的开销——

- 时间复杂度：

  - 爬楼梯：$O(n)$（$n$ 个状态，每个 $O(1)$ 转移）

  - 数字三角形：$O(n^2)$（$O(n^2)$ 个状态，每个 $O(1)$ 转移）

  - 最大子段和：$O(n)$

- 空间复杂度：

  - 爬楼梯：$O(n)$，滚动后 $O(1)$（只需保留 $f[i-1]$ 和 $f[i-2]$ 两个值）

  - 数字三角形：$O(n^2)$，滚动后 $O(n)$（只需保留上一行）

  - 最大子段和：$O(1)$
 
> 💡 **更一般地**：状态数 $S$、单次转移考察 $K$ 个前驱时，总复杂度 $O(SK)$。线性 dp 中常见的"$O(n)$ 状态、$O(1)$ 转移"对应 $O(n)$ 总复杂度（爬楼梯、最大子段和）；"$O(n)$ 状态、$O(n)$ 转移"对应 $O(n^2)$（如 [[最长上升子序列]] 朴素版）。

## 正确性证明

三个模板的"无后效性 + 最优子结构"已在"核心思想"中直观说明——下面用归纳法给出形式化论证。共同套路是**对推进维度 $i$ 归纳，分析"最后一步"的所有可能并验证转移完备**。

### 爬楼梯

**命题**：$f[i] =$ 从第 0 级到第 $i$ 级的方案数。

**证明**：对 $i$ 归纳。

**基础**：$f[0] = 1$（停在起点是唯一一种"到达 0 级"的方案）；$f[1] = 1$（只能从 0 级跨 1 级一种走法）。

**归纳**：假设 $f[0..i-1]$ 都正确（$i \ge 2$）。任何到达第 $i$ 级的合法走法，其**最后一步**必属于：

- 从 $i-1$ 级跨 1 级：剥离最后一步得到一个到达 $i-1$ 级的合法走法；反过来，任何到达 $i-1$ 级的合法走法末尾接"跨 1 级"得到一个到达 $i$ 级的合法走法——**双向一一对应**，方案数为 $f[i-1]$

- 从 $i-2$ 级跨 2 级：同理与"到达 $i-2$ 级的走法"双向一一对应，方案数为 $f[i-2]$

两类**互斥**（最后一步要么 1 级要么 2 级，不可兼）且**穷尽**（题目仅给两种跨步规则）——所以总方案数 $= f[i-1] + f[i-2]$。$\blacksquare$

### 数字三角形

**命题**：$f[i][j] =$ 从 $(1, 1)$ 走到 $(i, j)$ 的最大路径和。

**证明**：对 $i$ 归纳。

**基础**：$f[1][1] = a[1][1]$（起点只有自身一条"路径"，和即 $a[1][1]$）。

**归纳**：假设 $f[i-1][\cdot]$ 都正确。任一从 $(1, 1)$ 到 $(i, j)$ 的合法路径，其**最后一步**只可能从 $(i-1, j-1)$ 或 $(i-1, j)$ 走来（题目限定的两种走法的逆）。

**$\le$ 方向**（$f[i][j]$ 是上界）：设最优路径 $P$ 和为 $M$，剥离最后一步得到一条到 $(i-1, j-1)$ 或 $(i-1, j)$ 的路径，和为 $M - a[i][j]$。由归纳假设——

$$M - a[i][j] \le \max(f[i-1][j-1],\, f[i-1][j])$$

所以 $M \le \max(f[i-1][j-1],\, f[i-1][j]) + a[i][j]$。

**$\ge$ 方向**（$f[i][j]$ 可达）：取 $f[i-1][j-1]$ 或 $f[i-1][j]$ 对应的最优路径，在末尾接上 $(i, j)$，构造出合法路径，和恰为 $\max(\cdots) + a[i][j]$。

两方向相等，命题成立。$\blacksquare$

### 最大子段和（Kadane）

**命题**：$f[i] =$ 以 $i$ 为右端点的最大子段和（即 $\max_{1 \le l \le i} \sum_{k=l}^{i} a_k$）。

**证明**：对 $i$ 归纳。

**基础**：$f[1] = a[1]$（以 $1$ 为右端点的唯一子段是 $\{a_1\}$）。

**归纳**：假设 $f[i-1]$ 正确。考察以 $i$ 为右端点的最优子段 $[l^*, i]$ 中左端点的取值——

- **若 $l^* = i$**：子段为 $\{a_i\}$，和 $a_i$

- **若 $l^* < i$**：$[l^*, i-1]$ 必然是以 $i-1$ 为右端点的最优子段——否则设 $[l', i-1]$ 是更优的，则 $[l', i]$ 比 $[l^*, i]$ 更优，与 $[l^*, i]$ 最优矛盾。由归纳假设其和为 $f[i-1]$，所以 $[l^*, i]$ 和为 $f[i-1] + a_i$

两情形互斥且穷尽，取大者：

$$f[i] = \max(a_i,\, f[i-1] + a_i) = \max(f[i-1],\, 0) + a_i$$

**整体答案的正确性**：原问题求 $\max_{1 \le l \le r \le n} \sum_{k=l}^{r} a_k$。任何子段 $[l, r]$ 必有右端点 $r \in [1, n]$，恰好被 $f[r]$ 涵盖（$f[r]$ 已是固定 $r$ 时所有 $l$ 的最优）。所以总最大值 $= \max_{r=1}^{n} f[r]$。$\blacksquare$

> 💡 **共同的证明结构**：三个模板的归纳法都按 "**分析最后一步 → 验证两方向 → 合并取 $\max$ / 求和**" 的节奏推进。这正是 dp 正确性证明的通用范式——以后遇到新的 dp 题，都可以套这个模式自查。

## 几个常见错误

- **混淆"以 $i$ 结尾"vs"前 $i$ 个"**：最大子段和的状态是"以 $i$ 结尾"——$f[n]$ 不是答案，最终要 $\max_i f[i]$

- **边界遗漏**：$f[0]$、$f[1]$ 的特判常被忽略，写循环时容易越界

- **答案位置错误**：$f[n]$ vs $\max_i f[i]$——根据状态定义判断

- **不可达状态没置 $-\infty$**：求最大值时，若不可达写 0 会让 $\max$ 误取这个 0

## 几个能用线性 dp 描述的常见模型

| 模型        | 状态形式                         | 代表问题                  |
| --------- | ---------------------------- | --------------------- |
| 计数 / 方案   | $f[i] = $ 到达 $i$ 的方法数        | 爬楼梯、不同路径              |
| 路径最值      | $f[i][j] = $ 到 $(i,j)$ 的最优和  | 数字三角形、最小路径和           |
| 子段最值      | $f[i] = $ 以 $i$ 结尾的最优子段      | 最大子段和、最小子段和           |
| 子序列       | $f[i] = $ 以 $i$ 结尾的子序列长度     | [[最长上升子序列]]           |
| 双序列匹配     | $f[i][j] = $ 双前缀对齐结果         | [[最长公共子序列]]、编辑距离      |
| 决策序列      | $f[i][\text{state}]$         | [[状态机dp]]             |
