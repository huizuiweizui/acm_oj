#难度/★★★★

> "对**每个节点**作为根时求某值"——朴素 $O(n^2)$，换根 dp 用"两次 DFS"降到 $O(n)$。第二次 DFS 时通过"父→子"的关系**推导**新根答案，避免每次重新算。

## 前置知识

- [[树形dp]]

## 核心思想

> **树上距离和**：给一棵无根树（$n$ 个节点、$n-1$ 条边、边权均为 1）。对每个节点 $u$，求 $d_u = \sum_{v=1}^{n} \mathtt{dist}(u, v)$——即 $u$ 到所有其他节点的距离之和。要求**输出每个 $u$ 的 $d_u$**。

**朴素做法 $O(n^2)$**：对每个 $u$，做一次 [[DFS]] / [[BFS]] 算所有距离。$n \le 10^5$ 时这是 $10^{10}$ 操作，会 TLE。

**为什么有更优的解法**：观察相邻两个节点 $u, v$（$v$ 是 $u$ 的父节点）的 $d$ 关系——

- 把根从 $v$ 换到 $u$ 时，$u$ 子树内的所有节点离根**近了 1**

- $u$ 子树外的所有节点离根**远了 1**

设 $u$ 子树大小为 $\mathtt{sz}(u)$，则——

$$d_u = d_v + (n - \mathtt{sz}(u)) \cdot 1 - \mathtt{sz}(u) \cdot 1 = d_v + n - 2 \cdot \mathtt{sz}(u)$$

这个 $O(1)$ 的递推关系**直接由 $d_v$ 推出 $d_u$**——意味着只要先算出**某一个根**的 $d$，剩下 $n - 1$ 个根都能 $O(1)$ 推出！

**换根 dp 的两步法**：

1. **第一次 DFS（自底向上）**：以任意节点为根（比如节点 1），算出 $\mathtt{sz}[u]$ 和"以根 1 为视角"时的初步信息 $f[u]$（如"$u$ 子树到 $u$ 的距离和"）；最终汇总到根得到 $d_1$

2. **第二次 DFS（自顶向下）**：从已知的 $d_1$ 出发，用换根公式逐层传递给子节点，得到所有 $d_u$

> 💡 **换根 dp 的本质**：朴素法重算了大量重复工作；换根法把"根的位置"作为可变量、用 $O(1)$ 公式增量更新。这是动态规划"用旧值算新值"的精髓在树上的应用。

## 适用场景

- "对每个节点作为根时"求某个累加值 / 最优值 / 计数

- 经典题：树上距离和、最远 / 最近节点距离、子树贡献统计

- 朴素 $O(n^2)$ 显然 TLE 但相邻根之间能 $O(1)$ 推导的问题

- 不适用：跨根关系不能 $O(1)$ 推（如某些复杂的最值问题需要更高级技巧）；只需要单个根的答案（一次 [[树形dp]] 就够）

## 步骤拆解

1. **建无根树**：邻接表存双向边

2. **第一次 DFS（自底向上）**：以根 1 为视角，算出辅助量（如 $\mathtt{sz}[u]$、$f[u]$）以及根 1 的答案 $d_1$

3. **推导换根公式**：用"父 $\to$ 子" 的关系把 $d_v$（已知）变成 $d_u$

4. **第二次 DFS（自顶向下）**：先用换根公式计算 $d_u$，**然后**递归处理 $u$ 的每个子节点

5. **输出所有 $d_u$**

> ⚠️ **第二次 DFS 的核心顺序**：先算 $d_u$（基于父节点的 $d_{\mathtt{fa}}$）、再递归子节点——典型的"自顶向下"。注意和第一次 DFS（先递归子节点、再算 $f[u]$）的方向**完全相反**。

## 代码模板

**模板：树上距离和**

```cpp

class tree_distance_sum {

private:

    int n;

    vector<vector<int>> g_;                    // 邻接表（双向）

    vector<long long> sz;                      // sz[u] = u 子树大小（以 1 为根）

    vector<long long> f;                       // f[u] = u 子树内所有节点到 u 的距离和

    vector<long long> d_;                      // d_[u] = u 到所有节点的距离和（答案）


    // 第一次 DFS：自底向上，算 sz 和 f
    void dfs1(int u, int fa) {

        sz[u] = 1;

        f[u] = 0;

        for (int v : g_[u]) {

            if (v == fa) continue;

            dfs1(v, u);

            sz[u] += sz[v];

            f[u] += f[v] + sz[v];              // v 子树内每个节点到 u 比到 v 远 1

        }

    }

    // 第二次 DFS：自顶向下，算 d_
    void dfs2(int u, int fa) {

        for (int v : g_[u]) {

            if (v == fa) continue;

            d_[v] = d_[u] + (long long)n - 2 * sz[v];   // 换根公式

            dfs2(v, u);

        }

    }

public:

    tree_distance_sum(int n_in, const vector<vector<int>>& g_in) {

        n = n_in;

        g_ = g_in;

        sz.assign(n + 1, 0);

        f.assign(n + 1, 0);

        d_.assign(n + 1, 0);

    }

    vector<long long> solve(int root) {

        dfs1(root, 0);

        d_[root] = f[root];                    // 根的 d = 它子树内所有节点到它的距离和

        dfs2(root, 0);

        return d_;                             // 0 号位无效，从 1 号开始

    }

};
```

> 💡 **第一次 DFS 中的 $f[u] += f[v] + \mathtt{sz}[v]$**：$v$ 子树内每个节点到 $u$ 的距离比到 $v$ 的距离多 1。$v$ 子树有 $\mathtt{sz}[v]$ 个节点，所以增量为 $\mathtt{sz}[v]$；再加上"它们到 $v$ 的距离总和" $f[v]$，得到"它们到 $u$ 的距离总和"。

## 复杂度分析

- 时间复杂度：$O(n)$

  - 第一次 DFS：$O(n)$ —— 每个节点访问一次

  - 第二次 DFS：$O(n)$ —— 同上

- 空间复杂度：$O(n)$（邻接表 + 三个数组 + 递归栈）

> 💡 **对比朴素法**：朴素 $O(n^2)$ 在 $n = 10^5$ 时约 $10^{10}$ 步必 TLE；换根 dp $O(n)$ 约 $10^5$ 步，秒过。两次 DFS 的常数也很小（不到 $5 n$）。

## 正确性证明

### 换根公式的正确性

**命题**：设 $v$ 是 $u$ 的父节点（在某个固定根下），则 $d_u = d_v + n - 2 \cdot \mathtt{sz}(u)$，其中 $\mathtt{sz}(u)$ 是"以 $v$ 为根时 $u$ 的子树大小"。

**证明**：把树上所有 $n$ 个节点按"在 $u$ 子树中还是子树外"二分——

- **$u$ 子树内** 有 $\mathtt{sz}(u)$ 个节点。从根 $v$ 出发到这些节点要经过边 $(u, v)$；换到根 $u$ 后不再经过这条边——每个节点的距离**减 1**。总减少量：$\mathtt{sz}(u)$

- **$u$ 子树外**（含 $v$）有 $n - \mathtt{sz}(u)$ 个节点。从根 $v$ 出发到这些节点**不**经过边 $(u, v)$；换到根 $u$ 后**必须**经过这条边——每个节点的距离**加 1**。总增加量：$n - \mathtt{sz}(u)$

净变化：$+(n - \mathtt{sz}(u)) - \mathtt{sz}(u) = n - 2 \mathtt{sz}(u)$。

所以 $d_u = d_v + n - 2 \mathtt{sz}(u)$。$\blacksquare$

> 💡 **几何直观**：边 $(u, v)$ 把树分成两侧。换根相当于"边的方向反转"——一侧近 1、另一侧远 1。差值就是"两侧节点数之差"。

### 第二次 DFS 的拓扑序合法性

**命题**：第二次 DFS 中，计算 $d_u$ 时其父节点 $d_{\mathtt{fa}}$ 一定已经算出。

**证明**：第二次 DFS 是自顶向下的 [[DFS]]——根 $d_{\text{root}}$ 在 DFS 开始前已由第一次 DFS 求出（$= f[\text{root}]$）；递归进入子节点 $v$ 前已算好 $d_u$（父节点）。由归纳，每个节点 $d_v$ 计算时父节点 $d_u$ 已知。$\blacksquare$

## 应用扩展

### 应用一：树上每个节点的最远点距离

> 对每个节点 $u$，求 $\max_v \mathtt{dist}(u, v)$。

**思路**：维护两个量——

- $g_{\downarrow}[u] =$ 从 $u$ 向**子树内**走的最远距离（一次自底向上 DFS 算出）

- $g_{\uparrow}[u] =$ 从 $u$ 向**子树外**走的最远距离（一次自顶向下 DFS 算出）

答案就是 $\max(g_{\downarrow}[u],\, g_{\uparrow}[u])$。

**第二次 DFS 的 $g_{\uparrow}$ 转移**：$u$ 的某个子节点 $v$，它"向子树外走的最远距离"分两类——

- 经过 $u$ 然后向 $u$ 的子树外走：$g_{\uparrow}[u] + w(u, v)$

- 经过 $u$ 然后走 $u$ 的**其他**子树（不含 $v$）：$\max_{w \in \text{children}(u),\, w \ne v}(g_{\downarrow}[w] + w(u, w)) + w(u, v)$

第二项的关键是"排除 $v$ 自己"——为避免每次都 $O(\deg(u))$ 重算，常预处理 $u$ 子节点中"$g_{\downarrow}[w] + w(u, w)$" 的**前两大值**，若 $v$ 不是最大值贡献者则用最大值、否则用次大值。

### 应用二：树上累乘 / 路径数计数

类似"树上距离和"，但累加变累乘或计数。换根公式视具体题目重新推导。

### 应用三：带权树的距离和

边权不再恒为 1 时，第一次 DFS 中 $f[u] += f[v] + \mathtt{sz}(v) \cdot w(u, v)$；第二次 DFS 的换根公式变为 $d_u = d_v + (n - \mathtt{sz}(u)) \cdot w(u, v) - \mathtt{sz}(u) \cdot w(u, v) = d_v + (n - 2 \mathtt{sz}(u)) \cdot w(u, v)$。

## 几个常见错误

- **第二次 DFS 的顺序写反**：要先算 $d_v$（基于已知的 $d_u$）、**再**递归 $v$ 的子节点；写反会让所有节点 $d$ 都等于根的值

- **`sz[v]` 用错了根下的定义**：换根公式中的 $\mathtt{sz}(u)$ 是"以 $v$ 为根（即 $u$ 的原父节点）"下的子树大小——也就是第一次 DFS 求出的 $\mathtt{sz}$。换根**不改变**这个 $\mathtt{sz}$ 的值，因为它是"以初始根为视角"的定义

- **第一次 DFS 完忘记设 $d_{\text{root}} = f_{\text{root}}$**：换根的起点是根本身的 $d$，必须先填好

- **类型溢出**：$d_u$ 在大树上可达 $O(n^2)$ 量级（$n = 10^5$ 时 $10^{10}$），必须用 `long long`

- **无根树漏传 `fa`**：和 [[树形dp]] 中一样，双向边的邻接表 DFS 必须传 `fa` 避免回头

## 几种"自底向上 vs 自顶向下"DFS 的使用对比

| 场景          | 第一次 DFS                | 第二次 DFS           | 何时需要     |
| ----------- | ---------------------- | ----------------- | -------- |
| 普通 [[树形dp]] | 自底向上算 $f[\text{root}]$ | —                 | 只要根的答案   |
| 换根 dp       | 自底向上算辅助量 $f[u]$        | 自顶向下用换根公式算 $d[u]$ | 要每个节点的答案 |

**经验**：题目问"对每个节点 ..."且朴素 $O(n^2)$，多半就是换根 dp。
