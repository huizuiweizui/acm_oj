#难度/★★★★

> 树形 dp 与 [[0-1背包]] 的结合——节点是物品，但选某节点必须先选其所有祖先。状态在节点上、容量上各开一维，转移时把子树作为整体"打包"合并进父节点。

## 前置知识

- [[树形dp]]

## 核心思想

> **选课问题**：$n$ 门课程，每门有学分 $s_i$ 和**唯一**先修课 $p_i$（$p_i = 0$ 表示无先修课，即"根课程"）。选第 $i$ 门课时其先修课必须也已选。要求恰好选 $m$ 门，求最大学分。

**为什么这是树上背包**：

- 先修关系构成森林（每门课最多一个先修）——挂一个虚拟节点 0 作为所有"根课程"的父节点后变成一棵树

- "选 $i$ 必先选其祖先" → 在任意时刻，已选课程集合必然是"从根延伸的若干个连通块"——这是树上 [[0-1背包]] 的本质约束

- 数量限制（"恰好 $m$ 门"）是背包容量——所以叫**树上背包**

**状态怎么想**：朴素 [[0-1背包]] 的状态 $f[i][j]$（前 $i$ 件中选 $j$ 件的最优）无法表达"选某节点必先选其祖先"这个**树结构约束**。要在树上做背包，状态必须用**子树**为单位——

定义 $f[u][j] =$ 在以 $u$ 为根的子树中**选 $j$ 个课程（包括 $u$ 自身）**的最大学分。

为什么"必须包含 $u$"？因为子树中任何被选节点都要求 $u$ 也被选（祖先约束）——所以"选了任意节点就必选 $u$"。$j = 0$ 表示"$u$ 子树一个都不选"，是个特殊情形（实现时单独处理或纳入合并逻辑）。

**转移怎么推**：这是个**合并两棵子树的过程**。设 $u$ 已经处理完 $k-1$ 个子节点的合并，现在要把新子节点 $v$ 合并进来——

- "在 $u$ 子树中选 $j$ 个"可以拆成"在已合并部分选 $j - k$ 个、在 $v$ 子树中选 $k$ 个"（$0 \le k \le \min(j, \mathtt{size}(v))$）

$$f[u][j] = \max_{0 \le k \le j} \left( f[u][j - k]_{\text{合并前}} + f[v][k] \right)$$

这恰是 [[分组背包]] 的转移结构——把每个子树看作一组，"组内"枚举从该子树中选多少个。
  
> 💡 **核心顺序**：必须**先递归处理子节点**（得到子树的 $f[v]$）、**再合并到 $u$**（更新 $f[u]$）。这是 DFS 后序的标准节奏，与一般 [[树形dp]] 一致。

> ⚠️ **特别注意 "$u$ 自身的位置"**：状态 $f[u][j]$ 中 $u$ 已经被算上了。所以 $j$ 从 1 开始（$j = 0$ 时表示完全不选 $u$ 子树），合并子节点时枚举的 $k$（来自子节点）必须满足 $u$ 也被选——但 $u$ 已经在 $f[u][1] = s_u$ 这个初值里了，合并时直接累加即可。

## 适用场景

- 树上的"选若干个、有依赖关系"的最优化问题

- 选课、依赖背包、树上覆盖问题

- 经典题：选课（P2014）、二叉苹果树（P2015）、有线电视网（P1273）

- 不适用：无依赖关系的背包（用 [[0-1背包]]）；依赖关系是 DAG 而非树（更复杂，可能需要拓扑序 dp）

## 步骤拆解

1. 建树（注意可能是森林——挂虚拟根 0 把森林变成树）

2. DFS 后序遍历：递归处理 $u$ 的每个子节点 $v$

3. 合并 $v$ 子树到 $u$：用类似 [[分组背包]] 的内外两层循环（容量倒序、子内选数）

4. 答案：$f[\text{root}][m]$（虚拟根的话是 $f[0][m+1]$——多选一个虚拟根，但虚拟根学分为 0 故不影响）

## 代码模板

**模板：选课问题（P2014）**

```cpp

class course_selection {

private:

    int n, m;                                       // n 门课，选 m 门

    vector<vector<int>> children;                   // children[u] = u 的直接后继课程

    vector<long long> credit;                       // 学分（1-indexed）

    vector<vector<long long>> f;                    // f[u][j]

    vector<int> sz;                                 // 子树大小

    void dfs(int u) {

        sz[u] = 1;

        f[u][1] = credit[u];                        // 只选 u 自身（虚根 credit=0）

        for (int v : children[u]) {

            dfs(v);

            // 把 v 子树合并到 u：分组背包风格

            // j 倒序（类似 0-1 背包），上限 min(m + 1, sz[u] + sz[v])

            int total = min((long long)(m + 1), (long long)(sz[u] + sz[v]));

            for (int j = total; j >= 1; j--) {

                int k_max = min(j - 1, sz[v]);      // v 子树最多选 k 个（j - k >= 1 保证 u 被选）

                for (int k = 1; k <= k_max; k++) {

                    if (f[v][k] >= 0) {             // f[v][k] 可达

                        f[u][j] = max(f[u][j], f[u][j - k] + f[v][k]);

                    }

                }

            }

            sz[u] += sz[v];

        }

    }

public:

    course_selection(int n_in, int m_in,

                     const vector<vector<int>>& children_in,

                     const vector<long long>& credit_in) {

        n = n_in;

        m = m_in;

        children = children_in;

        credit = credit_in;

        sz.assign(n + 2, 0);

        // 注意虚根挂在 0，所以多开一行；选 m 门加上虚根共 m + 1

        f.assign(n + 2, vector<long long>(m + 2, -1));

    }

    long long solve() {

        f[0].assign(m + 2, -1);

        f[0][0] = 0;                                // 虚根：0 个不选时学分 0

        // 注意：DFS 调用时虚根 0 学分为 0，初始化 f[0][1] 也是合理的

        // 这里采用一种实现：直接 DFS 0，让递归填充

        // 简洁起见，下面给出最常见的写法：

        // DFS 从虚根 0 开始，f[0][1] 视作 0（虚根本身不计学分）

        dfs(0);

        return f[0][m + 1];                         // m+1 = 实选 m 门 + 虚根 1 门

    }

};
```

> ⚠️ **虚拟根的细节**：因为森林要挂虚根 0 才能用统一 DFS——虚根 0 算"被选"，但学分 0、不占用 $m$ 名额。常见写法是把答案落在 $f[0][m + 1]$（虚根 + $m$ 真课），或者特殊处理虚根。

> 💡 **判断 $f[v][k]$ 可达**：因为某些 $(v, k)$ 组合不可能（如 $k > \mathtt{sz}(v)$）—— 用 $f$ 初始化为 $-1$ 表示不可达、转移时检查，避免错误合并不可达态。

## 复杂度分析

- 时间复杂度：朴素分析 $O(n m^2)$；**精细分析**（每对节点 $(u, v)$ 只在它们的 LCA 处贡献一次合并）实际是 $O(nm)$ 或 $O(n^2)$

- 空间复杂度：$O(nm)$（$f[u][j]$ 二维数组）

> 💡 **关于 $O(nm)$ 的精细分析**：合并子节点 $v$ 到 $u$ 时，循环 $(j, k)$ 的总次数是 $\mathtt{sz}(u)_{\text{合并前}} \cdot \mathtt{sz}(v)$（而非朴素的 $m^2$）。所有节点的合并代价之和等价于"任意两节点 $a, b$ 的对在 LCA 处贡献 1 次"——总 $\binom{n}{2} = O(n^2)$。当 $m \le n$ 时再裁剪到 $O(nm)$。

## 正确性证明

### 状态合法性

**命题**：$f[u][j]$（$j \ge 1$）表示"以 $u$ 为根的子树中选 $j$ 个节点（包含 $u$）的合法选法（祖先约束满足）的最大学分"。

**证明**：

**祖先约束的满足**：由于 $f[u][j]$ 强制包含 $u$，子树中任意被选节点 $u'$ 的所有祖先（限制在 $u$ 子树内）都在"$u$ 到 $u'$ 的路径"上——只要路径上每个节点都被选，约束就满足。

由归纳：合并子节点 $v$ 时，从 $f[v][k]$（$k \ge 1$ 时 $v$ 被选）转移过来；而要让 $v$ 在 $u$ 子树中的所有祖先都被选，只需 $u$ 被选——这由 $f[u][\cdot]$ 状态定义保证。$\blacksquare$

### 合并转移的正确性

**命题**：合并新子节点 $v$ 时，

$$f[u][j]_{\text{new}} = \max_{0 \le k \le \min(j - 1,\, \mathtt{sz}(v))} \left( f[u][j - k]_{\text{old}} + f[v][k] \right)$$

正确刻画"在 $u$ 加上 $v$ 子树后的最优 $j$ 选法"。

**证明**：

任何合法的"在 $u$ 子树（已含 $v$）中选 $j$ 个"方案可拆为——

- "在 $u$ 之前已合并子节点的总子树中选 $j - k$ 个"

- "在 $v$ 子树中选 $k$ 个"（$0 \le k \le \mathtt{sz}(v)$，且需 $j - k \ge 1$ 保证 $u$ 被选）

由 $f[u][\cdot]_{\text{old}}$ 和 $f[v][\cdot]$ 的定义，两部分的最优值之和恰是上式右侧。所有 $k$ 的取值都被 $\max$ 涵盖——正确。$\blacksquare$

### 倒序枚举 $j$ 的必要性

**命题**：合并子节点 $v$ 时，外层 $j$ 必须**从大到小**枚举。

**证明**：和 [[0-1背包]] 一维滚动的论证一致——$f[u][j]_{\text{new}}$ 读取的 $f[u][j - k]$ 必须是"合并 $v$ 之前"的旧值。倒序枚举 $j$ 时，$j - k < j$ 还未被本轮（合并 $v$）触及，是旧值；正序枚举则 $f[u][j - k]$ 可能已被覆写，导致 $v$ 子树被"算两次"。$\blacksquare$

## 应用扩展

### 应用一：有线电视网（洛谷 P1273）

> 树形电视网络，叶子是用户、中间节点是中转站。每个用户愿意付 $w_u$ 看节目，每条边铺设代价 $c_e$。求最多能服务多少用户使得**总收入 $\ge$ 总代价**。

转化为树上背包：$f[u][k] =$ 在 $u$ 子树中服务 $k$ 个用户能获得的**最大净收入**。合并子节点的转移类似选课。最终找**最大的 $k$** 使 $f[\text{root}][k] \ge 0$。

### 应用二：二叉苹果树（洛谷 P2015）

> 一棵 $n$ 个节点的二叉树，每条边带"苹果数"。保留恰好 $q$ 条边时苹果数的最大总和。

$f[u][k] =$ 以 $u$ 为根的子树中保留 $k$ 条边时的最大苹果数。注意"边数"和"节点数"差 1，转移中要小心处理"保留与 $v$ 之间的边" + "$v$ 子树内保留的边"两部分。

## 几个常见错误

- **正序枚举 $j$**：合并子树时正序枚举 $j$ 会让 $v$ 子树被算多次——是最高频 bug。**必须倒序**

- **忘记初始化 $f[u][1]$**：DFS 到 $u$ 时应先把 $f[u][1] = $ "只选 $u$ 自己"的初值设好，再合并子节点；漏写会让 $f[u]$ 始终为 0

- **`sz[u]` 维护错位**：合并 $v$ 之前的 `sz[u]` 是"已合并部分"的大小，循环结束后才能 `sz[u] += sz[v]`。顺序错会让循环上界算错

- **虚拟根的学分意外参与计算**：森林挂虚根时虚根学分必须为 0、不计入 $m$ 名额——答案位置和 $f$ 的维度都要相应调整

- **下标 0 vs 1**：本笔记用 1-indexed，0 留给虚根（如果用到）
