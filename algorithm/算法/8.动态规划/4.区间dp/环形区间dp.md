#难度/★★★

> 区间 dp 的"环形"版本——把序列首尾相连，问题不再有"起点"和"终点"。**倍长数组**是化环为链的关键技巧，只需把 [[区间dp]] 在长度 $2n$ 的数组上跑一遍即可。

## 前置知识

- [[区间dp]]

## 核心思想

> **环形石子合并**：$n$ 堆石子排成一个**环**（第 $n$ 堆与第 $1$ 堆也相邻），每次合并相邻两堆代价为两堆之和，求合并成一堆的最小（或最大）总代价。

**为什么"环形"是难点**：链上的区间 dp 中，"区间 $[l, r]$"有明确含义——以 $l$ 为左端、$r$ 为右端、不跨越数组边界。但在环上，"区间"可以**绕过 $n$ 回到 $1$**——例如"$[n-2, 3]$"在环上是合法的（覆盖原本的位置 $n-2, n-1, n, 1, 2, 3$）。直接套用链上模板会漏掉所有"跨边界"的区间。

**核心技巧——倍长数组**：把原数组 $a[1..n]$ 复制一份接在后面，形成长度 $2n$ 的新数组 $a'[1..2n]$，其中 $a'[i] = a[((i - 1) \bmod n) + 1]$。

这个新数组上**任意长度为 $n$ 的连续区间** $[i, i+n-1]$ 对应原环上从位置 $i$ 开始的一个"环形序列"。把所有这种区间都跑一遍 [[区间dp]]，再取 $\min$ / $\max$ 即可。

**算法步骤**：

1. 构造倍长数组 $a'[1..2n]$

2. 在 $a'$ 上跑 $O((2n)^3) = O(n^3)$ 的区间 dp，得到 $f[l][r]$（$1 \le l \le r \le 2n$）

3. 答案 = $\min_{i=1}^{n} f[i][i + n - 1]$（或 $\max$）

> 💡 **倍长的本质**：在环上"切一刀"得到一条链——但切的位置会影响结果。倍长后所有 $n$ 种切法对应的链都被涵盖在 $a'$ 的不同 $[i, i+n-1]$ 子区间里，一并求解。

## 适用场景

- 环形序列上的合并、分割、染色等区间结构问题

- 题面有"首尾相接"、"成环"、"项链"、"圆桌"等字眼

- 经典模型：环形石子合并、能量项链、环形数字合并

- 不适用：环上但没有区间 dp 结构的问题（如环上最短路用 [[Dijkstra]]）；环很大但只要找一个最优断点（可能有 $O(n)$ 或 $O(n \log n)$ 的更优算法）

## 步骤拆解

1. 把原数组 $a[1..n]$ 倍长成 $a'[1..2n]$

2. 计算前缀和（基于 $a'$）

3. 在 $a'$ 上跑链版区间 dp，但只关心长度 $\le n$ 的区间（更长的没意义，浪费时间）

4. 答案在所有"以 $i$ 为起点、长度恰为 $n$" 的区间 $[i, i+n-1]$ 中取最优

## 代码模板

**模板：环形石子合并**

```cpp

class circular_stone_merge {

private:

    int n;

    vector<long long> a;                                // 1-indexed，长度 n

    vector<long long> ext;                              // 倍长数组，长度 2n

    vector<long long> presum;                           // ext 的前缀和

    vector<vector<long long>> f;

    long long sum_range(int l, int r) {

        return presum[r] - presum[l - 1];

    }

public:

    circular_stone_merge(int n_in, const vector<long long>& a_in) {

        n = n_in;

        a = a_in;

        // 构造倍长数组
        ext.assign(2 * n + 1, 0);

        for (int i = 1; i <= n; i++) {

            ext[i] = a[i];

            ext[i + n] = a[i];

        }

        // 前缀和
        presum.assign(2 * n + 1, 0);

        for (int i = 1; i <= 2 * n; i++) {

            presum[i] = presum[i - 1] + ext[i];

        }

        f.assign(2 * n + 1, vector<long long>(2 * n + 1, 0));

    }

    long long solve_min() {

        for (int len = 2; len <= n; len++) {                    // 只到长度 n

            for (int l = 1; l + len - 1 <= 2 * n; l++) {

                int r = l + len - 1;

                f[l][r] = LLONG_MAX;

                for (int k = l; k < r; k++) {

                    f[l][r] = min(f[l][r], f[l][k] + f[k + 1][r]);

                }

                f[l][r] += sum_range(l, r);

            }

        }

        long long ans = LLONG_MAX;

        for (int i = 1; i <= n; i++) {

            ans = min(ans, f[i][i + n - 1]);

        }

        return ans;

    }

    // 求最大代价：把 min 换成 max、初始置 LLONG_MIN
    long long solve_max() {

        // 重新填一遍 f

        for (auto& row : f) {

            fill(row.begin(), row.end(), 0);

        }

        for (int len = 2; len <= n; len++) {

            for (int l = 1; l + len - 1 <= 2 * n; l++) {

                int r = l + len - 1;

                f[l][r] = LLONG_MIN;

                for (int k = l; k < r; k++) {

                    f[l][r] = max(f[l][r], f[l][k] + f[k + 1][r]);

                }

                f[l][r] += sum_range(l, r);

            }

        }

        long long ans = LLONG_MIN;

        for (int i = 1; i <= n; i++) {

            ans = max(ans, f[i][i + n - 1]);

        }

        return ans;

    }

};
```

> ⚠️ **长度只到 $n$ 即可**：内层 `len` 不需要到 $2n$——长度超过 $n$ 的区间在环上已经"绕回原点"覆盖了重复元素，没意义。卡到 `len <= n` 把复杂度从 $O((2n)^3) = 8n^3$ 降到 $4n^3$，是 2 倍的常数优化。

> 💡 **求最大代价时**：经典题 [石子合并](https://www.luogu.com.cn/problem/P1880)要求**同时**求最小与最大代价——求最大时直接把 $\min$ 换成 $\max$ 即可，转移结构完全相同。

## 复杂度分析

- 时间复杂度：$O(n^3)$

  - 状态数：$O((2n) \cdot n) = O(n^2)$（左端点 $2n$ 种、长度最多 $n$）

  - 每个状态 $O(n)$ 枚举分割点

- 空间复杂度：$O(n^2)$（$2n \times 2n$ 的 $f$ 数组，常数是普通区间 dp 的 4 倍）

> 💡 **常数偏大**：相比链版区间 dp，时空都增加了 $4 \sim 8$ 倍的常数——所以环形版能解决的 $n$ 上限通常是链版的一半左右（约 $n \le 500$）。

## 正确性证明

### 倍长技巧的完备性

**命题**：原环上从任意位置 $i$ 出发的"环形区间 $[i, i+1, \ldots, i + n - 1]$（下标模 $n$ 后取）"恰好对应倍长数组 $a'$ 中的区间 $[i, i+n-1]$。

**证明**：对 $j \in [0, n-1]$，环上 $i$ 出发第 $j$ 个位置是 $((i - 1 + j) \bmod n) + 1$。倍长数组中位置 $i + j$ 满足 $1 \le i + j \le 2n$，且 $a'[i + j] = a[((i + j - 1) \bmod n) + 1] = a[((i - 1 + j) \bmod n) + 1]$——与环上对应位置取值一致。$\blacksquare$

### 答案正确性

**命题**：环形最优代价 = $\min_{i=1}^{n} f[i][i + n - 1]$（其中 $f$ 是在 $a'$ 上跑链版区间 dp 的结果）。

**证明**：环形问题的任何合法合并方案都对应"某个最后合并出的连续区间覆盖整个环"。在环上，最后合成的那一堆覆盖全 $n$ 个位置——它可以从环上任意位置 $i$ 开始顺时针延伸 $n$ 步形成。$f[i][i + n - 1]$ 就是"链版区间 dp"在 $a'$ 上对这个长度为 $n$ 的区间求得的最优代价，等于"以 $i$ 为起点切开环、再做链版合并"的最优代价。

所以——所有 $n$ 个可能的"起点切口" $i$ 都被涵盖，取 $\min$ 即环形最优。$\blacksquare$

### 与"枚举断点"方法的等价性

**替代思路**：把环在某个位置切开变成链，跑链版区间 dp——但切的位置会影响结果，需枚举 $n$ 个不同切口，复杂度 $O(n \cdot n^3) = O(n^4)$。

**倍长法的优势**：每次切口下的链版 dp 子问题之间**有大量重叠**——比如"从 $i$ 切开的链"与"从 $i+1$ 切开的链"共享几乎所有子区间。倍长法在 $a'$ 上做一次 dp 就把所有切口都同时算完，复杂度 $O(n^3)$，省掉一个 $n$。$\blacksquare$

## 几个常见错误

- **`len` 上限写成 $2n$**：浪费 8 倍时间且会让 $f[i][i + n - 1]$ 之外的状态被错误填入，可能影响答案区间的取值。**`len` 上限必须是 $n$**

- **答案取 $f[1][n]$**：这是只考虑了"从位置 1 出发"的链，漏掉所有跨边界的方案。**必须枚举 $i = 1$ 到 $n$ 取最优**

- **前缀和数组长度不够**：前缀和必须基于 $a'$（长度 $2n$）而不是 $a$（长度 $n$），否则跨边界区间的 $\mathtt{sum}$ 会读到无效值

- **倍长时未复制**：只把 $a'[i + n] = a[i]$ 容易漏写——必须 $a'[1..n]$ 和 $a'[n+1..2n]$ 都被赋值（取决于实现，可以是同一个循环）

## 应用扩展

### 应用一：能量项链（洛谷 P1063）

> 一串项链由 $n$ 颗珠子串成环，每颗珠子有"头标记"$a_i$ 和"尾标记"$a_{i+1}$（即第 $i$ 颗的尾就是第 $i+1$ 颗的头）。合并相邻两颗珠子产生能量 $a_l \cdot a_m \cdot a_r$（$l, m, r$ 是合并涉及的三个标记）。求合并成一颗珠子能产生的最大总能量。

**转化**：把环看作 $n+1$ 个标记构成的环（$a_1, a_2, \ldots, a_n, a_1$）。设 $f[l][r] = $ 合并标记序列 $a_l, a_{l+1}, \ldots, a_r$ 之间的所有珠子能产生的最大能量。

$$f[l][r] = \max_{l < k < r} (f[l][k] + f[k][r] + a_l \cdot a_k \cdot a_r)$$

注意分割点 $k$ 这里是**共享的标记**（不是分两段），状态枚举类似矩阵链乘。配合倍长技巧解环。

### 应用二：环形序列的其他 dp

环上"求若干段最优划分"、"环形选数不相邻"等问题，常用倍长技巧——但有些题（如环形选数不相邻问题）有更简洁的方法（**枚举第一个元素选不选**，分两次链版 dp，详见 [[状态机dp]]）。
