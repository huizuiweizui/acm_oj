#难度/★★★★★

> 当转移方程含 $j \cdot i$ 乘积项时——[[单调队列优化dp]] 失效。把每个候选 $j$ 看作平面上一个点 $(X_j, Y_j)$，$f[i]$ 最小化即"在所有点中求斜率为 $k_i$ 的直线的最小截距"——维护**凸壳**即可。

## 核心思想

[[单调队列优化dp]] 处理的转移有形式——

$$f[i] = \min_{j} \left( g(j) + h(i) \right)$$

但很多 dp 题的转移有"$j$ 与 $i$ 的耦合项"——比如 $j \cdot i$ 或 $(a_i - a_j)^2$ 这种**乘积**——一旦展开就出现 $f[i] = \min_j [g(j) - 2 a_i \cdot X_j + (\cdots)]$ 这种**含 $i$ 与 $j$ 乘积**的形式。$h(i)$ 不能简单提出 $\min$——单调队列失效。

**斜率优化的核心想法**：把上面的 $\min_j (g(j) - 2 a_i X_j)$ 改写为——

$$Y_j - K_i \cdot X_j$$

其中 $X_j, Y_j$ 都只依赖 $j$、$K_i$ 只依赖 $i$。在固定 $i$ 时，要最小化 $Y_j - K_i X_j$——**这正是"求一条斜率为 $K_i$ 的直线、使它过某个点 $(X_j, Y_j)$ 时截距最小"的几何问题**！

**几何直观**：把所有候选 $j$ 画成平面上的点 $\{(X_j, Y_j) : j\}$。截距 $b = Y - K \cdot X$ 表示直线 $Y = K X + b$ 在 $Y$ 轴上的高度。固定斜率 $K = K_i$ 平行移动直线、求"擦过某个点时最低 $b$"——只有**下凸壳**上的点才有机会成为最优；上凸壳的点永远被下方某直线压制。

**核心算法（求 $\min$ 时维护下凸壳）**：

1. 把每个已处理的 $j$ 作为点 $(X_j, Y_j)$ 加入凸壳

2. 处理新 $i$ 时，在凸壳上**二分** / **单调队列遍历**，找使 $Y_j - K_i X_j$ 最小的 $j$

3. 用最优 $j$ 转移得 $f[i]$，再把 $i$ 作为新点加入凸壳

**单调队列维护凸壳的两条简化**：

若 $X_j$ 关于 $j$ **单调递增**（多数题目自然成立），且 $K_i$ 关于 $i$ **单调**（多数题目也成立）——可用单调队列以**摊还 $O(1)$** 维护与查询，整体 $O(n)$。

> 💡 **斜率优化的判据**：
>
> - 转移方程展开后含 "$\alpha \cdot i \cdot j$" 或 "$(\text{含 } i) \cdot (\text{含 } j)$" 项 → 该用斜率优化
>
> - $X_j$ 与 $K_i$ 都单调 → 单调队列实现（$O(n)$）
>
> - $X_j$ 不单调或 $K_i$ 不单调 → 改用平衡树 / CDQ 分治维护凸壳（$O(n \log n)$）

## 经典例题：玩具装箱

> 给定 $n$ 个玩具，第 $i$ 个长度 $C_i$。要把玩具**按顺序**分成若干段、每段装入一个箱子。若一个箱子里装 $[l, r]$ 段玩具，则该箱长度为 $\sum_{i=l}^{r} C_i + (r - l)$（玩具之间有 1 单位间隔）。设箱子"标准长度"为 $L$，每个箱子代价为 $(\text{实际长度} - L)^2$。求最小总代价。

**状态怎么想**：典型的"分段 dp"——枚举最后一段的起点。

定义 $f[i] =$ 前 $i$ 个玩具的最小总代价（第 $i$ 个是某段的末尾）。

为使公式简洁，预处理 $s_i = \sum_{k=1}^{i} C_k$；最后一段是 $[j + 1, i]$ 时，箱子长度 = $s_i - s_j + (i - j - 1)$。

进一步代换 $a_i = s_i + i$（"虚拟前缀和"，把间隔纳入），箱子长度 = $a_i - a_j - 1$。令 $C = L + 1$——单段代价 = $(a_i - a_j - C)^2$。

**朴素转移**：

$$f[i] = \min_{0 \le j < i} \left[ f[j] + (a_i - a_j - C)^2 \right]$$

复杂度 $O(n^2)$。$n = 5 \times 10^4$ 时 $2.5 \times 10^9$ 必 TLE——需要优化。

**展开 + 重新整理**：

$$\begin{align}

f[i] &= \min_j \left[ f[j] + (a_i - a_j - C)^2 \right] \\

     &= \min_j \left[ f[j] + (a_j + C)^2 - 2 a_i (a_j + C) \right] + a_i^2 \\

     &= \min_j \left[ \underbrace{f[j] + (a_j + C)^2}_{Y_j} - 2 a_i \cdot \underbrace{(a_j + C)}_{X_j} \right] + a_i^2

\end{align}$$

把 $a_i^2$ 移到左侧、$\min$ 中只剩"$Y_j - 2 a_i X_j$"——

$$f[i] - a_i^2 = \min_j (Y_j - 2 a_i X_j)$$

固定 $i$，问题归结为：**给定平面上的点集 $\{(X_j, Y_j)\}_{0 \le j < i}$，求经过其中一个点、斜率为 $2 a_i$ 的直线的最小截距**。

**何时新候选 $j_2$ 优于旧候选 $j_1$**（$j_1 < j_2$）：

$$\left\{
\begin{gathered}
Y_{j_2} - 2 a_i X_{j_2} \le Y_{j_1} - 2 a_i X_{j_1} \\[6pt]
Y_{j_2} - Y_{j_1} \le 2 a_i (X_{j_2} - X_{j_1}) \\[6pt]
\frac{Y_{j_2} - Y_{j_1}}{X_{j_2} - X_{j_1}} \le 2 a_i \quad (\text{由 } X_j \text{ 单增})
\end{gathered}
\right.$$


**关键结论**：若两候选连线的**斜率 $\le 2 a_i$**，新点更优；否则旧点更优。

由这一比较可证——**只有下凸壳上的点能成为最优**。其他点恒被两侧的点压制（"夹击淘汰"）。

**两个单调性的利好**：

- $a_i = s_i + i$ 关于 $i$ **严格单增**（$s$ 单增、$i$ 单增）—— $K_i = 2 a_i$ 单增

- $X_j = a_j + C$ 关于 $j$ **严格单增**

两者单调使我们可以用**单调队列**摊还 $O(1)$ 维护：

- **队首**：随着 $K_i$ 增大，对"队首两个点连线斜率 $\le K_i$"的情形持续弹队首（"队首已不可能比下一个优"）

- **队尾**：新加入点 $i$ 时，弹出"形不成下凸"的队尾点（即"前两点连线斜率 $\ge$ 当前与队尾连线斜率"的）

**边界**：$f[0] = 0$（虚拟起点，空玩具集代价 0），把 $j = 0$ 作为初始候选入队。

**答案**：$f[n]$。

## 适用场景

- 分段 dp、序列划分 dp、最优投递问题等含"$f[i] = f[j] + (\text{含 } i, j \text{ 乘积的代价})$"的转移

- 数据规模 $n \ge 10^5$ 时朴素 $O(n^2)$ TLE 但有斜率结构

- 经典模型：玩具装箱、仓库建设、土地征用、印刷错误

- 不适用：转移中无乘积耦合（用 [[单调队列优化dp]]）；状态多维（需要其他工具）；代价函数不能整理成 $Y_j - K_i X_j$ 形式

## 步骤拆解

1. **写朴素转移**：$f[i] = \min_j \bigl[ f[j] + \text{cost}(j, i) \bigr]$

2. **展开 $\text{cost}$**：把 $j$ 与 $i$ 的耦合项整理出来——理想形式是 $Y_j - K_i X_j$，再加上只含 $i$ 的项

3. **设 $X_j, Y_j$**：要让 $X_j, Y_j$ 中**只含 $j$**——若题目里 $X_j$ 不单调可考虑代换

4. **判断单调性**：$X_j$ 单增？$K_i$ 单增？两者都单 → 用单调队列；否则用平衡树

5. **维护凸壳**：求 $\min$ 维护下凸壳；求 $\max$ 维护上凸壳

6. **答案**：$f[n]$ 或其他终态

## 代码模板

**模板：玩具装箱**

```cpp

class toy_packing {

private:

    int n;

    long long L;

    vector<long long> C;                                // 1-indexed

    vector<long long> a;                                // a[i] = sum(C[1..i]) + i

    vector<long long> f;

    // X_j = a[j] + (L + 1)
    long long X(int j) { return a[j] + L + 1; }

    // Y_j = f[j] + (a[j] + L + 1)^2 = f[j] + X(j)^2
    long long Y(int j) { return f[j] + X(j) * X(j); }

    // 斜率：(Y_b - Y_a) / (X_b - X_a)——用乘法比较避免精度

    // slope(a, b) <= K_i  等价于  (Y_b - Y_a) <= K_i * (X_b - X_a)

    // 这里 K_i = 2 * a[i]

    bool slope_le_K(int a_idx, int b_idx, long long K) {

        return (Y(b_idx) - Y(a_idx)) <= K * (X(b_idx) - X(a_idx));

    }

    // slope(a, b) >= slope(b, c)：队尾去除条件

    // 即 (Y_b - Y_a) * (X_c - X_b) >= (Y_c - Y_b) * (X_b - X_a)

    bool slope_ge(int a_idx, int b_idx, int c_idx) {

        return (Y(b_idx) - Y(a_idx)) * (X(c_idx) - X(b_idx))

            >= (Y(c_idx) - Y(b_idx)) * (X(b_idx) - X(a_idx));

    }

public:

    toy_packing(int n_in, long long L_in,

                const vector<long long>& C_in) {

        n = n_in;

        L = L_in;

        C = C_in;

        a.assign(n + 1, 0);

        for (int i = 1; i <= n; i++) {

            a[i] = a[i - 1] + C[i] + 1;                 // = sum(C[1..i]) + i

        }

        f.assign(n + 1, 0);

    }

    long long solve() {

        deque<int> dq;

        dq.push_back(0);                                // f[0] = 0，作为初始候选

        for (int i = 1; i <= n; i++) {

            long long K = 2 * a[i];

            // 1. 弹出队首：若前两点连线斜率 <= K，队首已不优
            while (dq.size() >= 2 && slope_le_K(dq[0], dq[1], K)) {

                dq.pop_front();

            }

            // 2. 用队首计算 f[i]
            int j = dq.front();

            long long dx = a[i] - a[j] - L - 1;

            f[i] = f[j] + dx * dx;

            // 3. 入队尾，先弹出形不成下凸的
            while (dq.size() >= 2

                && slope_ge(dq[dq.size() - 2], dq.back(), i)) {

                dq.pop_back();

            }

            dq.push_back(i);

        }

        return f[n];

    }

};
```

> ⚠️ **避免精度损失：用乘法代替除法判斜率**：
>
> 斜率 $\frac{Y_b - Y_a}{X_b - X_a} \le K$ 等价于 $(Y_b - Y_a) \le K (X_b - X_a)$（$X_b > X_a$ 时）。把除法换成乘法既避免浮点误差、又防止除零。
>
> ⚠️ **乘法溢出**：$X, Y, K$ 都可能很大，相乘可能爆 `long long`——题目大数据时可能要用 `__int128` 或分式比较的高精度技巧。

> 💡 **凸壳维护的两个对偶**：
>
> - 求 $\min$ + $X_j$ 与 $K_i$ 都单增 → 维护**下凸壳**，队首弹斜率 $\le K_i$ 的、队尾弹斜率$\ge$ 的
>
> - 求 $\max$ + $X_j$ 与 $K_i$ 都单增 → 维护**上凸壳**，方向反过来

## 复杂度分析

- 时间复杂度：$O(n)$

  - 每个 $j$ 最多入队一次、出队一次（队尾被新点挤掉 + 队首被新 $i$ 越过 ≤ 一次）

  - 主循环 $O(n)$ + 摊还 $O(n)$

- 空间复杂度：$O(n)$（$f$ 数组 + 凸壳队列）

> 💡 **不带单调性时的复杂度**：若 $K_i$ 不单调（但 $X_j$ 单调），需在凸壳上二分——$O(n \log n)$；若 $X_j$ 也不单调，需用平衡树 / 李超树 / CDQ 分治——$O(n \log n)$ 或 $O(n \log^2 n)$。

## 正确性证明

### 凸壳维护正确

**命题**：算法的双端队列在每轮结束后，队列中下标 $j_0 < j_1 < \cdots < j_t$ 对应的点 $(X_{j_0}, Y_{j_0}), (X_{j_1}, Y_{j_1}), \ldots, (X_{j_t}, Y_{j_t})$ 构成一个**下凸壳**——即相邻三点中点不在两端点的连线之上。

形式化：对所有相邻 $a, b, c$ 三点（$a, b, c$ 是队列中相邻下标），

$$\mathtt{slope}(a, b) < \mathtt{slope}(b, c)$$

其中 $\mathtt{slope}(p, q) = \frac{Y_q - Y_p}{X_q - X_p}$（$X_q > X_p$）。

**证明（归纳）**：基础（队列长度 $\le 2$）平凡成立。归纳步——入队 $i$ 前，反复执行"若 $\mathtt{slope}(\text{倒数第二}, \text{队尾}) \ge \mathtt{slope}(\text{队尾}, i)$ 则弹队尾"，直到不再满足或队列长度 $\le 1$。

弹完后剩下的队尾 $t'$ 满足 $\mathtt{slope}(t', \text{倒数第二}) < \mathtt{slope}(t', i)$（或队列长度 1）——加入 $i$ 后凸性条件依然满足。$\blacksquare$

### 队首即当前最优

**命题**：处理 $i$ 时，主循环步骤 1 之后，队首 $j_0$ 是 $\arg\min_j (Y_j - K_i X_j)$（即当前最优候选）。

**证明**：

**$j_0$ 比 $j_1$ 更优**：若 $\mathtt{slope}(j_0, j_1) > K_i$，由"何时 $j_2$ 优于 $j_1$"的推导可知 $j_0$ 比 $j_1$ 更优。步骤 1 持续弹队首直到不能弹——即满足 $\mathtt{slope}(j_0, j_1) > K_i$ 为止。

**$j_0$ 优于所有更后的 $j_t$**：由凸壳的递增斜率性 $\mathtt{slope}(j_0, j_1) < \mathtt{slope}(j_1, j_2) < \cdots$。若 $\mathtt{slope}(j_0, j_1) > K_i$，则后面所有相邻斜率都 $> K_i$——递归地由"$j_t$ 优于 $j_{t+1}$"推得 $j_0$ 优于所有。

**$j_0$ 优于凸壳外的点**：凸壳外的点早已被"夹击"——存在凸壳上某点比它更优，传递得 $j_0$ 也优于它。$\blacksquare$

### 摊还分析

**命题**：主循环总操作数 $O(n)$。

**证明**：每个下标 $i$ 最多入队 1 次、出队 1 次（要么被某轮队首弹出、要么被某轮队尾弹出）——总入出队 $\le 2n$ 次。主循环每轮的"弹队首"与"弹队尾"循环总迭代次数加起来 $\le 2n$ 次。总 $O(n)$。$\blacksquare$

## 应用扩展

### 应用一：仓库建设

> 给定 $n$ 个仓库的位置 $x_i$（单增）、库存 $p_i$、建仓库成本 $c_i$。要在某些位置建仓库，剩下的位置的货物运到最近的（上游或同位置的）建好的仓库——单位距离运费为 1。求总最小代价。

**状态**：$f[i] =$ 前 $i$ 个位置中、第 $i$ 个建仓库时的最小总代价。

朴素转移含"$x_i \cdot (\text{含 } j \text{ 的量})$"——同样可化为 $Y_j - K_i X_j$ 形式做斜率优化。

### 应用二：印刷错误 / Print Article（POJ 3709）

> 把长 $n$ 的非负数列拆成若干段，每段 $[l, r]$ 代价 $(\sum_{i=l}^{r} a_i - C)^2 + M$（$C, M$ 是常数）。求最小总代价。

与玩具装箱结构几乎一致——展开后 $X_j = s_j$、$Y_j = f[j] + s_j^2$、$K_i = 2 (s_i - C)$。

### 应用三：$K_i$ 不单调——李超树 / CDQ 分治

当 $K_i$ 不单调时（如某些题中 $K_i = a_i$ 但 $a_i$ 非单调），单调队列不能直接维护——

- **李超树**：每个区间存当前"最优直线"，新加一条直线 $O(\log n)$ 比较、查询 $O(\log n)$

- **CDQ 分治**：离线情况下把 $j < i$ 的关系递归处理，每层维护凸壳

两者复杂度 $O(n \log n)$ 或 $O(n \log^2 n)$，但实现复杂、调试困难——竞赛中实际优先考虑能否用简单方法。

## 几个常见错误

- **变形时把 $K_i$ 算错**：把 $-2 a_i$ 错写成 $2 a_i$ 会让斜率方向反——建议手推一遍而不是套公式

- **求 $\max$ 时仍维护下凸壳**：求 $\max$ 应维护**上凸壳**——斜率比较方向也要反过来

- **除法判斜率时除零 / 浮点误差**：必须用**乘法**比较，并注意 $X_b - X_a > 0$ 假设是否成立

- **$X_j$ 不单调误用单调队列**：单调队列要求 $X_j$ 单增（保证新加点在 $X$ 轴上严格右移）——不满足时改用平衡树

- **乘法溢出**：$X, Y$ 是 $10^{12}$ 级时乘积爆 `long long`——用 `__int128` 或分式判断

- **边界 $j = 0$ 漏初始化**：$f[0] = 0$ 是空段代价；漏掉的话首轮 $\min$ 取不到合法候选
