#难度/★★★★★

> dp 优化的"通法"——把 $f[i]$ 的转移规约成"在某种条件下查询前缀/区间最值或求和"的问题，用 [[树状数组]] / [[线段树]] $O(\log n)$ 维护。比单调队列/斜率优化更普适但多一个 $\log$。

## 核心思想

回顾前面三种优化的局限——

- [[单调队列优化dp]]：要求 $f[i] = \min_{j \in \text{窗口}} g(j) + h(i)$，且窗口端点单调

- [[斜率优化dp]]：要求转移可化为 $Y_j - K_i X_j$ 的直线截距形式

- [[矩阵快速幂优化dp]]：要求转移是**常系数线性**递推

这三类都有**严格的结构约束**——一旦题目不满足，朴素 $O(n^2)$ 又过不了，怎么办？

**数据结构优化的关键观察**：很多 dp 转移本质是——

$$f[i] = \mathop{\text{opt}}_{j \in \text{满足某条件}} \bigl( f[j] + \text{ 与 } j, i \text{ 有关的项} \bigr)$$

"满足某条件"可以是 $a_j < a_i$、$j < i$ 且 $b_j > b_i$、$j$ 在某个区间内、$j$ 上有某种标记…… 这种"**带约束的 $\arg\min / \arg\max$**"问题恰好是 [[树状数组]] / [[线段树]] 的拿手戏——它们能在 $O(\log n)$ 内完成"前缀最值"、"区间最值"、"二维偏序"等查询。

> 💡 **数据结构优化的判据**：
>
> - 朴素转移有"内层枚举 $j$ 并加约束"的 $O(n)$ 开销 → 必须优化
>
> - 没有单调队列/斜率优化适用的特殊结构 → 用数据结构兜底
>
> - 多 $\log$ 但能稳定 AC > 强行套不适用的优化导致 WA

## 经典例题：LIS 的树状数组实现

> 给一个长 $n$ 的整数数组 $a[1..n]$（已离散化，$a_i \in [1, V]$，$V \le n$），求其**最长严格上升子序列**的长度。

回顾 [[最长上升子序列]] 的朴素 dp——

$$f[i] = \max_{j < i,\, a_j < a_i} f[j] + 1$$

朴素 $O(n^2)$ 内层枚举 $j$。**优化思路**：内层 $\max$ 的本质是"在所有 $a_j < a_i$ 的 $j$ 中找 $f[j]$ 的最大值"——这是一个**前缀最大值查询**问题！

**重新组织视角**：不按下标 $j$ 组织信息，而按 **$a$ 值** 组织——

- 维护一个数组 $b[1..V]$，$b[v] = $ "目前处理过的所有 $a_j = v$ 的位置中 $f[j]$ 的最大值"

- 处理 $a[i]$ 时——

  - **查询**：$f[i] = (\max_{v < a_i} b[v]) + 1$

  - **更新**：$b[a_i] = \max(b[a_i],\, f[i])$

**为什么 BIT 适用**：上述只用到两种操作——单点更新 + 前缀最大值查询。[[树状数组]] 支持这两种操作各 $O(\log V)$，总 $O(n \log V)$。

**为什么这种 dp 比 LIS 二分版"更通用"**：

- 二分版只能处理"求长度"和"取最小末尾"的最值——但若题目要求"**带权 LIS**"（每个数有权 $w_i$、求最大权重和）就**不**能简单二分了

- BIT 版只需把 $f[i] = f[j] + 1$ 改成 $f[i] = f[j] + w_i$ ——**结构通用得多**

**朴素 $O(n^2)$** vs **BIT 优化 $O(n \log V)$** 的对比，恰好示范了"数据结构优化"如何把 dp 普适地加速。

> 💡 **核心抽象**：dp 用下标 $i$ 推进；数据结构按**值域** $v$ 索引——前者管"时间维度"、后者管"空间维度"，两者**正交**地组合在一起。

## 适用场景

- dp 内层枚举有约束（如 $j < i \wedge a_j < a_i$）的最值/求和问题

- 二维偏序、三维偏序计数 / 最值

- 区间 dp 中的子区间最值查询（如某些类似回文 dp 的题）

- 不满足 [[单调队列优化dp]] / [[斜率优化dp]] 特殊结构的 dp

- 离线 dp（题目所有查询已知）配合扫描线 + 数据结构

- 不适用：朴素 dp 本身就够快；约束过复杂（如非线性、非区间型）无法规约成数据结构查询

## 步骤拆解

1. **写朴素 dp**：$f[i] = \mathop{\text{opt}}_{j} (\cdots)$

2. **找内层枚举的约束**：是 $j < i$？$a_j < a_i$？两者同时？

3. **设计数据结构索引**：按值域索引（BIT/线段树）、还是按下标索引、还是按某种排序后的顺序处理

4. **拆"查询" + "更新"**：每个 $i$ 先查询、得 $f[i]$、再更新数据结构

5. **多维偏序**：先对一维排序（消去该维约束）、再对另一维用数据结构

## 代码模板

**模板：LIS 的树状数组实现**

```cpp

class lis_bit {

private:

    int n, V;

    vector<int> a;                                      // 1-indexed

    vector<int> bit_;                                   // bit_[v] 维护前缀最大值

    void update(int pos, int val) {

        for (; pos <= V; pos += pos & -pos) {

            bit_[pos] = max(bit_[pos], val);

        }

    }

    int query(int pos) {                                // 查询 [1, pos] 的最大值

        int res = 0;

        for (; pos > 0; pos -= pos & -pos) {

            res = max(res, bit_[pos]);

        }

        return res;

    }

public:

    lis_bit(int V_in, const vector<int>& a_in) {

        V = V_in;

        a = a_in;

        n = (int)a.size() - 1;

        bit_.assign(V + 1, 0);

    }

    int solve() {

        int ans = 0;

        for (int i = 1; i <= n; i++) {

            int prefix_max = (a[i] >= 2) ? query(a[i] - 1) : 0;

            int f_i = prefix_max + 1;

            update(a[i], f_i);

            ans = max(ans, f_i);

        }

        return ans;

    }

};
```

> 💡 **BIT 维护"前缀最大值"的合法性**：树状数组的经典用法是"前缀和" + "单点修改"——因为可加；"前缀最大值" + "单点更新（只增不减）"也合法——因为 $\max$ 也满足可叠加性。但**前缀最大值 + 任意单点修改**就不合法（删除某个值后整段最大值需要重新统计）。

> ⚠️ **严格 vs 非严格**：上述代码 `query(a[i] - 1)` 实现的是**严格上升**（$a_j < a_i$）。若要"非严格上升"（允许 $a_j = a_i$）改为 `query(a[i])`。

## 复杂度分析

- 时间复杂度：$O(n \log V)$

  - $n$ 个 $i$，每个 $O(\log V)$ 查询 + $O(\log V)$ 更新

- 空间复杂度：$O(V)$（树状数组）

> 💡 **离散化的必要性**：题目给的 $a_i$ 可能很大（如 $10^9$），不能直接用作 BIT 下标——先做 [[离散化]] 把 $a$ 映射到 $[1, n]$ 即可。$V = n$ 后复杂度变 $O(n \log n)$。

## 正确性证明

### dp 转移的正确性

**命题**：用 BIT 维护的 $f[i] = (\max_{v < a_i} b[v]) + 1$ 等于朴素 dp 的 $f[i] = \max_{j < i, a_j < a_i} f[j] + 1$。

**证明**：

**$\le$ 方向**：$b[v]$ 中存的是"过去处理过的 $a_j = v$ 的 $f[j]$ 最大值"，所以 $\max_{v < a_i} b[v] = \max_{j < i, a_j < a_i} f[j]$——左右两边只是组织视角不同（值域 vs 下标），实质相同。

**$\ge$ 方向**：同上对称。$\blacksquare$

### BIT 的正确性

详见 [[树状数组]]——这里仅指出："前缀最大值" + "单点 $\max$ 更新"是合法用法（因 $\max$ 在分块结构下可叠加）。

### 时间复杂度

每个 $i$ 一次查询 + 一次更新，各 $O(\log V)$；总 $O(n \log V)$。$\blacksquare$

## 应用扩展

### 应用一：二维偏序 LIS

> 给 $n$ 个二元组 $(x_i, y_i)$，求最长的 $\{(x_{i_1}, y_{i_1}), \ldots, (x_{i_k}, y_{i_k})\}$ 使下标递增、$x$ 严格递增、**且** $y$ 严格递增。

**思路**：先按 $x$ 排序（同 $x$ 时按 $y$ 降序），转化为"在 $y$ 上求严格上升子序列"——再用 BIT 维护。

**为什么 $x$ 相同时 $y$ 降序**：避免"$x$ 相等的两个 $y$ 都被选"（要求 $x$ 严格递增）。$y$ 降序排序后，先处理较大 $y$、再处理较小 $y$——较小 $y$ 不会被同 $x$ 的较大 $y$ 接到 LIS 中（因为 BIT 上"较小 $y$ 加入时较大 $y$ 还没在 BIT 里"）。

复杂度 $O(n \log n)$。

> 💡 **两个相同 $x$ 的处理是二维偏序题的固定套路**：根据约束是"严格 vs 非严格"决定第二维的排序方向——是消歧而不是修饰。

### 应用二：三维偏序——CDQ 分治 + BIT

> 给 $n$ 个三元组 $(a_i, b_i, c_i)$，对每个 $i$ 求满足 $a_j \le a_i \wedge b_j \le b_i \wedge c_j \le c_i$ 的 $j$ 的个数。

**思路**：把三维拆开——

- 第一维：按 $a$ 排序（消去）

- 第二维：用 CDQ 分治处理左右两半，合并时左半的 $b_j$ 与右半的 $b_i$ 用归并排序

- 第三维：在合并时用 BIT 处理 $c$

总复杂度 $O(n \log^2 n)$。这是数据结构优化 dp 的**进阶组合拳**。

### 应用三：区间最值 dp（线段树）

> 给定 $n$ 个整数 $a[1..n]$，对每个 $i$ 求 $f[i] = \max_{j \in [L_i, R_i]} (f[j] + w_{ij})$，其中 $[L_i, R_i]$ 是某种依赖于 $i$ 的区间。

朴素 $O(n^2)$；用 [[线段树]] 维护"$f[j] + (\text{与 } j \text{ 相关的项})$"的区间最大值，每个 $i$ 查询 $O(\log n)$、更新 $O(\log n)$——总 $O(n \log n)$。

具体的"$w_{ij}$" 怎么处理取决于题目——若 $w_{ij}$ 可分解为 $u(j) + v(i)$，那把 $u(j)$ 维护进数据结构、查询时再加 $v(i)$；否则可能需要更复杂的二维数据结构。

### 应用四：扫描线 + 离线 dp

某些题目所有 $i$ 的查询是离线的——可以按某个维度排序后扫描，用 [[线段树]] 维护"当前已处理状态" 的某些值，每个 $i$ 在扫描到时查询答案。

经典模型：

- "对每个点求半平面内点的某统计量"——扫描线 + 树状数组

- "区间和的最大子段类问题"——线段树维护合并信息

## 与其他 dp 优化的对比

|      | 单调队列      | 斜率优化            | 矩阵快速幂           | 数据结构          |
| ---- | --------- | --------------- | --------------- | ------------- |
| 适用条件 | 滑动窗口 + 单调 | $Y_j - K_i X_j$ | 常系数线性           | **通用最值/求和查询** |
| 复杂度  | $O(n)$    | $O(n)$          | $O(k^3 \log n)$ | $O(n \log n)$ |
| 实现难度 | 低         | 高               | 中               | 中             |
| 通用性  | 低         | 中               | 低               | **高**         |

**经验**：先想能不能套单调队列/斜率优化（$O(n)$）；若结构不满足、退而用数据结构（$O(n \log n)$）——多一个 $\log$ 但稳定 AC。

## 几个常见错误

- **值域过大未离散化**：$a_i$ 到 $10^9$ 时直接开 BIT 会 MLE——务必先离散化

- **BIT 维护"任意修改的最值"**：BIT 只支持"单点更新（不减）+ 前缀查询"的最值——若要支持任意删除/修改最值，需用线段树（节点存区间最值，单点修改 $O(\log n)$ 重算路径）

- **严格 vs 非严格越界**：`query(a[i] - 1)` 求严格小于，`query(a[i])` 求小于等于——一字之差结果不同

- **二维偏序的"消歧排序"忘了**：第一维相同时第二维的排序方向若与约束相反会让相同第一维的元素互相干扰

- **离散化漏掉哨兵**：某些题目离散化要保留"$a_i - 1$" 或 "$a_i + 1$" 等参考值——纯按 $a$ 离散化可能丢失边界信息

- **多 $\log$ 但常数大**：CDQ + 数据结构 $O(n \log^2 n)$ 在 $n = 10^6$ 时是 $4 \times 10^7$，可能 TLE——评估时要算清常数
