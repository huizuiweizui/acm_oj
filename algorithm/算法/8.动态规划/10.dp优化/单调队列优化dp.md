#难度/★★★★

> 当 dp 转移形如 $f[i] = \min_{j \in [i - k,\, i - 1]} g(j) + h(i)$——**在一个固定大小的滑动窗口里取最值**时，用 [[单调队列]] 把内层 $O(k)$ 摊还到 $O(1)$，整体 $O(nk) \to O(n)$。

## 核心思想

许多线性 dp 的转移有这样的形式——

$$f[i] = \mathop{\text{opt}}_{j \in [L(i),\, R(i)]} \Bigl( g(j) + h(i) \Bigr)$$

其中——

- $\text{opt}$ 是 $\min$ 或 $\max$

- $g(j)$ 只依赖 $j$（不含 $i$）

- $h(i)$ 只依赖 $i$（不含 $j$）

- 窗口 $[L(i), R(i)]$ 的左右端点都随 $i$ **单调不减**

朴素转移 $O(n) \times O(k) = O(nk)$（$k$ 是窗口宽度）。但仔细观察——

- 把 $h(i)$ 从 $\text{opt}$ 中提出（因为不含 $j$）：$f[i] = \left( \mathop{\text{opt}}_{j} g(j) \right) + h(i)$

- 问题归结为"**在 $g$ 序列上的滑动窗口最值**"——这是 [[单调队列]] 的经典战场

[[单调队列]] 用一个**单调**的双端队列维护"当前窗口中可能成为最优的 $j$"——每个 $j$ 摊还 $O(1)$ 入队 / 出队。总复杂度 $O(n)$。

> 💡 **能不能套用的判断**：转移方程能否拆成 "(只含 $j$ 的部分) + (只含 $i$ 的部分)"——若能、且窗口端点单调，就能套单调队列优化。若 $g$ 和 $h$ 之间有"$j \cdot i$" 这种**乘积项**，单调队列就失效——需要 [[斜率优化dp]] 或更高级技巧。

## 经典例题：烽火传递

> 长度为 $n$ 的一行有 $n$ 座烽火台，第 $i$ 座点亮的花费为 $a_i$（$a_i > 0$）。要求**任意连续 $m$ 座烽火台中至少有一座被点亮**——即不能存在连续 $m$ 座都不亮。求最小总花费。

**状态怎么想**：约束是"连续 $m$ 座中至少一座亮"——若把视角放在"**最近一座被点亮的位置**"上，就能把所有合法方案系统枚举出来。

定义——

$$f[i] = \text{第 } i \text{ 座**被点亮**、前 } i \text{ 座已满足约束时的最小总花费}$$

为什么强制"第 $i$ 座被点亮"？——这是 dp 状态的"标准形式"。任何合法方案都有"最后一个被点亮的座"，按它分类就能不重不漏地枚举所有合法方案。

**转移怎么推**：第 $i$ 座点亮后，向前找上一座被点亮的位置 $j$——

- 必须 $j \in [i - m, i - 1]$ —— 因为 $i$ 与 $j$ 之间最多有 $m - 1$ 座未点亮（约束"连续 $m$ 座至少一亮"等价于"两座相邻被点亮的间距 $\le m$"）

- 设 $j = 0$ 为虚拟起点（表示"$i$ 之前没有任何被点亮的座"）——则 $j = 0$ 合法当且仅当 $i \le m$（即前 $i - 1 \le m - 1$ 座都未点亮，未违反约束）

$$f[i] = a_i + \min_{j \in [\max(0,\, i - m),\, i - 1]} f[j]$$

**边界**：$f[0] = 0$（虚拟起点不耗花费）。

**答案**：$\min_{i = n - m + 1}^{n} f[i]$——最后 $m$ 座中必须至少一座被点亮，否则结尾 $m$ 座连续不亮违反约束。

**朴素的复杂度**：内层 $\min$ 枚举 $m$ 个 $j$，总 $O(nm)$。$n = 10^6$、$m = 10^5$ 时直接 TLE。

**单调队列优化**：注意到——

- $a_i$ 不依赖 $j$，可提出 $\min$

- 窗口 $[\max(0, i - m), i - 1]$ 的左右端点都随 $i$ 单调右移

完全符合"$f[i] = (\min_j g(j)) + h(i)$ + 单调窗口"的模式——可以套单调队列！

**维护一个单调递增的双端队列 $\mathtt{dq}$**，存的是下标 $j$，满足 $f[\mathtt{dq}[0]] \le f[\mathtt{dq}[1]] \le \cdots$，队首即当前窗口的最小值位置。

> 💡 **单调队列的两条纪律**：
>
> 1. **入队前清理队尾**：新元素 $f[i]$ 若 $\le$ 队尾对应的 $f$ 值，弹出队尾——因为新元素"更年轻 + 更小"，老元素彻底无用
>
> 2. **取队首前清理队首**：若队首已离开窗口（$\mathtt{dq}[0] < i - m$），弹出队首
>
> 两步加起来保证队列从头到尾严格递增、且始终对齐当前窗口。

## 适用场景

- 转移形如 $f[i] = \min_{j \in \text{窗口}} (g(j)) + h(i)$（或 $\max$）

- 窗口端点随 $i$ **单调**移动（左右端都不"回退"）

- 经典模型：长度受限的最值、跳跃 dp、修剪草坪类、[[多重背包]] 的滑窗优化

- 不适用：转移中 $g$ 和 $h$ 之间有 $j \cdot i$ 乘积项（用 [[斜率优化dp]]）；窗口端点非单调（朴素 dp 或用 [[ST表]] 静态查询）

## 步骤拆解

1. **写出朴素转移**：$f[i] = \min_{j} (\text{含 } i \text{ 与 } j \text{ 的表达式})$

2. **判断可优化性**：能否拆成 $g(j) + h(i)$？窗口端点是否单调？

3. **维护单调队列**：双端队列存下标，按 $f[\cdot]$（或某个 $g(j)$）单调

4. **每个 $i$ 处理三步**：清理队首过期 → 取队首作 $\min$ → 入队（清理队尾）

5. **答案**：从 $f$ 中取出题目要求的最终结果

## 代码模板

**模板：烽火传递**

```cpp

class fenghuo_transfer {

private:

    int n, m;

    vector<long long> a;                                // 1-indexed

public:

    fenghuo_transfer(int n_in, int m_in,

                     const vector<long long>& a_in) {

        n = n_in;

        m = m_in;

        a = a_in;

    }

    long long solve() {

        vector<long long> f(n + 1, 0);

        f[0] = 0;                                       // 虚拟起点

        deque<int> dq;

        dq.push_back(0);                                // 队列初始含虚拟起点

        for (int i = 1; i <= n; i++) {

            // 1. 清理队首：j < i - m 的元素已离开窗口
            while (!dq.empty() && dq.front() < i - m) {

                dq.pop_front();

            }

            // 2. 取队首（窗口内 f 最小的位置）
            f[i] = a[i] + f[dq.front()];

            // 3. 入队前清理队尾（维护 f 单调递增）
            while (!dq.empty() && f[dq.back()] >= f[i]) {

                dq.pop_back();

            }

            dq.push_back(i);

        }

        long long ans = LLONG_MAX;

        for (int i = n - m + 1; i <= n; i++) {

            ans = min(ans, f[i]);

        }

        return ans;

    }

};
```

> ⚠️ **`f[dq.back()] >= f[i]` 还是 `>`?**：严格 `>` 也能保证正确性，但会让队列里保留多个相等元素——浪费空间。用 `>=` 让队列更紧凑。

> 💡 **`f[0] = 0` 的处理**：虚拟起点要先入队，否则 $i = 1$ 时窗口为空、`dq.front()` 越界。这是单调队列优化 dp 常见的"哨兵"技巧。

## 复杂度分析

- 时间复杂度：$O(n)$

  - 每个下标最多入队一次、出队一次——总操作 $O(n)$

  - 主循环外层 $O(n)$ + 内层均摊 $O(1)$

- 空间复杂度：$O(n)$（$f$ 数组 + 双端队列）

> 💡 **相对于朴素 $O(nm)$ 的提升**：$n = m = 10^5$ 时朴素 $10^{10}$ 必 TLE，优化后 $10^5$ 瞬间。这是单调队列在 dp 上最具代表性的复杂度收益。

## 正确性证明

### 单调队列维持的不变量

**命题**：每次循环结束后，$\mathtt{dq}$ 满足——

1. 下标递增：$\mathtt{dq}[0] < \mathtt{dq}[1] < \cdots < \mathtt{dq}[\text{back}]$

2. $f$ 值单调不降：$f[\mathtt{dq}[0]] \le f[\mathtt{dq}[1]] \le \cdots \le f[\mathtt{dq}[\text{back}]]$

3. 所有 $\mathtt{dq}$ 中的下标都在当前合法窗口 $[i - m + 1, i]$ 内（处理完 $i$ 后）

**证明（归纳）**：

**基础**：初始 $\mathtt{dq} = [0]$，三条平凡成立。

**归纳步**：假设第 $i - 1$ 轮结束后三条成立。第 $i$ 轮——

- 步骤 1（清理队首）：移除 $\mathtt{dq}[0] < i - m$ 的位置，保留的都满足 $\mathtt{dq}[\cdot] \ge i - m$。条件 3 在窗口前移后被恢复

- 步骤 2（取队首）：不改变 $\mathtt{dq}$ 结构

- 步骤 3（入队前清理队尾）：移除队尾 $f$ 值 $\ge f[i]$ 的元素，剩下的队尾 $f[\mathtt{dq}[\text{back}]] < f[i]$

- 步骤 3（入队 $i$）：新队尾 $i$ 满足 $i > \text{旧队尾}$（条件 1）、$f[i] > f[\text{旧队尾}]$（条件 2）、$i \in [i - m + 1, i]$（条件 3）

三条不变量都保持。$\blacksquare$

### 取队首即为窗口最小值

**命题**：在步骤 2 处，$f[\mathtt{dq}[0]] = \min_{j \in [\max(0, i - m),\, i - 1]} f[j]$。

**证明**：

**$\mathtt{dq}[0]$ 在窗口内**：步骤 1 保证 $\mathtt{dq}[0] \ge i - m$，且 $\mathtt{dq}[0] \le i - 1$（$i$ 还未入队）。

**$\mathtt{dq}[0]$ 是当前窗口中 $f$ 最小**：考察任意在窗口内的下标 $j$——

- 若 $j \in \mathtt{dq}$：由不变量 2，$f[\mathtt{dq}[0]] \le f[j]$

- 若 $j \notin \mathtt{dq}$：说明 $j$ 在过去某轮入队时被弹出队尾，或入队时被新元素挤掉。无论何种情况，都因为"有某个 $j' > j$ 且 $f[j'] \le f[j]$"——传递地，存在 $\mathtt{dq}[0] > j$ 满足 $f[\mathtt{dq}[0]] \le f[j]$。

所以 $f[\mathtt{dq}[0]]$ 不大于窗口内任何 $f[j]$，且 $\mathtt{dq}[0]$ 本身在窗口内——即为最小值。$\blacksquare$

### 时间复杂度的摊还分析

**命题**：主循环总操作数 $O(n)$。

**证明**：每个下标 $i$ 在整个过程中——

- **入队** 1 次（步骤 3 末尾）

- **出队** 至多 1 次（步骤 1 的队首清理 + 步骤 3 的队尾清理总共发生一次）

所以入队 / 出队总次数 $\le 2n$，主循环每轮的"清理队尾"循环的总迭代次数加起来 $\le n$（摊还）。总 $O(n)$。$\blacksquare$

## 应用扩展

### 应用一：修剪草坪

> $n$ 头牛排成一列，第 $i$ 头的"效率"为 $a_i$（$a_i > 0$）。选一些牛使**任意连续 $k + 1$ 头中至少有一头不选**——即不能存在连续 $k + 1$ 头都被选。求所选牛效率的最大总和。

**状态怎么想**：和烽火传递对偶——枚举"最后一头**不选**的牛"。定义——

$$f[i] = \text{前 } i \text{ 头中、第 } i \text{ 头不选、约束已满足的最大总效率}$$

**转移**：枚举上一个不选的位置 $j$——$j \in [i - k - 1, i - 1]$（保证 $j$ 到 $i$ 间的连续选数不超过 $k$）。中间 $j + 1$ 到 $i - 1$ 全选——总贡献为 $S_{i-1} - S_j$（$S$ 是前缀和）。

$$f[i] = \max_{j \in [\max(0, i - k - 1),\, i - 1]} \bigl( f[j] + S_{i-1} - S_j \bigr) = S_{i-1} + \max_j \bigl( f[j] - S_j \bigr)$$

把 $S_{i-1}$ 提出（不依赖 $j$）——典型的"$g(j) + h(i)$"模式。维护单调队列存的就是按 $f[j] - S_j$ 单调递减的下标。

### 应用二：多重背包的单调队列优化

[[多重背包]] 的 $O(nV)$ 优化版正是单调队列优化 dp 的高级应用——按 $j \bmod w_i$ 划分同余类、在每条同余类上做滑动窗口最值。详见 [[多重背包]]。

### 应用三：跳跃 dp / 滑窗最大子段和

> 给一个长 $n$ 的数组 $a$，求长度**不超过 $k$** 的子段的最大和。

朴素 $O(nk)$；用前缀和 $S$，子段 $[l, r]$ 的和 $= S_r - S_{l-1}$——固定 $r$ 后最大化 $-S_{l-1}$（即最小化 $S_{l-1}$），$l - 1 \in [\max(0, r - k), r - 1]$。

单调队列维护 $S$ 的滑动窗口最小值，$O(n)$ 完成。

### 何时不能直接套用？

- **窗口端点不单调**：如 $L(i) = i - m_i$，$m_i$ 不单调——单调队列失效，需用 [[ST表]] 或线段树（每次 $O(\log n)$ 查询）

- **转移含 $i \cdot j$ 项**：需要 [[斜率优化dp]] 把"维护一条单调队列"升级为"维护一个凸壳"

- **多维窗口**：二维滑窗最值更复杂，需用单调队列嵌套或其他算法

## 几个常见错误

- **队首过期检查的不等号写反**：要弹出的是 $\mathtt{dq}[0] < L(i)$ 的，不是 $\le$。临界 $\mathtt{dq}[0] = L(i)$ 时仍在窗口

- **入队前的队尾清理弄反方向**：求 $\min$ 维护单调**递增**队列（队首最小），队尾要弹"$\ge$ 新值"的；求 $\max$ 维护**递减**，队尾弹"$\le$ 新值"的。两者别混

- **忘记入虚拟起点**：$f[0] = 0$ 后必须 `dq.push_back(0)`，否则首轮取队首会越界

- **答案不在 $f[n]$**：烽火传递的答案是 $\min_{i \in [n - m + 1, n]} f[i]$，不是 $f[n]$。要根据状态定义判断

- **不可优化情形误用单调队列**：转移含 $j$ 与 $i$ 的乘积项时必须改用 [[斜率优化dp]]，强套单调队列会错
