#难度/★★★

> 第 $i$ 件物品有 $s_i$ 件——介于 [[0-1背包]] 和 [[完全背包]] 之间的"有限重复"模型。朴素做法 $O(nVs)$，二进制拆分降到 $O(nV \log s)$，单调队列优化逼近 $O(nV)$。

## 前置知识

- [[0-1背包]]

- [[单调队列]]

## 核心思想

> 物品 $n$ 类，第 $i$ 类体积 $w_i$、价值 $v_i$、**最多可选 $s_i$ 件**，背包容量 $V$，求最大价值。

朴素转移类似完全背包但限制 $k$ 的范围：

$$f[i][j] = \max_{0 \le k \le s_i,\, k w_i \le j} \left( f[i-1][j - k w_i] + k v_i \right)$$

复杂度 $O(nV \sum s_i / n) = O(nV \bar s)$（$\bar s$ 是平均件数）——若 $\sum s_i$ 大，会 TLE。

多重背包的精妙之处在于有**三种**层层递进的优化——

### 法一：朴素枚举

直接套上面的转移方程，对每件物品枚举选 $k$ 件。复杂度 $O(V \sum s_i)$。

### 法二：二进制拆分

**核心思想**：把 $s_i$ 件相同物品拆成 $\lceil \log_2(s_i + 1) \rceil$ "组"，每组当成一件 [[0-1背包]] 的物品——但每组的体积和价值是若干件原物品的整数倍，让这些组**任意选与不选**就能凑出 $0 \sim s_i$ 的所有数量。

具体地，把 $s_i$ 拆成 $1, 2, 4, \ldots, 2^{k}, r$，其中 $r = s_i - (2^{k+1} - 1) \ge 0$ 且 $r < 2^{k+1}$。$k$ 取最大整数使 $2^{k+1} - 1 \le s_i$。

例如 $s_i = 13$ 拆成 $1, 2, 4, 6$（因为 $1 + 2 + 4 = 7 \le 13$，剩下 $13 - 7 = 6$）。

把 $\log s_i$ 个"批次"看作独立物品做 0-1 背包，复杂度降到 $O(nV \log s)$。

### 法三：单调队列优化

**核心思想**：朴素转移 $f[i][j] = \max_{0 \le k \le s_i} (f[i-1][j - k w_i] + k v_i)$ 的 $\max$ 是在一个**步长为 $w_i$ 的滑动窗口**上取的——按 $j \bmod w_i$ 把同余类分组，每组内是经典的滑动窗口最值，可以用 [[单调队列]] $O(1)$ 摊还。

复杂度优化到 $O(nV)$——理论最优，但常数较大、写起来繁琐，比赛中除非 $\log$ 都过不去否则一般用二进制拆分版。

## 适用场景

- 物品有限数量、可选 $0 \sim s_i$ 件的最优化问题

- 面值有限张数的硬币凑数（问能凑出哪些金额、最少张数等）

- 不适用：每件无限制（用 [[完全背包]]）；每件 1 次（用 [[0-1背包]]）；同组互斥（用 [[分组背包]]）

## 步骤拆解

**朴素法**：三重循环 $i, j, k$ 直接套转移。

**二进制拆分法**：

1. 对每类物品，把 $s_i$ 拆成 $1, 2, 4, \ldots, 2^t, r$（$r$ 为剩余）

2. 每个"批次"看作一件 0-1 背包物品：体积 $2^j w_i$、价值 $2^j v_i$

3. 对所有批次跑 [[0-1背包]] 模板

**单调队列法**：

1. 外层枚举物品 $i$

2. 中层按 $j \bmod w_i$ 划分同余类，对每个剩余 $r \in [0, w_i)$ 处理

3. 内层在同余类上滑动单调队列，求 $\max(f[i-1][r + p w_i] - p v_i)$ 在 $p \in [\max(0, q - s_i), q]$ 的窗口最值

4. 当前 $f[i][r + q w_i] = $ (窗口最值) $+ q v_i$

## 代码模板

**模板一：二进制拆分**

```cpp

class knapsack_multi_binary {

private:

    int n;

    long long V;

    vector<long long> w, v;

    vector<long long> s;                            // 每件件数

    vector<long long> f;

public:

    knapsack_multi_binary(int n_in, long long V_in,

                          const vector<long long>& w_in,

                          const vector<long long>& v_in,

                          const vector<long long>& s_in) {

        n = n_in;

        V = V_in;

        w = w_in;

        v = v_in;

        s = s_in;

        f.assign(V + 1, 0);

    }

    long long solve() {

        for (int i = 1; i <= n; i++) {

            long long cnt = s[i];

            // 二进制拆分：1, 2, 4, ..., 2^t, r

            for (long long k = 1; k <= cnt; k <<= 1) {

                long long batch_w = k * w[i];

                long long batch_v = k * v[i];

                for (long long j = V; j >= batch_w; j--) {  // 0-1 背包，倒序

                    f[j] = max(f[j], f[j - batch_w] + batch_v);

                }

                cnt -= k;

            }

            if (cnt > 0) {                                  // 剩余部分作为最后一组

                long long batch_w = cnt * w[i];

                long long batch_v = cnt * v[i];

                for (long long j = V; j >= batch_w; j--) {

                    f[j] = max(f[j], f[j - batch_w] + batch_v);

                }

            }

        }

        return f[V];

    }

};

```

> 💡 **拆分策略**：循环条件 `k <= cnt` 配合 `cnt -= k`，最后剩下的 `cnt` 就是不足下一个 $2^j$ 的尾巴。例如 $s_i = 13$：先取 $k = 1$ 剩 12、$k = 2$ 剩 10、$k = 4$ 剩 6——此时 $k = 8 > 6$ 退出循环，把剩下的 6 作为最后一组。

**模板二：单调队列优化**

```cpp

class knapsack_multi_deque {

private:

    int n;

    long long V;

    vector<long long> w, v, s;

    vector<long long> f, g;                         // f 当前行，g 上一行

public:

    knapsack_multi_deque(int n_in, long long V_in,

                         const vector<long long>& w_in,

                         const vector<long long>& v_in,

                         const vector<long long>& s_in) {

        n = n_in;

        V = V_in;

        w = w_in;

        v = v_in;

        s = s_in;

        f.assign(V + 1, 0);

        g.assign(V + 1, 0);

    }

    long long solve() {

        for (int i = 1; i <= n; i++) {

            g = f;                                          // g 保存上一行

            for (long long r = 0; r < w[i] && r <= V; r++) {    // 枚举余数

                deque<long long> dq;                        // 存下标 p

                for (long long q = 0; r + q * w[i] <= V; q++) {

                    long long j = r + q * w[i];

                    // 维护窗口大小不超过 s[i] + 1

                    while (!dq.empty() && dq.front() < q - s[i]) {

                        dq.pop_front();

                    }

                    // 单调性：g[r + p*w] - p*v 关于 p 的单调递减队列

                    long long val_q = g[j] - q * v[i];

                    while (!dq.empty() &&

                           g[r + dq.back() * w[i]] - dq.back() * v[i] <= val_q) {

                        dq.pop_back();

                    }

                    dq.push_back(q);

                    long long p = dq.front();

                    f[j] = g[r + p * w[i]] + (q - p) * v[i];

                }

            }

        }

        return f[V];

    }

};
```

> 💡 **为什么队列里存 $p$ 而不是值**：单调队列的标准技巧——存下标，需要时再用下标取值。这样判"窗口范围"和"取实际值"都方便。

> ⚠️ **必须保留上一行 `g`**：单调队列优化转移读的是 $f[i-1][\cdot]$，所以**不能**直接在 $f$ 上滚动覆盖；必须额外开 `g = f` 备份。

## 复杂度分析

- 时间复杂度：

	- 朴素：$O(V \sum s_i)$
	
	- 二进制拆分：$O(nV \log s)$
	
	- 单调队列优化：$O(nV)$ 


- 空间复杂度：$O(V)$ 

## 正确性证明

### 二进制拆分的覆盖完备性

**命题**：把 $s$ 拆成 $1, 2, 4, \ldots, 2^t, r$（$2^{t+1} - 1 \le s < 2^{t+2} - 1$，$r = s - (2^{t+1} - 1)$），则**任选若干批次**能凑出的件数恰好是 $\{0, 1, 2, \ldots, s\}$。

**证明**：

**先证 $0 \sim 2^{t+1} - 1$ 的所有整数可达**：用归纳法。每个 $0 \sim 2^{t+1} - 1$ 之间的整数都有唯一二进制表示 $\sum_{j=0}^{t} b_j 2^j$（$b_j \in \{0, 1\}$）——选第 $j$ 批次（值为 $2^j$）当且仅当 $b_j = 1$，恰好凑出。

**再证 $2^{t+1} \sim s$ 的所有整数可达**：设目标值 $x \in [2^{t+1}, s]$。一定选**最后一组 $r$**（共凑得 $r$）；还需用前 $t+1$ 组凑出 $x - r \in [2^{t+1} - r, s - r] = [2^{t+1} - r, 2^{t+1} - 1]$。因 $r < 2^{t+1}$，区间 $[2^{t+1} - r, 2^{t+1} - 1]$ 是 $[0, 2^{t+1} - 1]$ 的子集，由前一段已证可达。

**反向：不会超过 $s$**：所有批次之和恰为 $1 + 2 + \cdots + 2^t + r = (2^{t+1} - 1) + r = s$。$\blacksquare$

### 单调队列优化的转移化简

**命题**：朴素转移 $f[i][j] = \max_{0 \le k \le s_i,\, k w_i \le j} (f[i-1][j - k w_i] + k v_i)$ 可以按 $j \bmod w_i$ 同余类分组，组内化为滑动窗口最值。

**证明**：把 $j$ 写成 $j = r + q w_i$，其中 $r = j \bmod w_i \in [0, w_i)$、$q = \lfloor j / w_i \rfloor$。

枚举的 $j - k w_i = r + (q - k) w_i$——令 $p = q - k$，则 $p \in [\max(0, q - s_i), q]$ 且 $r + p w_i \ge 0$。代入——

$$f[i][j] = \max_{p \in [\max(0, q - s_i),\, q]} \left( f[i-1][r + p w_i] + (q - p) v_i \right)$$

把不依赖 $p$ 的 $q v_i$ 提出 $\max$：

$$f[i][j] = q v_i + \max_{p \in [\max(0, q - s_i),\, q]} \left( f[i-1][r + p w_i] - p v_i \right)$$

令 $h(p) = f[i-1][r + p w_i] - p v_i$——这是关于 $p$ 的一个序列，固定 $i$ 和 $r$ 时与 $j$ 无关。$f[i][j]$ 的计算变成"在 $h$ 上长度不超过 $s_i + 1$ 的滑动窗口的最大值"——经典 [[单调队列]] 题型，每个 $p$ 入队/出队 $O(1)$ 次，总复杂度 $O(V)$ 处理一行物品。$\blacksquare$

### 复杂度统计

二进制拆分：每类物品拆出 $O(\log s_i)$ 个 0-1 背包物品，每个跑 $O(V)$，总 $O(V \sum_i \log s_i) = O(nV \log s_{\max})$。

单调队列：每类物品对所有 $r \in [0, w_i)$ 跑滑动窗口，总状态数 $\sum_r \lceil V/w_i \rceil = O(V)$，每个 $O(1)$ 摊还。总 $O(nV)$。

## 几个常见错误

- **二进制拆分忘记最后剩余项**：循环退出后 `cnt` 可能 > 0，必须额外作为一组处理

- **拆分边界写错**：循环条件应是 `k <= cnt`（不是 `k <= s[i]`），并在循环体内 `cnt -= k`——否则会让最后一组超出实际剩余

- **单调队列优化时 $f$ 自身覆盖**：单调队列读的是 $f[i-1]$，所以**不能**直接滚动；必须保留上一行

- **窗口范围越界**：窗口大小是 $s_i + 1$（包含 $p = q$ 自身），不是 $s_i$

- **价值为 0 的物品**：拆分后批次价值为 0，会被跳过；单调队列会照常处理（值不变）

## 应用扩展

### 多重背包 + "可行性"

判断"能否恰好凑出体积 $V$"——把 $\max$ 换成 $\lor$（布尔或），$f[j]$ 表示可达性。可用 `bitset` 进一步加速到 $O(nVs / w)$（其中 $w$ 是机器字长 64）。

### 多重背包变形：金额无上限但每张面值有限张

经典如**硬币凑数问题**——每张面值限张数，问能凑出哪些金额。把 $f[j]$ 定义改成"能否凑出 $j$"，转移用单调队列优化布尔最值（实际就是是否存在 $p$ 使 $f[i-1][r + p w_i] = $ true）。
