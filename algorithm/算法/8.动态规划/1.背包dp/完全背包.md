#难度/★★

> 每件物品**可以选无限次**——把 [[0-1背包]] 的"选或不选"变成"选 0 件、1 件、2 件……"，但聪明的转移让复杂度依旧是 $O(nV)$。

## 前置知识

- [[0-1背包]]

## 核心思想

> 物品 $n$ 件，第 $i$ 件体积 $w_i$、价值 $v_i$，背包容量 $V$，**每件物品可选任意多次**（包括 0 次），求最大价值。

直觉上的转移会写成——

$$f[i][j] = \max_{k \ge 0,\, k w_i \le j} \left( f[i-1][j - k w_i] + k v_i \right)$$

枚举第 $i$ 件物品选 $k$ 件，复杂度 $O(nV \cdot V/w) = O(nV^2/w)$，太慢。

**关键观察**：上式的 $k = 0$ 项是 $f[i-1][j]$；$k \ge 1$ 项是 $f[i-1][j - k w_i] + k v_i$。把 $k \ge 1$ 项中的"少一件"提取出来：令 $k' = k - 1$，则——

$$\max_{k \ge 1} (\cdots) = \max_{k' \ge 0} \left( f[i-1][(j - w_i) - k' w_i] + k' v_i \right) + v_i = f[i][j - w_i] + v_i$$

注意右边变成了 $f[i][j - w_i]$（**同一行**！）——因为 $f[i][j - w_i]$ 的定义已经允许第 $i$ 件物品选任意次。所以——

**状态定义**：$f[i][j] = $ 考虑前 $i$ 类物品、容量不超过 $j$ 时的最大价值。

**转移方程**：

$$f[i][j] = \max \left( \underbrace{f[i-1][j]}_{\text{第 } i \text{ 件一件不选}}, \underbrace{f[i][j - w_i] + v_i}_{\text{至少选一件第 } i \text{ 件}} \right)$$

**初始化**：$f[0][j] = 0$。

**答案**：$f[n][V]$。

> 💡 **唯一的不同**：转移方程右侧第二项是 $f[i][j - w_i]$（**当前行**）而不是 $f[i-1][j - w_i]$（**上一行**）。仅一字之差，含义截然不同——前者允许"再选一件第 $i$ 类"，后者只能"换下一类物品"。

## 适用场景

- 物品可重复选取的最优化问题（最大价值、最小代价等）

- 完全方案数：硬币凑数、整除分解等"每种物品无限取"的计数问题

- 有界资源下的"重复选购"决策（虚拟货币兑换、技能点分配等）

- 不适用：每件物品有数量限制（用 [[多重背包]]）；每种物品至多 1 次（用 [[0-1背包]]）

## 步骤拆解

1. 状态与维度同 [[0-1背包]]：$f[i][j]$

2. 转移方程的两个分支：不选第 $i$ 类（继承 $f[i-1][j]$）/ 至少选一件（依赖 $f[i][j-w_i]$）

3. 二维版可任意顺序遍历内层 $j$，但一维版必须**正序**（与 [[0-1背包]] 的倒序恰恰相反）

4. 答案 $f[n][V]$

## 代码模板

**模板一：二维 dp**

```cpp

class knapsack_complete_2d {

private:

    int n;

    long long V;

    vector<long long> w, v;

    vector<vector<long long>> f;

public:

    knapsack_complete_2d(int n_in, long long V_in,

                         const vector<long long>& w_in,

                         const vector<long long>& v_in) {

        n = n_in;

        V = V_in;

        w = w_in;

        v = v_in;

        f.assign(n + 1, vector<long long>(V + 1, 0));

    }

    long long solve() {

        for (int i = 1; i <= n; i++) {

            for (long long j = 0; j <= V; j++) {

                f[i][j] = f[i - 1][j];                              // 不选第 i 类

                if (j >= w[i]) {

                    f[i][j] = max(f[i][j], f[i][j - w[i]] + v[i]);  // 多选一件第 i 类

                }

            }

        }

        return f[n][V];

    }

};
```

**模板二：滚动数组（一维）**

```cpp

class knapsack_complete_1d {

private:

    int n;

    long long V;

    vector<long long> w, v;

    vector<long long> f;

public:

    knapsack_complete_1d(int n_in, long long V_in,

                         const vector<long long>& w_in,

                         const vector<long long>& v_in) {

        n = n_in;

        V = V_in;

        w = w_in;

        v = v_in;

        f.assign(V + 1, 0);

    }

    long long solve() {

        for (int i = 1; i <= n; i++) {

            for (long long j = w[i]; j <= V; j++) {                 // ⚠️ 必须正序

                f[j] = max(f[j], f[j - w[i]] + v[i]);

            }

        }

        return f[V];

    }

};
```

> ⚠️ **完全背包正序，0-1 背包倒序**——只差一个枚举方向，但含义完全相反。务必记牢。

> 💡 **如何记忆**：正序枚举意味着"读取的 $f[j-w_i]$ 是本轮已经更新的值"——也就是允许第 $i$ 件物品被反复选中，正是完全背包要的语义。倒序则"读旧值"，每件只用一次。

## 复杂度分析

- 时间复杂度：$O(nV)$

- 空间复杂度：

	- 二维 $O(nV)$
	
	- 一维 $O(V)$

## 正确性证明

### 转移方程的等价化简

**命题**：朴素转移 $f[i][j] = \max_{k \ge 0} (f[i-1][j - k w_i] + k v_i)$ 与简化转移 $f[i][j] = \max(f[i-1][j], f[i][j - w_i] + v_i)$ **等价**。

**证明（朴素 $\Rightarrow$ 简化）**：

朴素式按 $k$ 是否为 0 分情形——

- $k = 0$：贡献 $f[i-1][j]$

- $k \ge 1$：贡献 $\max_{k \ge 1} (f[i-1][j - k w_i] + k v_i)$

对后者做变量代换 $k' = k - 1$（$k' \ge 0$）：

$$\max_{k \ge 1} (f[i-1][j - k w_i] + k v_i) = \max_{k' \ge 0} (f[i-1][(j - w_i) - k' w_i] + (k' + 1) v_i)$$

把 $v_i$ 提出 $\max$：

$$= v_i + \max_{k' \ge 0} (f[i-1][(j - w_i) - k' w_i] + k' v_i) = v_i + f[i][j - w_i]$$

最后一步用了 $f[i][j']$ 的朴素定义本身。所以——

$$f[i][j] = \max(f[i-1][j],\, f[i][j - w_i] + v_i)$$

$\blacksquare$

### 一维滚动正序的必要性

**命题**：一维 $f[j]$ 正序枚举 $j$，更新 $f[j]$ 时所读取的 $f[j - w_i]$ 是**本轮已更新过**的值，恰好对应转移方程中的 $f[i][j - w_i]$。

**证明**：第 $i$ 轮内层正序枚举 $j$ 从 $w_i$ 到 $V$。当处理 $j$ 时——

- $f[j - w_i]$（因 $j - w_i < j$）**已经在本轮被处理过**

- 由归纳假设，$f[j - w_i]$ 当前的值等于 $f[i][j - w_i]$

- 因此 $f[j] \leftarrow \max(f[j],\, f[j - w_i] + v_i) = \max(f[i-1][j],\, f[i][j - w_i] + v_i)$，正是 $f[i][j]$

更严格地，**循环不变量**：第 $i$ 轮枚举 $j$ 之前——

- 所有 $j' < j$：$f[j'] = f_i[j']$（已更新为本轮新值）

- 所有 $j' \ge j$：$f[j'] = f_{i-1}[j']$（仍为上一轮旧值）

更新 $f[j]$ 时，$f[j - w_i]$ 满足前者，$f[j]$ 自身满足后者——两个值都是转移方程要的。$\blacksquare$

## 几个常见错误

- **写错枚举方向**：完全背包正序、0-1 背包倒序——把方向写反就会得到完全错误的语义但代码不报错，是**最隐蔽的 bug**

- **混用 $f[i-1]$ 和 $f[i]$**：二维版若误写成 $f[i-1][j-w_i] + v_i$，就退化成 0-1 背包

- **方案数版本忘记初始化 $f[0] = 1$**：求"凑出 $j$ 的方法数"时漏掉空方案

- **物品价值为 0**：完全背包中若某件 $v_i \le 0$，"无限选"会让 $\max$ 取它没意义——但若 $v_i = 0$ 且 $w_i = 0$，会陷入死循环（题目通常保证 $w_i \ge 1$）

## 应用扩展

### 求凑数方案数（硬币问题）

经典题型："用面值 $c_1, c_2, \ldots, c_n$ 的硬币凑出 $V$ 元，问有多少种方案？"——

$$f[i][j] = f[i-1][j] + f[i][j - c_i]$$

把 $\max$ 换成加法即可。一维滚动：`f[j] += f[j - c[i]]`，正序。初始化 $f[0] = 1$。

### 求最少硬币数

$$f[i][j] = \min(f[i-1][j],\, f[i][j - c_i] + 1)$$

把 $\max$ 换成 $\min$，价值贡献 $v_i$ 换成 1（每用一枚记 1）。初始化 $f[\cdot] = +\infty$（不可达），$f[0] = 0$。

### 完全背包 + 限制总件数

加一维"已用件数 $k$"：$f[i][j][k]$。转移——

$$f[i][j][k] = \max(f[i-1][j][k],\, f[i][j-w_i][k-1] + v_i)$$

复杂度 $O(nVK)$。
