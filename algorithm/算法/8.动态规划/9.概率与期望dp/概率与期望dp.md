#难度/★★★★

> 用 dp 求概率或期望——转移方程的形式与最优化 dp 类似，但**取期望代替取最大**，且常常需要**逆向推导**（从终态推回起点）。

- [[线性dp]]

## 核心思想

期望 dp 与计数 dp、最优化 dp 的对比——

|       | 最优化 dp          | [[计数dp]] | 期望 dp                  |
| ----- | --------------- | -------- | ---------------------- |
| 状态值含义 | 最优值             | 方案数      | 期望值（实数）                |
| 转移合并  | $\max$ / $\min$ | $+$      | **按概率加权求和**            |
| 推进方向  | 正向（前 $\to$ 后）为主 | 正向为主     | **常常是逆向**（终态 $\to$ 起点） |

**两个核心定理（期望 dp 的基石）**——

> 💡 **期望的线性性**：对任意（甚至不独立的）随机变量 $X, Y$，
> $$E[X + Y] = E[X] + E[Y]$$
> 推论：$E\left[\sum_i a_i X_i\right] = \sum_i a_i E[X_i]$。

> 💡 **全期望公式**：若随机事件 $u$ 有若干互斥的"下一步" $v_1, v_2, \ldots$，各发生概率 $p_1, p_2, \ldots$，则
> $$E[X \mid u] = \sum_i p_i \cdot E[X \mid v_i]$$
> 这是期望 dp 转移方程的形式来源。

**为什么期望 dp 常用逆向推导**：

若定义 $f[u] =$ "从状态 $u$ 出发到终态的期望某值"，则 $f[u]$ 由 $f$ 在**$u$ 的后继状态**上的值加权得到——而 $u$ 的后继是题目直接给定的（如 DAG 的出边、随机过程的转移概率），**概率分布已知**。

若定义 $f[u] =$ "从起点到达状态 $u$ 时的期望某值"，则 $f[u]$ 由 $f$ 在 $u$ 的**前驱状态**上的值加权——但需要知道"恰好走到 $u$ 来"的概率，这要先求出**到达每个状态的概率分布** $P(u)$，更复杂。

所以**期望 dp 的标准写法是逆向**：$f[\text{终态}] = 0$ 出发、反推到 $f[\text{起点}]$。

## 经典例题：绿豆蛙的归宿

> 给定一个**有向无环图（DAG）**，起点 $1$、终点 $n$。每条边带边权 $w$。从一个节点出发时，**等概率**选择一条出边走（若该节点出度为 $k$，每条出边的概率为 $1/k$）。终点 $n$ 出度为 0、是吸收态。求从 $1$ 到 $n$ 路径总边权的**数学期望**。

**状态怎么想**：题目本质是个随机游走过程——每一步的概率分布只依赖当前所在节点。这种"未来只依赖当前状态"的性质就是**马尔可夫性质**——非常适合 dp。

按照逆向 dp 的思路，定义——

$$f[u] = \text{从节点 } u \text{ 出发到达终点 } n \text{ 的期望路径长度}$$

无后效性：$f[u]$ 只依赖 $u$ 的后继 $v$ 的 $f[v]$——题目限定 DAG 保证后继不会"反过来依赖" $u$。

**转移怎么推**：从 $u$ 出发，等概率选一条出边 $(u, v, w)$。由**全期望公式**——

$$f[u] = \sum_{(u, v, w) \in E} \frac{1}{\deg^+(u)} \cdot (w + f[v])$$

化简（把常数 $1 / \deg^+(u)$ 提出）：

$$f[u] = \frac{1}{\deg^+(u)} \sum_{(u, v, w) \in E} (f[v] + w)$$

**直观解读**：在 $u$ 选边，每条边贡献"该边权 + 走到下一个点的期望" 之均值。

**边界**：$f[n] = 0$（已到终点，剩余期望路径长度为 0）。

**答案**：$f[1]$。

**遍历顺序**：DAG 上的**逆拓扑序**——先算"靠近终点"的节点，再推到起点。或者用 [[记忆化搜索]] 让 DFS 自然实现这个顺序。

> 💡 **DAG 上的期望 dp 是天然有定义的**：因为没有环，从任意 $u$ 出发到 $n$ 都能在有限步内到达（题目通常保证可达），所以 $f[u]$ 是一个有限实数。一旦图有环，"期望步数"可能涉及解线性方程组——不能简单 dp。

## 适用场景

- 随机过程的期望步数、期望长度、期望得分

- DAG / 树上的随机游走

- 概率约束的最优化问题（"期望最大化"）

- 与**期望线性性**结合的复杂期望分解（分别求每个事件的期望、再求和）

- 不适用：随机过程有环（要解线性方程组、不再是 dp）；状态空间不可数（要积分而非求和）

## 步骤拆解

1. **判断是不是马尔可夫性质**：未来是否只依赖当前状态？是→可用 dp

2. **确定推进方向**：通常**逆向**（设 $f[u]$ 为"从 $u$ 出发到终态的期望"）

3. **列出 $u$ 的所有后继 $v$ 及对应概率 $p_{u \to v}$**

4. **写转移**：$f[u] = \sum_v p_{u \to v} (f[v] + \text{cost}_{u \to v})$

5. **边界**：$f[\text{终态}] = 0$（已到终点，无剩余期望）

6. **遍历顺序**：DAG 用逆拓扑序 / 记忆化搜索；树用 DFS 后序

## 代码模板

**模板：绿豆蛙的归宿（记忆化搜索 + 浮点数）**

```cpp

class green_frog_double {

private:

    int n;

    vector<vector<pair<int, double>>> g_;     // g_[u] = {(v, w)}，0/1-indexed 统一

    vector<double> f;

    vector<bool> visited;

    void dfs(int u) {

        if (visited[u]) return;

        visited[u] = true;

        if (u == n) {

            f[u] = 0;

            return;

        }

        int k = (int)g_[u].size();

        if (k == 0) {

            f[u] = 0;                         // 死路（题目通常保证不发生）

            return;

        }

        double sum = 0;

        for (auto [v, w] : g_[u]) {

            dfs(v);

            sum += f[v] + w;

        }

        f[u] = sum / k;

    }

public:

    green_frog_double(int n_in,

                      const vector<vector<pair<int, double>>>& g_in) {

        n = n_in;

        g_ = g_in;

        f.assign(n + 1, 0);

        visited.assign(n + 1, false);

    }

    double solve() {

        dfs(1);

        return f[1];

    }

};
```

> 💡 **为什么用记忆化搜索而非显式拓扑序**：DAG 上的逆向 dp 用记忆化搜索能自然处理"先计算后继再计算自己"的顺序——`dfs(u)` 调用时会先递归 `dfs(v)` 完成所有后继的计算。比手写拓扑排序更简洁。

## 复杂度分析

- 时间复杂度：$O(n + m)$

  - 每个节点访问一次（DFS 后被 `visited` 标记）

  - 每条边遍历一次（在父节点的 `g_[u]` 中）

- 空间复杂度：$O(n + m)$（邻接表 + 数组 + 递归栈）

## 正确性证明

### 转移方程的正确性

**命题**：$f[u] = \frac{1}{k} \sum_{(u, v, w)} (f[v] + w)$，其中 $k = \deg^+(u)$。

**证明**：从 $u$ 出发的随机游走，第一步等概率选一条出边 $(u, v_i, w_i)$（$i = 1, \ldots, k$）。设 $L_u$ 表示"从 $u$ 到 $n$ 的路径总边权"这个随机变量。

按第一步走的边分类——

- 走 $(u, v_i, w_i)$：剩余路径是"从 $v_i$ 到 $n$"，记其总边权为 $L_{v_i}$。本次走完后 $L_u = w_i + L_{v_i}$

由全期望公式——

$$f[u] = E[L_u] = \sum_{i=1}^{k} P(\text{走第 } i \text{ 条边}) \cdot E[L_u \mid \text{走第 } i \text{ 条边}]$$

代入 $P = 1/k$、$E[L_u \mid \text{走第 } i \text{ 条边}] = w_i + E[L_{v_i}] = w_i + f[v_i]$——

$$f[u] = \sum_{i=1}^{k} \frac{1}{k} (w_i + f[v_i]) = \frac{1}{k} \sum_i (f[v_i] + w_i)$$

由期望线性性，"走第 $i$ 条边"和"走完后到 $n$ 的距离"独立，期望可拆。$\blacksquare$

### 边界与终态正确

**命题**：$f[n] = 0$。

**证明**：从 $n$ 出发已在终点，剩余路径长度恒为 0，所以期望为 0。$\blacksquare$

### 记忆化搜索的拓扑序合法性

**命题**：`dfs(u)` 计算 $f[u]$ 时，所有后继 $v$ 的 $f[v]$ 已被计算。

**证明**：DAG 无环——从 $u$ 出发不可能回到 $u$。递归 `dfs(v)` 必在有限步内终止（不会无限递归）。`visited` 标记保证每个节点只算一次。$\blacksquare$

## 应用扩展

### 应用一：模数下的期望表示（用乘法逆元）

题目常要求"答案对 $10^9 + 7$ 取模"——但期望是分数（如 $\frac{1}{3}$）。**解决方案**：把 $\frac{p}{q}$ 表示为 $p \cdot q^{-1} \pmod{P}$，其中 $q^{-1}$ 是 $q$ 在模 $P$ 下的乘法逆元（详见 [[乘法逆元]]）。

```cpp

class green_frog_mod {

private:

    int n;

    static constexpr long long MOD = 1'000'000'007;

    vector<vector<pair<int, long long>>> g_;

    vector<long long> f;

    vector<bool> visited;

    long long qpow(long long a, long long b, long long p) {

        long long r = 1;

        a %= p;

        while (b > 0) {

            if (b & 1) r = r * a % p;

            a = a * a % p;

            b >>= 1;

        }

        return r;

    }

    long long inv(long long a) {

        return qpow(a, MOD - 2, MOD);                   // 费马小定理

    }

    void dfs(int u) {

        if (visited[u]) return;

        visited[u] = true;

        if (u == n) { f[u] = 0; return; }

        int k = (int)g_[u].size();

        if (k == 0) { f[u] = 0; return; }

        long long sum = 0;

        for (auto [v, w] : g_[u]) {

            dfs(v);

            sum = (sum + f[v] + w) % MOD;

        }

        f[u] = sum * inv(k) % MOD;

    }

public:

    green_frog_mod(int n_in,

                   const vector<vector<pair<int, long long>>>& g_in) {

        n = n_in;

        g_ = g_in;

        f.assign(n + 1, 0);

        visited.assign(n + 1, false);

    }

    long long solve() {

        dfs(1);

        return f[1];

    }

};

```

> ⚠️ **浮点数 vs 取模**：浮点数版精度有限（连续乘 $\frac{1}{k}$ 会累积误差），适合对精度要求不高（输出 2 位小数）的题；取模版精确但需要逆元计算。看题目要求选用。

### 应用二：期望线性性的"多重维护"——OSU!

> 给定一个长 $n$ 的谱面，每个音符**独立**地以概率 $p_i$ 按对。连续按对 $k$ 个音符贡献 $k^3$ 分。求总得分的期望。

直接维护"得分的期望"很难——因为 $k^3$ 是非线性的。但用**期望的线性性**+ 多重维护——

定义在第 $i$ 个音符**结束后**——

- $E_i^{(1)} = E[\text{以 } i \text{ 结尾的连续按对长度}]$

- $E_i^{(2)} = E[(\text{以 } i \text{ 结尾的连续按对长度})^2]$

考察"加入第 $i+1$ 个音符"对总得分期望的贡献——

- 若按对（概率 $p_{i+1}$）：连续长度从 $L$ 变成 $L + 1$，**对总得分的增量**是 $(L+1)^3 - L^3 = 3L^2 + 3L + 1$

- 若没按对（概率 $1 - p_{i+1}$）：连续长度归零，无增量

由期望线性性，"加入第 $i+1$ 个音符的得分增量的期望"= $p_{i+1} (3 E_i^{(2)} + 3 E_i^{(1)} + 1)$。把所有增量加起来就是总期望。

同时维护 $E_i^{(1)}$、$E_i^{(2)}$ 的递推：

$$E_{i+1}^{(1)} = p_{i+1} (E_i^{(1)} + 1)$$

$$E_{i+1}^{(2)} = p_{i+1} (E_i^{(2)} + 2 E_i^{(1)} + 1)$$

**核心思想**：高阶矩 $k^3$ 不能直接 dp，但用"$1$、$L$、$L^2$ 的期望"作为辅助状态——每多一阶矩，递推就多一个对应的辅助量。这是期望 dp 的高阶套路。

### 应用三：正向概率 dp（与逆向期望 dp 对比）

某些题问"到达状态 $u$ 的概率"——这种**正向**计算更自然。

例：抛 $n$ 次硬币，正面概率 $p$，求恰好得到 $k$ 次正面的概率。

定义 $f[i][j] =$ 抛了 $i$ 次硬币、恰好 $j$ 次正面的概率。

$$f[i][j] = p \cdot f[i-1][j-1] + (1 - p) \cdot f[i-1][j]$$

边界 $f[0][0] = 1$、答案 $f[n][k]$。

**这是计数 dp 的概率版本**——每个转移的"+1 方案"换成了"+概率"。

## 几个常见错误

- **方向选错**：把"从起点到 $u$ 的期望"作为状态，结果发现转移依赖"恰好到 $u$ 的概率"，反而更难。**经验**：期望几乎都用逆向（终态为 $f = 0$）

- **环引发的死循环**：随机过程有环（如随机游走可回头）时，记忆化搜索会死循环——需先判断 DAG 性 / 改用解方程组

- **浮点数精度**：连续乘 $1/k$ 在 $k$ 大且层数多时会累积误差；要求高精度时改用模数 + 逆元

- **混淆"$f[u]$ 的概率维"与"$f[u]$ 的期望维"**：$f[u]$ 是数（不是分布）。如果状态本身需要带分布，往往是题目状态设计有问题

- **取模忘记逆元**：直接用 `sum / k` 在模数下是错的——必须 `sum * inv(k) % MOD`

- **从"必须到达 $n$"假设里悄悄假设了概率 1**：若某些节点出度为 0 但不是 $n$，从这些节点出发**永远到不了 $n$**——期望就没有定义。题目通常保证不会出现，但实现时要小心
