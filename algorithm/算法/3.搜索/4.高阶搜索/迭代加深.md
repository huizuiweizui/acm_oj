#难度/★★★★

> 把 DFS 限制在"深度不超过 $d$"内，从小到大枚举 $d$ 的搜索策略——兼具 BFS 的"找最短解"与 DFS 的"小空间"。

## 前置知识

- [[DFS]]

- [[BFS]]

## 核心思想

[[DFS]] 空间小（只存当前路径），但找到的不一定是最短解。

[[BFS]] 求最短解，但要存下整个"已访问层"的状态——状态空间巨大时内存爆掉。

**迭代加深 DFS（Iterative Deepening DFS, IDDFS）**：限制 DFS 的最大深度为 $d$，从 $d = 1$ 开始一次次重启 DFS，每次把上限 $+1$。一旦在某个 $d$ 下找到解，那个解必然是**步数恰好为 $d$ 的最优解**——因为更小的 $d$ 都失败了。

乍看上去重复搜索浪费时间，但其实**最深一层占了几乎全部代价**——浅层重复几次相比深层那一次微不足道。整体复杂度与单次 BFS 同阶（如果搜索树指数级展开）。

迭代加深特别适合"解的步数较少（$d$ 较小），但每层分支多（搜索树极宽）"的场景。BFS 在这种情况下会被宽度撑爆，而迭代加深用 DFS 的栈空间从容应对。

## 适用场景

- 求最短解，且**解的步数较少**（$d \le 30$ 左右）

- 搜索树**分支因子大**，BFS 难以承受空间

- 经典模型：八数码、华容道、立体迷宫等步数有限但分支多的问题

- 配合估价函数变成 [[A∗]] 的"低空间版"——**IDA\***（IDA-star）

- 不适用：解的步数很大（如几百步）；搜索树很窄（直接 BFS / DFS 就够）

## 步骤拆解

1. 设定步数上限 `max_depth = 1`

2. 调用 `dfs(start, 0, max_depth)`：

   a. 当前深度 `d` 等于 `max_depth` 时，检查是否到达目标——是则成功返回

   b. 否则枚举所有后继状态，递归 `dfs(next, d + 1, max_depth)`

3. 若失败，`max_depth += 1`，回到第 2 步重启搜索

4. 直到找到解，此时 `max_depth` 即为最少步数

## 代码模板

**模板一：标准迭代加深 DFS**

```cpp

class iddfs {

private:

    int target_depth;

    bool found;

    // ... 题目相关的状态变量

    bool dfs(int cur_depth) {

        if (is_goal()) {                    // 是否到达目标

            return true;

        }

        if (cur_depth == target_depth) {    // 深度上限到了，剪枝

            return false;

        }

        // 枚举所有可能的下一步

        for (int op = 0; op < op_count(); op++) {

            apply(op);                      // 修改状态

            if (dfs(cur_depth + 1)) {

                return true;

            }

            undo(op);                       // 撤销修改（回溯）

        }

        return false;

    }

public:

    int solve() {

        for (target_depth = 0; target_depth <= MAX_LIMIT; target_depth += 1) {

            if (dfs(0)) {

                return target_depth;

            }

        }

        return -1;                          // 在限制内无解

    }

};
```

> 💡 **迭代加深 + 剪枝 = IDA\***：在 `dfs` 入口加一个估价函数 `h(state)`，剪枝条件改为 `cur_depth + h(state) > target_depth`。这就把迭代加深升级成了启发式搜索（详见 [[A∗]]）。

> ⚠️ **必须能"撤销"操作**：迭代加深本质是 DFS，每次递归后必须能恢复现场。这是回溯式 DFS 的标准要求。

**模板二：八数码用迭代加深 + 估价（IDA*）**

```cpp

// 9 个数字 1-8 + 0（空），目标排成 [1,2,3,4,5,6,7,8,0]

// 每次把 0 与相邻数字交换。求最少步数

class eight_puzzle_ida {

private:

    int target_depth;

    vector<int> a;                          // 当前 9 个数字

    int zero_pos;                           // 0 的位置

    int target[9] = {1, 2, 3, 4, 5, 6, 7, 8, 0};

    // 估价函数：还原所需的最少步数下界——曼哈顿距离之和
    int heuristic() {

        int h = 0;

        for (int i = 0; i < 9; i++) {

            if (a[i] == 0) {

                continue;

            }

            int target_idx = a[i] - 1;

            h += abs(i / 3 - target_idx / 3) + abs(i % 3 - target_idx % 3);

        }

        return h;

    }

    bool dfs(int cur_depth, int prev_op) {

        int h = heuristic();

        if (h == 0) {

            return true;

        }

        if (cur_depth + h > target_depth) { // IDA* 关键剪枝

            return false;

        }

        int dx[] = {-1, 1, 0, 0};

        int dy[] = {0, 0, -1, 1};

        int x = zero_pos / 3;

        int y = zero_pos % 3;

        for (int d = 0; d < 4; d++) {

            if ((d ^ 1) == prev_op) {       // 不要走"回头路"

                continue;

            }

            int nx = x + dx[d];

            int ny = y + dy[d];

            if (nx < 0 || nx >= 3 || ny < 0 || ny >= 3) {

                continue;

            }

            int np = nx * 3 + ny;

            swap(a[zero_pos], a[np]);

            int saved_zero = zero_pos;

            zero_pos = np;

            if (dfs(cur_depth + 1, d)) {

                return true;

            }

            zero_pos = saved_zero;

            swap(a[zero_pos], a[np]);

        }

        return false;

    }

public:

    eight_puzzle_ida(vector<int>& start) {

        a = start;

        for (int i = 0; i < 9; i++) {

            if (a[i] == 0) {

                zero_pos = i;

            }

        }

    }

    int solve() {

        for (target_depth = 0; target_depth <= 50; target_depth += 1) {

            if (dfs(0, -1)) {

                return target_depth;

            }

        }

        return -1;

    }

};
```

> 💡 **估价函数的性质**：必须是"实际还需步数的**下界**"——`h(state)` 必须 $\le$ 真实最优代价。这样 `cur_depth + h(state) > target_depth` 才能正确剪枝（不会误剪可行解）。这种估价称为"可行的"（admissible）。
  
## 复杂度分析

- 时间复杂度：$O(b^{d^*})$，与单次 DFS 同阶（多一个常数倍）

- 空间复杂度：$O(d^*)$，远小于 BFS

## 正确性证明

### 找到的解是最短解

**核心命题**：迭代加深 DFS 第一次成功返回时，对应的 `target_depth` 即为最短解的步数。

**证明**：

设最优解步数为 $d^*$。

**$d < d^*$ 时算法失败**：在深度上限为 $d$ 的 DFS 中，所有解都被 `cur_depth == target_depth` 这个剪枝过滤——只有恰好深度 $\le d$ 的状态才被检查。但任何解都需 $\ge d^*$ 步到达，故没有任何路径在限制 $d < d^*$ 内到达终点。

**$d = d^*$ 时算法成功**：DFS 会枚举所有不超过 $d^*$ 步的搜索路径。最优路径对应一个长度为 $d^*$ 的合法决策序列，由 [[DFS]] 的完备性（详见其笔记中"枚举型 DFS 的完备性"），这条路径必然被枚举到。

由于我们从 $d = 1$ 开始递增，必然在 $d = d^*$ 时第一次成功。$\blacksquare$

### 重复搜索的代价是常数级

**命题**：迭代加深的总时间复杂度与"单次深度 $d^*$ 的 DFS"同阶。

**证明**：

设搜索树是均匀的 $b$ 叉树，深度上限 $d^*$。第 $i$ 轮搜索访问的节点数约为 $b^i$。总访问数：

$$T(d^*) = \sum_{i=1}^{d^*} b^i = b \cdot \frac{b^{d^*} - 1}{b - 1}$$

当 $b \ge 2$ 时，$T(d^*) \le 2 b^{d^*}$。

**与单次 DFS 比较**：单次深度 $d^*$ 的 DFS 访问 $b^{d^*}$ 个节点。迭代加深的总访问数最多是它的 $\frac{b}{b-1}$ 倍——$b = 2$ 时为 2 倍，$b \to \infty$ 时趋近 1 倍。

**直觉理解**：搜索树最深一层的节点数是前面所有层节点数之和的同阶量级（指数增长意味着"最后一层占绝大多数"）。所以"重复搜索浅层"在渐近意义下不重要。$\blacksquare$

### IDA* 的剪枝正确性

**命题**：在迭代加深中加入估价 $h$ 后，剪枝条件 `cur_depth + h(state) > target_depth` 不会误删合法解，**前提是 $h$ 可采纳**（$h(\text{state}) \le$ 从 `state` 到目标的真实最少步数）。

**证明**：

考虑从当前状态 $s$ 出发的任意合法解，其总步数 = 当前深度 + 从 $s$ 到目标的真实步数 $\ge$ `cur_depth` + $h(s)$。

若 `cur_depth + h(s) > target_depth`，则任何从 $s$ 出发的合法解的总步数也 $> \text{target\_depth}$——这与"我们正在寻找步数 $\le \text{target\_depth}$ 的解"矛盾。所以可以安全剪枝。

**反例**：若 $h$ 不可采纳（即 $h$ 高估了真实剩余步数），剪枝可能过于激进——某些合法解会被错误地排除。

例如真实剩余步数为 3，但 $h$ 报告为 5。当 `cur_depth = target_depth - 4` 时，剪枝条件 `cur_depth + 5 > target_depth` 触发，但其实从这里出发还有合法解。$\blacksquare$

## 与相关算法的对比

**与 BFS 的空间对比**：

BFS 维护"已访问层"，宽度可能达 $b^d$，存不下。迭代加深的空间只是 DFS 栈深度 $O(d^*)$——天壤之别。

**与 [[A∗]] 的对比**：

A* 启发式搜索通常更快（找到解后可以立即终止），但 A* 需要维护一个 `priority_queue`，空间 $O(\text{已访问状态数})$ 还是大。

IDA* = 迭代加深 + 估价剪枝，空间 $O(d^*)$，但因为每次重启而损失"曾经的剪枝信息"。在实际竞赛中，IDA* 比 A* 更常用（特别是状态空间巨大时）。
