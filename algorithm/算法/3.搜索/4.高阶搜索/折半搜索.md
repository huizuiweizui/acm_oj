#难度/★★★

> 把指数级搜索一分为二：左半暴力枚举所有结果存起来，右半枚举时配对查询，把 $O(2^n)$ 变为 $O(2^{n/2})$。

## 前置知识

- [[DFS]]

- [[二分查找]]

## 核心思想

许多题目要求"从 $n$ 个元素中选若干个"满足某条件——状态空间为 $2^n$。当 $n \approx 20$ 时朴素枚举尚可（$10^6$），但 $n$ 到 $40$ 时 $2^{40} \approx 10^{12}$ 直接爆炸。

**折半搜索（Meet in the Middle）的关键**：把元素均分两半，左半和右半各自暴力枚举所有 $2^{n/2}$ 种子集。然后利用左半生成的"结果集"，对右半的每种选法**快速配对查询**——这样总复杂度从 $O(2^n)$ 降到 $O(2^{n/2} \log 2^{n/2}) = O(2^{n/2} \cdot n)$。

$n = 40$ 时这相当于把 $10^{12}$ 降到 $10^6 \cdot 20 = 2 \times 10^7$，完全可行。

折半搜索的精髓在于"配对"——只有当**两个子问题的解能 $O(\log)$ 内合并**（如求和、求异或）时，这种思想才奏效。

## 适用场景

- 子集和问题（求是否存在子集使和等于 $T$，或子集和的方案数）

- 异或类问题（左右两半异或值匹配）

- $n$ 在 $30 \sim 50$ 范围内的暴力题

- 双向 BFS 的离散版本

- 不适用：$n$ 太小（直接暴力）；$n$ 太大（$2^{n/2}$ 也存不下）；左右两半的合并代价高

## 步骤拆解

1. **均分**：把 $n$ 个元素分成两半，记 $L = n / 2$，$R = n - L$

2. **枚举左半**：枚举所有 $2^L$ 种选法，把每种选法的"结果"（如子集和）记入数组 `left_results[]`

3. **整理左半**：对 `left_results[]` 排序（或建哈希表）以支持快速查询

4. **枚举右半**：枚举所有 $2^R$ 种选法，对每种结果在左半中**二分查询**或哈希查找，统计配对数量

5. **合并答案**：根据题目要求（计数 / 求最优 / 判断可行）汇总结果

## 代码模板

**模板一：子集和等于 T 的方案数**

```cpp

// 给定 n 个数 a[1..n]，求选出子集使和等于 T 的方案数

class subset_sum_count {

private:

    int n;

    long long T;

    vector<long long> a;

    // 枚举区间 [lo, hi] 上所有 2^(hi-lo+1) 个子集和
    vector<long long> enumerate_sums(int lo, int hi) {

        int len = hi - lo + 1;

        vector<long long> result;

        result.reserve(1 << len);

        for (int S = 0; S < (1 << len); S++) {

            long long sum = 0;

            for (int i = 0; i < len; i++) {

                if ((S >> i) & 1) {

                    sum += a[lo + i];

                }

            }

            result.push_back(sum);

        }

        return result;

    }

public:

    subset_sum_count(vector<long long>& arr, long long target) {

        n = arr.size() - 1;                 // 下标 1..n

        a = arr;

        T = target;

    }

    long long solve() {

        int L = n / 2;

        // 左半：a[1..L]

        vector<long long> left = enumerate_sums(1, L);

        // 右半：a[L+1..n]

        vector<long long> right = enumerate_sums(L + 1, n);

        sort(left.begin(), left.end());

        long long ans = 0;

        for (long long r : right) {

            // 找左半中等于 T - r 的个数

            long long need = T - r;

            // 用 STL 二分（也可手写开区间二分）

            auto it1 = lower_bound(left.begin(), left.end(), need);

            auto it2 = upper_bound(left.begin(), left.end(), need);

            ans += it2 - it1;

        }

        return ans;

    }

};
```

> 💡 **枚举子集的位运算技巧**：`for (int S = 0; S < (1<<len); S++)` 让 $S$ 遍历所有 $2^{\text{len}}$ 个子集；`(S >> i) & 1` 检查第 $i$ 位是否选中。这是状态压缩的标准操作。

**模板二：判断子集和是否能等于 T**

```cpp
bool subset_sum_exists(vector<long long>& a, long long T) {

    int n = a.size() - 1;

    int L = n / 2;

    // 枚举左半
    vector<long long> left;

    for (int S = 0; S < (1 << L); S++) {

        long long sum = 0;

        for (int i = 0; i < L; i++) {

            if ((S >> i) & 1) {

                sum += a[i + 1];

            }

        }

        left.push_back(sum);

    }

    sort(left.begin(), left.end());

    // 枚举右半，二分查找匹配
    int R = n - L;

    for (int S = 0; S < (1 << R); S++) {

        long long sum = 0;

        for (int i = 0; i < R; i++) {

            if ((S >> i) & 1) {

                sum += a[L + i + 1];

            }

        }

        if (binary_search(left.begin(), left.end(), T - sum)) {

            return true;

        }

    }

    return false;

}
```

## 复杂度分析

- 时间复杂度：$O(2^{n/2} \cdot n)$（含排序与查询）

- 空间复杂度：$O(2^{n/2})$，存储左半枚举结果

## 正确性证明

### 完备性：所有合法解都能被枚举到

**核心命题**：对原问题的任意合法解 $S \subseteq \{1, 2, \ldots, n\}$，折半搜索都能正确统计/找到它。

**证明**：

把 $S$ 拆成两部分——$S_L = S \cap \{1, \ldots, L\}$（属于左半的部分）和 $S_R = S \cap \{L+1, \ldots, n\}$（属于右半的部分）。两部分独立，$S = S_L \cup S_R$ 且 $S_L \cap S_R = \emptyset$。

**关键性质**：左半的 $2^L$ 种枚举包含**所有可能的 $S_L$**；右半的 $2^R$ 种枚举包含**所有可能的 $S_R$**。

以"子集和等于 $T$"为例：

- $S$ 是合法解 $\iff \text{sum}(S_L) + \text{sum}(S_R) = T$

- 即 $\text{sum}(S_R) = T - \text{sum}(S_L)$

枚举右半遍历所有 $S_R$，对每个 $\text{sum}(S_R)$ 在左半中查找等于 $T - \text{sum}(S_R)$ 的子集和——由于左半枚举完整，必然能找到对应的 $S_L$。

每个合法 $(S_L, S_R)$ 对都在算法中被精确遇到一次，所以计数正确。$\blacksquare$

### 复杂度从 $2^n$ 降到 $2^{n/2}$ 的来源

朴素枚举所有子集 $2^n$ 次操作。折半后：

- 枚举左半：$2^{n/2}$ 次

- 排序左半：$O(2^{n/2} \cdot \frac{n}{2})$

- 枚举右半 + 每次二分查询：$2^{n/2} \cdot O(\log 2^{n/2}) = 2^{n/2} \cdot O(n)$

总计 $O(2^{n/2} \cdot n)$，远小于 $O(2^n)$。

**为什么是$\sqrt{}$形式的优化**：

$2^n = 2^{n/2} \cdot 2^{n/2}$。折半搜索把"两个 $2^{n/2}$ 的乘积"分解为"两个 $2^{n/2}$ 的独立计算 + 一次配对查询"——这是经典的"meet in the middle"思想，把指数底数砍半。$\blacksquare$

### 关键前提——可合并性

**命题**：折半搜索奏效的必要条件是"原问题的解能由两半的局部解通过简单运算合并"。

**正例**：

- 子集和：$\text{sum}(S) = \text{sum}(S_L) + \text{sum}(S_R)$（可加）

- 子集异或：$\text{xor}(S) = \text{xor}(S_L) \oplus \text{xor}(S_R)$（可异或）

- 路径数（图论）：左右两段独立，乘起来即可

**反例**：

- 子集中位数：左半的中位数与右半的中位数无法直接合并出整体中位数

- 子集元素之间的关系约束（如"两两距离 $\ge K$"）：跨越两半的约束使得左右不能独立枚举

所以折半搜索不是"万能法宝"——必须先确认"两半的局部信息能在 $O(\log)$ 或 $O(1)$ 内合并"。$\blacksquare$

### 与状压 DP 的对比

[[状压dp]] 也常用于"$n \le 20$ 的子集枚举"问题，但它要求**子问题之间有递推关系**（如 TSP）。折半搜索更"暴力"——不依赖结构，直接两半穷举，可处理状压 dp 难以建模的题目（如约束跨越两半）。

**双向 BFS 的折半本质**：

设两点最短路径长 $d$。单向 BFS 探索 $b^d$ 个节点。双向 BFS 各探索 $d/2$ 层，共 $2 b^{d/2}$ 个节点——同样的"折半降到平方根"思想。
