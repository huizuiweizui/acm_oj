#难度/★★★

> 从 $n$ 个不同元素中选 $k$ 个的方案数 $\binom{n}{k} = \frac{n!}{k!(n-k)!}$——模数下用阶乘 + 逆元 $O(1)$ 查询，超大 $n$ 用 Lucas 定理。

## 核心思想

**组合数**：$\binom{n}{k}$ 表示"从 $n$ 个不同元素中选 $k$ 个（不计顺序）"的方案数。基本公式：

$$\binom{n}{k} = \frac{n!}{k! \cdot (n - k)!}$$

约定 $0 \le k \le n$；$k > n$ 或 $k < 0$ 时 $\binom{n}{k} = 0$。

**OI 中的核心问题**：组合数的精确值会爆炸（$\binom{60}{30}$ 已超 $10^{17}$），通常题目要求 $\binom{n}{k} \bmod p$。计算时分母不能直接除——必须用 [[乘法逆元]]。
  
**主要算法**：

| 方法                | 适用情形                   | 预处理               | 单次查询          |
| ----------------- | ---------------------- | ----------------- | ------------- |
| **杨辉三角递推**        | $n, k$ 较小 $(\le 5000)$ | $O(n^2)$          | $O(1)$        |
| **阶乘 + 逆元**       | 单次模数 + 中等 $n$          | $O(n)$            | $O(1)$        |
| **Lucas 定理**      | 巨大 $n$ 但 $p$ 小（质数）     | $O(p)$            | $O(\log_p n)$ |
| **扩展 Lucas**      | 模数为合数（高级）              | $O(p \log p)$     | $O(\log n)$   |

OI 中最实用的是 **阶乘 + 逆元法**——预处理 $O(n)$，单次查询 $O(1)$。下面以此为主线，最后给出 Lucas 定理。

**核心做法**：

1. 预处理 $\mathtt{fact}[i] = i! \bmod p$（$0 \le i \le n$）

2. 预处理 $\mathtt{inv\_fact}[i] = (i!)^{-1} \bmod p$

3. 查询 $\binom{n}{k} = \mathtt{fact}[n] \cdot \mathtt{inv\_fact}[k] \cdot \mathtt{inv\_fact}[n - k] \bmod p$

逆元数组的预处理用"双递推"：先用费马小定理求出 $\mathtt{inv\_fact}[n]$，再倒着递推 $\mathtt{inv\_fact}[i] = \mathtt{inv\_fact}[i + 1] \cdot (i + 1)$（详见 [[乘法逆元]] 末尾）。

## 适用场景

- **计数 dp**：$\binom{n}{k}$ 作为转移系数（如多项式系数、容斥）

- **概率与期望**：方案数分母分子表示概率

- **二项式定理**：$(x + y)^n = \sum_k \binom{n}{k} x^k y^{n-k}$

- **格路计数 / 路径方案数**：从 $(0, 0)$ 到 $(n, m)$ 只能向右或向上的方案数 $= \binom{n+m}{n}$

- **容斥系数**：$(-1)^k \binom{n}{k}$ 在很多容斥公式中出现

- 不适用：模数为合数且非质数幂（要用扩展 Lucas，本笔记不展开）

## 步骤拆解

**主流方法（阶乘 + 逆元）**：

1. **预处理阶乘**：$\mathtt{fact}[0] = 1$；$\mathtt{fact}[i] = \mathtt{fact}[i-1] \cdot i \bmod p$（$i = 1, \ldots, n$）

2. **预处理阶乘逆元**：先 $\mathtt{inv\_fact}[n] = \mathtt{pow\_mod}(\mathtt{fact}[n], p - 2)$；再倒着递推 $\mathtt{inv\_fact}[i] = \mathtt{inv\_fact}[i + 1] \cdot (i + 1) \bmod p$

3. **查询**：$\binom{n}{k} = \mathtt{fact}[n] \cdot \mathtt{inv\_fact}[k] \cdot \mathtt{inv\_fact}[n - k] \bmod p$（同时检查 $0 \le k \le n$，否则返回 $0$）

**Lucas 定理（$n$ 巨大时）**：

> 当 $p$ 为质数：$\binom{n}{k} \equiv \binom{n \bmod p}{k \bmod p} \cdot \binom{\lfloor n / p \rfloor}{\lfloor k / p \rfloor} \pmod p$

递归调用：每层把 $n, k$ 拆为"对 $p$ 的商"和"对 $p$ 的余数"，余数部分用预处理的 $\binom{\cdot}{\cdot}$ 表查询，商部分递归。深度 $O(\log_p n)$。

## 代码模板

**模板一：阶乘 + 逆元（最常用）**

```cpp
class binomial_modular {

private:

    int n_max;

    long long p;

    vector<long long> fact, inv_fact;

    long long pow_mod(long long a, long long b) {

        long long res = 1;

        a %= p;

        while (b > 0) {

            if (b & 1) res = res * a % p;

            a = a * a % p;

            b >>= 1;

        }

        return res;

    }

public:

    binomial_modular(int n_max_in, long long p_in) {

        n_max = n_max_in;

        p = p_in;

        fact.assign(n_max + 1, 1);

        inv_fact.assign(n_max + 1, 1);

        for (int i = 1; i <= n_max; i++) {

            fact[i] = fact[i - 1] * i % p;

        }

        inv_fact[n_max] = pow_mod(fact[n_max], p - 2);

        for (int i = n_max - 1; i >= 0; i--) {

            inv_fact[i] = inv_fact[i + 1] * (i + 1) % p;

        }

    }

    long long binom(long long n, long long k) {

        if (k < 0 || k > n) {

            return 0;

        }

        return fact[n] * inv_fact[k] % p * inv_fact[n - k] % p;

    }

};
```

> 💡 **预处理一次 + 多次查询的总复杂度**：$O(n_\text{max} + q)$，其中 $q$ 是查询次数。$n_\text{max}$ 取所有查询中的最大值。

> ⚠️ **`p` 必须是质数**：因为用了费马小定理求 $(n!)^{-1}$。常见模数 $10^9 + 7$、$998244353$ 都是质数。

**模板二：杨辉三角递推（$n$ 小时）**

```cpp
class binomial_pascal {

private:

    int n_max;

    long long p;

    vector<vector<long long>> c;

public:

    binomial_pascal(int n_max_in, long long p_in) {

        n_max = n_max_in;

        p = p_in;

        c.assign(n_max + 1, vector<long long>(n_max + 1, 0));

        for (int i = 0; i <= n_max; i++) {

            c[i][0] = 1;

            for (int j = 1; j <= i; j++) {

                c[i][j] = (c[i - 1][j - 1] + c[i - 1][j]) % p;

            }

        }

    }

    long long binom(int n, int k) {

        if (k < 0 || k > n) return 0;

        return c[n][k];

    }

};
```

> 💡 **何时选杨辉三角**：$n \le 5000$ 时空间能开下；$p$ 是任意整数（不必质数）；查询特别多但 $n$ 小。

**模板三：Lucas 定理（$n$ 巨大时）**

```cpp

class binomial_lucas {

private:

    long long p;

    binomial_modular base;                      // 处理 n, k < p 的情况

public:

    binomial_lucas(long long p_in)

        : p(p_in), base((int)p - 1, p_in) {}

    long long binom(long long n, long long k) {

        if (k == 0) {

            return 1;

        }

        // Lucas: C(n, k) = C(n%p, k%p) * C(n/p, k/p) mod p
        return base.binom(n % p, k % p) * binom(n / p, k / p) % p;

    }

};
```

> 💡 **何时选 Lucas**：$n, k$ 巨大（如 $10^{18}$）但 $p$ 较小（如 $\le 10^5$）。预处理只需 $O(p)$。

> 复杂度：单次查询 $O(\log_p n)$。

## 复杂度分析

- 阶乘 + 逆元法：预处理 $O(n)$，单次查询 $O(1)$

- 杨辉三角：预处理 $O(n^2)$，单次查询 $O(1)$

- Lucas 定理：预处理 $O(p)$，单次查询 $O(\log_p n)$

## 正确性证明

### 组合数的基本递推（杨辉三角）

**命题（Pascal 法则）**：$\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$。

**证明（组合解释）**：从 $n$ 个元素中选 $k$ 个——

- 考虑某个特定元素 $e$：选出的 $k$ 个中要么含 $e$，要么不含

- 含 $e$：从剩余 $n-1$ 个中再选 $k-1$ 个，共 $\binom{n-1}{k-1}$ 方案

- 不含 $e$：从剩余 $n-1$ 个中选 $k$ 个，共 $\binom{n-1}{k}$ 方案

两种互斥情况之和即 $\binom{n}{k}$。$\blacksquare$

**代数证明**：

$$\binom{n-1}{k-1} + \binom{n-1}{k} = \frac{(n-1)!}{(k-1)!(n-k)!} + \frac{(n-1)!}{k!(n-k-1)!}$$

通分（公分母 $k!(n-k)!$）：

$$= \frac{(n-1)! \cdot k + (n-1)! \cdot (n-k)}{k!(n-k)!} = \frac{(n-1)! \cdot n}{k!(n-k)!} = \frac{n!}{k!(n-k)!} = \binom{n}{k}$$

$\blacksquare$

### 阶乘 + 逆元法的正确性

**命题**：$\binom{n}{k} \equiv n! \cdot (k!)^{-1} \cdot ((n-k)!)^{-1} \pmod p$。

**证明**：组合数定义为 $\binom{n}{k} = \frac{n!}{k!(n-k)!}$——这是**整数**（组合数永远是整数）。在模 $p$ 下做"除法"等价于乘以逆元，所以：

$$\binom{n}{k} \bmod p = (n! \cdot (k!(n-k)!)^{-1}) \bmod p = n! \cdot (k!)^{-1} \cdot ((n-k)!)^{-1} \bmod p$$

最后一步用了 $(k!(n-k)!)^{-1} = (k!)^{-1} \cdot ((n-k)!)^{-1}$（逆元的乘法性质）。$\blacksquare$

**前提条件**：$\gcd(k!, p) = 1$ 和 $\gcd((n-k)!, p) = 1$——当 $p$ 是质数且 $p > n$ 时自动满足（$k!$ 中所有因子都 $< p$，与 $p$ 互质）。若 $p \le n$ 这种朴素方法**会出错**——必须用 Lucas 定理。

### inv_fact 倒着递推的正确性

**关系**：$(i+1)! = (i+1) \cdot i!$。两边求逆元：

$$((i+1)!)^{-1} \cdot (i+1) = ((i+1) \cdot i!)^{-1} \cdot (i+1) = (i!)^{-1}$$

即 $\mathtt{inv\_fact}[i] = \mathtt{inv\_fact}[i + 1] \cdot (i + 1)$。

倒着递推从 $\mathtt{inv\_fact}[n]$ 出发推到 $\mathtt{inv\_fact}[0]$，每步 $O(1)$。$\blacksquare$

### Lucas 定理

**Lucas 定理**：若 $p$ 为质数，$n = a_t p^t + a_{t-1} p^{t-1} + \cdots + a_0$，$k = b_t p^t + \cdots + b_0$（$p$ 进制展开），则

$$\binom{n}{k} \equiv \prod_{i=0}^{t} \binom{a_i}{b_i} \pmod p$$

等价的**递推形式**：

$$\binom{n}{k} \equiv \binom{n \bmod p}{k \bmod p} \cdot \binom{\lfloor n/p \rfloor}{\lfloor k/p \rfloor} \pmod p$$

**证明：基于母函数 $(1 + x)^n \bmod p$ 的性质——

由 $p$ 是质数，二项式 $(1 + x)^p \equiv 1 + x^p \pmod p$（"频率倍增"现象）。所以：

$$(1 + x)^n = (1 + x)^{\sum a_i p^i} \equiv \prod_i (1 + x^{p^i})^{a_i} \pmod p$$

展开右边——$x^k$ 系数只能由"每个因子贡献某些 $x^{p^i b_i'}$"组成，其中 $\sum b_i' p^i = k$。由唯一性 $b_i' = b_i$。所以 $x^k$ 系数 $= \prod_i \binom{a_i}{b_i}$，即 Lucas 定理。$\blacksquare$

**Lucas 的实用价值**：处理 $n, k$ 巨大但 $p$ 小的场景。例如 $n = 10^{18}, p = 10^5$ 时——预处理 $O(p)$ 阶乘 + 逆元，每次查询 $O(\log_p n) \approx 4$ 次乘法。

### 一个常见误区——"$\binom{n}{k}$ 取模 $\ne$ 正确算"

很多人写 $\binom{n}{k} \bmod p$ 时直接除 $k! \cdot (n-k)!$——错误！整数除法在模 $p$ 下不等于"模意义除法"：

```cpp

// 错误！分子已经被 mod p 了，整数除法毫无意义

long long c = fact[n] / (fact[k] * fact[n - k] % p);

```

正确做法必须用逆元——这正是本笔记的核心。

## 几个常用的组合恒等式

记下来，做题时能快速识别：

- **对称性**：$\binom{n}{k} = \binom{n}{n - k}$

- **吸收性**：$k \binom{n}{k} = n \binom{n - 1}{k - 1}$

- **总和**：$\sum_{k = 0}^{n} \binom{n}{k} = 2^n$

- **交错和**：$\sum_{k = 0}^{n} (-1)^k \binom{n}{k} = 0$（$n \ge 1$）

- **Vandermonde**：$\binom{m + n}{r} = \sum_{k = 0}^{r} \binom{m}{k} \binom{n}{r - k}$

- **小球同色公式（Hockey-Stick）**：$\sum_{i = 0}^{n} \binom{i + k}{k} = \binom{n + k + 1}{k + 1}$

## 几个常见错误

- **$p$ 不是质数还用费马**：必须确认 $p$ 是质数。$10^9 + 7$ 和 $998244353$ 都是质数。$10^9$ 不是质数（$10^9 = 2 \cdot 5^9 \cdot 5 \cdots$ 这种）

- **$n \ge p$ 还用阶乘 + 逆元**：$n \ge p$ 时 $n!$ 含 $p$ 因子，$\bmod p$ 后为 0，逆元不存在。这种情况必须用 Lucas

- **`fact[k] * fact[n-k]` 爆 long long**：两个数相乘前最好先各自 mod p；最终结果再 mod p
