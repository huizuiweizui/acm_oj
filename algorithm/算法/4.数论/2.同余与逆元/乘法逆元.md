#难度/★★★ 

> 模意义下没有"除法"——但只要 $\gcd(a, p) = 1$，$a$ 就有"乘法逆元" $a^{-1}$ 满足 $a \cdot a^{-1} \equiv 1 \pmod p$，"除以 $a$"等价于"乘以 $a^{-1}$"。

- [[快速幂]]

## 核心思想

**问题来源**：很多算法的中间结果会爆 `long long`，必须**全程取模**——比如组合数 $\binom{n}{k} = \frac{n!}{k!(n-k)!}$。整数除法在模意义下不能直接做：$\frac{a}{b} \bmod p \ne (a \bmod p) / (b \bmod p)$。

**乘法逆元**给出了"模意义下的除法"——

> 给定模数 $p$ 和整数 $a$，若存在整数 $a^{-1}$ 使得 $a \cdot a^{-1} \equiv 1 \pmod p$，则称 $a^{-1}$ 为 $a$ 在模 $p$ 意义下的**乘法逆元**。

存在性条件：$a^{-1}$ 存在 $\Leftrightarrow$ $\gcd(a, p) = 1$。

**有了逆元，"除法"就变成了"乘法"**：

$$\frac{a}{b} \bmod p = (a \cdot b^{-1}) \bmod p$$

求逆元的三种主流方法——

- **费马小定理（推荐）**：当 $p$ 为质数且 $\gcd(a, p) = 1$，$a^{p-2} \equiv a^{-1} \pmod p$。用 [[快速幂]]，$O(\log p)$

- **扩展欧几里得**：解 $ax + py = 1$，$x$ 即为逆元。$O(\log \min(a, p))$。**适用于 $p$ 不是质数但 $\gcd(a, p) = 1$ 的情形**

- **线性递推**：在 $O(n)$ 时间内求出 $1, 2, \ldots, n$ 在模 $p$ 下的全部逆元。**适用于需要批量逆元**（如组合数预处理）

## 适用场景

- **组合数取模**：$\binom{n}{k} \bmod p$ 必须用逆元（详见 [[组合数]]）

- **概率与期望模数题**：分母不为整数时模意义下表示为"乘以分母逆元"

- **多项式 / 矩阵运算的模数版**：除法操作必须改写为乘逆元

- **解一次同余方程** $ax \equiv b \pmod p$：等价于求 $x \equiv b \cdot a^{-1} \pmod p$

- 不适用：$\gcd(a, p) > 1$（逆元不存在）；不取模的纯整数运算（直接做除法即可）

## 步骤拆解

**方法一：费马小定理**

1. 检查 $p$ 是否为质数（否则不能用此方法）

2. 检查 $\gcd(a, p) = 1$（保证逆元存在）

3. 用 [[快速幂]] 求 $a^{p-2} \bmod p$，即为 $a^{-1}$

**方法二：扩展欧几里得（exgcd）**

1. 用 exgcd 求一组整数 $(x, y)$ 满足 $ax + py = \gcd(a, p)$

2. 若 $\gcd(a, p) \ne 1$ 则逆元不存在

3. 否则 $ax \equiv 1 \pmod p$，$x$ 即逆元（取模规整化到 $[0, p)$）

**方法三：线性递推**

1. $\mathtt{inv}[1] = 1$

2. 对 $i$ 从 $2$ 到 $n$：$\mathtt{inv}[i] = -(p / i) \cdot \mathtt{inv}[p \bmod i] \bmod p$

3. 取模规整化（加 $p$ 再 $\bmod p$ 避免负数）

## 代码模板

**模板：三种方法的统一接口**

```cpp
class modular_inverse {

public:

    // 快速幂：a^b mod p

    static long long pow_mod(long long a, long long b, long long p) {

        long long res = 1;

        a %= p;

        if (a < 0) a += p;

        while (b > 0) {

            if (b & 1) res = res * a % p;

            a = a * a % p;

            b >>= 1;

        }

        return res;

    }

    // 方法一：费马小定理（要求 p 为质数）
    static long long inv_fermat(long long a, long long p) {

        return pow_mod(a, p - 2, p);

    }

    // 扩展欧几里得：求 ax + by = gcd(a, b) 的一组 (x, y)，返回 gcd
    static long long exgcd(long long a, long long b, long long& x, long long& y) {

        if (b == 0) {

            x = 1;

            y = 0;

            return a;

        }

        long long g = exgcd(b, a % b, y, x);

        y -= (a / b) * x;

        return g;

    }

    // 方法二:exgcd（要求 gcd(a, p) = 1，p 不必是质数）
    static long long inv_exgcd(long long a, long long p) {

        long long x, y;

        long long g = exgcd(a, p, x, y);

        if (g != 1) {

            return -1;                          // 逆元不存在

        }

        return (x % p + p) % p;

    }

    // 方法三:线性递推（求 1..n 在 mod p 下的所有逆元）
    static vector<long long> inv_linear(int n, long long p) {

        vector<long long> inv(n + 1, 0);

        inv[1] = 1;

        for (int i = 2; i <= n; i++) {

            inv[i] = (p - p / i) * inv[p % i] % p;

        }

        return inv;

    }

};
```

> 💡 **三种方法的选择**：

> - 单点求逆 + $p$ 是质数 → **费马小定理**（最简单，一行 `pow_mod`）

> - 单点求逆 + $p$ 不是质数 → **exgcd**

> - 批量求 $1, \ldots, n$ 的逆元 + $p$ 是质数 → **线性递推**（$O(n)$ 比 $n$ 次费马快）

> ⚠️ **取模负数处理**：exgcd 求出的 $x$ 可能是负数，要 `(x % p + p) % p` 规整到 $[0, p)$。

> ⚠️ **`p` 必须是质数才能用费马小定理 / 线性递推**：题目给的模数 $p = 998244353$ 或 $10^9 + 7$ 都是质数，可以放心用。但若 $p = 10^9$ 这种合数，就只能用 exgcd。

## 复杂度分析

- 费马小定理：$O(\log p)$

- exgcd：$O(\log \min(a, p))$

- 线性递推：$O(n)$ 求出 $n$ 个逆元

## 正确性证明

### 费马小定理求逆元

**费马小定理**：若 $p$ 为质数且 $\gcd(a, p) = 1$，则

$$a^{p - 1} \equiv 1 \pmod p$$

**推论（求逆元）**：两边除以 $a$（即乘 $a^{-1}$）得

$$a^{p - 2} \equiv a^{-1} \pmod p$$

所以快速幂算 $a^{p-2}$ 即得逆元。

**费马小定理的证明（草图）**：考虑集合 $S = \{1, 2, \ldots, p-1\}$。乘以 $a$（mod $p$）后得到 $aS = \{a, 2a, \ldots, (p-1)a\}$（每个元素 mod $p$）——

由 $\gcd(a, p) = 1$，$aS$ 中任两元素 $ai, aj$（$1 \le i < j \le p-1$）的差 $a(j - i)$ 不被 $p$ 整除（因为 $p \nmid a$ 且 $p \nmid (j - i)$）——所以 $aS \bmod p$ 仍是 $\{1, 2, \ldots, p-1\}$ 的一个排列。

两边取连乘得：

$$\prod_{i=1}^{p-1} (a \cdot i) \equiv \prod_{i=1}^{p-1} i \pmod p$$

即 $a^{p-1} \cdot (p-1)! \equiv (p-1)! \pmod p$。由 $\gcd((p-1)!, p) = 1$，两边同除得 $a^{p-1} \equiv 1$。$\blacksquare$

### exgcd 求逆元

**Bezout 定理**：对任意整数 $a, b$，方程 $ax + by = \gcd(a, b)$ 有整数解 $(x, y)$。

**推论**：若 $\gcd(a, p) = 1$，则方程 $ax + py = 1$ 有整数解。两边对 $p$ 取模：

$$ax \equiv 1 \pmod p$$

即 $x$ 是 $a$ 的逆元。

**exgcd 的递归正确性**：

设 $\mathtt{exgcd}(a, b)$ 返回 $\gcd(a, b)$ 并求出 $(x, y)$ 满足 $ax + by = \gcd(a, b)$。

**基础** $b = 0$：$\gcd(a, 0) = a$；取 $x = 1, y = 0$ 满足 $a \cdot 1 + 0 \cdot 0 = a$。

**归纳**：设递归 $\mathtt{exgcd}(b, a \bmod b)$ 返回 $\gcd(b, a \bmod b) = \gcd(a, b)$，且 $(x', y')$ 满足

$$b x' + (a \bmod b) y' = \gcd(a, b)$$

由 $a \bmod b = a - \lfloor a / b \rfloor \cdot b$ 代入：

$$b x' + a y' - \lfloor a / b \rfloor \cdot b y' = \gcd(a, b)$$

整理得 $a y' + b (x' - \lfloor a / b \rfloor y') = \gcd(a, b)$。

所以原问题的解为 $x = y'$，$y = x' - \lfloor a / b \rfloor y'$——这正是代码中的递归更新公式。$\blacksquare$

### 线性递推的正确性

**关键变形**：对任意 $i$，$p$ 可写成 $p = \lfloor p / i \rfloor \cdot i + (p \bmod i)$，即

$$\lfloor p / i \rfloor \cdot i + (p \bmod i) \equiv 0 \pmod p$$

整理得

$$\lfloor p / i \rfloor \cdot i \equiv -(p \bmod i) \pmod p$$

两边乘 $i^{-1} \cdot (p \bmod i)^{-1}$：

$$\lfloor p / i \rfloor \cdot (p \bmod i)^{-1} \equiv -i^{-1} \pmod p$$

即

$$i^{-1} \equiv -\lfloor p / i \rfloor \cdot (p \bmod i)^{-1} \pmod p$$

代码实现：`inv[i] = (p - p / i) * inv[p % i] % p`（`p - p / i` 把负号 + 模数合并）。

**正确性的前提**：递推用到 $\mathtt{inv}[p \bmod i]$，由 $p \bmod i < i$，递推总是从更小的下标取值——拓扑顺序正确。

**初值**：$\mathtt{inv}[1] = 1$（因为 $1 \cdot 1 \equiv 1$）。

**对 $i$ 与 $p$ 互质的隐含要求**：递推过程中要求每个 $\mathtt{inv}[p \bmod i]$ 已存在。当 $p$ 是质数时 $\gcd(i, p) = 1$ 对所有 $1 \le i < p$ 都成立——所以质数模数下递推合法。$\blacksquare$

### 逆元存在的等价条件

**命题**：$a$ 在模 $p$ 下有逆元 $\Leftrightarrow$ $\gcd(a, p) = 1$。

**"$\Leftarrow$"**：由 Bezout 定理 $\exists x, y$ 使 $ax + py = 1$，所以 $ax \equiv 1 \pmod p$，$x$ 即逆元。

**"$\Rightarrow$"（反证）**：设 $a a^{-1} \equiv 1 \pmod p$ 但 $g = \gcd(a, p) > 1$。由 $g | a$ 和 $g | p$，$g | (a a^{-1} - 1 \cdot p \cdot ???)$ ... 更直接：$g | (a a^{-1})$ 且 $g | p$，但 $a a^{-1} - 1 \equiv 0 \pmod p$ 即 $p | (a a^{-1} - 1)$，所以 $g | (a a^{-1} - 1)$。结合 $g | a a^{-1}$ 得 $g | 1$，所以 $g = 1$，矛盾。$\blacksquare$

## 几个常见错误

- **滥用费马小定理**：忘记检查 $p$ 是否为质数。$p = 4$ 时 $a^{p-2} = a^2$ 显然不是逆元

- **`int` 溢出**：求逆过程中 `a * inv[p % i]` 可能爆 `int`，必须用 `long long`

- **负数模数处理**：`x % p` 在 C++ 中可能是负数，要 `(x % p + p) % p`

- **批量求逆元用了 $n$ 次费马**：$O(n \log p)$ 而非 $O(n)$，常数大且没必要

## 应用：批量求阶乘逆元的"O(n) 双递推"

求 $0!, 1!, \ldots, n!$ 的逆元——配合 [[组合数]] 预处理用。

**朴素**：每个 $\mathtt{inv\_fact}[i]$ 单独算 $O(\log p)$，总 $O(n \log p)$。

**优化**：利用 $\mathtt{inv\_fact}[i] = \mathtt{inv\_fact}[i + 1] \cdot (i + 1) \bmod p$（因为 $(i+1)! = (i+1) \cdot i!$，两边求逆得 $(i!)^{-1} = ((i+1)!)^{-1} \cdot (i+1)$）。

倒着递推——只需一次费马小定理求 $\mathtt{inv\_fact}[n]$，其余 $O(1)$ 推出。总 $O(n)$。

```cpp
vector<long long> fact(n + 1), inv_fact(n + 1);

fact[0] = 1;

for (int i = 1; i <= n; i++) {

    fact[i] = fact[i - 1] * i % p;

}

inv_fact[n] = pow_mod(fact[n], p - 2, p);

for (int i = n - 1; i >= 0; i--) {

    inv_fact[i] = inv_fact[i + 1] * (i + 1) % p;

}
```
