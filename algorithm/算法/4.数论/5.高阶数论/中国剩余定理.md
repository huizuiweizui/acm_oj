#难度/★★★★

> 同余方程组的"合并器"——若各模数两两互质，CRT 给出唯一解；模数不互质时用扩展 CRT 逐对合并。

## 前置知识

- [[乘法逆元]]

- [[GCD与LCM]]

## 核心思想

**问题**：求一个整数 $x$，同时满足若干同余方程

$$\begin{cases} x \equiv a_1 \pmod{m_1} \\ x \equiv a_2 \pmod{m_2} \\ \vdots \\ x \equiv a_n \pmod{m_n} \end{cases}$$

**中国剩余定理（CRT）**：当 $m_1, m_2, \ldots, m_n$ **两两互质**时，方程组在 $\bmod\, M = \prod m_i$ 意义下有**唯一**解。

**构造解**——记 $M_i = M / m_i$，$t_i \equiv M_i^{-1} \pmod{m_i}$（用 [[乘法逆元]] 求出），则

$$x \equiv \sum_{i=1}^{n} a_i M_i t_i \pmod M$$

**直觉**：每个 $a_i M_i t_i$ 在模 $m_i$ 下"贡献" $a_i$，在模 $m_j$（$j \ne i$）下贡献 $0$——它们互不干扰。

**扩展 CRT（exCRT）**：当 $m_i$ **不两两互质**时，逐对合并方程——

> 给定两个方程 $x \equiv a_1 \pmod{m_1}$、$x \equiv a_2 \pmod{m_2}$。设 $x = a_1 + k m_1$（满足第一个），代入第二个：$a_1 + k m_1 \equiv a_2 \pmod{m_2}$，即 $k m_1 \equiv a_2 - a_1 \pmod{m_2}$。这是关于 $k$ 的一次同余方程，用 exgcd 解。

合并后得到新方程 $x \equiv a' \pmod{\mathrm{lcm}(m_1, m_2)}$，再与第三个方程合并，依次进行。

**有解性**：合并 $(a_1, m_1)$ 和 $(a_2, m_2)$ 时，要求 $\gcd(m_1, m_2) \mid (a_2 - a_1)$——否则原方程组无解。

## 适用场景

- **求满足多个同余条件的整数**：经典模型如"韩信点兵"、模意义下的某些枚举问题

- **大模数分解**：$p = p_1 p_2 \cdots p_k$（互质因子）的同余问题，分别在每个 $p_i$ 下处理后用 CRT 合并

- **模意义下的拉格朗日插值**：在多个模数下求出值再 CRT 合并

- **算法竞赛中的"模数特殊"题目**：题目给非质数模数（如 $p = 9982\ldots$）时，可能要分解后 exCRT

- 不适用：方程组本身无解（如 $x \equiv 1 \pmod 2$ 与 $x \equiv 0 \pmod 4$ 矛盾）；模数过大无法存储 lcm

## 步骤拆解

**CRT（互质情形）**：

1. 计算 $M = \prod_{i=1}^{n} m_i$

2. 对每个 $i$ 计算 $M_i = M / m_i$ 和 $t_i \equiv M_i^{-1} \pmod{m_i}$（用 exgcd）

3. 答案 $x = \left(\sum_{i=1}^{n} a_i M_i t_i\right) \bmod M$

**扩展 CRT（一般情形，逐对合并）**：

1. 初始化 $\mathtt{ans} = a_1$，$M = m_1$

2. 对 $i$ 从 $2$ 到 $n$：

   a. 当前已知 $x \equiv \mathtt{ans} \pmod M$，新方程 $x \equiv a_i \pmod{m_i}$

   b. 设 $x = \mathtt{ans} + k M$，代入 $\Rightarrow k M \equiv a_i - \mathtt{ans} \pmod{m_i}$

   c. 用 exgcd 求 $g = \gcd(M, m_i)$ 与对应的 $k_0$

   d. 若 $g \nmid (a_i - \mathtt{ans})$ 则无解

   e. 否则 $k \equiv k_0 \cdot \frac{a_i - \mathtt{ans}}{g} \pmod{m_i / g}$

   f. 更新 $\mathtt{ans} \mathrel{+}= k M$，$M \mathrel{\cdot}= m_i / g$（即 $M = \mathrm{lcm}(M, m_i)$）

3. 最终 $\mathtt{ans} \bmod M$ 即解

## 代码模板

**模板一：CRT（要求 $m_i$ 两两互质）**

```cpp
class crt {

private:

    static long long exgcd(long long a, long long b, long long& x, long long& y) {

        if (b == 0) {

            x = 1;

            y = 0;

            return a;

        }

        long long g = exgcd(b, a % b, y, x);

        y -= (a / b) * x;

        return g;

    }

    static long long inv(long long a, long long p) {

        long long x, y;

        exgcd(a, p, x, y);

        return (x % p + p) % p;

    }

public:

    // 求满足 x ≡ a[i] (mod m[i]) 的 x，要求 m[i] 两两互质
    static long long solve(vector<long long>& a, vector<long long>& m) {

        int n = a.size();

        long long M = 1;

        for (long long v : m) {

            M *= v;

        }

        long long ans = 0;

        for (int i = 0; i < n; i++) {

            long long Mi = M / m[i];

            long long ti = inv(Mi, m[i]);

            ans = (ans + (__int128)a[i] * Mi % M * ti) % M;

        }

        return (ans + M) % M;

    }

};
```

> 💡 **为什么用 `__int128`**：当 $M$ 很大（如 $10^{18}$）时，$a_i \cdot M_i$ 可能溢出 `long long`。用 `__int128` 可以稳妥处理；竞赛中也可用 **龟速乘**（mulmod 通过加法迭代避免溢出）。

**模板二：扩展 CRT（不要求互质）**

```cpp
class excrt {

private:

    static long long exgcd(long long a, long long b, long long& x, long long& y) {

        if (b == 0) {

            x = 1;

            y = 0;

            return a;

        }

        long long g = exgcd(b, a % b, y, x);

        y -= (a / b) * x;

        return g;

    }

    static long long mulmod(long long a, long long b, long long m) {

        // 龟速乘：避免溢出
        long long res = 0;

        a %= m;

        if (a < 0) a += m;

        b %= m;

        if (b < 0) b += m;

        while (b > 0) {

            if (b & 1) res = (res + a) % m;

            a = (a + a) % m;

            b >>= 1;

        }

        return res;

    }

public:

    // 求满足 x ≡ a[i] (mod m[i]) 的 x；无解返回 -1
    static long long solve(vector<long long>& a, vector<long long>& m) {

        int n = a.size();

        long long ans = a[0];

        long long M = m[0];

  

        for (int i = 1; i < n; i++) {

            long long b = ((a[i] - ans) % m[i] + m[i]) % m[i];

            long long x, y;

            long long g = exgcd(M, m[i], x, y);

            if (b % g != 0) {

                return -1;                      // 无解

            }

            long long t = m[i] / g;

            x = mulmod(x, b / g, t);            // x = (x * (b/g)) mod t

            ans = ans + mulmod(M, x, M / g * m[i]);

            M = M / g * m[i];                   // lcm

            ans = (ans % M + M) % M;

        }

        return ans;

    }

};
```

> ⚠️ **`exgcd` 求出的 $x$ 可能很大**：要先 `mulmod(x, b/g, t)` 把它限制在 $[0, t)$ 内，否则后续 $\mathtt{ans} + Mx$ 可能爆 `long long`。

> ⚠️ **lcm 计算的次序**：`M / g * m[i]` 顺序不能换成 `M * m[i] / g`——前者先除后乘避免中间结果溢出。

## 复杂度分析

- CRT：$O(n \log \max(m_i))$（$n$ 次 exgcd）

- exCRT：$O(n \log \max(m_i))$（$n$ 次 exgcd + 龟速乘）

- 空间：$O(n)$

## 正确性证明

### CRT 的存在性

**命题**：当 $m_1, \ldots, m_n$ 两两互质时，构造的 $x = \sum a_i M_i t_i$ 满足所有方程。

**证明**：固定一个 $j$，验证 $x \equiv a_j \pmod{m_j}$。

考察求和中的每一项 $a_i M_i t_i$——

- **当 $i = j$**：$M_j = M / m_j$ 与 $m_j$ 互质（因为 $m_j$ 与其他 $m_i$ 互质）。$t_j$ 满足 $M_j t_j \equiv 1 \pmod{m_j}$。所以 $a_j M_j t_j \equiv a_j \pmod{m_j}$。

- **当 $i \ne j$**：$M_i = M / m_i$ 含因子 $m_j$（因为 $m_j$ 是 $M$ 的因子但不是 $m_i$ 的因子）。所以 $M_i \equiv 0 \pmod{m_j}$，进而 $a_i M_i t_i \equiv 0 \pmod{m_j}$。

求和得 $x \equiv a_j \pmod{m_j}$。$\blacksquare$

### CRT 的唯一性

**命题**：在 $\bmod\, M$ 意义下，方程组的解唯一。

**证明（反证）**：假设存在两个解 $x_1, x_2 \in [0, M)$ 都满足方程组。

对每个 $i$，$x_1 \equiv x_2 \equiv a_i \pmod{m_i}$，所以 $m_i \mid (x_1 - x_2)$。

由 $m_i$ 两两互质，$\mathrm{lcm}(m_1, \ldots, m_n) = M$ 也整除 $x_1 - x_2$。所以 $M \mid (x_1 - x_2)$。

而 $x_1, x_2 \in [0, M)$ 蕴含 $|x_1 - x_2| < M$。结合 $M \mid (x_1 - x_2)$ 必有 $x_1 = x_2$。$\blacksquare$

### 扩展 CRT 的合并

**命题**：考虑两个方程 $x \equiv a_1 \pmod{m_1}$ 与 $x \equiv a_2 \pmod{m_2}$。设 $g = \gcd(m_1, m_2)$，$L = \mathrm{lcm}(m_1, m_2)$。

  

- 若 $g \nmid (a_2 - a_1)$：无解

- 否则有唯一解 $x \equiv a' \pmod L$，其中 $a' = a_1 + k m_1$，$k$ 满足 $k m_1 \equiv a_2 - a_1 \pmod{m_2}$

**证明**：设 $x = a_1 + k m_1$（满足第一方程）。代入第二方程：

  

$$a_1 + k m_1 \equiv a_2 \pmod{m_2} \;\Longleftrightarrow\; k m_1 \equiv a_2 - a_1 \pmod{m_2}$$

这是关于 $k$ 的一次同余方程。由 [[乘法逆元]] 中证明的结论：

$k m_1 \equiv c \pmod{m_2}$ 有解 $\Leftrightarrow$ $\gcd(m_1, m_2) \mid c$。所以——

- $g \nmid (a_2 - a_1) \Rightarrow$ 无解

- 否则存在 $k$，且解集为 $k \equiv k_0 \pmod{m_2 / g}$（$k_0$ 是某个特解）

对应 $x = a_1 + k m_1$——其中 $k$ 模 $m_2 / g$，所以 $x$ 模 $m_1 \cdot (m_2 / g) = m_1 m_2 / g = \mathrm{lcm}(m_1, m_2) = L$。$\blacksquare$

**归纳合并的正确性**：每次合并把两个方程并为一个等价方程——所以 $n$ 次合并后得到的单一方程等价于原方程组。$\blacksquare$

### 用 exgcd 求一次同余方程

**回顾**：exgcd 求 $a x + b y = \gcd(a, b)$ 的解 $(x_0, y_0)$。

对方程 $a x \equiv c \pmod b$（其中 $g = \gcd(a, b) \mid c$）：

$$a \cdot (x_0 \cdot c / g) \equiv g \cdot (c / g) = c \pmod b$$

所以 $x = x_0 \cdot (c / g) \bmod (b / g)$ 是一个解，且解集为 $\{x + k \cdot b / g : k \in \mathbb Z\}$。

代码中：

```cpp

long long g = exgcd(M, m[i], x, y);     // M*x + m[i]*y = g

x = mulmod(x, b / g, t);                 // 把 x 缩到 [0, t = m[i]/g) 范围

```

正是这个公式的实现。$\blacksquare$

## 几个常见错误

- **CRT 误用于不互质的 $m_i$**：必须改用 exCRT，不要硬套 CRT

- **`long long` 溢出**：$M$ 接近 $10^{18}$ 时各种乘法都易溢出；坚持用 `__int128` 或龟速乘

- **`exgcd` 求出的 $x$ 没规整**：直接用作系数会出错。用 `(x % t + t) % t` 或 `mulmod` 规整到 $[0, t)$

- **lcm 计算顺序**：`M / g * m[i]` 而非 `M * m[i] / g`——避免中间溢出

## 与相关算法的联系

- **[[乘法逆元]]**：CRT 中用逆元求 $t_i$；exCRT 中用 exgcd 解一次同余方程

- **[[模运算]]** / **[[GCD与LCM]]**：基础工具

- **算法竞赛的"奇怪模数"**：当 $p$ 是合数（如 $p = 9 \times 10^{18}$ 这种），分解 $p = p_1 p_2 \cdots$ 后分别处理再 CRT 合并是常用套路
