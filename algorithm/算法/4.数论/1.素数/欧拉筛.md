#难度/★★

  > 在 $O(n)$ 时间内筛出 $[1, n]$ 内所有素数，每个合数仅被它最小的质因子筛掉一次。

## 前置知识

- [[埃氏筛]]

## 核心思想

[[埃氏筛]] 的瓶颈在于：一个合数会被它的**多个**质因子重复标记。例如 $12 = 2 \times 6 = 3 \times 4$，会被 $2$ 和 $3$ 同时筛掉。

**欧拉筛的关键**：保证每个合数**只被其最小质因子筛掉一次**。具体做法是——枚举每个数 $i$，再枚举已经发现的质数 $p$，用 $i \cdot p$ 标记合数；但当 $p \mid i$ 时立即 `break`，因为继续往下乘时 $p$ 不再是 $i \cdot p_\text{next}$ 的最小质因子。

这个 `break` 是欧拉筛的灵魂。

## 适用场景

- 需要预处理大范围（$n \le 10^7 \sim 10^8$）内所有素数

- 顺便需要每个数的**最小质因子**（线性筛在筛的过程中天然得到）

- 求积性函数（欧拉函数 $\varphi$、莫比乌斯函数 $\mu$、约数个数等）—— 线性筛可以在 $O(n)$ 内同时算出

- 当 $n$ 较小时（如 $n \le 10^6$），埃氏筛已经够用且常数更小

## 步骤拆解

1. 维护 `is_prime[]`（标记数组）和 `prime[]`（已发现的质数列表）

2. 从 $i = 2$ 枚举到 $n$：

   - 若 `is_prime[i]` 为真，把 $i$ 加入 `prime[]`

   - 枚举所有已发现的质数 `prime[j]`，标记 `is_prime[i * prime[j]] = false`

   - **关键**：若 `i % prime[j] == 0`，立即 `break`

3. 整个过程结束后，`prime[]` 即为所有素数

## 代码模板

```cpp

const int n = 1e7 + 5;

vector<bool> is_prime(n + 1, true);

vector<int> prime(n + 1)

int cnt = 1;

is_prime[1] = false;

void linear_sieve(int n) {

    for (int i = 2; i <= n; i++) {

        if (is_prime[i]) {
        
	        prime[cnt] = i;
	        
	        cnt += 1;
        
        }

        for (int j = 1; j <= cnt && (long long) i * prime[j] <= n; j++) {

            is_prime[i * prime[j]] = false;

            if (i % prime[j] == 0) {
            
	            break;   // 灵魂之笔
	            
            }

        }

    }

}

```

> 💡 想顺便记录每个数的最小质因子？把 `is_prime[i * prime[j]] = false;` 改成 `min_prime[i * prime[j]] = prime[j];` 即可。

## 复杂度分析

- 时间复杂度：$O(n)$

- 空间复杂度：$O(n)$

## 正确性证明

**唯一性**：要证每个合数 $x$ 只被它的最小质因子 $p$ 筛一次。

设合数 $x$ 的最小质因子为 $p$，记 $i = x / p$。注意此时 $p \le$ $i$ 的最小质因子（否则与 $p$ 是 $x$ 最小质因子矛盾）。

筛 $x$ 时的过程：枚举到 $i$，再枚举质数 $p$ 时筛掉 $x = i \cdot p$。

**为什么 `break` 是对的**：若 `i % prime[j] == 0`，说明 `prime[j]` 是 $i$ 的某个质因子，且因为 `prime[]` 是从小到大遍历，`prime[j]` 就是 $i$ 的最小质因子。此时再考虑 $i \cdot \text{prime}[j+1]$，它的最小质因子是 `prime[j]`（不是 `prime[j+1]`），所以应当由后续的 $i' = i \cdot \text{prime}[j+1] / \text{prime}[j]$ 配合 `prime[j]` 来筛掉，而不是现在。

**完整性**：每个合数 $x$ 都会被筛到。设 $x$ 的最小质因子为 $p$，$i = x/p$，那么 `i % p` 要么不为 0（说明 $p$ 不是 $i$ 的因子，循环还会继续到 $p$），要么为 0 但此时正好 $p$ 是要筛的质数，依然会执行筛除再 break。$\blacksquare$
