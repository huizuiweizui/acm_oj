#难度/★★

> 用 $O(n \log \log n)$ 时间筛出 $[1, n]$ 内的所有素数：通过每个素数来标记所有合数。

## 核心思想

**埃氏筛的核心观察**：从 $2$ 开始，遇到一个**未被标记**的数 $i$，它必然是素数（否则会有更小的因子先把它标记掉）；然后把 $i$ 的所有倍数 $2i, 3i, 4i, \ldots$ 都标记为合数。

朴素埃氏筛会重复标记一些数，但已经比朴素法快得多。其总时间复杂度由调和级数给出：$\sum_{p \le n,\, p \text{ 素}} \dfrac{n}{p} = O(n \log \log n)$。

## 适用场景

- 需要预处理小到中等范围的素数（$n \le 10^7$）

- 当 $n$ 很大（$n \ge 10^8$）或需要每个数的最小质因子时，应使用 [[欧拉筛]]

## 步骤拆解

1. 初始化 `is_prime[2..n]` 为 `true`

2. 从 $i = 2$ 枚举到 $n$：

   - 若 `is_prime[i]` 为真，则 $i$ 是素数

   - 把 $i$ 的所有倍数标记为合数：从 $j = i \cdot i$ 开始（更小的倍数已被更小的素因子标记过），步长为 $i$

3. 所有 `is_prime[i]` 为 `true` 的 $i$ 即为素数

## 代码模板

```cpp

const int n = 1e7 + 5;

vector<bool> is_prime(n + 1, true);

vector<int> prime(n + 1)

int cnt = 1;

is_prime[1] = false;

void eratosthenes_sieve(int n) {

    for (int i = 2; i <= n; i++) {

        if (is_prime[i]) {

            prime[cnt] = i;
            
            cnt += 1;

            // 从 i*i 开始（小于 i*i 的合数 i*k (k<i) 已被 k 的某个小素因子标记）

            for (long long j = (long long) i * i; j <= n; j += i) {

                is_prime[j] = false;

            }

        }

    }

}

```


## 复杂度分析

- 时间复杂度：$O(n \log \log n)$

- 空间复杂度：$O(n)$

## 正确性证明

**结论**：算法结束后，`is_prime[i] == true` 当且仅当 $i$ 是素数。

**反向**（若 $i$ 是合数则会被标记为 `false`）：设 $i$ 是合数，最小质因子为 $p$，则 $p \le \sqrt i$，且 $i / p \ge p$。当 $j = p$ 的循环中，会枚举到倍数 $i = p \cdot (i/p)$，且 $i \ge p^2 = p \cdot p$，因此从 $p \cdot p$ 起步的循环会标记到 $i$。

**正向**（若 $i$ 是素数则不会被标记）：素数没有除 $1$ 和自身外的因子，所以不会有 `j < i` 的素数 $j$ 满足 $j \mid i$，自然不会被任何外层循环标记。$\blacksquare$
