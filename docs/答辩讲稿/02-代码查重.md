## 一、答辩讲稿（口播，约 3–4 分钟）

> "第一个创新点是**代码查重**。
>
> **先说为什么需要它、为什么难。** 作业和考试开放后，学生抄代码是必然的。但抄袭者很'聪明'——他只要把变量 `sum` 改成 `total`、把 `i` 改成 `k`，再调一下缩进、加几行注释，**文本就完全不一样了**。所以最朴素的'逐字符比对'毫无用处。我需要一种**对改名、重排版、改注释都鲁棒**的相似度度量。
>
> **我用的是 Winnowing 指纹算法**，它也是斯坦福著名查重系统 MOSS 的核心。整个过程四步：
>
> **第一步，词法归一化。** 我把源代码切成一个个 token，然后做抽象——所有变量名、函数名统一变成符号 `I`，数字变成 `N`，字符串变成 `S`，运算符和标点原样保留，注释直接丢掉。这一步是关键：**改名之后，token 串完全不变**，因为名字都被抹成 `I` 了。剩下的运算符骨架和 I/N/S 的排布，刻画的是程序的**结构**。
>
> **第二步，取 k-gram 并哈希。** 我把 token 串里每相邻 5 个 token 取出来作为一个片段，对每个片段算一个哈希值，得到一串哈希。
>
> **第三步，Winnowing 取指纹。** 我在这串哈希上滑一个长度为 4 的窗口，每个窗口里取**最小的那个哈希**作为指纹。这样得到一个稀疏的指纹集合。它有个**理论保证**：只要两份代码有长度不小于 8 个 token 的相同片段，就一定会共享至少一个指纹——不会漏检。
>
> **第四步，算相似度。** 两份代码的指纹集合，我用**重叠系数**（交集除以较小集合大小）作为主指标，Jaccard 系数作对照。
>
> **效果我做了实验。** 同一段求和代码：纯改名得 1.0（因为 token 串没变）；改名+重排版+加注释+调声明顺序这种中等抄袭得 0.526；而完全不同算法的代码只有 0.263。也就是说**抄袭样本是无关代码的大约两倍**，用 0.5 做阈值能干净地分开。
>
> 最后**我也如实说局限**：这种 token 级方法**无法检测跨语言抄袭**，而且当前把关键字也归一成了 I、损失了一点判别力——这些我在论文里都写了，也给了改进方向。"

## 二、原理拆解（你自己要更明白一层）

- **为什么归一化能抗改名**：判别力来自"结构"而非"名字"。把名字抹掉后，剩下的运算符/标点 + I/N/S 排布就是结构指纹。
- **为什么取最小哈希（Winnowing）而不是全要**：全 k-gram 指纹量大、噪声多；Winnowing 用窗口最小值**稀疏采样**，少而不漏（有 $t=w+k-1$ 的检出保证）。
- **为什么用重叠系数**：抄袭常是"抄一段再扩写"，被抄的那份是子集——重叠系数（除以较小集合）对"子集被包含"更敏感，趋近 1。
- **函数题的特殊处理**：函数题提交存的是"公共驱动+学生函数"，若整段比对会被公共样板污染、误报。所以学生原始函数单存 `raw_code`，查重只比它。

## 📚 这里你需要懂的（被追问也不慌）

- **什么是 token / 词法分析**：把代码切成"标识符、数字、运算符"这些最小单元。
- **什么是 k-gram**：相邻 k 个单元组成的片段（自然语言里也叫 n-gram）。
- **哈希是干嘛的**：把任意片段映射成一个整数，方便比较和取最小值。
- **集合相似度**：Jaccard = 交/并；重叠系数 = 交/较小集合。你要能说清两者区别、为什么主用重叠系数。
- **Winnowing 的检出保证**：长度 ≥ w+k-1 的相同片段必被捕获——这是它比"随机取指纹"强的地方。
- **归一化为什么抗改名**（最常被问，必须能用一句话讲清）。

## 🎓 需要补学的知识（不熟就去补这些）

- **哈希函数基础**：什么是多项式哈希、为什么取大素数模降碰撞。（任意《算法》教材的字符串哈希章节）
- **字符串相似度 / 集合相似度**：Jaccard、重叠系数、（进阶）MinHash。
- **Winnowing 原论文**：Schleimer, Wilkerson, Aiken (2003) *Winnowing: Local Algorithms for Document Fingerprinting*——**至少读懂摘要和那个检出保证定理**，答辩引用一篇经典文献很加分。
- **MOSS / JPlag 是什么**：知道业界两大查重系统、各自思路（MOSS=Winnowing 指纹，JPlag=token 序列贪心匹配 GST），能做对比。
- **（进阶，可选）滚动哈希、LSH/局部敏感哈希**：用于把 O(n²) 两两比对降到近线性，可作为论文"未来工作"。
- **ROC 曲线 / 准确率-召回率**：如果你要在论文里做查重效果实验，需要会画。

## 五、评委可能这样问 + 怎么答

**Q：为什么用 Winnowing，不用编辑距离或最长公共子序列（LCS）？**
> A：编辑距离/LCS 是 O(n²)，对大量提交两两比对太慢；而且它们是字符级的，对"插入无关代码"很敏感、对"改名"几乎无抵抗。Winnowing 在归一化后做指纹，既抗改名又稀疏高效，还有漏检的理论保证。

**Q：k=5、w=4 是怎么定的？**
> A：这是 Winnowing 文献里的常见经验值，对应检出保证是"≥8 个 token 的雷同必被抓"。k 太小噪声多、太大易被局部修改打断。论文里我可以补一个参数消融实验（k、w 取不同值看准确率/召回率），把它定量化。

**Q：学生能不能绕过你的查重？**
> A：纯改名、重排版、改注释绕不过（我实验验证了，得分接近 1）。但如果**大幅重构逻辑、换算法**，相似度会显著下降——不过那时学生其实已经"重写"了，某种程度上达到了练习目的。我也诚实地把"跨语言抄袭检测不了"列为局限。

**Q：重叠系数和 Jaccard 有什么区别，为什么主用前者？**
> A：Jaccard 是交并比、对称；重叠系数是交除以较小集合。抄袭常是"抄一段再加东西"，被抄方是子集，重叠系数对这种包含关系更敏感，所以主用它，Jaccard 作对照防止把"短代码碰巧重叠"误判。

**Q：复杂度多少？大规模行不行？**
> A：单份代码指纹是线性的；一道题 m 个学生两两比对是 O(m²)。一个班完全够用。全校规模可以用 MinHash + LSH 做近似把两两比对降到近线性——这是我的未来工作。

**Q：为什么 Python 的注释处理要特殊？**
> A：`//` 在 C/C++/Java 是行注释，但在 Python 里是整除运算符。我按语言构造不同的词法规则，否则会把 Python 的 `a // b` 之后整行误删——这是我实现时专门处理的一个坑。
