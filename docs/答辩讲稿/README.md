## 答辩前必背清单（背不下来就先背这些）

**整体（00）**

- 一句话定位：竞赛 OJ → 全校考试平台 + 三个算法创新点。
- 三创新点各解决什么：查重防抄、Rating 量化实力、学习路径个性化导航。

**查重（02）**

- 四步：词法归一化 → k-gram → Winnowing 取最小哈希 → 重叠系数。
- **归一化为什么抗改名**：变量名都抹成 `I`，token 串不变。
- 检出保证：≥ w+k-1 = 8 个 token 的雷同必被抓。
- 实测：抄袭 0.526 vs 无关 0.263。

**Rating（03）**

- Elo 胜率公式：`P=1/(1+10^((Rb−Ra)/400))`。
- seed = 1 + Σ 别人胜我的概率，**排除自身**（最易被问）。
- 几何平均 + 二分反解 + 取半步 + 零和校正。
- 实测：+112/+19/−39/−94，单调、近似零和、幂等。

**学习路径（04）**

- 前置依赖 = DAG；**后序 DFS = 合法学习顺序**（前置一定在前）。
- 掌握度 = 关联题通过率 ≥ 0.5；标签启发式（并诚实说局限）。

**工程（07）**

- 分层：接口层 + 纯算法服务层（可独立测试/实验）。
- 加表不改表；回滚式端到端测试（事务 + 末尾回滚，不污染数据）。

**后端 / 评测（08）**

- 评测七态怎么来：AC/WA 比对输出、TLE 超时、MLE 退出码 137、RE 非零、CE 编译失败、NT 无测试点。
- 沙箱隔离：断网 + 内存/CPU 上限 + 限进程数 + 只读挂载 + 跑完即焚。
- 扛并发：提交入队立即返回，Worker 并发数 = 同时最多几个评测的硬闸门；重启不丢任务、可分机扩容。

## 三个"诚实牌"（主动说局限 = 加分，别藏）

1. 查重：**跨语言抄袭检测不了**（token 级方法固有局限）。
2. 防作弊：切屏检测是**行为审计、前端可绕过**，非强保证。
3. 整体：完成了**后端测试 + 前端构建**，**尚未浏览器实跑 / 压测**。

> 评委最爱问"局限在哪""未来怎么改进"。每篇结尾的局限和未来工作就是用来答这个的——主动讲，比被追出来强。
