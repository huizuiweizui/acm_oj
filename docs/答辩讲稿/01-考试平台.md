# 答辩讲稿 01 · 考试 / 作业平台（地基）

> 对应 M1–M4。这块是"把竞赛 OJ 变成全校考试平台"的主体工程，体现系统设计能力。配套技术文档：`docs/01-考试平台设计.md`。

---

## 一、答辩讲稿（口播，约 3–4 分钟）

> "这一块是平台的**考试地基**，也就是把竞赛 OJ 改造成全校能用的考试系统，主要解决四件事。
>
> **第一，多种题型。** 竞赛 OJ 只有编程题，但期末机考一半是选择、判断、填空。所以我新建了一个**客观题题库**，用 JSON 字段灵活承载四种题型的选项和答案，并实现了**自动判分**——选择/判断走集合比较，填空支持每个空配多个可接受写法、可忽略大小写。
>
> **第二，函数题。** 这是 PTA 很典型的题型：学生只写一个函数，不写主程序。难点在于怎么评测一个不完整的程序。我的做法是——**不改动评测核心**，而是在学生提交时，把题目预设的'隐藏驱动代码'和学生的函数**拼接成一个完整程序**，再喂给原有的评测器。同时我做了一个细节设计：学生的原始函数单独存一个字段，这样**查重时只比学生写的部分**，不会被公共驱动代码污染。
>
> **第三，考试模式。** 我把原来的'作业'进化成一个**三态容器**——练习、作业、考试，参照 PTA 的'题目集'。考试态有几个关键设计：**不泄题**，下发给学生的试卷里客观题是没有标准答案的；**考试中不揭晓对错**，交卷后才公布；**限时**，用服务器时间做客户端时钟校准、到点自动交卷；**题序按学生 ID 稳定打乱**，同一个学生每次刷新顺序一致、但不同学生不同，防抄邻座；还有**切屏监测**，记录学生切走窗口的次数。这里我要诚实说明：切屏检测是**行为审计**，前端能被绕过，不是强制手段——这点我论文里写清楚了。
>
> **第四，成绩管理。** 编程题不再是'过了满分、不过零分'，而是**按测试点通过率给部分分**。教师看的全班**成绩单**我特别做了性能优化——不管班级多大，**固定三次数据库查询**就能算完所有人的总分，避免了'每个学生查一次'的性能陷阱。成绩单还能导出 Excel。"

## 二、原理拆解

- **客观题为什么用 JSON 字段**：四种题型的选项/答案结构差异大，用 JSON 一个字段灵活承载，不用为每种题型建表。
- **函数题的"拼接"为什么巧妙**：它把"特殊评测"问题转化成"提交前的代码预处理"，从而完全复用现有评测器——零风险。
- **为什么试卷要剥答案**：安全。前端拿到的任何数据用户都能看，所以标准答案绝不能下发到前端。
- **稳定打乱怎么做到"同人一致、异人不同"**：用 `md5(用户ID + 题目ID)` 排序——同一用户对同一题哈希固定，所以顺序稳定；不同用户哈希不同，所以顺序不同。
- **成绩单为什么能 3 次查询**：把"每人一查"改成"按用户分组的聚合查询 + Python 内合并"，这是解决 N+1 查询的标准手法。

## 📚 这里你需要懂的

- **RESTful API / 前后端怎么通信**：前端发请求、后端返 JSON。
- **客观题四种题型的判分逻辑**（尤其多选为什么"集合相等"、填空怎么处理多写法）。

- **"不泄题"为什么重要**：前端数据用户可见，标准答案必须留在后端。
- **部分分怎么算**：测试点通过率 × 分值。
- **N+1 查询是什么、为什么要避免**（成绩单优化的卖点）。

## 五、评委可能这样问 + 怎么答

**Q：函数题你是怎么评测一个不完整的程序的？**
> A：我没有改评测器。学生提交函数体后，后端把题目预设的隐藏驱动（含 main 和测试逻辑）和学生函数拼成完整程序，再交给原有评测器编译运行。这样函数题完全复用了已有评测流程，零改动、零风险。

**Q：你的防作弊（切屏检测）能被绕过吗？**
> A：能。切屏检测是前端通过浏览器事件上报的**行为审计**，技术上可以绕过，所以我把它定位成"威慑和留痕"而非"强制保证"，论文里如实写明。真正的强约束需要专用客户端或锁屏考试环境，超出本项目范围。

**Q：考试时怎么防止学生看到答案？**
> A：标准答案只存在后端，下发给前端的试卷数据里客观题**不含答案字段**；考试进行中提交也只返回"已保存"，对错和解析要等交卷后才返回。这样前端任何时候都拿不到答案。

**Q：成绩单那个"3 次查询"具体怎么做的？**
> A：我没有对每个学生分别查分，而是用三次批量查询——一次取成员、一次按用户分组聚合客观题得分、一次取编程提交，然后在内存里合并算每个人的总分。所以查询数和班级人数无关，避免了 N+1。

**Q：编程题部分分怎么来的？**
> A：评测器本来就会记录每个测试点过没过。我取学生对该题所有提交里"通过测试点比例"的最大值，乘以题目分值，就是部分分。这样写对一半也能拿一半分，比"全或无"更合理。
