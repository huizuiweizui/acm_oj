# 工程架构与测试方法

> 讲清楚这一大批功能在工程上「怎么组织、怎么验证、怎么保证不出乱子」。论文的「系统设计」与「测试」章节可取材于此。

---

## 1. 总体架构

```
浏览器 Vue 3 SPA  ──/api/* (axios + JWT 拦截器)──▶  Django REST API
                                                        │
                          ┌─────────────────────────────┤
                          ▼                             ▼
                  judge/services/（服务层）       judge/models.py（模型）
                   similarity.py 查重              加表不改表
                   rating.py     评分              迁移 0014→0024
                   judger.py     评测核心（不动）
                   sandbox.py    执行隔离
```

分层原则：**视图（API）只做权限+序列化+编排，算法/业务下沉到 `services/`**。这样 `similarity.py`、`rating.py` 都是纯函数模块，不依赖 Django 请求，可独立单测、可复现实验（对论文很重要）。

## 4. 测试方法：回滚式端到端验证

### 为什么不用 Django TestCase

本机数据库是真实 **MySQL**，没有独立测试库；且很多逻辑要走完整的「视图 → 权限 → 序列化」链路。

### 做法

用「**事务包裹 + 末尾抛异常回滚**」+ DRF `APIRequestFactory` 真实调用视图：

```python
class Rollback(Exception): pass
try:
    with transaction.atomic():
        # 1. 造数据（用户/团队/题目/提交…）
        # 2. APIRequestFactory + force_authenticate 真实调用视图
        req = factory.post(path, data, format="json")
        force_authenticate(req, user=teacher)
        resp = SomeAPIView.as_view()(req, **url_kwargs)
        # 3. 断言 resp.data
        raise Rollback()            # 末尾回滚，数据库零污染
except Rollback:
    pass
```

纯算法模块（`similarity.py`）甚至不需要 Django——用 `importlib` 直接加载文件单测。

### 覆盖情况

每个里程碑都有对应测试且全过，例如：

| 里程碑 | 验证点 |
|--------|--------|
| M1 客观题 | 四题型判分 10 用例（多选顺序无关、填空大小写） |
| M3 考试流 | 进入→答题→中途拉卷（确认不泄答案）→交卷→揭晓 |
| M5 查重 | 抄袭 0.526 vs 无关 0.263（区分度 ~2×） |
| M6 Rating | 4 人单调 + 近似零和 + 幂等 |
| M8 IOI | 双人总分 150/125 排名 + 封榜隐藏 |

## 5. 前端架构

### 设计系统复用

无第三方 UI 库，全手写。新页面严格沿用既有约定：

- `<script setup>` + Composition API
- scoped CSS + **CSS 变量**（`--accent` / `--bg-card` / `--border` / `--text-*`）——天然支持已有的暗/亮主题
- `.modal-overlay` / `.form-input` / `.btn-primary` 等类名约定
- `flash()` toast、`@/api/*` 命名导出

### 考试前端 4 切片

| 切片 | 页面 | 难点 |
|------|------|------|
| ① | `QuestionBankView` 题库 | 类型感知出题表单（选项下标管理、key 自动 A/B/C） |
| ② | `TeamDetailView` 组卷（扩展弹窗） | 三态 + 考试配置 + 编程/客观题各带分值，向后兼容 |
| ③ | `ExamView` 学生答题 | 倒计时（服务器时钟校准）/ 自动保存 / 切屏监测 / 交卷 |
| ④ | `GradebookView` + `PlagiarismView` | 成绩单 + 查重报告（相似度条 + 并排代码） |

另有题单两页、学习路径节、题解 Tab、每日一题卡片、Rating 曲线等。

### ⚠️ 顺手修的构建坑

`npm run build` 因 monaco worker 打包要求**单独安装 esbuild** 而失败（`Cannot find package 'esbuild'`，预先存在、与新代码无关）。`npm i -D esbuild` 修复。

期间用 `vue/compiler-sfc` 的 `parse / compileScript / compileTemplate` 做**单文件快验**，绕开整链构建——这招在前端构建坏掉时仍能确认某个 `.vue` 能否编译。
